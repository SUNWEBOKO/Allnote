## 2 全书主线

前四章是概率论：从随机事件与概率出发，用随机变量描述试验结果，再推广到多维随机变量，最后用期望、方差、协方差等数字特征概括分布。

第五章和第六章是连接段。大数定律说明样本均值为什么稳定在总体均值附近，中心极限定理说明标准化后的和为什么近似正态；第六章给出统计量的精确分布，为推断提供概率基础。

第七章和第八章是数理统计：参数估计用样本推断未知参数，假设检验用样本判断关于参数的命题。两者共用同一套枢轴量，把枢轴量反解成参数范围就是置信区间，把参数临界值代入就是拒绝域。

## 3 统一记号与约定

| 记号 | 含义 |
| --- | --- |
| $\Omega$ | 样本空间 |
| $P(A)$ | 事件 $A$ 的概率 |
| $F_X(x)$ | 分布函数 $P(X\le x)$ |
| $p_k$ | 离散型分布律 $P(X=x_k)$ |
| $f_X(x)$ | 连续型概率密度 |
| $E(X)$ | 数学期望 |
| $D(X)$ | 方差，与 $\operatorname{Var}(X)$ 同义 |
| $\sigma_X$ | 标准差 $\sqrt{D(X)}$ |
| $\operatorname{Cov}(X,Y)$ | 协方差 |
| $\rho_{XY}$ | 相关系数 |
| $E(X\mid Y)$ | 条件期望 |
| $\overline X$ | 样本均值，观测值写作 $\overline x$ |
| $S^2$ | 样本方差，分母为 $n-1$ |
| $\mu,\sigma^2$ | 总体均值与总体方差 |

约定：

- $N(\mu,\sigma^2)$ 的第二个参数是方差，标准化时除以标准差 $\sigma$。
- 指数分布采用率参数 $E(\lambda)$，密度为 $\lambda e^{-\lambda x}$，均值为 $\frac1\lambda$。
- 分位点统一采用上侧约定：$Z_\alpha$ 满足 $P(Z>Z_\alpha)=\alpha$。下标越小，分位点越大。
- 样本方差 $S^2$ 的分母为 $n-1$，使 $E(S^2)=\sigma^2$；最大似然估计的方差分母为 $n$，两者不要混用。
- 假设检验中双侧写 $H_0:\mu=\mu_0$，单侧把待判断的方向放在 $H_1$，$H_0$ 取含边界的不等式；拒绝域在边界 $\mu=\mu_0$ 处计算。

## 4 常用分布

### 4.1 离散型

| 分布 | 分布律 | $E(X)$ | $D(X)$ |
| --- | --- | ---: | ---: |
| $B(1,p)$ | $p^k(1-p)^{1-k}$，$k=0,1$ | $p$ | $p(1-p)$ |
| $B(n,p)$ | $\binom nkp^k(1-p)^{n-k}$ | $np$ | $np(1-p)$ |
| $P(\lambda)$ | $e^{-\lambda}\dfrac{\lambda^k}{k!}$ | $\lambda$ | $\lambda$ |
| 几何分布 | $(1-p)^{k-1}p$，$k=1,2,\ldots$ | $\dfrac1p$ | $\dfrac{1-p}{p^2}$ |
| 超几何分布 | $\dfrac{\binom Mk\binom{N-M}{n-k}}{\binom Nn}$ | $n\dfrac MN$ | $n\dfrac MN\left(1-\dfrac MN\right)\dfrac{N-n}{N-1}$ |

### 4.2 连续型

| 分布 | 密度 | $E(X)$ | $D(X)$ |
| --- | --- | ---: | ---: |
| $U(a,b)$ | $\dfrac1{b-a}$，$a<x<b$ | $\dfrac{a+b}{2}$ | $\dfrac{(b-a)^2}{12}$ |
| $E(\lambda)$ | $\lambda e^{-\lambda x}$，$x>0$ | $\dfrac1\lambda$ | $\dfrac1{\lambda^2}$ |
| $N(\mu,\sigma^2)$ | $\dfrac1{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$ | $\sigma^2$ |

### 4.3 三大抽样分布

| 分布 | 构造 | 主要用途 |
| --- | --- | --- |
| $\chi^2(\nu)$ | $\nu$ 个独立标准正态变量的平方和 | 正态总体方差的推断 |
| $t(\nu)$ | $Z/\sqrt{V/\nu}$，$Z\sim N(0,1)$ 与 $V\sim\chi^2(\nu)$ 独立 | $\sigma$ 未知时正态均值的推断 |
| $F(m,n)$ | $\dfrac{U/m}{V/n}$，$U\sim\chi^2(m)$ 与 $V\sim\chi^2(n)$ 独立 | 两个正态总体方差比的推断 |

## 5 常用分位点

上侧分位点的常用数值：

| 分位点 | 数值 | 分位点 | 数值 |
| --- | ---: | --- | ---: |
| $z_{0.05}$ | $1.6449$ | $z_{0.025}$ | $1.9600$ |
| $z_{0.01}$ | $2.3263$ | $z_{0.005}$ | $2.5758$ |
| $t_{0.025}(15)$ | $2.1314$ | $t_{0.05}(10)$ | $1.8125$ |
| $\chi^2_{0.025}(19)$ | $32.8523$ | $\chi^2_{0.975}(19)$ | $8.9065$ |
| $F_{0.025}(9,9)$ | $4.0260$ | $F_{0.975}(9,9)$ | $0.2484$ |

正态与 $t$ 分布关于 $0$ 对称，故 $z_{1-\alpha}=-z_\alpha$、$t_{1-\alpha}(\nu)=-t_\alpha(\nu)$；$F$ 分布满足 $F_\alpha(m,n)=1/F_{1-\alpha}(n,m)$；卡方分布不对称，上下分位点需分别查表。

## 6 公式速查

### 6.1 概率论

| 主题 | 公式 |
| --- | --- |
| 加法公式 | $P(A\cup B)=P(A)+P(B)-P(A\cap B)$ |
| 条件概率 | $P(B\mid A)=\dfrac{P(A\cap B)}{P(A)}$ |
| 乘法公式 | $P(A\cap B)=P(A)P(B\mid A)$ |
| 全概率公式 | $P(B)=\sum_iP(A_i)P(B\mid A_i)$ |
| 贝叶斯公式 | $P(A_k\mid B)=\dfrac{P(A_k)P(B\mid A_k)}{\sum_iP(A_i)P(B\mid A_i)}$ |
| 二项概率 | $P(X=k)=\binom nkp^k(1-p)^{n-k}$ |
| 正态标准化 | $Z=\dfrac{X-\mu}{\sigma}\sim N(0,1)$ |
| 方差 | $D(X)=E(X^2)-[E(X)]^2$ |
| 和的方差 | $D(X+Y)=D(X)+D(Y)+2\operatorname{Cov}(X,Y)$ |
| 相关系数 | $\rho_{XY}=\dfrac{\operatorname{Cov}(X,Y)}{\sigma_X\sigma_Y}$ |
| 全期望公式 | $E(X)=E\bigl[E(X\mid Y)\bigr]$ |
| 卷积公式 | $f_Z(z)=\int f_X(x)f_Y(z-x)\,dx$（独立） |
| 切比雪夫不等式 | $P(\lvert X-E(X)\rvert\ge\varepsilon)\le\dfrac{D(X)}{\varepsilon^2}$ |
| 中心极限定理 | $\dfrac{\overline X-\mu}{\sigma/\sqrt n}\approx N(0,1)$（$n$ 较大） |
| 二项正态近似 | $B(n,p)\approx N(np,np(1-p))$，边界作连续性修正 |

### 6.2 数理统计

| 主题 | 公式 |
| --- | --- |
| 样本均值 | $E(\overline X)=\mu$，$D(\overline X)=\dfrac{\sigma^2}{n}$ |
| 样本方差 | $E(S^2)=\sigma^2$，$S^2=\dfrac1{n-1}\sum(X_i-\overline X)^2$ |
| 卡方枢轴量 | $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$ |
| $t$ 枢轴量 | $\dfrac{\overline X-\mu}{S/\sqrt n}\sim t(n-1)$ |
| $F$ 枢轴量 | $\dfrac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}\sim F(n_1-1,n_2-1)$ |
| 均值区间，$\sigma$ 已知 | $\overline X\pm z_{\alpha/2}\dfrac{\sigma}{\sqrt n}$ |
| 均值区间，$\sigma$ 未知 | $\overline X\pm t_{\alpha/2}(n-1)\dfrac S{\sqrt n}$ |
| 两样本均值差区间 | $(\overline X-\overline Y)\pm t_{\alpha/2}(n_1+n_2-2)S_p\sqrt{\dfrac1{n_1}+\dfrac1{n_2}}$ |
| 方差区间 | $\left(\dfrac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right)$ |
| 比例区间 | $\hat p\pm z_{\alpha/2}\sqrt{\dfrac{\hat p(1-\hat p)}n}$ |
| 均值检验，$\sigma$ 已知 | $U=\dfrac{\overline X-\mu_0}{\sigma/\sqrt n}\sim N(0,1)$ |
| 均值检验，$\sigma$ 未知 | $T=\dfrac{\overline X-\mu_0}{S/\sqrt n}\sim t(n-1)$ |
| 方差检验 | $\chi^2=\dfrac{(n-1)S^2}{\sigma_0^2}\sim\chi^2(n-1)$ |

表中条件概率与乘法公式要求相应条件概率的分母为正；全概率公式要求 $\{A_i\}$ 为完备事件组且 $P(A_i)>0$，贝叶斯公式还要求 $P(B)>0$。两样本均值差区间中的 $S_p^2=\frac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}$，只在两正态总体方差未知但相等时使用。精确的均值、方差与方差比推断都以正态总体为前提，$F$ 枢轴量还要求两个样本相互独立。
