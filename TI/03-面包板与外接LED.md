## 本节主线

前几节 LED 闪烁在板载 LED 上完成，本节用面包板、杜邦线、插件 LED 和电阻搭建外接 LED 电路。完成之后，程序能通过指定 GPIO 引脚输出高低电平，驱动自己搭建的 LED 亮灭。

知识主线分三层：认识面包板内部导通规则 → 搭建 LED 电路 → 在 CCS 中配置引脚并写代码。

## 1\. 面包板的导通规则

面包板内部是金属弹片，按固定方式连接各个插孔。

- **中间区域**：五个孔一组导通。同一组的五个孔电气连通，相邻组之间不通。
- **电源长条**：一整排连通（但上下两排之间不通）。适合分配公共电源轨或 GND。

用万用表蜂鸣档测量最可靠。不同面包板可能中间断开，使用前测一遍。

## 2\. 把开发板插到面包板

先断电。排针对准孔位轻轻压入。插入时排针焊歪会很难插。开发板排针两侧留出孔位，方便 GPIO、GND、VCC 引出。

## 3\. 建立公共 GND

所有电压信号以 GND 为参考点。用杜邦线从开发板 GND 连接到面包板一侧电源长条，这一整排就变为公共地线。后续需要接地的元件直接插到这排即可，不用都拉回开发板。

**注意**：$3.3\text{ V}$ 和 GND 不要接在同一条导通轨上，否则短路。

## 4\. 外接 LED 电路

本节的接法仿照板载 LED 原理图，选用 `PA15` 作为控制引脚：

```
PA15 → LED 正极 → LED 负极 → 限流电阻 → GND
```

- `PA15` 高电平（$3.3\text{ V}$）：电流经 LED 和电阻到 GND，LED 亮
- `PA15` 低电平（$0\text{ V}$）：无足够正向电压，LED 灭

LED 长脚为正极，短脚为负极。掰弯引脚前先记住哪根是正极。

## 5\. 限流电阻必须存在

LED 不是普通电阻，导通后压降相对固定。没有电阻限流，电流可能过大，损坏 LED 或 GPIO。

限流电阻估算：$R = (V_{CC} - V_F) / I$。红色 LED 取 $V_F \approx 2.0\text{ V}$、$I=5\text{ mA}$，得 $R \approx 260\ \Omega$，可选 $330\ \Omega$ 到 $1\text{ k}\Omega$。

## 6\. CCS 中添加 PA15 为 GPIO 输出

在原有 GPIO 组中新增一个引脚：
1. 点击添加，命名如 `LEDE`（不能与已有名称重复）
2. 引脚选择 `PA15`
3. 方向选 `Output`
4. 初始值选 `Clear`（低电平）或 `Set`（高电平）
5. 保存并重新编译

配置工具生成的宏名与命名相关，代码中使用自动生成的名称。

## 7\. GPIO 输出结构选项

- **标准模式**：最常用，适合 LED、按键等
- **高速模式**：用于高速信号翻转，但可能带来电磁干扰
- **高驱动模式**：提供更大电流，但不能直接驱动大负载

LED 指示灯选标准模式即可。

## 8\. 代码控制 PA15

```c
DL_GPIO_setPins(GPIO_LEDS_PORT, GPIO_LEDS_LEDE_PIN);   // PA15 高电平，LED 亮
delay_ms(500);
DL_GPIO_clearPins(GPIO_LEDS_PORT, GPIO_LEDS_LEDE_PIN); // PA15 低电平，LED 灭
delay_ms(500);
```

端口名和引脚宏名以配置工具生成为准。若板载 LED 和外接 LED 同步亮灭，说明两个 GPIO 都被正确控制。

## 9\. 编译烧录与现象验证

烧录前记得重新插 USB 供电。正常现象：板载绿灯和外接 LED 同步闪烁。

外接 LED 不亮排查顺序：
1. 板载 LED 是否正常闪烁？否 → 程序未运行或烧录失败
2. PA15 配置是否正确？宏名是否写错？
3. 接线是否接到 PA15？LED 正负极？电阻串联？GND 共地？
4. 万用表测 PA15 对地电压，是否在高低电平之间跳变

## 一页速记

- 面包板中间五孔一组导通，电源长条整排导通
- 公共 GND 是所有信号的参考点
- 外接 LED：GPIO → LED 正极 → LED 负极 → 电阻 → GND
- 限流电阻必加，$330\ \Omega$ 起步
- syscfg 中 GPIO 配置：选引脚 PA15、方向 Output、保存后 Rebuild
- 代码中 setPins 置高电平亮、clearPins 清零灭（取决于接法）
- 接线先断电，分层排查：电源→烧录→GPIO 电压→LED 电路
