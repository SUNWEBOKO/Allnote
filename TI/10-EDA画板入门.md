## 本节主线

比赛中常需要根据机械结构和引脚分配，快速设计一块小电路板。本节使用立创 EDA 重新绘制一个按键模块，并增加旋钮输入，最终得到一块可用于单片机输入检测的简易 PCB。

功能：10 个按键输入（GPIO 电平检测）+ 1 个旋钮输入（电位器 ADC 采样）。

## 1\. PCB 设计流程

```
新建工程 → 绘制原理图 → 转换到 PCB → 摆放元件 → 画板框 → 布线 → 铺铜 → DRC 检查 → 下单打样
```

原理图关注"连接关系"，PCB 关注"物理实现"。

## 2\. 新建工程与原理图

立创 EDA 新建工程，进入原理图界面。常用操作：
- 放置器件：搜索添加元件
- 空格：旋转元件
- 导线工具：连接引脚
- 非连接标识：标记不用的引脚

元件位号自动分配：设置中搜索"位号"，设为自动分配，避免出现 `SW?`。

## 3\. 按键原理图

主要元件：`1×10P` 排针（引出 10 个按键信号）、`1×2P` 排针、10 个 $6\times6\text{ mm}$ 轻触按键。

四脚轻触按键内部结构：脚 1-2 相连、脚 3-4 相连，按下时两侧导通。只需连接一边的一个脚和另一边的一个脚，其余用非连接标识。

按键连接方式：

```
GPIO1 ── 按键1 ── 公共端
GPIO2 ── 按键2 ── 公共端
...       ...        ...
```

公共端接 GND（低电平有效）或 VCC（高电平有效），单片机配合上拉或下拉输入。常用低电平有效（公共端接 GND，单片机开启内部上拉）。

## 4\. 转换到 PCB

原理图画好后，通过"设计 → 更新/转换原理图到 PCB"进入 PCB 界面。元件初始杂乱摆放，需手动布局。

## 5\. PCB 布局与板框

布局建议：
- 10 个按键排成一排
- `1×10P` 排针放在按键一侧
- 螺丝孔放在边角

板框用矩形工具绘制，转换为毫米单位。尺寸示例：宽 $80\text{ mm}$，高度根据元件排列调整。

## 6\. 布线

细线提示（飞线）表示原理图中需要连接但 PCB 上还没连的点。用单路布线工具沿飞线提示连接。

推荐 45° 斜线过渡，避免直角弯和锐角弯。

## 7\. 添加安装孔

放置焊盘 → 图层设为多层 → 设置钻孔直径（如 $3\text{ mm}$ 配 M3 螺丝）和焊盘外径（如 $5\text{ mm}$）→ 删除网络（安装孔不接信号）。

## 8\. 旋钮（电位器）

器件：`RK097 3P` 电位器 + `1×3P` 排针引出。

原理图连接：

```
电位器 1 脚 → VCC
电位器 2 脚 → ADC 输入（中间抽头）
电位器 3 脚 → GND
```

旋钮位置靠近板边方便手拧，不与其他元件冲突。

## 9\. 铺铜

布线完成后铺铜。常见铺铜到 GND 网络，形成大面积地平面提升抗干扰。顶层底层均可铺铜。快捷键 `Shift + B` 重新铺铜。

**注意**：铺铜前确认网络名，误选信号网络会导致大面积短路。

## 10\. DRC 检查

PCB 画完后必须运行 DRC（设计规则检查），检查：
- 未连接的网络
- 短路
- 线宽过小
- 间距不足

DRC 无报错才可下单。下单前确认：尺寸、层数（双层）、板厚、颜色、数量。

## 11\. 常见错误

- 只画原理图未转 PCB → 不能打样
- 位号显示问号 → 改为自动分配
- 按键四脚全乱接 → 内部两两相连，只需接两侧各一脚
- 忘记公共端 → 按键模块必须有公共端电平
- 旋钮中间脚接错 → 中间脚输出，接 ADC
- 铺铜网络选错 → 确认连接 GND
- 不做 DRC → 下单前必须检查

## 一页速记

- PCB 流程：原理图 → 布局 → 板框 → 布线 → 铺铜 → DRC → 下单
- 四脚按键内部两两相连，公共端决定输入电平逻辑
- 旋钮电位器：两端接 VCC/GND，中间接 ADC
- 走线用 45°，避免直角
- 螺丝孔用焊盘实现，设多层、设孔径、删网络
- 铺铜连接 GND，降低干扰
- DRC 不报错再下单
