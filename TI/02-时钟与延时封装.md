## 本节主线

上节完成了 LED 闪烁，本节围绕两个问题展开：第一，程序运行快慢由什么决定——时钟配置；第二，如何通过 GPIO 控制外部器件——外接 LED。

核心是理解"时钟源 → 分频/倍频 → CPU clock → 程序执行速度"这条主线，并把依赖主频的延时计算封装成 `delay_ms()` 函数。

## 1\. 时钟周期、CPU 频率与程序速度

CPU 执行程序依赖时钟信号提供节拍。频率越高，单位时间内指令周期越多。频率 $f$ 与周期 $T$ 的关系：

$$T = \frac{1}{f}$$

当 $f = 32\text{ MHz}$，$T = 31.25\text{ ns}$；当 $f = 80\text{ MHz}$，$T = 12.5\text{ ns}$。

延时函数通常空转固定数量的时钟周期。主频提高后，每个周期变短，同样的周期数对应的实际时间变短。例如等待 $8\,000\,000$ 个周期：

- $32\text{ MHz}$ 下：$t = 8\,000\,000 / 32\,000\,000 = 0.25\text{ s}$
- $80\text{ MHz}$ 下：$t = 8\,000\,000 / 80\,000\,000 = 0.1\text{ s}$

这就是为什么修改时钟频率后 LED 闪烁会明显变快。

## 2\. 从 32 MHz 到 80 MHz 的时钟配置

默认 CPU clock 为 $32\text{ MHz}$（内部时钟源）。开发板外部晶振为 $40\text{ MHz}$，连接到 `PA5`、`PA6`。要到达 $80\text{ MHz}$，需在 syscfg 中沿时钟树配置：

1. 启用外部晶振，填写频率 $40\text{ MHz}$
2. 选择通往 CPU clock 的路径
3. 通过分频、倍频模块将频率配置到 $80\text{ MHz}$
4. 检查中间每个节点的频率是否在允许范围内

配置保存后重新编译，生成的配置头文件中主频宏会从 $32\text{ MHz}$ 变为 $80\text{ MHz}$。

## 3\. 封装 delay_ms() 函数

直接写固定周期数延时的缺陷：主频变化后延时时间跟着变。

封装思路：利用配置工具生成的主频宏，让函数内部根据当前主频自动计算周期数。

```c
// delay.h
#ifndef DELAY_H
#define DELAY_H
#include "ti_msp_dl_config.h"
void delay_ms(uint32_t ms);
#endif

// delay.c
#include "delay.h"
void delay_ms(uint32_t ms) {
    delay_cycles((CPUCLK_FREQ / 1000U) * ms);
}
```

核心公式：$N = f \cdot t$（$N$：周期数，$f$：主频，$t$：时间）。将毫秒转换：`N = (CPUCLK_FREQ / 1000) * ms`。

调用时只需写 `delay_ms(500)`，主频改变后宏自动更新，业务代码无需修改。

注意：如果 `ms` 很大，乘法可能超出 `uint32_t` 范围。入门延时几百毫秒通常问题不大。

## 4\. 外接 LED 电路

准备器材：开发板、下载器、万用表、杜邦线、面包板、插件 LED、限流电阻。

限流电阻公式（欧姆定律）：

$$R = \frac{V_{CC} - V_F}{I}$$

$V_{CC}=3.3\text{ V}$，红色 LED 的 $V_F\approx 2.0\text{ V}$，取 $I=5\text{ mA}$：

$$R = \frac{3.3 - 2.0}{0.005} = 260\ \Omega$$

实际可选 $330\ \Omega$ 到 $1\text{ k}\Omega$。电阻大一些更安全，LED 暗一些但足够指示。

LED 有两种接法：
- **高电平点亮**：GPIO → LED → 电阻 → GND，`setPins()` 亮
- **低电平点亮**：$3.3\text{ V}$ → 电阻 → LED → GPIO，`clearPins()` 亮

推荐先使用高电平点亮接法，更符合直觉。

## 5\. 逐层调试思路

- 时钟配置是否生效 → 检查生成的头文件中主频宏
- LED 闪烁速度是否变化 → 验证主频确实改变
- 外接 LED 不亮 → 测量 GPIO 电压是否变化、LED 极性、电阻、GND 共地

## 易错点

- `delay_cycles(8000000)` 延时的是周期数，不是秒数。主频从 $32\to 80\text{ MHz}$ 后，实际时间从 $0.25\text{ s}$ 变为 $0.1\text{ s}$。
- 时钟配置不要只看最终 CPU clock，要检查中间每段频率限制。
- 外部晶振频率和引脚必须与原理图一致（$40\text{ MHz}$，`PA5`、`PA6`）。
- 每节课工程独立复制到工作区，避免路径和重命名问题。

## 一页速记

- 时钟周期 $T = 1/f$，主频越高程序越快
- delay_cycles 等待的是"周期数"不是"秒数"，主频变了延时时间就变
- 封装 delay_ms() 使代码不依赖固定主频——用主频宏自动换算
- 外接 LED 必须串联限流电阻（$330\ \Omega$ 起步），注意 LED 极性和接法
- GPIO 高电平 $\approx 3.3\text{ V}$，低电平 $\approx 0\text{ V}$
- 调试拆成：配置→编译→烧录→GPIO 电压→电路连接，逐层排查
