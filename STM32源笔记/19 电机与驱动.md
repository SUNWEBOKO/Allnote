# 19. 电机与 TB6612 驱动

> 本节重点：理解 STM32 如何通过 TB6612 驱动芯片将小电流 GPIO/PWM 信号转换为电机的方向与速度控制，掌握方向真值表与驱动库接口。

---

## 1. 直流电机控制基础

直流电机基本规律：

- 两端加电转动
- 交换极性，转向改变
- 改变平均电压，转速改变

### 为什么不能直接接 GPIO

| 原因 | 说明 |
|------|------|
| 驱动电流不足 | GPIO 输出电流很小，带不动电机 |
| 反电动势 | 电机启停/换向时产生反向高压 |
| 供电隔离 | 电机电源与逻辑电源需要分离 |

因此实际链路为：

```text
STM32 GPIO/PWM → 驱动芯片（TB6612）→ 直流电机
```

### H 桥电路原理

TB6612 的核心是 **H 桥（H-Bridge）**——四个开关管组成"Ｈ"形电路：

```text
          VCC
           │
      ┌───[S1]───┐
      │           │
    MOT_A      MOT_B
      │           │
      └───[S2]───┘
           │
          GND
```

电机接在 MOT_A 和 MOT_B 之间，四个开关管（实际为 MOSFET）的不同组合决定电机的行为：

| S1 | S2 | S3 | S4 | 行为 | 说明 |
|:--:|:--:|:--:|:--:|------|------|
| 通 | 断 | 断 | 通 | MOT_A → VCC, MOT_B → GND，**电机正转** | 电流从 A 流向 B |
| 断 | 通 | 通 | 断 | MOT_A → GND, MOT_B → VCC，**电机反转** | 电流从 B 流向 A |
| 断 | 断 | 断 | 断 | 全部断开，**滑行（Coast）** | 电机惯性自由旋转 |
| 通 | 断 | 通 | 断 | 两端都接 VCC，**刹车（Brake）** | 两端等电位短接制动 |
| 断 | 通 | 断 | 通 | 两端都接 GND，同样是 **刹车** | |

**Brake vs Coast 的电气本质**：

- **Coast（滑行）**：四个开关全断，电机两端悬空，感应电动势无回路，电机靠惯性缓慢停转
- **Brake（刹车）**：电机两端通过开关管接到同一电位（同 VCC 或同 GND），感应电动势形成短路回路，产生反向制动电流，电机迅速停转

TB6612 将四个开关管集成为芯片内部结构，对外仅暴露 IN1/IN2 两个方向控制脚和一个 PWM 速度控制脚：

```text
IN1 = 1, IN2 = 0 → 等效 S1 通、S4 通（正转）
IN1 = 0, IN2 = 1 → 等效 S2 通、S3 通（反转）
IN1 = 0, IN2 = 0 → 等效全断开（Coast）
IN1 = 1, IN2 = 1 → 等效同端短接（Brake）
```

## 2. TB6612 控制信号

TB6612 是双 H 桥驱动芯片，可控制两路直流电机。

| 通道 | 方向控制 | 速度控制 |
|------|----------|----------|
| A 通道 | `AIN1`、`AIN2` | `PWMA` |
| B 通道 | `BIN1`、`BIN2` | `PWMB` |

- `IN1/IN2`：普通 GPIO 输出高低电平，决定方向
- `PWM`：定时器 PWM 输出占空比，决定速度

---

## 3. 方向真值表（A 通道）

| AIN1 | AIN2 | 电机状态 | 驱动库函数 |
|:----:|:----:|----------|------------|
| 0 | 0 | 滑行（Coast） | `TB6612_Coast()` |
| 0 | 1 | 反转 | `TB6612_Backward()` |
| 1 | 0 | 正转 | `TB6612_Forward()` |
| 1 | 1 | 刹车（Brake） | `TB6612_Brake()` |

B 通道同理，将 `AIN1/AIN2` 换为 `BIN1/BIN2`。

理解重点：

- 方向由两个 IN 脚决定
- 速度由 PWM 占空比决定
- Brake（短接制动）和 Coast（滑行）都能让电机停，但电气状态不同

---

## 4. 驱动库硬件映射

移植时需在 `tb6612.h` 中修改三类宏：

### A 通道方向 GPIO

```c
#define AIN1_GPIO_Port TB6612_AIN1_GPIO_Port
#define AIN2_GPIO_Port TB6612_AIN2_GPIO_Port
#define AIN1_Pin       TB6612_AIN1_Pin
#define AIN2_Pin       TB6612_AIN2_Pin
```

### B 通道方向 GPIO

```c
#define BIN1_GPIO_Port TB6612_BIN1_GPIO_Port
#define BIN2_GPIO_Port TB6612_BIN2_GPIO_Port
#define BIN1_Pin       TB6612_BIN1_Pin
#define BIN2_Pin       TB6612_BIN2_Pin
```

### PWM 定时器与通道

```c
#define PWMA_TIM         &htim3
#define PWMA_TIM_CHANNEL TIM_CHANNEL_1
#define PWMB_TIM         &htim3
#define PWMB_TIM_CHANNEL TIM_CHANNEL_2
```

## 5. 驱动函数

### 5.1 初始化

```c
TB6612_Init(ONLY_A);   // 初始化 A 通道
TB6612_Init(ONLY_B);   // 初始化 B 通道
TB6612_Init(ALL);      // 初始化全部通道
```

初始化动作：配置 PWM 定时器参数 → 启动 PWM → 调用 `Coast()` 默认滑行停止。

### 5.2 方向与速度控制

| 函数 | 作用 |
|------|------|
| `TB6612_Forward(motor, speed)` | 正转，speed: 0~100 |
| `TB6612_Backward(motor, speed)` | 反转 |
| `TB6612_Brake(motor)` | 刹车（短接制动） |
| `TB6612_Coast(motor)` | 滑行（断开驱动） |

### 5.3 速度设置

驱动库将速度范围定义为 `0~100`，定时器配置为：

```c
__HAL_TIM_SET_PRESCALER(PWMA_TIM, 72 - 1);    // 分频 → 1MHz
__HAL_TIM_SET_AUTORELOAD(PWMA_TIM, 100 - 1);  // 100 档
// speed = 0~100 直接对应 CCR = 0~100
```

### 5.4 典型使用流程

```c
TB6612_Init(ONLY_A);

TB6612_Forward(ONLY_A, 50);   // 正转，速度 50%
HAL_Delay(1000);

TB6612_Backward(ONLY_A, 50);  // 反转，速度 50%
HAL_Delay(1000);

TB6612_Coast(ONLY_A);          // 滑行停止
```

## 6. 高频易错点

1. **把 IN1/IN2 当成 PWM 脚**。IN 脚只控方向，速度由独立 PWM 控制。

2. **忘记配置 PWM 模式**。PWMA/PWMB 的定时器通道必须在 CubeMX 中配成 PWM 输出。

3. **宏名与 CubeMX 生成的不一致**。`tb6612.h` 中的宏必须和 `main.h` 中的一致。

4. **初始化哪个通道就用哪个通道**。只初始化了 `ONLY_A`，后面不要直接操作 `ONLY_B`。

5. **速度超过范围**。驱动内部会钳位到 100，但调用方应主动保持 0~100。

6. **误以为 Brake 和 Coast 一样**。两者都停机，但方向脚状态不同——Brake 短路制动，Coast 断开驱动。

7. **忘记电机外部供电和共地**。TB6612 需要独立的电机电源，逻辑地与电机地必须共地。

## 7. 一页速记

### 控制模型
```text
方向：两个 IN 脚（1/0 正转，0/1 反转）
速度：PWM 占空比（0~100%）
```

### A 通道真值表
```text
IN1=0, IN2=0 → 滑行
IN1=0, IN2=1 → 反转
IN1=1, IN2=0 → 正转
IN1=1, IN2=1 → 刹车
```

### 移植要点
```text
改 GPIO 宏 → 改 PWM 宏 → 检查 CubeMX 配置
```

### 核心 API
| 函数 | 用途 |
|------|------|
| `TB6612_Init(motor)` | 初始化并滑行停止 |
| `TB6612_Forward(motor, speed)` | 正转 |
| `TB6612_Backward(motor, speed)` | 反转 |
| `TB6612_Brake(motor)` | 刹车 |
| `TB6612_Coast(motor)` | 滑行 |

### 最重要的一句话
> 电机控制链路的本质是"小信号 → 驱动芯片 → 大电流执行"——GPIO 和 PWM 只发信号，电流由 TB6612 和外部电源提供。
