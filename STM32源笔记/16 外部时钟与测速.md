## 1. 为什么需要外部时钟

| 时钟类型 | 用途 | 计数依据 |
|----------|------|----------|
| 内部时钟 | 定时 | 固定的时钟脉冲 |
| 外部时钟 | 计量外部事件次数 | 外部信号脉冲 |

外部时钟适合的场景：

- 转动圈数计数
- 传送带通过件数统计
- 基于脉冲的频率/速度/距离测量

## 2. 两种外部时钟模式

### 2.1 外部时钟模式 2（ETR 直入）

```text
ETR 引脚 → 滤波 → 边沿检测 → 触发控制器 → CNT +1
```

| 特点 | 说明 |
|------|------|
| 路径 | 最短，ETR 直入触发控制器 |
| 配置 | 时钟源直接选择 `ETR` |
| 配置项 | 极性、预分频、滤波（Clock Filter） |

### 2.2 外部时钟模式 1（通过从模式控制器）

```text
TI1/TI2/ETR → 滤波 → 触发器 → 从模式控制器(时钟模式1) → CNT +1
```

| 特点 | 说明 |
|------|------|
| 路径 | 经从模式控制器，更灵活 |
| 触发源 | TI1FP1、TI2FP2、TI1_ED、ETRF 等 |
| 配置 | 时钟源用内部，从模式选 `External Clock Mode 1` |

### 2.3 两种模式对比

| 对比项 | 模式 2（ETR 直入） | 模式 1（从模式） |
|--------|-------------------|------------------|
| 配置复杂度 | 低 | 较高 |
| 触发源选择 | 仅 ETR | 多种选择 |
| 滤波能力 | 有 | 有 |
| 路径长度 | 短 | 较长 |

## 3. 传送带测速实战思路

```text
反射式红外传感器 → 读取黑白条纹 → 输出脉冲 → 定时器计数
```

- 每检测到一条黑条纹，传感器输出一个脉冲
- 定时器累计脉冲数 → 对应条纹通过次数
- 结合每格距离计算出位移和速度
- 配合 OLED 实时显示

## 4. 抖动与滤波

### 4.1 抖动来源

机械/光学边缘在切换瞬间会产生窄脉冲抖动，导致"计数虚高"：

```text
理想信号：▁╱▔╲▁
实际信号：▁╱╲╱╲╱╲╱╲╱▔╲▁    （边缘抖动）
```

### 4.2 定时器输入滤波原理

滤波通过"采样频率 + 连续样本判定"来过滤短毛刺：

- 设定采样频率和连续 N 个相同样本才算有效
- 脉宽小于滤波阈值的毛刺被过滤

### 4.3 调试建议

| 调试阶段 | 滤波策略 |
|----------|----------|
| 初步验证 | 滤波值调大（如 Filter=15），确认能计数但无抖动 |
| 精细调整 | 逐步降低滤波值，在响应速度和稳定性之间平衡 |

注意：滤波能力受内部时钟频率影响，主频改变后滤波效果会变化。

## 5. 计数上限与扩展

### 5.1 16 位计数器限制

最大计数值：65535。超过后会回卷到 0。

### 5.2 扩展方案

| 方法 | 做法 | 适用场景 |
|------|------|----------|
| 更新中断扩展 | 开更新中断，在中断中对高位做软件累加 | 需要保留精确计数值 |
| 周期读取累加 | 定时读取当前 CNT 并累加到 32 位变量 | 速度计算等非精确累计场景 |

速度计算推荐使用"固定时间窗内的脉冲增量"：

```c
// 每 100ms 读取一次
int32_t delta = cnt_now - cnt_prev;  // 脉冲增量
float speed = delta / 0.1f;          // 脉冲/秒
cnt_prev = cnt_now;
```

## 6. 高频易错点

1. **计数不动**。输入引脚连错，或模式 1/模式 2 的配置不匹配外部信号路径。

2. **计数乱跳**。滤波太弱或传感器阈值未调好，抖动脉冲被误计数。

3. **计数翻倍**。边沿选择与信号形态不匹配，双沿都被计入（如高低电平都触发）。

4. **主频修改后计数行为变化**。重新检查输入滤波参数和定时器时钟链。

5. **回卷未处理**。长时间运行时不处理 16 位计数器的溢出，速度/位置计算出错。

## 7. 一页速记

### 两种外部时钟模式
```text
模式 2：ETR 直入，路径短，配置简单
模式 1：经从模式控制器，触发源选择更灵活
```

### 滤波调试顺序
```text
先调大滤波值验证无抖动 → 再逐步降低到理想平衡点
```

### 计数扩展
```text
长时间计数必须处理 16 位回卷
推荐方法：固定时间窗内取增量算速度
```

### 最重要的一句话
> 外部计数实战中，先解决"抖动过滤"，再谈算法精度。
