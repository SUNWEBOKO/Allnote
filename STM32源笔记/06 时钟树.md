# 06. 时钟树：从必要性到实战配置

> 本节重点：理解 MCU 为什么必须依赖时钟信号，建立 SYSCLK → HCLK → PCLK 的主干关系，掌握定时器时钟倍频规则与常见 72MHz 配置。

## 1. 时钟为什么必需

- 逻辑门传播延时会引入瞬态错误状态，寄存器采样需要统一时序基准。
- 时钟沿相当于**全芯片统一拍点**，让寄存器在稳定时刻采样。
- 外设层面同样依赖时钟：串口波特率、定时器计时、总线传输都离不开时钟。

---

## 2. 主干时钟路径

```text
时钟源 → SYSCLK → AHB 预分频 → HCLK → APB1 预分频 → PCLK1
                                     → APB2 预分频 → PCLK2
```

### 2.1 各级时钟含义

| 时钟 | 全称 | 作用 |
|------|------|------|
| `SYSCLK` | System Clock | 系统核心时钟，由时钟源选择决定 |
| `HCLK` | AHB Bus Clock | 供 CPU、内存、DMA、AHB 总线 |
| `PCLK1` | APB1 Bus Clock | 供低速外设（定时器、I2C、USART 等），上限 36MHz |
| `PCLK2` | APB2 Bus Clock | 供高速外设（GPIO、SPI、USART1、ADC 等），上限 72MHz |

### 2.2 计算公式

```text
HCLK  = SYSCLK / AHB_Prescaler
PCLK1 = HCLK / APB1_Prescaler
PCLK2 = HCLK / APB2_Prescaler
```

---

## 3. 定时器时钟倍频规则

定时器挂在 APB 总线上，但 `TIMxCLK` 存在**倍频规则**：

| APBx 预分频 | TIMxCLK |
|-------------|---------|
| 1（不分频） | `= PCLKx` |
| > 1（分频） | `= 2 × PCLKx` |

这条规则直接影响定时器频率计算。例如 APB1 预分频为 2 时，PCLK1 = 36MHz，但 TIMxCLK = 72MHz。

---

## 4. 时钟源选择

### 4.1 三种时钟源

| 时钟源 | 来源 | 精度 | 启动速度 | 典型用途 |
|--------|------|------|----------|----------|
| `HSI` | 内部 RC 振荡器（8MHz） | 一般 | 快 | 上电默认、无外部晶振 |
| `HSE` | 外部晶振（4~16MHz） | 高 | 慢 | 要求稳定时钟的场景 |
| `PLL` | 锁相环倍频（输入来自 HSI/HSE） | 取决于输入源 | 较快 | 需要高主频（如 72MHz） |

### 4.2 典型 72MHz 配置

```text
HSE (8MHz) → PLL x9 → SYSCLK = 72MHz
                    → AHB 不分频 → HCLK = 72MHz
                    → APB1 分频 2 → PCLK1 = 36MHz, TIMxCLK = 72MHz
                    → APB2 不分频 → PCLK2 = 72MHz, TIMxCLK = 72MHz
```

---

## 5. 其他关键时钟节点

| 时钟 | 说明 |
|------|------|
| `SysTick` | 系统节拍定时器，为 `HAL_Delay` 提供时间基准 |
| `LSI` | 低速内部时钟（约 40kHz），常用于独立看门狗、RTC |
| `LSE` | 低速外部晶振（32.768kHz），常用于 RTC 精准走时 |
| `CSS` | 时钟安全系统，HSE 异常时自动切回 HSI 并触发告警 |
| `MCO` | 时钟输出引脚，可将内部时钟输出到引脚供测试 |

## 6. CubeMX 配置步骤

### 6.1 最小配置流程

| 步骤 | 操作 |
|------|------|
| 1 | `System Core → RCC` 选择外部晶振（HSE） |
| 2 | 进入 `Clock Configuration` 页面 |
| 3 | 在 HSE 旁输入 `8`（外部晶振频率） |
| 4 | PLL 源选择 `HSE`，倍频数设为 `x9` |
| 5 | 调整各总线预分频，使 `HCLK` 显示为 `72MHz`（绿色校验通过） |
| 6 | 确认红色字体无错误提示 |

### 6.2 检查要点

- 所有总线频率必须在芯片规格范围内（红色字体表示越界）
- 定时器频率需要结合倍频规则手动复核

---

## 7. 高频易错点

1. **定时器频率算错**。漏看 APB 分频 > 1 时 TIMxCLK = 2 × PCLKx。

2. **串口波特率偏差大**。外部晶振未启用，实际用的是 HSI，频率偏差导致波特率不准。

3. **CubeMX 时钟配置出现红色字体**。表示某总线超限，必须调分频修正。

4. **低功耗唤醒异常**。未理清停机模式下哪些时钟仍工作。

5. **迁移工程后外设时序异常**。先核对时钟树，再看外设初始化代码是否匹配。

---

## 8. 一页速记

### 时钟主干
```text
SYSCLK → (AHB 分频) → HCLK → (APB1/2 分频) → PCLK1/PCLK2
```

### 定时器倍频规则
```text
APB 分频 = 1   → TIMxCLK = PCLKx
APB 分频 > 1   → TIMxCLK = 2 × PCLKx
```

### 常见 72MHz 配置
```text
HSE 8MHz → PLL x9 → SYSCLK 72MHz
AHB: /1, APB1: /2, APB2: /1
```

### 最重要的一句话
> 工程调试时优先把时钟树跑通，再看外设问题，排障效率最高。
