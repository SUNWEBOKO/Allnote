
# 一阶低通滤波（EMA）的实现

## 1. 为什么传感器数据需要滤波

在机器人控制、嵌入式采集、姿态估计、温度监测等场景中，传感器读数通常不会是一条干净平滑的曲线，而是带有随机抖动。噪声可能来自传感器本身、电源纹波、机械振动、环境干扰或 ADC 采样误差。

如果直接把原始数据送入控制器、判断逻辑或显示模块，系统可能出现以下问题：

- 控制量频繁抖动，执行器不断小幅动作；
- 阈值判断反复触发，产生误报或误动作；
- 曲线显示毛躁，难以观察真实变化趋势；
- PID 等闭环控制对噪声过度响应，降低稳定性。

滤波的目标不是“让数据变好看”，而是从带噪声的数据流中提取出更可信的趋势信号。一阶低通滤波就是最常用、最容易实现的一类方法：它保留缓慢变化的低频趋势，抑制快速跳变的高频噪声。

在工程代码中，一阶低通滤波常以 **EMA（Exponential Moving Average，指数移动平均）** 的形式实现。

---

## 2. 核心公式

EMA 一阶低通滤波的递推公式为：

$$
y_t = \alpha x_t + (1 - \alpha)y_{t-1}
$$

其中：

- $x_t$：当前时刻读取到的原始数据；
- $y_t$：当前时刻输出的滤波结果；
- $y_{t-1}$：上一时刻的滤波结果；
- $\alpha$：滤波系数，也叫平滑系数，通常满足 $0 < \alpha < 1$。

这个公式的直观含义是：

> 当前输出 = 一部分当前读数 + 一部分历史滤波结果。

也就是说，滤波器并不完全相信当前读数，而是把当前数据和过去积累下来的趋势混合在一起。每次新数据到来时，只需要保存上一次滤波结果 $y_{t-1}$，再执行一次乘加运算即可。

因此，EMA 一阶低通滤波非常适合 MCU、机器人控制器、传感器实时采样等资源有限的场景。

---

## 3. 参数 $\alpha$ 的意义

$\alpha$ 是一阶低通滤波中最重要的参数，它决定滤波器在“响应速度”和“平滑程度”之间如何取舍。

### 3.1 $\alpha$ 较大：响应快，但抑噪弱

当 $\alpha$ 较大，例如 $\alpha = 0.8$：

$$
y_t = 0.8x_t + 0.2y_{t-1}
$$

当前原始数据占主要权重，滤波输出会快速跟随输入变化。

优点：

- 对真实变化反应快；
- 滞后较小；
- 适合对实时性要求较高的控制场景。

缺点：

- 平滑效果较弱；
- 原始数据中的抖动仍会明显传到输出端。

### 3.2 $\alpha$ 较小：抑噪强，但响应慢

当 $\alpha$ 较小，例如 $\alpha = 0.1$：

$$
y_t = 0.1x_t + 0.9y_{t-1}
$$

历史滤波结果占主要权重，滤波器更相信过去的趋势。

优点：

- 输出曲线更平滑；
- 对随机高频噪声有更强抑制作用。

缺点：

- 对真实变化反应迟钝；
- 会产生明显滞后；
- 在快速闭环控制中可能导致控制不及时，甚至引起振荡。

### 3.3 调参口诀

可以用下面两句话记住调参方向：

- 输出太抖：减小 $\alpha$；
- 输出太慢：增大 $\alpha$。

工程上常从 $\alpha = 0.1 \sim 0.3$ 开始尝试，然后把原始数据 $x_t$ 和滤波输出 $y_t$ 画在同一张曲线上，对比平滑程度和响应延迟。

## 4. 为什么它叫“指数移动平均”

虽然公式里只出现了当前数据 $x_t$ 和上一时刻输出 $y_{t-1}$，但如果把递推公式展开，就会发现它实际上隐式使用了所有历史数据。

由

$$
y_t = \alpha x_t + (1 - \alpha)y_{t-1}
$$

继续代入

$$
y_{t-1} = \alpha x_{t-1} + (1 - \alpha)y_{t-2}
$$

可得：

$$
\begin{aligned}
y_t
&= \alpha x_t + (1 - \alpha)\left[\alpha x_{t-1} + (1 - \alpha)y_{t-2}\right] \\
&= \alpha x_t + \alpha(1 - \alpha)x_{t-1} + (1 - \alpha)^2 y_{t-2}
\end{aligned}
$$

继续展开后：

$$
y_t = \alpha x_t + \alpha(1 - \alpha)x_{t-1} + \alpha(1 - \alpha)^2x_{t-2} + \alpha(1 - \alpha)^3x_{t-3} + \cdots
$$

可以看到，越新的数据权重越大，越旧的数据权重按 $(1-\alpha)^k$ 指数衰减。

这说明 EMA 的本质是：

- 它是对历史数据的加权平均；
- 权重不是平均分配，而是离当前越近权重越大；
- 旧数据不会突然失效，而是逐渐变得不重要；
- 只保存一个历史状态 $y_{t-1}$，就等效保留了长时间的历史影响。

这也是它相比普通滑动平均更适合嵌入式实时系统的原因：普通滑动平均通常需要保存一个窗口数组，而 EMA 只需要一个状态变量。

## 5. 与一阶低通滤波的关系

一阶低通滤波的连续时间形式可以写成：

$$
\tau \frac{dy(t)}{dt} + y(t) = x(t)
$$

其中 $\tau$ 是时间常数。$\tau$ 越大，滤波越平滑，但响应越慢；$\tau$ 越小，响应越快，但抑噪能力越弱。

如果采样周期为 $\Delta t$，可以把连续滤波器离散化为 EMA 形式：

$$
y_t = \alpha x_t + (1 - \alpha)y_{t-1}
$$

若已知希望的截止频率 $f_c$，通常先计算时间常数：

$$
\tau = \frac{1}{2\pi f_c}
$$

再根据采样周期计算 $\alpha$。常用的精确离散形式为：

$$
\alpha = 1 - e^{-\frac{\Delta t}{\tau}}
$$

也有一种工程上常见的近似写法：

$$
\alpha = \frac{\Delta t}{\tau + \Delta t}
$$

两者在 $\Delta t$ 远小于 $\tau$ 时比较接近。实际项目中，如果只是做传感器平滑，可以直接调 $\alpha$；如果需要按明确的截止频率设计滤波器，则更适合从 $f_c$、$\tau$ 和 $\Delta t$ 推出 $\alpha$。

## 6. 基本代码实现

### 6.1 最小实现

```c
float alpha = 0.2f;      // 滤波系数：越大响应越快，越小越平滑
float y = 0.0f;          // 滤波输出
bool initialized = false;

float low_pass_filter(float x)
{
    if (!initialized)
    {
        y = x;           // 第一次用原始值初始化，避免冷启动大偏差
        initialized = true;
        return y;
    }

    y = alpha * x + (1.0f - alpha) * y;
    return y;
}
```

右边的 `y` 表示上一周期的滤波结果，左边的 `y` 表示更新后的当前滤波结果。这个覆盖过程就是递推状态更新。

### 6.2 封装成结构体

如果项目中有多个传感器通道，可以把滤波器封装成结构体：

```c
typedef struct
{
    float alpha;
    float y;
    int initialized;
} LowPassFilter;

void LowPassFilter_Init(LowPassFilter *filter, float alpha)
{
    filter->alpha = alpha;
    filter->y = 0.0f;
    filter->initialized = 0;
}

float LowPassFilter_Update(LowPassFilter *filter, float x)
{
    if (!filter->initialized)
    {
        filter->y = x;
        filter->initialized = 1;
        return filter->y;
    }

    filter->y = filter->alpha * x + (1.0f - filter->alpha) * filter->y;
    return filter->y;
}
```

使用方式：

```c
LowPassFilter acc_x_filter;

LowPassFilter_Init(&acc_x_filter, 0.2f);

while (1)
{
    float raw_acc_x = Read_Acc_X();
    float filtered_acc_x = LowPassFilter_Update(&acc_x_filter, raw_acc_x);

    // 后续控制或显示使用 filtered_acc_x
}
```

## 7. 实现时的关键细节

### 7.1 初始值不要随便设为 0

如果真实数据在 100 附近，而滤波初始值设为 0，那么启动后输出需要一段时间才能追上真实值。这段收敛时间内的输出并不可信。

常见处理方式：

- 第一次读取原始值时，直接令 $y_0 = x_0$；
- 启动阶段先采集多次取平均值作为初始值；
- 在滤波器收敛前，不把输出用于关键控制。

### 7.2 采样周期要稳定

一阶低通滤波的实际效果与采样周期有关。如果 $\Delta t$ 忽快忽慢，同一个 $\alpha$ 对应的实际滤波强度也会变化。

如果采样周期固定，可以使用常数 $\alpha$。如果采样周期不固定，建议根据每次实际的 $\Delta t$ 动态计算：

$$
\alpha = 1 - e^{-\frac{\Delta t}{\tau}}
$$

### 7.3 不要把 $\alpha$ 写死成魔术数字

建议把 $\alpha$ 定义为宏、配置项或可调参数，方便调试：

```c
#define ACC_LPF_ALPHA 0.2f
```

或者在调参阶段通过串口命令、上位机参数、配置文件动态修改。

### 7.4 观察曲线比凭感觉调参更可靠

调试滤波器时，最好同时记录：

- 原始数据 $x_t$；
- 滤波输出 $y_t$；
- 控制系统最终使用的数据。

把它们画在同一张图上，可以直接看到噪声是否被压下去、真实变化是否被拖慢。

## 8. 适用场景与局限

### 8.1 适用场景

一阶低通滤波适合处理随机抖动明显、但真实趋势变化相对连续的信号，例如：

- 温度、湿度、光照等缓慢变化的传感器数据；
- 电池电压、电流采样；
- 摇杆输入、旋钮 ADC 输入；
- 距离传感器的轻微跳动；
- IMU 某些低频姿态量或控制量的平滑。

### 8.2 局限

一阶低通滤波不是万能的：

- 它不能消除固定偏差，传感器有 offset 时仍需要校准；
- 它会引入延迟，$\alpha$ 越小延迟越明显；
- 它不适合保留尖锐突变信号；
- 它无法区分“真实快速变化”和“高频噪声”，只能按频率特征做取舍；
- 在强动态控制系统中，过度滤波可能让控制器拿到过时信息。

---

## 9. 易错点总结

| 易错点 | 后果 | 建议 |
|---|---|---|
| 认为 $\alpha$ 越小越好 | 输出很平滑，但严重滞后 | 根据响应速度和平滑程度折中 |
| 初始值随便设为 0 | 启动阶段输出偏差大 | 第一次读数或多次平均初始化 |
| 采样周期不稳定 | 滤波强度变化，曲线表现不一致 | 固定采样周期，或按 $\Delta t$ 动态计算 $\alpha$ |
| 滤波后仍直接做高频控制 | 控制响应变慢 | 控制场景中谨慎选择截止频率 |
| 用滤波代替校准 | 固定偏差仍然存在 | offset、比例误差应单独校准 |

---

## 10. 速记

- 一阶低通滤波的工程实现常用 EMA：

$$
y_t = \alpha x_t + (1 - \alpha)y_{t-1}
$$

- $\alpha$ 大：更相信当前值，响应快，抖动也更明显；
- $\alpha$ 小：更相信历史值，曲线平滑，但滞后更大；
- EMA 的“指数”来自历史权重的指数衰减；
- 实现时只需要一个状态变量、一个滤波系数和一行更新公式；
- 初始值、采样周期、调参方式会显著影响实际效果；
- 它适合抑制随机高频噪声，不负责消除传感器系统性偏差。
