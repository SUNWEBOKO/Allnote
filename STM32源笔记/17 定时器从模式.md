# 17. 定时器从模式：复位、门控、触发

> 本节重点：搞清楚从模式不是"计数源"，而是"工作状态控制器"——控制计数器何时开始、暂停或复位。

## 1. 从模式的角色

从模式控制的是**计数器的工作状态**（何时开始/暂停/复位），而非计数时钟源本身。

```text
外部时钟模式 2 (ETR) → 独立配置时钟源
从模式（Reset/Gate/Trigger） → 控制计数器的启停复位行为
```

计数时钟可来自内部时钟或外部时钟模式 2，二者可与从模式配合使用。**关于外部时钟模式 1 和模式 2 的详细原理与配置，已在第 16 节专门讲解。**

---

## 2. 三种从模式对比

| 模式 | 触发条件 | 计数器行为 | 典型场景 |
|------|----------|-----------|----------|
| 复位模式（Reset） | 触发边沿 | 立即复位为 0，产生更新事件 | 外部事件同步对齐 |
| 门模式（Gated） | 触发电平 | 高电平计数，低电平暂停（或相反） | 测量信号门控时间 |
| 触发模式（Trigger） | 触发边沿 | 启动计数 | 外部信号启动定时 |

### 2.1 复位模式（Reset Mode）

触发边沿到来时：

```text
CNT → 立即复位为 0 → 产生更新事件（U事件） → 可能触发更新中断
```

适用于"被外部事件重新同步"或"外部信号对齐计数值基准"的场景。

### 2.2 门模式（Gated Mode）

触发输入电平控制计数开关：

```text
门开（有效电平）→ 计数器正常运行
门关（无效电平）→ 暂停计数，CNT 保持当前值
```

适用于测量信号电平持续时间、条件采样窗口等。

### 2.3 触发模式（Trigger Mode）

检测到触发边沿后启动计数。默认行为是"启动后持续计数，不自动停止"。

与单脉冲模式（One Pulse Mode）组合后可实现：**触发一次，跑完一轮就停。**

## 3. 标志位区分中断来源

定时器更新中断的来源可能有两种：

| 来源 | 说明 |
|------|------|
| ARR 回卷 | 计数器计到 ARR 正常溢出 |
| 从模式触发 | 复位模式触发边沿产生的更新事件 |

使用触发标志位区分：

```c
if (__HAL_TIM_GET_FLAG(&htimx, TIM_FLAG_UPDATE))
{
    if (__HAL_TIM_GET_FLAG(&htimx, TIM_FLAG_TRIGGER))
    {
        // 来源：从模式触发
        __HAL_TIM_CLEAR_FLAG(&htimx, TIM_FLAG_TRIGGER);
    }
    else
    {
        // 来源：ARR 正常回卷
    }
    // 清除更新标志
    __HAL_TIM_CLEAR_FLAG(&htimx, TIM_FLAG_UPDATE);
}
```

## 4. CubeMX 配置步骤

| 步骤 | 操作 |
|------|------|
| 1 | 选择定时器，配置基础参数（PSC/ARR） |
| 2 | 从模式选择 `Reset` / `Gated` / `Trigger` |
| 3 | 触发源选择 `TI1FP1` / `TI2FP2` / `ETRF` 等 |
| 4 | 设置触发边沿或极性和输入滤波 |
| 5 | 若需中断，在 NVIC 打开对应定时器中断 |
| 6 | `HAL_TIM_Base_Start_IT()` 启动 |

---

## 5. 常见现象：上电就进一次更新回调

某些初始化流程可能使更新标志位在启动前已经置位。

**解决方法**：在 `Start_IT` 前清除更新标志：

```c
__HAL_TIM_CLEAR_FLAG(&htimx, TIM_FLAG_UPDATE);
HAL_TIM_Base_Start_IT(&htimx);
```

---

## 6. 高频易错点

1. **门模式"看起来没生效"**。检查触发极性是否与实际输入电平匹配。

2. **复位模式与自动更新混淆**。使用触发标志位区分中断来源。

3. **触发模式"无法停"**。这是模式本身的特性——触发只负责启动，需配合单脉冲或软件停表。

4. **程序启动后立即触发一次**。启动前清 `UPDATE` 标志位。

5. **从模式和外部时钟模式 1 概念混用**。外部时钟模式 1 是从模式的一种特例；从模式不只有这个用途。

---

## 7. 一页速记

### 三种模式核心行为

| 模式 | 行为 | 触发条件 |
|------|------|----------|
| 复位 | 触发边沿 → 清零 CNT + 更新事件 | 边沿 |
| 门控 | 有效电平 → 计数；无效电平 → 暂停 | 电平 |
| 触发 | 触发边沿 → 开始计数 | 边沿 |

### 排查顺序
```text
触发源 → 极性 → 滤波 → 标志位
```

### 最重要的一句话
> 从模式不决定"用什么时钟来计数"，它决定"计数器什么时候工作"。
