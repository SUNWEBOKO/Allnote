> 本节重点：理解定时器输入捕获机制——边沿到来时硬件锁存 CNT 到 CCR，掌握利用上升沿+下降沿双通道测量脉宽的方法。

## 1. 超声波测距原理

HC-SR04 模块工作流程：

```text
给 Trig 引脚一个高电平脉冲 → 模块发射超声波
                           → Echo 引脚输出高电平（宽度 = 往返时间）
```

距离公式：

$$
distance_{\text{cm}} = \frac{pulse_{\text{time,us}} \times 0.034}{2}
$$

- `0.034 cm/μs`：声速约 `340 m/s` 换算成厘米/微秒后的近似值
- `÷2`：Echo 高电平宽度表示声波往返时间，测距要换成单程距离

---

## 2. 为什么用输入捕获

### 2.1 轮询方式的局限

- 软件读到上升沿后才启动计时，存在调度开销
- 软件读到下降沿后停止计时，存在读取延迟
- 精度受主循环频率和中断响应时间影响

### 2.2 输入捕获的优势

| 方式 | 捕获时刻 | 精度 | CPU 占用 |
|------|----------|------|----------|
| 轮询 GPIO | 软件检测到变化时 | 低（受循环周期影响） | 高 |
| 输入捕获 | 边沿到来瞬间硬件锁存 | 高（硬件级） | 低（中断后读取） |

> **输入捕获本质：边沿到来 → 硬件瞬间将 CNT 锁存到 CCR，程序随时读取都准确。**

---

## 3. 双通道捕获机制

### 3.1 单通道限制

一个输入捕获通道一次只能配置为上升沿或下降沿（不能同时捕获双边沿）。

### 3.2 通道配对

定时器通道有"直接/间接"配对关系：

| 配对组 | 直接模式 | 间接模式 |
|--------|----------|----------|
| 第 1 组 | CH1 | CH2 |
| 第 2 组 | CH3 | CH4 |

本例配置：

| 通道 | 模式 | 捕获边沿 | 作用 |
|------|------|----------|------|
| CH3 | 直接模式 | 上升沿 | 记录脉冲开始时刻 |
| CH4 | 间接模式（映射到 CH3 输入） | 下降沿 | 记录脉冲结束时刻 |

两通道共享同一输入信号 `Echo`，CH3 抓上升沿，CH4 抓下降沿。

| PA11 | Trig | GPIO 输出，触发超声波发射 |
| PA10 | Echo → TIM1_CH3 | 输入捕获，测量高电平宽度 |

## 6. HAL 代码实现

### 6.1 初始化

```c
HAL_TIM_Base_Start(&htim1);                           // 启动时基
HAL_TIM_IC_Start(&htim1, TIM_CHANNEL_3);              // CH3 捕获使能
HAL_TIM_IC_Start_IT(&htim1, TIM_CHANNEL_4);           // CH4 捕获中断使能
```

### 6.2 主循环触发测距

```c
void trigger_measurement(void)
{
    HAL_GPIO_WritePin(Trig_GPIO_Port, Trig_Pin, GPIO_PIN_SET);   // Trig 拉高
    HAL_Delay(1);                                                   // 保持 1ms
    HAL_GPIO_WritePin(Trig_GPIO_Port, Trig_Pin, GPIO_PIN_RESET); // Trig 拉低
    __HAL_TIM_SET_COUNTER(&htim1, 0);                               // 清零计数
    // 等待 CH4 下降沿中断通知测量完成
}
```

### 6.3 捕获回调

```c
extern volatile uint8_t measure_done;
extern volatile float distance_cm;

void HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim)
{
    if (htim->Instance == TIM1)
    {
        uint32_t up   = HAL_TIM_ReadCapturedValue(&htim1, TIM_CHANNEL_3); // 上升沿 CNT
        uint32_t down = HAL_TIM_ReadCapturedValue(&htim1, TIM_CHANNEL_4); // 下降沿 CNT

        if (down > up)
        {
            uint32_t pulse_us = down - up;
            distance_cm = pulse_us * 0.034f / 2.0f;
        }
        else
        {
            // down <= up，说明计数器在两次捕获之间发生了回卷（溢出）
            // 此时高电平已跨过 ARR 边界，实际脉宽需要用完整周期补偿：
            // pulse_us = (ARR + 1 - up) + down
            uint32_t pulse_us = (ARR_VAL + 1 - up) + down;
            distance_cm = pulse_us * 0.034f / 2.0f;
        }

        measure_done = 1;
    }
}
```

## 7. 工程细节

- **触发脉冲宽度**：HC-SR04 手册要求 Trig 脉冲至少 10μs。视频中用 `HAL_Delay(1)`（1ms）是为了简化，工程上建议用 `HAL_Delay(1)` 或微秒级延时
- **计数器清零**：每次触发前清零计数器，避免溢出干扰
- **浮点支持**：使用 `printf` 输出浮点数需在工程中开启浮点格式支持
- **测量盲区**：超声波易受目标材质、入射角度、近距离障碍物影响

---

## 8. 高频易错点

1. **忘记启动捕获通道**。只启动了时基（`Base_Start`）没启动 IC（`IC_Start`）。

2. **CH4 间接模式配置错误**。间接模式的触发源必须正确关联到对应通道组的输入。

3. **回调中不判断减法的正负**。未考虑计数器回卷时 `down < up` 的情况。

4. **触发脉冲宽度过短或漏发**。Trig 脉冲必须在模块规格范围内。

5. **printf 输出浮点异常**。未开启编译器的浮点格式支持。

## 9. 一页速记

### 输入捕获本质
```text
边沿到来 → 硬件锁存 CNT 到 CCR
```

### 测距本质
```text
测 Echo 高电平宽度 → pulse_us × 0.034 / 2 → distance_cm
```

### 配置本质
```text
一升（CH3 Rising）+ 一降（CH4 Falling）+ 通道配对 + 捕获中断
```

### 核心 API
| 函数 | 用途 |
|------|------|
| `HAL_TIM_IC_Start(tim, ch)` | 启动输入捕获 |
| `HAL_TIM_IC_Start_IT(tim, ch)` | 启动输入捕获（中断方式） |
| `HAL_TIM_ReadCapturedValue(tim, ch)` | 读取捕获的 CNT 值 |
| `HAL_TIM_IC_CaptureCallback()` | 捕获中断回调 |

### 最重要的一句话
> 输入捕获与 PWM 输出共享同一套定时器比较机制，只是一个"读时间"，一个"写时间"。
