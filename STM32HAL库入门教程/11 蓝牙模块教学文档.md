# 蓝牙串口通信与小程序控制

> 本节重点：理解蓝牙串口驱动对接方式与小程序通信协议，掌握数据包解析框架与绘图调参机制。

---

学完本节，需要能回答：

- 小程序通信协议的数据包格式是什么？方括号起什么作用？
- 如何在主循环中解析按键、滑杆、摇杆三种数据包？

## 1. 驱动对接

### 1.1 硬件连接

| 蓝牙模块 | STM32 / USB 转串口 |
|----------|-------------------|
| TXD | RXD |
| RXD | TXD |
| GND | GND |
| VCC | 3.3V 或 5V（查模块手册） |

要点：

- TXD ↔ RXD **必须交叉**；
- 必须共地，否则电平无参考点；
- 供电电压以模块手册为准，不确定时优先用 3.3V。

---

### 1.1.1 首次使用：波特率与配对（最容易卡住的环节）

很多入门者卡在"串口助手能看到数据，小程序搜不到设备"或"能连上但收不到东西"，绝大多数是下面两步没做：

1. **波特率必须一致**：经典蓝牙串口模块（HC-05/HC-06/BT24）出厂波特率通常是 `9600`，也有模块是 `115200`。CubeMX 里 USART 波特率要和模块一致，两边不一致时，收/发会全是乱码。
2. **模块需要先配对**：模块上电后进入 AT 配置模式（HC-05 按住按键上电进入 AT 模式，AT 指令波特率常见 `38400`），常用指令：

| AT 指令 | 作用 |
|---------|------|
| `AT` | 测试通信，返回 `OK` |
| `AT+NAME=xxx` | 改蓝牙名称 |
| `AT+PSWD=1234` | 改配对密码（默认多为 1234） |
| `AT+UART=9600,0,0` | 改波特率（HC-05 指令格式） |
| `AT+ROLE=1` | 设为主模式（HC-05；HC-06 只支持从机，无需设置） |

设置完后**重新上电**才生效，再打开手机蓝牙配对（输入密码），然后小程序才能搜索/连接。

另外：蓝牙模块的串口电平多为 3.3V，和 STM32 直连通常没问题；如果模块手册标注需要 5V 逻辑，就要加电平转换，不要直接硬接。

> 工程中已有的蓝牙串口驱动源码位于 `E:\ProjectStm\驱动库\蓝牙串口通信`，接口与下文 API 表一致。

### 1.2 驱动 API

```c
#include "bluetooth_serial.h"
```

| 函数 | 作用 |
|------|------|
| `BluetoothSerial_Init(huart)` | 初始化，启动中断接收 |
| `BluetoothSerial_SendString(str)` | 发送字符串（阻塞发送，50ms 超时） |
| `BluetoothSerial_Printf(format, ...)` | 格式化发送（内部调用 SendString） |
| `BluetoothSerial_OnUartRxCplt(huart)` | 串口接收中断处理（HAL 回调的入口） |

全局标志：

```c
extern char Bluetooth_RxPacket[BT_RX_PACKET_SIZE];   // 当前完整数据包（不含 [ ]）
extern volatile uint8_t Bluetooth_RxFlag;             // 收到完整包后置 1，用户清零
```

协议帧定界：

```text
[ ... ]   →   收到 [ 开始接收，收到 ] 结束，中间内容存入 Bluetooth_RxPacket
```

---

### 1.3 集成步骤

```c
// Step 1 — 初始化（传入已配置好的 UART 句柄）
BluetoothSerial_Init(&huart1);

// Step 2 — 在工程统一的 HAL 回调中路由
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    BluetoothSerial_OnUartRxCplt(huart);
    // 其他 UART 接收模块也在这里分发
}

// Step 3 — 主循环检查 Bluetooth_RxFlag
while (1)
{
    if (Bluetooth_RxFlag)
    {
        char packet[BT_RX_PACKET_SIZE];
        memcpy(packet, Bluetooth_RxPacket, sizeof(packet));
        __disable_irq();
        Bluetooth_RxFlag = 0;
        __enable_irq();
        packet[sizeof(packet) - 1U] = '\0';
        ParsePacket(packet);
    }
}
```

当前配套驱动源码自身定义了 `HAL_UART_RxCpltCallback()`，单独使用时可以工作，但与其他也需要 UART 回调的模块会发生重复定义。工程集成时应让驱动只暴露 `BluetoothSerial_OnUartRxCplt()`，由应用层唯一的 HAL 回调统一分发。

必须先复制完整包，再清 `Bluetooth_RxFlag`。当前驱动在标志为 1 时不会改写包缓冲区，所以复制过程本身不必关中断，只需在复制完成后用极短临界区清标志。若先清标志再直接解析全局缓冲区，ISR 会立即允许接收下一包，主循环可能解析到被覆盖的数据。

发送示例：

```c
BluetoothSerial_SendString("hello");
BluetoothSerial_Printf("[display,0,0,voltage:%d]", adc_value);
```

## 2. 小程序通信协议

### 2.1 统一格式

所有数据包采用统一结构：

```text
[类型,参数1,参数2,...]
```

- 包定界符：`[` 为包头，`]` 为包尾
- 参数间以英文逗号 `,` 分隔
- 驱动接收后 `Bluetooth_RxPacket` 中**不包含方括号**，仅保留中间内容

### 2.2 按键 — `K`

```text
[K,按键名称,down]     // 按下
[K,按键名称,up]       // 松开
```

| 字段 | 说明 |
|------|------|
| K | 按键标识符 |
| 按键名称 | 用户在小程序中设置的按键名 |
| down / up | 按下 / 松开 |

示例：

```text
[K,LED,down]
[K,forward,up]
```

### 2.3 滑杆 — `slider`

```text
[slider,滑杆名称,值]
```

| 字段 | 说明 |
|------|------|
| slider | 滑杆标识符 |
| 滑杆名称 | 用户设置的滑杆名 |
| 值 | 浮点数或整数格式 |

示例：

```text
[slider,Kp,3.25]
[slider,target,80]
```

### 2.4 摇杆 — `joystick`

```text
[joystick,左横向,左纵向,右横向,右纵向]
```

| 字段 | 说明 |
|------|------|
| joystick | 摇杆标识符 |
| 左横向 / 左纵向 / 右横向 / 右纵向 | 值范围 -100 ~ 100 |

示例：

```text
[joystick,0,100,0,0]
[joystick,-50,80,20,-10]
```

### 2.5 显示屏 — `display`

```text
[display,X,Y,内容,字号]
```

| 字段 | 说明 |
|------|------|
| display | 显示屏标识符 |
| X, Y | 显示坐标（像素） |
| 内容 | 显示文本 |
| 字号 | 可选，默认 18 |

清屏：

```text
[display-clear]
```

### 2.6 绘图 — `plot`

```text
[plot,值1]               // 单条曲线
[plot,值1,值2,值3]       // 多条曲线
```

示例：

```text
[plot,0]
[plot,50,-20,100]
```

清空绘图区：

```text
[plot-clear]
```

## 3. 绘图

### 3.1 单曲线示例

```c
float x = 0.0f;
float y = 0.0f;

while (1)
{
    x += 0.1f;
    y = sinf(x);
    BluetoothSerial_Printf("[plot,%f]", y);
    HAL_Delay(50);
}
```

### 3.2 多曲线示例

```c
float y1 = sinf(x);
float y2 = cosf(x);
BluetoothSerial_Printf("[plot,%f,%f]", y1, y2);
```

发送太快可能造成数据拥堵。`50~100 ms` 只能作为当前小程序和短数据包的起始值；实际最短间隔要由波特率、每包字节数、阻塞发送时间和小程序处理能力共同决定，并用丢包计数验证。

### 3.3 坐标轴设置（小程序端）

- Y 轴自动缩放：小程序默认开启，可取消后手动设置 Ymin / Ymax；
- X 轴点数：控制显示窗口宽度；
- 固定 Y 轴范围适合观察固定幅值信号（如正弦波设为 -2 ~ 2）。

## 4. 调参

### 4.1 滑杆配置建议

| 参数 | 建议最小值 | 建议最大值 | 建议步距 |
|------|-----------|-----------|---------|
| Kp | 0 | 10 | 0.01 |
| Ki | 0 | 5 | 0.001 |
| Kd | 0 | 1 | 0.001 |
| 目标速度 | -100 | 100 | 1 |

### 4.2 参数落地原则

滑杆参数不能从字符串直接写入控制器。推荐顺序是：

```text
局部副本分字段 -> 检查字段数量 -> 严格转换数值 -> 检查有限性和范围 -> 更新参数
```

例如 $K_p$、$K_i$、$K_d$ 应分别设置项目允许的上下限。转换失败、出现 `NaN/Inf`、字段缺失或数值越界时，本包直接丢弃，保留上一组有效参数。

### 4.3 统一解析入口

按键、滑杆和摇杆都应进入同一个 `ParsePacket()`，再按首字段分派。解析只操作主循环复制出的局部包，不在 UART ISR 中执行；完整的显式游标实现见下一节。

## 5. 完整解析框架

```c
#include <string.h>
#include <stdlib.h>
#include <stdio.h>
#include <math.h>

static float Kp = 0.0f, Ki = 0.0f, Kd = 0.0f;
static int8_t LH = 0, LV = 0, RH = 0, RV = 0;

static char *NextField(char **cursor)
{
    if (!cursor || !*cursor || **cursor == '\0') return NULL;
    char *field = *cursor;
    char *comma = strchr(field, ',');
    if (comma) {
        *comma = '\0';
        *cursor = comma + 1;
    } else {
        *cursor = NULL;
    }
    return field;
}

static int ParseFloat(const char *text, float min, float max, float *out)
{
    if (!text || !out) return 0;
    char *end = NULL;
    float value = strtof(text, &end);
    if (end == text || *end != '\0' || !isfinite(value) ||
        value < min || value > max) return 0;
    *out = value;
    return 1;
}

static void ParseKey(char **cursor)
{
    char *name = NextField(cursor);
    char *action = NextField(cursor);
    if (!name || !action || NextField(cursor) != NULL) return;

    if (strcmp(name, "LED") == 0 && strcmp(action, "down") == 0)
        BluetoothSerial_Printf("[display,0,0,LED:ON]");
    else if (strcmp(name, "LED") == 0 && strcmp(action, "up") == 0)
        BluetoothSerial_Printf("[display,0,0,LED:OFF]");
}

static void ParseSlider(char **cursor)
{
    char *name = NextField(cursor);
    char *value = NextField(cursor);
    if (!name || !value || NextField(cursor) != NULL) return;

    if (strcmp(name, "Kp") == 0)
        (void)ParseFloat(value, 0.0f, 10.0f, &Kp);
    else if (strcmp(name, "Ki") == 0)
        (void)ParseFloat(value, 0.0f, 5.0f, &Ki);
    else if (strcmp(name, "Kd") == 0)
        (void)ParseFloat(value, 0.0f, 1.0f, &Kd);
}

static void ParseJoystick(char **cursor)
{
    float value[4];
    for (int i = 0; i < 4; ++i) {
        if (!ParseFloat(NextField(cursor), -100.0f, 100.0f, &value[i])) return;
    }
    if (NextField(cursor) != NULL) return;
    LH = (int8_t)value[0]; LV = (int8_t)value[1];
    RH = (int8_t)value[2]; RV = (int8_t)value[3];
}

void ParsePacket(char *packet)
{
    char *cursor = packet;
    char *tag = NextField(&cursor);
    if (!tag) return;

    if (strcmp(tag, "K") == 0)              ParseKey(&cursor);
    else if (strcmp(tag, "slider") == 0)    ParseSlider(&cursor);
    else if (strcmp(tag, "joystick") == 0)  ParseJoystick(&cursor);
}
```

主循环：

```c
while (1)
{
    if (Bluetooth_RxFlag)
    {
        char packet[BT_RX_PACKET_SIZE];
        memcpy(packet, Bluetooth_RxPacket, sizeof(packet));
        __disable_irq();
        Bluetooth_RxFlag = 0;
        __enable_irq();
        packet[sizeof(packet) - 1U] = '\0';
        ParsePacket(packet);
    }
}
```

当前协议和驱动还有明确边界：

- 接收缓冲区最多保存一个完整包；主循环未消费时，新包会被忽略。
- 包内容不能无约定地包含 `,`、`[` 或 `]`；若显示文本需要这些字符，应增加转义或长度字段。
- 超长帧会被丢弃并重新寻找下一处 `[`，应用层应记录溢出次数。
- 参数必须先校验完整性和范围，再写入 PID、电机等执行逻辑。

## 6. 一页速记

### 6.1 硬件连线

```text
蓝牙 TXD → STM32 RXD
蓝牙 RXD → STM32 TXD
GND → GND（共地）
```

### 6.2 协议格式

| 类型 | 格式 |
|------|------|
| 按键 | `[K,名称,down/up]` |
| 滑杆 | `[slider,名称,值]` |
| 摇杆 | `[joystick,LH,LV,RH,RV]` |
| 显示 | `[display,X,Y,内容]` |
| 绘图 | `[plot,值1,值2,...]` |
| 清屏 | `[display-clear]` / `[plot-clear]` |

### 6.3 核心 API

| 函数 | 作用 |
|------|------|
| `BluetoothSerial_Init(huart)` | 初始化，启动中断接收 |
| `BluetoothSerial_Printf(fmt, ...)` | 格式化发送 |
| `Bluetooth_RxFlag` | 收到完整包后置 1，用户清零 |

### 6.4 解析框架

```c
void ParsePacket(char *packet)
{
    char *cursor = packet;
    char *tag = NextField(&cursor);
    if (!tag) return;

    if (strcmp(tag, "K") == 0)              ParseKey(&cursor);
    else if (strcmp(tag, "slider") == 0)    ParseSlider(&cursor);
    else if (strcmp(tag, "joystick") == 0)  ParseJoystick(&cursor);
}
```

### 6.5 绘图要点

- 发送间隔：从 50~100ms 起测，再按波特率、包长和丢包情况调整
- Y 轴：先自动缩放，需要时固定范围
- 解析局部副本并使用显式游标，避免 `strtok` 的全局状态和不可重入问题
