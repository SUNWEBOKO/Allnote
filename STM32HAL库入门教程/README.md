# STM32 HAL 库入门教程

## 学习目标

- 从零建立并下载 STM32F103 HAL 工程。
- 按外设原理配置 CubeMX 并编写驱动。
- 用可观察的实验结果验证外设功能。
- 根据症状定位接线、配置和代码问题。

这套教程面向已经接触 C 语言、准备动手学习 STM32F103 HAL 的读者。各章按“外设原理 → CubeMX 配置 → 自己编写程序与驱动 → 上板验证”推进；参考工程用于核对配置和排查故障，练习工程由自己建立。

## 5. 每章的固定闭环

1. 先读"本章问题"和学习目标；
2. 在 `MyCode` 中按本章步骤新建工程（第 0 章教过完整流程；时间紧时可复制模板，但改名步骤不能省）；
3. 按章节要求完成 CubeMX 配置；
4. 只在 `User/` 或 `USER CODE` 区域写自己的代码；
5. 用 VS Code 官方 STM32 插件编译、下载和调试；
6. 记录接线、参数、现象和失败原因；
7. 通过本章验收后再进入下一章。

记录接线、参数、预期现象、实际现象和处理过程，后续排查同一块板子上的问题时就能直接对照。

## 6. 结论标记

教程中每个关键结论尽量标注可信级别：

- **代码事实**：可以在配套工程、`.ioc` 或构建结果中核对；
- **课程参考**：来自原教程或参考工程，不能自动当作本机实测；
- **待实测**：必须在自己的开发板、传感器和接线条件下验证。

## 7. 安全提醒

首次上电先断开电机、传感器和高功率负载。软件停止不能替代硬件断电、限流和急停。教程中的 LED、按键、总线和传感器现象，最终以自己的实验记录为准。
