# STM32 HAL 库入门教程

## 学习目标

- 从零建立并下载 STM32F103 HAL 工程。
- 按外设原理配置 CubeMX 并编写驱动。
- 用可观察的实验结果验证外设功能。
- 根据症状定位接线、配置和代码问题。

这套教程面向已经接触 C 语言、准备动手学习 STM32F103 HAL 的读者。各章按"外设原理 → CubeMX 配置 → 自己编写程序与驱动 → 上板验证"推进。

## 0. 实验环境

阅读示例代码会用到变量、函数、指针、结构体和位运算；接线时需要辨认电源极性并保证共地。寄存器和单片机机制会在相关章节就地引入，不需要提前学完。

**软件**（版本为模板基线，前后相近版本一般可照做）：

| 软件 | 用途 |
| --- | --- |
| STM32CubeMX 6.17.0 | 图形化配置芯片、生成初始化代码 |
| VS Code + STM32 官方扩展 | 编辑、编译、下载、调试 |
| CMake + Ninja + arm-none-eabi-gcc | 实际构建链，由 STM32 扩展调起。源文件清单登记在 `CMakeLists.txt`，与第 00 章第 5 节一致 |
| STM32Cube FW_F1 V1.8.7 | HAL 库固件包（CubeMX 管理） |
| ST-LINK 驱动 | 让 Windows 识别下载器 |

**硬件**（按章节逐步引入，以各章接线表为准）：

- STM32F103C8T6 最小系统板 + ST-LINK V2 下载器（第 0 章起，全程使用）；
- LED、限流电阻、轻触按键（第 1 章）；
- 0.96 寸 OLED（SSD1306，I2C 接口，第 2、6、7、9、10 章反复用作显示）；
- 红外对管、旋转编码器（第 4、5 章）；
- SG90 舵机、TB6612FNG 电机驱动 + 直流减速电机（第 5 章）；
- 电位器或光敏电阻分压电路等模拟输入（第 6、7 章）；
- USB 转 TTL 串口模块（第 8 章连接电脑；USART3 迁移时也可接蓝牙透传模块）；
- MPU6050 六轴传感器模块（第 9 章）；
- W25Q64 Flash 存储模块（第 10 章）；
- 面包板、杜邦线若干。

## 1. 工具流程与代码边界

- 工具流程：STM32CubeMX 生成外设代码，VS Code 官方 STM32 插件配合 CMake 完成编译、下载和调试
- 代码边界：CubeMX 管理 `Core/`；自己编写的代码放在 `User/` 或 CubeMX 的 `USER CODE` 区域
- 驱动来源：各章先手写 HAL 直调看清原理，再用 `E:\ProjectStm\驱动库` 里的同名驱动收口。默认引脚与参数以 `E:\ProjectStm\PIDproject\01 PID` 当前工程为基准，引脚、句柄等集中在各自 `.h` 顶部的宏；换实验接线时，宏与 CubeMX 配置一起改，调用接口保持一致；完整清单见驱动库 `README.md`。

学完基础课程后，接着做 [[STM32倒立摆/00 项目背景与技术|STM32 倒立摆实验]]。它复用这些接口，把本教程分开练习的按键、时基、采样、电机、编码器和显示组合起来；对应关系见 [[STM32倒立摆/03 基础驱动：CubeMX与HAL库实现#1.5 与入门教程共用驱动|倒立摆驱动配置表]]。倒立摆文档保留 PID 工程固定引脚的代码，入门教程用其宏定义版，不要求两份源文件逐字相同。宏版保留格式化输出限长；MOTOR 与倒立摆一样直接写 CCR，不控 STBY，限幅放主程序。

倒立摆系列目前完成到基础驱动（第 03 篇），控制程序尚未落地；本教程不依赖其后续内容。`03` 篇第 1.5 节是两套文档的共同接口表，列出各驱动的宏位置与 PID 默认配置。

资源分配按章切换，不是一套工程通吃：显示默认用软件 I2C（`PB8/PB9`）；06、07 章 `PB10/PB11` 空闲，OLED 接硬件 I2C2；09 章起 `PB10/PB11` 归 MPU6050，10 章的 SPI 又占用 `PA4~PA7`，OLED 回到软件版；08 章的 USART3 也与 I2C2 共用 `PB10/PB11`。换章时按该章接线表恢复，不要带着上一章的引脚配置继续。

## 2. 怎么读每一章

每章默认从第 00 章的模板工程派生；同一章有多个实验时各自建工程，不把不同外设配置混在一起。正文第一次用到某块屏或某个驱动时会注明沿用了哪一章，换版本时先看那句。

每章的结构大致相同，读第一遍时按顺序走，回查时直接跳到对应位置：

| 位置   | 作用                             |
| ---- | ------------------------------ |
| 本章问题 | 先接住上一章的结果，再抛出这一章要回答什么          |
| 学习目标 | 读完应当能做到的几件事                    |
| 正文   | 外设原理 → CubeMX 配置 → 最小代码 → 预期现象 |
| 章末导航 | 上一篇、下一篇的跳转链接                   |

每章的预期现象写在对应实验末尾，那是核对结果的地方；遇到与预期不符的现象时，回到该实验的接线表和 CubeMX 配置项逐项核对。

## 4. 逐章一览：每章解决什么问题

按表中名称自行建立独立子工程，一个实验一个目录，方便单独调试。目录名用于说明组织方式，不代表本笔记目录内已附完整可编译工程；建工程和登记源文件的方法见第 00 章。

| 章   | 解决的问题                      | 完成后你能做到                  | 子工程目录 |
| --- | -------------------------- | ------------------------ | --- |
| 00  | 建立可编译、可下载的工程底座             | 跑通工具链，LED 闪烁             | 模板工程（后续各章由它派生） |
| 01  | 选对 GPIO 模式，点亮 LED、读取按键     | 读写任意引脚，按"现象"定位接线错误       | 实验一（输出）、实验二（按键输入） |
| 02  | 让 OLED 显示内容，软硬件两种 I2C 都能驱动 | 换驱动只改接线和 CMake，显示代码一字不动  | 硬件 `I2C2` 版与软件 `PB8/PB9` 版 |
| 03  | 看懂时钟树，把主频配到 72 MHz         | 解释每个外设的时钟从哪来             | 两套 `.ioc`：HSI `8 MHz` 对照、`72 MHz` 实验（见 3.1 节对照表） |
| 04  | 用中断处理突发事件，避免主循环持续轮询        | 配置 EXTI 和 NVIC 优先级       | `01_IR_PB14`、`02_Encoder_PB0_PB1` |
| 05  | 用定时器生成周期事件、PWM 并捕获输入信号     | 呼吸灯、舵机、电机调速、测频测占空比、测速    | `03_PWM_LED`、`04_PWM_Servo`、`05_Motor`，另有实验一/二/六/七（时基、外部计数、输入捕获、编码器） |
| 06  | 把模拟电压变成数字：单次非扫描            | 单次非扫描采集电位器，理解量化和采样时间     | `01_Basic` |
| 07  | 让 DMA 替 CPU 搬数据，做多通道 ADC   | 内存拷贝、ADC 多通道自动采集与定时触发采样  | `02_ADC_Scan`、`03_ADC_TimerTrigger`，另有实验一（内存到内存） |
| 08  | 串口轮询、中断、DMA 与不定长接收        | 按场景选轮询、中断或 DMA           | `01_UART2_Polling`、`02_UART2_IT`、`03_UART2_DMA`、`04_UART2_ReceiveToIdle` |
| 09  | 讲透 I2C 时序，再用软、硬两种方式读六轴数据   | 自己写出 I2C 时序，读取加速度和角速度并换算 | 软件 I2C 版与 HAL 硬件 I2C 版 |
| 10  | SPI 时序与 Flash 读写           | 软、硬 SPI 驱动 W25Q64 存取数据   | `01_SoftSPI_GPIO`、`02_HardSPI_HAL`、`03_HardSPI_Library` |

把这张表和外设分配放在一起看，进入倒立摆时会更顺：01/02/05/06/08 的 LED、OLED、定时器/电机/编码器、RP、串口驱动会按同一套接口进入综合工程（引脚用宏改到倒立摆总表），03/04/07 提供时钟、中断和 DMA 基础；09 的 MPU6050、10 的 W25Q64 属于扩展外设，倒立摆基础版不使用。10 章的 `PA4~PA7` 与倒立摆的 `RP3/RP4`、编码器 A/B 重叠，单独实验可以，合并工程必须重新分配引脚。
