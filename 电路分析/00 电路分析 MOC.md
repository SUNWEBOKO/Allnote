## 2 三条主线

**电阻电路：定律 → 等效 → 列方程 → 定理。** KCL、KVL 与元件伏安关系是全部依据；等效变换在结构规整时化简电路，网孔法与结点法在结构复杂时系统列方程，电路定理则利用线性性质拆分电源或压缩端口。第 01 章的功率守恒与唯一性是所有方法的共同检查手段；第 02 章的端口等效只保证外部关系，第 03 章的矩阵规则有明确边界，第 04 章的每个定理都依赖线性、时不变或解唯一中的某几条。

**动态电路：储能元件 → 初始值 → 三要素 → 二阶。** 电容电压与电感电流不能跃变，由此确定初始值；一阶电路的响应由初始值、稳态值和时间常数完全确定，三要素公式来自戴维南等效后的一阶微分方程；二阶电路由特征根区分过阻尼、临界阻尼与欠阻尼，两个初始条件缺一不可。阶跃响应与冲激响应通过求导联系，冲激的作用是给状态量一个可计算的跳变。

**正弦稳态：相量 → 阻抗 → 功率 → 推广。** 相量把微分方程变成复数代数方程，电阻电路的方法全部迁移到阻抗电路；在此基础上处理耦合电感、谐振与频率响应、三相电路；非正弦周期激励按频率拆开、逐个用相量法；非线性电路在工作点附近线性化后，又回到线性电路的方法。相量法、谐波分析法、小信号法各自有三个前提，使用时先核对前提，再动笔。

## 3 统一记号与约定

| 记号 | 含义 |
| --- | --- |
| $u,i$ | 瞬时值 |
| $U,I$ | 直流量或有效值 |
| $U_m,I_m$ | 最大值（振幅） |
| $\dot U,\dot I$ | 有效值相量 |
| $Z=R+jX$、$Y=G+jB$ | 阻抗、导纳 |
| $U_{oc}$、$I_{sc}$、$R_{eq}$ | 开路电压、短路电流、等效电阻 |
| $\tau$ | 时间常数 |
| $\alpha$、$\omega_0$、$\omega_d$ | 衰减系数、固有角频率、衰减振荡角频率 |
| $\omega_0$、$Q$、$\rho$ | 谐振角频率、品质因数、特性阻抗 |
| $P$、$Q$、$S$、$\bar S$ | 有功、无功、视在、复功率 |
| $U_P,I_P$、$U_L,I_L$ | 三相的相量值、线量值 |
| $k$、$M$、$n$ | 耦合系数、互感、理想变压器变比 |
| $r_d$、$g_d$、$C_d$、$L_d$ | 动态电阻、动态电导、动态电容、动态电感 |
| $\lambda$、$\mathrm{THD}$ | 功率因数、总谐波畸变率 |

约定：

- 电阻、电容、电感默认取关联参考方向；吸收功率关联方向下为 $p=ui$，非关联为 $p=-ui$。
- 正弦量统一用正弦函数作基准，相量的模取有效值。
- 无功功率 $Q$ 与品质因数 $Q$ 同字母，按上下文区分。
- 电源置零：电压源短路、电流源开路，受控源保留。
- 理想变压器取 $n=N_1/N_2$，阻抗由二次侧折算到一次侧乘 $n^2$。
- 三相默认正序 A→B→C；线量下标用双字母，相量下标用单字母加 $P$。

## 4 常用结论速查

| 主题 | 结论 |
| --- | --- |
| 独立方程数 | KCL $n-1$ 个，KVL $b-n+1$ 个 |
| 电桥平衡 | $R_1R_4=R_2R_3$ 时桥臂无电流，可断开或短接 |
| 对称 Y-Δ | $R_\Delta=3R_Y$；Δ→Y 用相邻边乘积除以三边之和 |
| 电源变换 | $u_s$ 串 $R$ $\iff$ $u_s/R$ 并 $R$ |
| 叠加定理 | 只叠加电压、电流；功率先合成再算 |
| 戴维南与诺顿 | $U_{oc}=R_{eq}I_{sc}$；含受控源用外加电源法 |
| 最大功率 | $R_L=R_{eq}$，$P_{\max}=\dfrac{U_{oc}^2}{4R_{eq}}$；交流 $Z_L=Z_{eq}^*$ |
| 换路定则 | $u_C(0^+)=u_C(0^-)$，$i_L(0^+)=i_L(0^-)$ |
| 三要素法 | $f(t)=f(\infty)+[f(0^+)-f(\infty)]e^{-t/\tau}$，$\tau=R_{eq}C$ 或 $L/R_{eq}$ |
| 二阶串联 RLC | $\alpha=\dfrac R{2L}$，$\omega_0=\dfrac1{\sqrt{LC}}$；$\alpha$ 与 $\omega_0$ 比较定阻尼类型 |
| 元件相量关系 | $\dot U_L=j\omega L\dot I$，$\dot U_C=\dfrac{\dot I}{j\omega C}$ |
| 正弦功率 | $P=UI\cos\varphi$，$Q=UI\sin\varphi$，$\bar S=\dot U\dot I^*$ |
| 功率因数补偿 | $C=\dfrac{P}{\omega U^2}(\tan\varphi_0-\tan\varphi)$ |
| 耦合电感串联 | $L_1+L_2\pm2M$；并联 $\dfrac{L_1L_2-M^2}{L_1+L_2\mp2M}$ |
| 引入阻抗 | $Z_{ref}=\dfrac{(\omega M)^2}{Z_{22}}$ |
| 串联谐振 | $U_L=U_C=QU_s$，$Q=\dfrac1R\sqrt{\dfrac LC}$，$\Delta\omega=\dfrac{\omega_0}{Q}$ |
| 并联谐振 | $Z_{\max}=R$，$Q=\dfrac{R}{\omega_0L}$，$\Delta\omega=\dfrac1{RC}$ |
| 三相对称 | Y：$U_L=\sqrt3U_P$；Δ：$I_L=\sqrt3I_P$；$P=\sqrt3U_LI_L\cos\varphi$ |
| 非正弦有效值 | $I=\sqrt{I_0^2+I_1^2+I_2^2+\cdots}$ |
| 非正弦平均功率 | $P=U_0I_0+\sum U_kI_k\cos\varphi_k$ |
| 动态电阻 | $r_d=\left.\dfrac{\mathrm{d}u}{\mathrm{d}i}\right|_Q$；二极管 $r_d=U_T/I_D$ |

## 5 复习路径

第一轮按 01→04 打通电阻电路：先把参考方向、功率符号和 KCL/KVL 练熟，再用等效变换和列方程处理结构复杂的网络，最后用定理减少计算量。第二轮按 05→08 处理储能与正弦稳态：一阶、二阶电路的共同问题是初始值和微分方程，正弦稳态的共同问题是相量与阻抗；耦合电感只是把互感项补进 KVL，谐振只是阻抗虚部为零的特殊频率。第三轮按 09→11 推广：三相是单相正弦稳态的对称组合，非正弦是多个单频问题的叠加，非线性是在工作点附近的线性化。每章末尾的小结给出该章方法链，遇到跨章题时先判断它属于哪条主线，再调用对应方法。
