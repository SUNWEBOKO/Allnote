# 变压器原理与分析方法

变压器是电工学与电路原理中的核心电磁设备。理论分析从空心变压器入手建立互感模型，再通过三个理想化条件过渡到理想变压器。前者揭示电磁耦合的本质，后者提供简洁实用的工程分析工具。

---

## 空心变压器模型

空心变压器不含铁磁材料芯，两个线圈仅通过空气（或非铁磁性介质）进行互感耦合。虽然实际电力变压器必须依赖高磁导率铁芯来减少漏磁并提高耦合效率，但空心模型排除了铁芯非线性和磁滞损耗的干扰，是建立变压器纯线性电路方程的基础。

### 电路结构与参考方向

一次侧（原边）回路接入交流电压源 $u_s$，包含线圈电阻 $R_1$ 和自感 $L_1$。二次侧（副边）回路包含线圈电阻 $R_2$、自感 $L_2$，并连接负载阻抗 $Z_L$。两线圈之间存在互感 $M$。

一次侧回路总自阻抗：
$$
Z_{11} = R_1 + j\omega L_1
$$

二次侧回路总自阻抗（含负载）：
$$
Z_{22} = R_2 + j\omega L_2 + Z_L
$$

**电流参考方向的设定原则：**
一次侧电流 $i_1$ 通常设定为从电压源正端流入线圈。二次侧电流 $i_2$ 的设定需根据分析视角决定：若将变压器视为双口网络，$i_2$ 通常设为从二次侧端口流出；若从负载回路分析，$i_2$ 的方向应使负载电压与电流满足关联参考方向。解题时必须首先明确题目给定的参考方向，因为这直接决定了互感电压项的正负号。

### 回路方程与互感电压符号判定

对一、二次侧分别列写 KVL 方程。互感电压项的符号由**同名端位置**和**电流参考方向**共同决定，这是空心变压器分析中最易出错的环节。

假设两线圈的同名端均在上方，$i_1$ 流入同名端，$i_2$ 流出同名端（即从二次侧上端流出并流入负载），回路方程为：
$$
u_s = Z_{11} i_1 - j\omega M i_2
$$
$$
0 = Z_{22} i_2 - j\omega M i_1
$$

**互感电压符号判定规则（在本节的参考方向设定下）：**
1. 确定电流流入自身线圈的端子是否为同名端。若 $i_1$ 流入同名端，则它在二次侧感应的互感电压的正极也在二次侧的同名端。
2. 观察受感回路电流的参考方向：若 $i_2$ 从同名端流出，则互感电压与 $i_2$ 方向相反，方程中取负号；若 $i_2$ 也流入同名端，则取正号。
3. 题设方向一旦改变，上述两式中的 $\pm$ 号必须相应调整。

解上述方程组，可得一、二次侧电流：
$$
i_1 = \frac{u_s}{Z_{11} + \dfrac{(\omega M)^2}{Z_{22}}}
$$
$$
i_2 = \frac{j\omega M}{Z_{22}} i_1
$$
计算时，通常先利用第一个公式求出 $i_1$，再代入第二个公式求 $i_2$。

### 引入阻抗（反应阻抗）

在分析一次侧回路时，二次侧回路通过互感对一次侧产生的影响，可以等效为一个串联在一次侧回路中的阻抗，称为**引入阻抗**（或反应阻抗）$Z_{\text{ref}}$：
$$
Z_{\text{ref}} = \frac{(\omega M)^2}{Z_{22}}
$$
引入阻抗将互感耦合解耦为一次侧的串联电路——一次侧只需面对自身的 $Z_{11}$ 和一个折算而来的 $Z_{\text{ref}}$，不再需要直接处理二次侧变量。

对 $Z_{\text{ref}}$ 进行分母有理化，分离实部与虚部：
$$
Z_{\text{ref}} = \frac{(\omega M)^2}{R_{22} + jX_{22}} = \frac{(\omega M)^2}{R_{22}^2 + X_{22}^2} R_{22} - j \frac{(\omega M)^2}{R_{22}^2 + X_{22}^2} X_{22}
$$
其中，实部为**引入电阻** $R_{\text{ref}}$，虚部为**引入电抗** $X_{\text{ref}}$。

引入阻抗具有两个关键特性：
1. **引入电阻恒为正**：代表二次侧回路消耗的有功功率（含二次侧铜损和负载功率）等效折合到一次侧的电阻。
2. **引入电抗性质反转**：$X_{\text{ref}}$ 的符号与二次侧总电抗 $X_{22}$ 恒相反。若二次侧呈感性（$X_{22} > 0$），反射到一次侧的引入电抗呈容性（$X_{\text{ref}} < 0$），反之亦然。这一特性源于 $X_{\text{ref}}$ 表达式中 $X_{22}$ 前的负号，在谐振分析和阻抗补偿中必须留意。

### 等效电路与功率计算

将引入阻抗串入一次侧回路，即可得到二次侧折合到一次侧的等效电路：

从电源端看入的**输入阻抗**为：
$$
Z_{\text{in}} = Z_{11} + Z_{\text{ref}}
$$
一次侧电流可直接由欧姆定律计算：
$$
i_1 = \frac{u_s}{Z_{\text{in}}}
$$
求得 $i_1$ 后，通过 $i_2 = \dfrac{j\omega M}{Z_{22}} i_1$ 得到二次侧电流。这种方法将耦合电路"解耦"为普通串联电路，计算流程清晰。

同理，也可将一次侧折合到二次侧——此时需在二次侧用一个受控电压源 $j\omega M i_1$ 等效一次侧的影响。先求开路电压 $u_{\text{oc}} = j\omega M i_1\big|_{i_2=0}$，再求戴维宁等效阻抗，最后接上负载求解。两种等效方式结果完全一致，选择哪种取决于题目要求从哪一侧分析。

变压器的总有功功率消耗等于一次侧和二次侧损耗之和。利用等效电路计算最为简便：
$$
P_{\text{total}} = |i_1|^2 (R_1 + R_{\text{ref}})
$$
式中，$|i_1|^2 R_1$ 为一次侧线圈铜损；$|i_1|^2 R_{\text{ref}}$ 代表了二次侧回路消耗的总有功功率（包含二次侧铜损与负载有功功率）。直接从二次侧计算 $|i_2|^2(R_2 + \mathrm{Re}\{Z_L\})$ 也能得到相同结果，两种途径等价——这本身就是引入阻抗概念的定量验证。

### 示例 1：空心变压器稳态计算

**描述：**
已知空心变压器电路参数：$R_1 = 1.6\,\Omega$，$j\omega L_1 = j2.4\,\Omega$；$R_2 = 2\,\Omega$，$j\omega L_2 = j5\,\Omega$；负载为纯电阻 $Z_L = 3\,\Omega$；互感抗 $j\omega M = j2\,\Omega$；电源 $u_s = 10\angle 0^\circ\,\text{V}$。求一、二次侧电流 $i_1$ 和 $i_2$。

**分析思路：**
先计算一、二次侧自阻抗，再利用公式求出引入阻抗，将其与一次侧自阻抗相加得到输入阻抗，最后求出 $i_1$ 并通过电流传递关系求 $i_2$。

**过程：**
1. 计算回路自阻抗：
   $$Z_{11} = 1.6 + j2.4\;\Omega$$
   $$Z_{22} = (2 + 3) + j5 = 5 + j5\;\Omega$$

2. 计算引入阻抗：
   $$Z_{\text{ref}} = \frac{(\omega M)^2}{Z_{22}} = \frac{2^2}{5 + j5} = \frac{4(5 - j5)}{50} = 0.4 - j0.4\;\Omega$$
   注意引入电抗为 $-j0.4$，与二次侧电抗 $+j5$ 符号相反，符合阻抗反转规律。

3. 求一次侧电流 $i_1$：
   $$i_1 = \frac{u_s}{Z_{11} + Z_{\text{ref}}} = \frac{10\angle 0^\circ}{(1.6 + 0.4) + j(2.4 - 0.4)} = \frac{10\angle 0^\circ}{2 + j2} = \frac{10\angle 0^\circ}{2\sqrt{2}\angle 45^\circ} = \frac{5}{\sqrt{2}}\angle -45^\circ\;\text{A}$$

4. 求二次侧电流 $i_2$：
   先计算传递系数：
   $$\frac{j\omega M}{Z_{22}} = \frac{j2}{5 + j5} = \frac{j2(5 - j5)}{50} = \frac{10 + j10}{50} = \frac{\sqrt{2}}{5}\angle 45^\circ$$
   代入 $i_1$：
   $$i_2 = \frac{\sqrt{2}}{5}\angle 45^\circ \times \frac{5}{\sqrt{2}}\angle -45^\circ = 1\angle 0^\circ\;\text{A}$$

**结果：**
$i_1 = 3.536\angle -45^\circ\,\text{A}$，$i_2 = 1\angle 0^\circ\,\text{A}$。

**易错点：**
- 计算 $Z_{\text{ref}}$ 时，分子是 $(\omega M)^2$（即互感抗模的平方），不要误写为 $(j\omega M)^2$ 导致符号错误。本例中 $\omega M = 2$，故分子为 $4$。
- 最后相乘时幅角相加（$45^\circ + (-45^\circ) = 0^\circ$）而非相减。
- 本题参数经过特意选取——$R_1$ 与引入电阻之和恰好为 $2$，一次侧电抗 $\omega L_1 = 2.4$ 与引入电抗 $-j0.4$ 相抵后恰为 $j2$，使计算简洁。实际题目中数字一般不会如此整齐，但求解流程完全相同。

## 理想变压器模型

真实电力变压器采用高磁导率硅钢片叠压成铁芯，其损耗极小且耦合极紧密。在工程分析中，通过引入三个理想化条件，可将空心变压器模型大幅简化为理想变压器，从而得到极其简洁的电压、电流和阻抗关系。

### 三个理想化条件及其物理意义

**条件一：无损耗。** 假设线圈电阻 $R_1 = R_2 = 0$，铁芯无磁滞和涡流损耗。此条件消除了电路中的有功损耗，使变压器表现为纯无功耦合元件，电压-电流关系中不再出现电阻项。

**条件二：全耦合。** 耦合系数 $k = 1$，即 $M = \sqrt{L_1 L_2}$。这意味着一个线圈产生的磁通全部穿过另一个线圈，无漏磁通。数学上，磁链方程组的系数行列式 $L_1 L_2 - M^2 = 0$，导致原方程组奇异：电压比可由磁通关系确定，但电流比仍无法唯一解出。

**条件三：自感无穷大。** $L_1 \to \infty$ 且 $L_2 \to \infty$，但两者的比值保持为常数。实际中通过使用高磁导率材料和增加匝数来逼近此条件。此条件使得激磁电流趋于零，从而确立严格的电流比例关系。

### 三个条件如何逐步简化模型（数学推导）

三个条件并非孤立成立，而是依次作用于空心变压器的回路方程，最终将其简化为理想变压器的简单关系。

**条件一（无损耗）** 去掉了回路方程中的电阻项。原本 $Z_{11} = R_1 + j\omega L_1$ 简化为 $Z_{11} = j\omega L_1$，$Z_{22}$ 同理。电压-电流关系变成纯电感耦合方程。为推导方便，此处设两电流均流入同名端（互感项取正号），与前一节的流出约定不同，但电压比结果与方向约定无关：

$$
u_1 = j\omega L_1 i_1 + j\omega M i_2
$$
$$
u_2 = j\omega M i_1 + j\omega L_2 i_2
$$

**条件二（全耦合）** 使 $M = \sqrt{L_1 L_2}$，可将上面两个方程改写为：

$$
u_1 = j\omega\sqrt{L_1}\bigl(\sqrt{L_1}\, i_1 + \sqrt{L_2}\, i_2\bigr)
$$
$$
u_2 = j\omega\sqrt{L_2}\bigl(\sqrt{L_1}\, i_1 + \sqrt{L_2}\, i_2\bigr)
$$

两个方程的括号内完全相同——它们本质上只有一个独立方程。两式相除立即得到电压比 $u_1/u_2 = \sqrt{L_1}/\sqrt{L_2} = N_1/N_2$，但电流的绝对大小在此步尚不能确定。这就是"系数行列式为零、方程组退化"的含义。

**条件三（$L \to \infty$）** 提供了确定电流比所需的额外约束。由于 $u_1$ 是有限值（由有限电压源驱动），而 $\sqrt{L_1} \to \infty$，上式中括号内的量必须趋于零：

$$
\sqrt{L_1}\, i_1 + \sqrt{L_2}\, i_2 \to 0
$$

利用 $\sqrt{L_1}/\sqrt{L_2} = N_1/N_2$（因为 $L \propto N^2$），得到 $N_1 i_1 + N_2 i_2 = 0$，即电流比 $i_1/i_2 = -N_2/N_1$。三个条件共同作用，才将电压比和电流比完全确定。
### 电压与电流关系

**电压关系：**
在全耦合条件下，一、二次侧交链的磁通 $\Phi$ 相同。根据电磁感应定律，每匝线圈感应的电动势相等，因此总电压比严格等于匝数比：
$$
\frac{u_1}{u_2} = \frac{N_1}{N_2} = n
$$
其中 $N_1$、$N_2$ 为一、二次侧匝数，$n$ 称为**变比**（匝数比）。电压关系与负载电流大小无关。

**电流关系：**
结合全耦合与电感无穷大条件，由磁动势平衡方程可推导电流关系。若 $i_1$ 流入同名端，$i_2$ 也流入同名端，总磁动势为零：
$$
N_1 i_1 + N_2 i_2 = 0 \implies \frac{i_1}{i_2} = -\frac{N_2}{N_1} = -\frac{1}{n}
$$
若 $i_2$ 设定为流出同名端，则磁动势方程为 $N_1 i_1 - N_2 i_2 = 0$，此时 $i_1 / i_2 = 1/n$。负号仅取决于参考方向的设定，不改变物理本质。解题时必须先明确参考方向约定，再决定正负号。

### 阻抗变换特性

从一次侧看入的输入阻抗 $Z_{\text{in}}$ 与二次侧负载阻抗 $Z_L$ 的关系为：
$$
Z_{\text{in}} = \frac{u_1}{i_1} = \frac{n u_2}{\frac{1}{n} i_2} = n^2 \frac{u_2}{i_2} = n^2 Z_L
$$
推导中设 $i_1$ 流入同名端、$i_2$ 流出同名端（此时电流比 $i_1/i_2 = 1/n$）。若采用两电流均流入同名端的约定，$i_1 = -\dfrac{1}{n} i_2$，代入后负号与负载阻抗定义中的关联方向相抵消，结果仍为 $Z_{\text{in}} = n^2 Z_L$。可见阻抗变换结果与方向约定无关。

阻抗变换是理想变压器在电子与通信工程中最核心的应用。通过选择合适的匝数比 $n$，可以将任意负载阻抗变换为与信号源内阻相匹配的值，从而实现最大功率传输。

### 功率特性与使用禁忌

理想变压器本身不消耗也不储存能量，输入功率瞬时值等于输出功率瞬时值。设 $u_2$ 与 $i_2$ 为关联参考方向，则：
$$
p_1 + p_2 = u_1 i_1 + u_2 i_2 = 0
$$
变压器仅起能量传输和电气隔离作用，效率为 100%。

**使用禁忌（致命错误）：**
1. **电压源供电时，二次侧严禁短路**。因 $u_1 = n u_2$，若二次侧短路强制 $u_2 = 0$，则一次侧电压 $u_1 = 0$，相当于将电压源直接短路，会产生无穷大电流烧毁电源。实际变压器二次侧通常需要加保护电路（如熔断器）。
2. **电流源供电时，二次侧严禁开路**。因 $i_1 = \pm \frac{1}{n} i_2$，若二次侧开路强制 $i_2 = 0$，则一次侧电流 $i_1 = 0$，相当于将电流源开路，会产生极高电压击穿绝缘。

### 典型应用示例

#### 示例 2：阻抗匹配计算

**描述：**
音频信号源内阻 $R_s = 800\,\Omega$，负载为 $8\,\Omega$ 的扬声器。为使扬声器获得最大功率，需通过理想变压器进行阻抗匹配，求变压器变比 $n$。

**分析思路：**
最大功率传输定理要求从一次侧看入的等效输入阻抗等于信号源内阻。利用阻抗变换公式 $Z_{\text{in}} = n^2 Z_L$ 建立方程。

**过程：**
设变比为 $n = N_1 / N_2$，令 $Z_{\text{in}} = R_s$：
$$
n^2 \times 8 = 800
$$
解得 $n^2 = 100$，即 $n = 10$。

**结果：**
应选用变比为 $10:1$ 的变压器（$N_1 : N_2 = 10 : 1$）。此时 $8\,\Omega$ 扬声器折合到一次侧为 $800\,\Omega$，与信号源内阻匹配，负载获得最大功率。

**易错点：**
变比 $n$ 定义为 $N_1/N_2$。$n=10$ 表示一次侧匝数是二次侧的 10 倍，这是一个降压变压器（电压降低，电流升高），符合高内阻信号源驱动低阻负载的物理直觉。

#### 示例 3：多绕组变压器等效分析

**描述：**
某理想变压器有一个一次绕组和两个二次绕组，匝数比分别为 $N_1:N_{21} = 3:1$（即变比 $n_1 = 3$）和 $N_1:N_{22} = 5:1$（即变比 $n_2 = 5$）。两个二次绕组分别接有 $8\,\Omega$ 和 $4\,\Omega$ 的纯电阻负载。求一次侧的等效输入电阻。

**分析思路：**
多个二次绕组共用同一个铁芯磁路，它们对一次侧的影响是独立的。需将各个负载分别折合到一次侧，由于一次侧电压 $u_1$ 是公共变量，两个反射支路的电压均为 $u_1$，故折合后的阻抗在一次侧呈并联关系。

**过程：**
1. 将第一个负载折合到一次侧：
   $$Z_{\text{ref1}} = n_1^2 \times 8 = 3^2 \times 8 = 72\;\Omega$$
2. 将第二个负载折合到一次侧：
   $$Z_{\text{ref2}} = n_2^2 \times 4 = 5^2 \times 4 = 100\;\Omega$$
3. 计算一次侧总等效电阻（两者并联）：
   $$R_{\text{eq}} = Z_{\text{ref1}} \parallel Z_{\text{ref2}} = \frac{72 \times 100}{72 + 100} \approx 41.86\;\Omega$$

**结果：**
一次侧等效输入电阻约为 $41.86\,\Omega$。

**易错点：**
极易将两个反射阻抗误认为串联。判断依据是：各二次绕组独立地与一次绕组耦合，各自产生独立的折合阻抗，这些阻抗从一次侧电源的角度看是同时存在的，因此为并联而非串联。

#### 示例 4：升压变压器参数计算

**描述：**
理想升压变压器铭牌标示匝数比为 $1:10$（即 $N_1 : N_2 = 1 : 10$），二次侧接负载 $R_L = 50\,\Omega$。一次侧接入 $u_s = 10\angle 0^\circ\,\text{V}$ 的理想电压源。求一、二次侧电流及二次侧电压。

**分析思路：**
明确变比 $n$ 的定义为 $N_1/N_2$。利用阻抗变换求出一次侧电流，再利用电压、电流比例关系求二次侧参数。

**过程：**
1. 确定变比：$n = N_1 / N_2 = 1 / 10 = 0.1$（注意不是 $10$）。
2. 计算一次侧输入阻抗：
   $$Z_{\text{in}} = n^2 R_L = 0.1^2 \times 50 = 0.5\;\Omega$$
3. 计算一次侧电流：
   $$i_1 = \frac{u_s}{Z_{\text{in}}} = \frac{10}{0.5} = 20\;\text{A}$$
4. 计算二次侧参数。设 $i_2$ 流出同名端，则 $i_2 = n i_1$：
   $$i_2 = 0.1 \times 20 = 2\;\text{A}$$
   二次侧电压：
   $$u_2 = i_2 R_L = 2 \times 50 = 100\;\text{V}$$
   （也可通过电压比验证：$u_2 = \frac{1}{n} u_1 = 10 \times 10 = 100\,\text{V}$）。

**结果：**
一次侧电流为 $20\,\text{A}$，二次侧电流为 $2\,\text{A}$，二次侧电压为 $100\,\text{V}$。

**工程直觉：**
升压变压器一次侧匝数少、电压低、电流大；二次侧匝数多、电压高、电流小。在实际设备中，可通过观察线圈导线粗细来判断绕组属性：电流大的绕组导线更粗，电流小的绕组导线更细。

**易错点：**
当题目给出"变比为 $1:10$"时，很多学生误将 $n$ 取为 $10$，导致阻抗变换计算为 $100 \times 50 = 5000\,\Omega$，结果完全错误。必须明确 $n = N_1/N_2 = 0.1$。判断升/降压的方法：$n < 1$ 为升压，$n > 1$ 为降压。

## 空心与理想变压器特性对比

空心变压器与理想变压器并非对立的两个概念，而是同一物理实体在不同分析精度下的数学抽象。空心模型揭示了电磁耦合的底层数学机制，而理想模型提供了工程计算的极简工具。两者的核心特性对比如下：

| 特性维度 | 空心变压器 | 理想变压器 |
| :--- | :--- | :--- |
| **能量损耗** | 包含线圈电阻 $R_1, R_2$ 产生的铜损 | 无损耗，效率 100% |
| **磁耦合程度** | 存在漏磁，耦合系数 $k < 1$ | 全耦合，无漏磁，$k = 1$ |
| **线圈电感** | 自感 $L_1, L_2$ 为有限值 | 自感趋于无穷大，$L \to \infty$ |
| **电压关系** | 需通过联立 KVL 回路方程求解 | 严格成正比，$u_1 / u_2 = n$ |
| **电流关系** | 需通过联立 KVL 回路方程求解 | 严格成反比，$i_1 / i_2 = \pm 1/n$ |
| **阻抗等效** | 引入阻抗 $Z_{\text{ref}} = (\omega M)^2 / Z_{22}$ | 阻抗变换 $Z_{\text{in}} = n^2 Z_L$ |
| **主要应用场景** | 高频电路、空心线圈传感器、理论推导 | 电力系统分析、低频阻抗匹配、工程估算 |

**模型选择指导：** 在解决具体电路问题时，若题目明确给出互感 $M$ 和自感 $L$ 的具体数值，必须使用空心变压器的回路方程或引入阻抗法；若题目仅给出变比 $n$ 或匝数比，且未提及损耗与漏磁，则应直接采用理想变压器的三大基本关系进行求解。在工程实践中，若工作频率较高或线圈间距较大（如射频天线耦合、无线充电），漏磁和损耗不可忽略，必须使用空心变压器模型（或含漏感的非理想变压器模型）；而在工频电力传输或音频隔离中，铁芯变压器的激磁电流和漏抗极小，采用理想变压器模型足以满足绝大多数系统级计算需求。从空心到理想的过渡并非一步跳变——三个条件依次消去损耗、消除漏磁、确定电流比，最终得到简洁而实用的理想模型。
