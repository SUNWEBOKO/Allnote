# 01 导论：马克思主义的创立与本质属性

对应教材导论。本章以选择题为主（著作与"第一"的对应、本质属性）；"马克思主义的内涵"是马哲大题的第一题，见 [[09 期末大题十五题速答]]。

## 1. 马克思主义的内涵（大题第 1 题）

从四个要素作答，每个要素展开一两句即可：

1. **创立者**：由马克思、恩格斯创立，并为后继者所不断发展。
2. **内容**：关于自然、社会和人类思维发展一般规律的科学理论体系。
3. **目标**：批判资本主义、建设社会主义、最终实现共产主义。
4. **性质（最根本的作用）**：关于无产阶级和人类解放的科学。

鲜明特征（五个，答题关键词，逐个展开）：

- **科学性**：正确反映客观世界发展规律。
- **革命性**：鲜明的无产阶级立场和批判精神。
- **人民性**：马克思主义的**本质属性**，首要的、最鲜明的品格。
- **实践性**：**首要的和基本的观点**，从实践中来、到实践中去，在实践中检验和发展。
- **发展性**：与时俱进、开放的理论体系。

科学性与革命性的统一，是马克思主义的鲜明特征。

两个"最"最容易混，单选高频，务必分开记：

| 问法 | 答案 |
|---|---|
| 最根本的**世界观和方法论** | 辩证唯物主义与历史唯物主义 |
| **最重要的理论品质**（历久不衰的根本原因、根本属性） | 与时俱进（与时俱进性） |

## 2. 三大组成部分与地位（单选高频）

| 组成部分 | 地位 |
|---|---|
| 马克思主义哲学 | 理论基础 |
| 马克思主义政治经济学 | 主要内容（运用与论证） |
| 科学社会主义 | 理论目的（核心与归宿） |

问"理论基础"选马哲；问"主要内容"选政治经济学；问"理论目的／归宿"选科学社会主义。三句话连在一起也可以考多选。

**三大来源与三大组成一一对应**（选择题最爱用的对位，问"A 是 X 的直接理论来源"就往右栏找）：

| 直接理论来源 | 吸收后形成的组成部分 |
|---|---|
| 德国古典哲学 | 马克思主义哲学（理论基础） |
| 英国古典政治经济学 | 马克思主义政治经济学（主要内容） |
| 英法批判的空想社会主义 | 科学社会主义（核心） |

口诀：**来源**——德哲、英经、法空（康德黑格费尔巴，圣傅欧）；**组成**——哲（基础）、经（主体）、社（核心）。两组顺序一致，可一起背。

## 3. 标志性著作（单选高频）

| 著作         | 意义                                     |
| ---------- | -------------------------------------- |
| 《共产党宣言》    | 标志马克思主义公开问世（也标志科学社会主义诞生）               |
| 《资本论》      | 系统阐述剩余价值理论，被誉为"工人阶级的圣经"                |
| 《反杜林论》     | 恩格斯 1876—1878 年著，全面阐述马克思主义理论体系（三个组成部分），被誉为"马克思主义的百科全书" |
| 《神圣家族》     | 批判青年黑格尔派唯心主义                       |
| 《费尔巴哈的提纲》  | 确立了科学的实践观，"包含着新世界观的天才萌芽的第一个文件"         |
| 《德意志意识形态》  | 首次系统阐述唯物史观                             |
| 《德法年鉴》上的论文 | 1844 年 2 月，表明马克思完成了从唯心主义向唯物主义、从革命民主主义向共产主义的"两个转变" |

著作类题目最爱挖的坑，按三组对比记：

1. **"体系" vs "公开问世"**：《反杜林论》讲体系，《共产党宣言》讲问世。
2. **"首次系统阐述"** 只给《德意志意识形态》（唯物史观）；"天才萌芽的第一个文件"只给《费尔巴哈的提纲》（实践观）。
3. **"两个转变"** 只在《德法年鉴》论文（1844 年 2 月），不是《共产党宣言》（1848 年）。

记忆提示：教材章节顺序里唯物史观在第三章，第三章讲完马克思主义哲学的脉络就完成了——所以《德意志意识形态》首次阐述唯物史观，对应"马克思主义哲学的诞生"。

## 4. 产生条件（考概率低，留印象）

- **社会根源**：资本主义经济社会的发展及其矛盾运动。
- **阶级基础**：无产阶级反对资产阶级的斗争。
- **思想渊源**：下面三大直接理论来源。

三大**直接**理论来源及其代表人物（必考，选择题常挖人物）：

| 来源 | 代表人物 |
|---|---|
| 德国古典哲学 | 康德、黑格尔、费尔巴哈 |
| 英国古典政治经济学 | 亚当·斯密、大卫·李嘉图 |
| 英法批判的空想社会主义 | 圣西门、傅立叶、欧文 |

- **易错点**：**法国启蒙思想**（伏尔泰、孟德斯鸠）不属于马克思主义的直接理论来源；空想社会主义是"**批判的空想**社会主义学说"，不是"科学社会主义"。
- **继承关系（易混，必查）**：马克思批判地吸收了黑格尔哲学的**"合理内核"＝辩证法**，批判地吸收了费尔巴哈哲学的**"基本内核"＝唯物主义**，二者结合形成辩证唯物主义。
  - 口诀：**黑格尔辩证、费尔巴哈唯物**——顺序别颠倒（"辩证"归黑格尔，"唯物"归费尔巴哈）。

## 5. 两大理论发现与社会主义的飞跃

- 马克思、恩格斯最重要的理论贡献是**两大发现**：**唯物史观** 和 **剩余价值学说**。
- 这两大发现把社会主义从空想变为科学，实现了社会主义发展史上**从空想到科学的飞跃**（唯物史观＋剩余价值学说被称为科学社会主义的两大理论基石）。
- 口诀：**两大发现＝唯物史观、剩余价值；促空想到科学。**

## 6. 当代生命力与正确态度

马克思主义在当今世界显示出强大生命力，体现在三方面：

1. 观察当代世界变化的**认识工具**；
2. 指引当代中国发展的**行动指南**；
3. 引领人类社会进步的**科学真理**。

对待马克思主义的正确态度：

- 坚持**解放思想、实事求是、与时俱进**；
- 核心要求是**发展马克思主义**——不断有所发现、有所创造、有所前进，从教条式理解和僵化应用中解放出来。
- 忌讳：把马克思主义当作僵死不变的教条（考"教条主义""静止观"一律错）。
