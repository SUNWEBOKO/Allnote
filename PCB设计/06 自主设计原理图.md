# 自主设计原理图

**前置知识**：已完成01-05章，理解原理图和PCB基本概念
**本节目标**：学会通过立创开源平台获取参考设计、掌握阅读芯片规格书的方法、能独立画出原理图

## 整体流程

自主设计原理图的核心流程：

1. **明确功能需求**——确定要实现的电路功能
2. **芯片选型**——在开源平台或商城搜索合适的芯片
3. **阅读规格书**——看懂芯片的典型应用电路和引脚定义
4. **设计原理图**——按规格书中的参考电路搭建
5. **PCB布局布线**——将原理图转换为实际板子

## 立创开源硬件平台

网址：立创开源硬件平台（立创开源广场）

这个平台上有很多开源项目，从小的功能模块到较大的完整项目都有。使用方式：

- **搜索功能**：进入平台后直接搜索需要的模块关键词，例如"锂电池充电"，会出现大量相关开源项目
- **查看设计图**：点进项目后可以看到完整的原理图和PCB设计，支持网页版工程查看，可拖动、选中，也可以直接复制工程到自己的工作区
- **参考芯片选型**：把项目中用到的芯片型号记下来，到立创商城搜索购买

开源项目的原理图可以直接参考使用，但需要注意：开源设计不一定完全标准，有些芯片可能没有对应的开源项目，这时就需要学会看规格书自己设计。

## 芯片规格书阅读——以 TP4054 为例

TP4054 是一款常用的锂电池充电管理芯片。从规格书中需要关注以下几个部分：

### 关键参数

- **最大耐压**：11V，适用于 11V 以下的系统
- **典型应用**：单节锂电池充电器

### 必须看的表格

1. **最大额定值（Absolute Maximum Ratings）**——确认输入电压范围是否满足使用场景。例如 TP4054 耐压 11V，用 5V USB 供电没问题，但用 12V 给这个芯片充电就会烧掉
2. **电气特性（Electrical Characteristics）**——详细电气参数
3. **引脚功能（Pin Configuration & Description）**——每个引脚的作用
4. **典型应用电路（Typical Application Circuit）**——这是画原理图时最重要的参考

### 快速方法

把规格书 PDF 下载下来，扔到 AI 阅读工具里，描述自己的使用场景，让 AI 帮判断芯片是否满足要求。

## TP4054 充电电路设计

### 基本电路 vs 功能齐全电路

规格书中给出了两种典型电路：

- **基本电路**：只有充电功能
- **功能齐全电路**：增加了充电指示灯（其他部分与基本电路相同）

推荐使用功能齐全的版本，多一个指示灯方便判断充电状态。

### 电路搭建步骤

1. 在原理图中放置 TP4054 芯片（通过芯片的 C 号在立创商城搜索后复制到工程中）
2. **5V 输入**：VCC 引脚接 5V，VCC 对地接 4.7μF 电容
3. **BAT 输出**：BAT 引脚对地接 10μF 电容
4. **电阻配置**：规格书中的 2kΩ 电阻可以用两个 1kΩ 串联替代（减少物料种类），CHRG 引脚接 1kΩ 限流电阻
5. **GND 引脚**直接接地

### 电池连接

电池正极接 BAT 引脚，负极接 GND。在 PCB 上可以用**测试点**（Test Point）作为电池的连接焊盘：

- 正极测试点标 BAT+
- 负极测试点标 BAT-

测试点直径建议 2mm，放在 PCB 背面，方便电池导线直接焊接。电池到货后红线接正极、黑线接负极。

### 电池开关

在电池正极回路中串联一个**滑动开关**，不用电池时可以手动断开：

- 开关型号：小型滑动开关（搜索"滑动开关"，选销量高的）
- 原理：滑到右边时引脚 2-3 导通，滑到左边时引脚 1-2 导通
- 接线：电池接中间引脚（2），电路端接一侧引脚（3），滑到另一侧（1）即断开
- 布局时开关的滑动方向应朝向板子边缘

## 电池选型

常见的 3.7V 锂电池：

- **18650 圆柱电池**
- **软包电池**（银色扁平封装）

满电电压 4.2V，亏电电压建议用到 3.5V~3.3V 就停止，低于这个值可能无法再充上电。搜索"3.7V 锂电池"即可找到。

## 二极管防反接电路

当系统同时有 USB 供电和电池供电时，需要防止 5V 与电池电压冲突。

### 原理

在 5V 线路与 BAT 网络之间串联一个二极管（常用 **1N4148W**）：

- 二极管方向：负极朝向 5V 侧，正极朝向 BAT 侧
- 正向导通（BAT→5V），反向截止（5V→BAT）

### 工作逻辑

- **插入 USB（5V）时**：5V 电压高于 BAT（3.7V），二极管反向截止，相当于断开。5V 直接给充电芯片供电，同时给电池充电
- **拔掉 USB 时**：5V 网络空载，BAT（3.7V）通过二极管正向导通到 LDO，由电池给系统供电

这样不需要手动切换，电路自动选择供电来源。

## Type-C 接口电路

用 Type-C 母座替代排针作为 5V 输入接口，可以直接用手机充电器给板子供电。

### 必要元件

- Type-C 母座（母口）
- 两个 5.1kΩ 电阻（CC1 和 CC2 引脚对地）

### 为什么需要 5.1kΩ 下拉电阻

Type-C 协议中，CC 引脚通过 5.1kΩ 电阻下拉，告诉充电器"我是用电器，不是充电器"，充电器才会输出 5V。没有这两个电阻，有些充电器不会供电。

### 接线

- VBUS → 5V 网络
- GND → GND
- CC1、CC2 各通过 5.1kΩ 电阻接 GND
- DP1 与 DP2 相连，DN1 与 DN2 相连（直通）

### PCB 布局

- Type-C 母座必须放在板子边缘，否则会被板体挡住无法插拔
- 焊接侧留出足够空间方便手工焊接
- 两个 5.1kΩ 电阻放在母座附近

## ADC 电压检测

为了在单片机端读取电池剩余电量，需要用 ADC 采样电池电压。

### 分压电路

电池电压范围 4.2V（满电）~3.3V（亏电），而 STM32 的 ADC 最大输入只能到 3.3V。需要将电池电压通过两个电阻分压后再送入 ADC 引脚。

电路：BAT → R1 → ADC 采样点 → R2 → GND

- ADC 采样点接 STM32 的 PA0 引脚（ADC Channel 0）
- 分压比例保证 4.2V 分压后 ≤ 3.3V

### 电阻取值原则

- 比例正确即可，不要求特定阻值
- 阻值不能太小，否则电池会持续对地放电，很快耗完
- 阻值可以大到兆欧级别

### 软件配合

单片机通过 ADC 采样得到分压点的电压，再根据分压比例反推出电池实际电压，从而判断剩余电量。这部分内容在 STM32 编程课程的 ADC 章节中详细讲解。

### 备用

如果 PA0 引脚需要用于其他功能，直接把分压电阻拆掉即可恢复。

## 常见错误与排查

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 芯片不工作 / 不亮 | 供电引脚 VDD/VSS 未连接，或滤波电容缺失 | 检查芯片供电网络和 VCAP 引脚 |
| 原理图导入 PCB 后元件位置异常 | 原理图中元件未放置在板子图页内 | 确保原理图在板子节点下，而不是孤立的图页 |
| 从开源平台复制电路后网络名冲突 | 不同模块使用了同名但不同意的网络标签 | 在原理图中统一修改网络名，避免同名异义 |
| 规格书电路与工程元件不一致 | 选用的芯片封装与实际购买的元件不同 | 确认立创商城中 C# 对应的封装型号 |
| Type-C 插不进去 | 插座没有放在板边 | 将 Type-C 母座放在板框边缘，伸出一半 |
| 电池很快没电 | 分压电阻阻值太小 | 电阻至少 10kΩ 以上，可用到 MΩ 级别 |
| 焊接后二极管方向错误 | 防反接二极管极性接反 | 确认二极管负极朝向 VCC/负载侧 |
| SMT 下单时找不到元件 | 原理图中元件没有立创 C# | 确保所有元件从立创商城选取，有供应商编号 |
| 芯片引脚功能看错导致接反 | 未仔细核对规格书引脚定义 | 在规格书中找到引脚功能表，逐引脚确认 |
| 元件耐压选小导致烧毁 | 忽略工作电压与元件耐压的关系 | 电容耐压至少为实际电压的 1.5 倍 |
| 忽略芯片数据手册中的典型电路 | 直接照抄开源项目未理解原理 | 先阅读规格书 Typical Application 章节 |

## PCB 布局要点

1. **以芯片为中心**：将芯片放在中间，各引脚的配套元件就近放置
2. **Type-C 在板边**：确保母座伸出板边缘
3. **开关在板边**：滑动方向朝向板边缘
4. **电池焊盘放背面**：电池粘贴在 PCB 背面，焊盘也放在底层
5. **丝印标注**：充电指示灯、电源指示灯、PC13 指示灯、各排针对应的 GPIO 编号都标在丝印层上，避免后面忘记

## 自主学习任务：串口转 USB

在开发板上集成串口转 USB 功能，省去外部 USB-TTL 转换器。

### 思路

在立创开源平台上搜索"串口"相关项目，找到串口转 USB 的芯片模块，将它的电路融合到自己的开发板中。

### 原理

用一颗专用芯片将 MCU 的串口信号（TX/RX）转换成 USB 信号，直接通过 USB 接口发送到电脑。电脑插上 USB 线就能读取串口数据。

需要先学完 STM32 编程课程中的串口部分，再结合 PCB 设计课程来完成这个任务。
