# 原理图基础概念

**前置知识**：已完成 01 章软件安装并熟悉界面
**本节目标**：理解原理图的核心概念（元件/引脚/网络/封装），为动手绘制做准备

## 原理图与 PCB

原理图（Schematic）用抽象符号表示电路连接关系，每个元件以简化符号呈现，与实际物理形状不同。PCB（Printed Circuit Board）展示元件在板上的物理位置和实际走线，是制造电路板的依据。

设计流程：先画原理图确定各元件之间的电气连接，再根据原理图画 PCB。PCB 上的所有连接必须与原理图一一对应。直接画 PCB 时，大量走线和元件堆叠在一起，很难看清哪个元件接到哪根线。

## 元件

原理图中的每个元件用标准符号表示。常见元件及其符号特征：

| 元件类型 | 符号特征 |
|---------|---------|
| 电阻 | 锯齿形或矩形 |
| 电容 | 两条平行线 |
| LED | 三角形加箭头 |
| 晶振 | 矩形加频率标注 |
| 芯片（IC） | 矩形加引脚编号 |
| 按键 | 开关符号 |
| 排针 | 一排引脚 |

**位号（Reference Designator）**：每个元件在原理图中有一个唯一的标识，如 R1、C1、LED1、U1。复制元件时系统会自动递增位号（LED1 → LED2）。

## 引脚

元件符号上的每个引脚对应实际元件的一个物理引脚，原理图中用灰色小点表示。引脚是导线连接的起点或终点。

## 导线

绿色线表示导线（Wire），用于连接元件的引脚，建立电气连接。

## 网络

**为什么需要网络？** 当两个引脚距离较远或位于不同图页时，用实际导线直接连接会使原理图变得杂乱。网络概念用名称代替物理走线来表示连接关系。

**什么是网络？** 网络是指所有电气上连在一起的导体——包括导线、引脚、过孔——的集合。同一网络中的所有点电位相同。网络的概念贯穿原理图和 PCB 设计的全过程。

举例：在一张原理图中，从 STM32 芯片的 PA0 引脚引出一根线，经过一个过孔到 PCB 背面继续走线，最终连接到排针的一个引脚。这根完整的路径就是一个网络，名为 PA0。

**如何查看网络？** 在立创 EDA 中，点击左侧面板的「网络」可以查看所有网络及其包含的线段。选中一个网络后，原理图和 PCB 上对应的导线和焊盘会同步高亮。

**注意事项：**
- 同一网络在不同图页中依然相连
- 不同网络的导线不能直接交叉连接（交叉处无连接点时表示不连通）
- 可以通过在原理图中选中某个网络，再切换到 PCB 视图来验证走线是否正确

## 网络标签

**为什么需要网络标签？** 当引脚隔着很远距离，或需要跨图页连接时，画一条长导线布线困难且阅读不便。网络标签用名称代替物理导线，使原理图保持整洁。

**什么是网络标签？** 网络标签（Net Label）是附加在导线或引脚上的文本标识。所有具有相同网络标签的引脚和导线属于同一个网络，效果等同于用一根导线直接连接。

例如，在原理图第一页的排针引脚上放置网络标签 PA0，在第二页的 STM32 引脚上也放置 PA0，这两个引脚就被视为已经连接，无需在页间画实际导线。

**网络标签的类型：**

1. **自定义标签**：如 PA0、PA1、RESET、BOOT0，由设计者命名
2. **电源标签**：VCC、3.3V、5V，用专用符号表示
3. **地标签**：GND，用专用符号表示

电源和地标签本质上是网络标签，只是符号不同，便于在复杂原理图中快速识别。

**命名规则：**
- 只能使用英文字符，不能使用中文
- 最好不要包含空格
- 建议使用有意义的名称，便于阅读和理解

## 封装

**为什么需要封装？** 同一电气参数的元件（如 510Ω 电阻）可以有不同的物理尺寸。设计 PCB 时必须明确每个元件的尺寸才能正确布局和布线。

**什么是封装？** 封装（Footprint）描述元件在 PCB 上的物理尺寸、焊盘布局和引脚排列方式，即元件实际焊接在板子上的样子。

**常见封装尺寸：**

| 封装 | 尺寸（长×宽） | 特点 |
|------|-------------|------|
| 0805 | 2.0mm × 1.25mm | 尺寸较大，适合手工焊接 |
| 0603 | 1.6mm × 0.8mm | 尺寸较小 |

**选型建议：** 同一块板上尽量使用统一的封装尺寸。这样更换不同阻值或容值的元件时，不需要更换 PCB 布局，备料也更方便。初学者建议优先选 0805 封装，手工焊接难度低。

**查看封装的方法：**
- 选中元件后，在右侧属性面板点击封装字段，可以查看封装的 3D 形状和尺寸
- 将元件导入 PCB，可以直接看到不同封装的尺寸差异

## 集成电路 vs 分立元件

**集成电路（IC）**：将多个电子元件集成在一个半导体芯片上，如 STM32 微控制器、运放芯片等。IC 通常有多个引脚，功能复杂，在原理图中以矩形符号加引脚编号表示。

**分立元件**：单独的电子元件，如电阻、电容、电感、二极管、三极管等。每个分立元件通常只实现单一功能，封装形式多样。

在原理图设计中，IC 负责核心功能（如运算、控制），分立元件负责辅助功能（如滤波、限流、分压）。

在 PCB 设计中，IC 通常需要更多的布线资源和电源去耦电容，分立元件的布局则更灵活。

## 常见错误与踩坑
- 混淆网络（Net）和网络标签（Net Label）——网络是连接关系，标签是命名标识
- 封装选错导致 PCB 上放不下元件
- 引脚编号与数据手册不一致导致连线错误
- 电源网络未使用专用电源标签符号
