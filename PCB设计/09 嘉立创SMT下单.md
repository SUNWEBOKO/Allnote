# 嘉立创 SMT 下单流程

> 如果你已完成 [04 下单制造](04%20下单制造.md) 的 Gerber 导出和 PCB 下单流程，可以直接从 BOM 表导出开始。

**前置知识**：已完成04章PCB下单，手头有GERBER文件
**本节目标**：掌握BOM表和坐标文件的导出、了解基础库与拓展库的区别、能独立完成SMT下单

## 目标

在嘉立创完成 PCB 制造后，由嘉立创将元器件焊接好，收到即用。

## 前置条件

- 已完成 PCB 设计（原理图 + PCB Layout）
- 原理图中的元器件来自立创商城（C# 可直接匹配，省去手动选型）

## 操作步骤

### 下单 PCB

SMT 必须先下 PCB 订单，流程与常规 PCB 下单完全相同：

1. 在 EDA 中导出 Gerber 文件（文件 → 导出 → Gerber），检查 DRC 无误后保存
2. 打开立创下单助手，下单 PCBA/PCB/FPC 订单 → 计价下单
3. 上传 Gerber 文件，选择数量（如 5 片），立即下单
4. 选择优惠券（留意是否领到盲盒券——有机会附带免费 SMT）
5. 确认生产稿、板厚（默认 1.6mm）、拼板方式、阻焊颜色等参数，与常规 PCB 下单一致
6. 添加二维码（前缀码、防冲码类别、尺寸），切换到底层空白位置放置
7. **SMT 贴片** 选项选 **需要**

> 所有免费的选项都选免费，不需要的增值服务选不需要。

### 提交 PCB 订单，进入 SMT 页面

点击 **提交 PCB 订单** → 确认生产稿选 **不需要确认** → 跳转到 SMT 贴片下单页面。

### 导出 BOM 与坐标文件

在 EDA 工程中导出两个文件：

**BOM 表（物料清单）**
- 文件 → 导出 → 物料清单（BOM 表）
- 全部参数默认，修改文件名，导出保存

**坐标文件**
- 文件 → 导出 → 坐标文件
- 全部参数默认，修改文件名（避免与 BOM 重名），导出保存

得到两个表格文件：一个 BOM 表，一个坐标文件。

### 上传 BOM 与坐标

在 SMT 下单页面：
1. BOM 文件 → 上传刚才导出的 BOM 表
2. 坐标文件 → 上传坐标文件
3. 备货方式：按页面默认勾选即可
4. 贴片数量：选择全贴或自定义数量
5. 焊接层：选 **只贴顶层**（单面价格便宜很多）
6. 应用行业：消费电子
7. 产品类型：经济型
8. 测试、贴插焊点等选 **无要求** 或 **不知道**（嘉立创会协助处理）

### 元件匹配——基础库 vs 拓展库

匹配选型方式选 **自助匹配**，进入匹配页面后会列出所有元件及其贴片位置。

**关键概念**

| 类型 | 说明 | 费用 |
|------|------|------|
| 基础库 | 嘉立创常备库存的通用元件 | 不收换料费 |
| 拓展库 | 非基础库元件，需频繁切换料带 | 按种类收取换料费 |

**尽量选用基础库元件**，可大幅降低 SMT 费用。

#### 检查要点

逐个元件检查，每项确认无误后打勾：

1. **C# （元件编号）**是否匹配
2. **封装**是否一致
3. **正负极方向**是否正确
4. **库存**是否有货
5. 有红色警告 → 点 **替换**，选择基础库中合适的元件
   - 例如 LED 可搜索封装规格（如 0805），筛选基础库，选白色或其他颜色
6. 无法匹配的元件（如螺丝孔、测试点）→ 直接 **删除不贴**

### 处理异常器件

检查完毕 → 点击 **备料完成** → 若有异常器件提示，点 **快速定位处理** → 确认异常事件 → 下一步。

### 提交订单

1. 选择设计工具：立创 EDA
2. 确认交期、收件信息
3. 点击 **提交订单**
4. 页面跳转后关闭所有页面

### 支付

在立创下单助手首页 → **SMT 订单** → **SMT 订单列表** → 查看订单 → 确认支付。

- 费用构成：**元器件费用 + 换料费（拓展库产生）**
- 若领取到 SMT 免费券（盲盒券），换料费可减免，仅需支付元器件费用
- 支付后可在进度跟踪查看生产状态，等收快递

## 注意事项

1. **原理图设计时尽量选用基础库/标准库元件**，直接从立创商城选型并确认 C# 匹配，可省去后期手动替换的麻烦
2. **所有元件设计在同一面**——经济型 SMT 只支持单面贴片
3. 遇到不确定的选项可直接选 **不知道**，嘉立创会协助处理
4. 换料费可能比元器件本身还贵（如文中案例：元件 30 元，换料费 100+ 元），**务必优先选基础库**

## 常见错误与踩坑
- BOM表元件与实际封装不匹配
- 坐标文件导出时原点位置设置不对
- 选错基础库/拓展库导致无法匹配
- 未检查立创库存导致缺料
- 换料费超预期
