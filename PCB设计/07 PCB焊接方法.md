# PCB 焊接方法

**前置知识**：已有焊接工具和待焊PCB
**本节目标**：掌握贴片元件和插件元件的焊接方法、了解常见焊接缺陷及处理方法

> 本文为补充知识，与主课程视频独立。你可以在PCB打样到手后、实际焊接前参考本文。

## 焊接工具

| 工具 | 用途 |
|------|------|
| 调温电烙铁 | 熔化焊锡，连接元件与焊盘。建议使用恒温烙铁，温度可调 |
| 焊锡丝 | 含松香芯的锡丝，推荐直径 0.6–0.8mm |
| 助焊剂（松香/焊膏） | 去除氧化层，帮助焊锡流动 |
| 镊子 | 夹持贴片元件 |
| 吸锡器 / 吸锡带 | 拆焊、清理多余焊锡 |
| 热风枪 | 拆焊多引脚元件、焊接 QFN/BGA 封装 |
| 酒精或洗板水 | 清洗焊接后残留的助焊剂 |
| 放大镜或显微镜 | 检查焊点质量、观察连锡情况 |

## 焊接温度参考

| 焊接方式 | 推荐温度 |
|---------|---------|
| 普通含铅焊锡丝（烙铁） | 300–320°C |
| 无铅焊锡丝（烙铁） | 340–370°C |
| 热风枪（拆焊） | 350–380°C（视风速和距离调整） |

温度过低会导致虚焊（焊锡不流动、呈颗粒状），温度过高会损坏元件或烧焦 PCB。

## 贴片元件焊接

### 点焊法（适用于电阻、电容、LED 等两端元件）

1. 先在**一个焊盘**上镀少量焊锡
2. 用镊子夹持元件，对准焊盘位置
3. 加热已镀锡的焊盘，同时将元件引脚推入熔化的焊锡中，移开烙铁
4. 待焊锡凝固后，焊接另一侧引脚

### 拖焊法（适用于多引脚 IC，如 STM32、LDO 等）

1. 将 IC 对准焊盘，先焊接**对角引脚**固定位置
2. 沿一侧所有引脚均匀涂抹助焊剂
3. 用烙铁头蘸取适量焊锡，从一侧第一个引脚开始匀速拖向最后一个引脚
4. 多余焊锡会被拖走，引脚间自动分离。少量连锡可加助焊剂后重新拖一次
5. 用吸锡带清理残留的桥接焊锡

### 回流焊（适用于批量焊接）

1. 在焊盘上涂锡膏（可用钢网或手动点涂）
2. 用镊子或贴片机放置元件
3. 放入加热台或回流焊炉，按锡膏温度曲线加热（预热→升温→回流→冷却）
4. 冷却后检查焊点

## 插件元件焊接

1. 将元件引脚穿过 PCB 通孔
2. 烙铁接触引脚与焊盘接触面，送入焊锡丝
3. 焊锡熔化充满通孔后，先移开焊锡丝，再移开烙铁
4. 用斜口钳剪去过长的引脚

## 常见焊接缺陷与处理

| 缺陷 | 现象 | 原因 | 处理方法 |
|------|------|------|---------|
| 虚焊 | 焊点呈颗粒状、不光滑 | 温度不够 / 焊盘氧化 | 加助焊剂后重新加热 |
| 连锡（短路） | 相邻两个焊盘被焊锡桥接 | 焊锡过量 | 用吸锡带吸除，或加助焊剂后重新拖焊 |
| 冷焊 | 焊点发灰、无光泽 | 加热时间不足 / 冷却过快 | 重新加热至充分流动 |
| 焊盘脱落 | 铜箔从 PCB 上剥离 | 温度过高 / 反复加热 / 机械应力 | 飞线连接（预防为主） |
| 锡珠 | 焊点周围有微小锡球 | 加热过快 / 助焊剂爆溅 | 清洗去除，防止短路 |

## 焊接注意事项

- **LED 和塑料封装元件**：热风枪温度不宜过高（建议 ≤ 350°C），时间不宜过长，否则塑料外壳会熔化或变色
- **过孔不要放在焊盘上**：焊锡会沿过孔流走，导致焊盘缺锡
- **芯片引脚方向**：焊接前务必确认芯片标记（凹口/圆点/斜角）与 PCB 丝印一致
- **ESD 防护**：焊接敏感芯片（如 MOS 管、IC）时建议佩戴防静电手环，或触摸接地金属释放静电
- **清洗**：焊接完成后用酒精或洗板水清除助焊剂残留，尤其是高阻抗电路，残留物可能导致漏电

## 常见错误与踩坑
- 温度过高烧坏焊盘或元件
- 锡量过多导致短路
- 助焊剂残留未清洗
- 虚焊未能及时发现
- 湿敏元件未预热
