# PCB 下单制造指南

**前置知识**：已完成03章PCB绘制并通过DRC
**本节目标**：掌握Gerber文件导出方法、能独立完成PCB下单流程

## 前置条件

- PCB 布局布线全部完成
- DRC 检查无错误：`检查 DRC → 清除错误 → 再次检查直到 0 错误`

## 导出 Gerber 制板文件

1. 在软件中点击「文件 → 导出 → Gerber 文件」
2. 修改文件名（如 `项目名_PCB`）
3. 保持自定义配置为默认，**不勾选丝印层**
4. 点击「一键导出」
5. 软件会再次要求 DRC 检查——这是最后一道保险，通过后才能继续
6. 选择保存位置，确定后得到一个 ZIP 压缩包

## 在嘉立创下单

### 领取免费 PCB 优惠券

1. 打开嘉立创下单助手，扫码登录
2. 进入「用户中心 → 优惠券中心 → PCB 免费券」
3. 在优惠券领取页面选择 **1~4 层喷锡专用券**，点击立即领取
4. 扫码完成领取

### 上传 Gerber 文件

1. 回到首页，展开「PCB/FPC 订单」，点击「计价下单」
2. 上传刚导出的 ZIP 文件，等待解析完成

### 配置参数

系统会自动检测以下参数，保持默认即可：

| 参数 | 值 |
|------|-----|
| 层数 | 2（自动识别） |
| 板子尺寸 | 自动检测 |
| 板材 | FR4 |
| 板厚 | 1.6mm（默认） |
| 外层铜厚 | 默认 |
| 阻焊颜色 | 自选（本例选蓝色） |

手动设置的参数：

- **板子数量**：展开选择 5 块（最低起做）
- **确认生产稿**：选「不需要」（可选服务需收费）
- **出货方式**：单片
- **品质赔付服务**：按合同标准常规处理
- **其他**：全部默认

> **免费 PCB 尺寸限制**：免费优惠券仅限 PCB 最长边 ≤ 10 cm（即 10 × 10 cm 以内），超出需按正常价格收费。当前课程中的板子都在此范围内。

### 添加溯源序列号（二维码）

1. 点击「添加溯源序列号」
2. 选择「仅印刷二维码」
3. 输入前缀码（如项目缩写）
4. 防冲码选择「年月日」
5. 二维码尺寸选「最小」
6. 点击「指定位置添加」，在 PCB 空白位置单击放置二维码
7. 点击「完成标记」，保存成功即可

> **注意：** 二维码不能放置在过孔或元件上，否则会提示「位置检测不通过，与其他元件重叠」。下方有走线不影响。

### 交期与物流

| 选项 | 选择 |
|------|------|
| 交期 | 正常 3 天（免费） |
| SMT 贴片 | 不需要 |
| 钢网 | 不需要 |
| 发票 | 个人发票（自行填写） |
| 发货方式 | 默认电子收据，不同交期一起发货 |
| 收货地址 | 自行填写 |
| 快递 | 可选包邮快递 |

### 提交订单

1. 在优惠券处选择已领取的免费券——总价应变为 0
2. 若总价不等于 20 元（优惠前基价），说明前面有选项选错，需回头检查
3. 点击「提交订单」→ 再次确认 → 点击「确认提交」→ 0 元直接点击「支付」
4. 支付成功后即可免费制作 5 块 PCB，包邮送达

## 补充：原理图修正记录

**背景：** 原视频教程中 STM32 芯片的 VSSA 与 VDDA 引脚画反。以下按正确接法记录。

### VSSA / VDDA 正确接法

| 引脚 | 连接 |
|------|------|
| VSSA | GND |
| VDDA | 3.3V |

### 修改步骤

1. 在原理图中将 VSSA 接 GND、VDDA 接 3.3V
2. 执行「设计→更新转换→导入 PCB」
3. 在弹出的网络变更窗口中点击「应用修改」
4. 在 PCB 中重新连接这两个引脚：
   - 从 3.3V 电容处删除旧过孔
   - 切换到背面层（第二层），删除旧走线
   - 重新走线并打过孔
   - 在右侧属性面板中将该网络从 GND 改为 3.3V
5. 同样处理其他报错引脚的对应网络
6. **重新铺铜**：顶部和底部铜区域均重建
7. 在空白区域添加 GND 过孔，选择过孔并在右侧改网络为 GND
8. 检查顶部和底部铜区域的网络分配，确保正确后重新重建铜区域

## 常见错误与踩坑

- 未检查原理图错误就下单（参考 VSSA/VDDA 案例）
- 免费 PCB 超出 10 × 10 cm 尺寸限制
- Gerber 导出层数选择不全
- 下单参数与设计不匹配
