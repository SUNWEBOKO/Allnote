# PCB 绘制

**前置知识**：已完成02章原理图绘制并通过DRC
**本节目标**：掌握PCB布局布线流程、理解PCB图层概念、能独立完成PCB设计并通过DRC

## 原理图与PCB图

原理图是抽象连线图，用绿色连线表示元件引脚之间的连接关系，同一组连线构成一个**网络**。PCB图是实物图，板上的走线、焊盘、铜皮会原封不动地制造出来，相当于把设计直接“打印”到基板上。

## 从原理图导入到PCB

1. 打开工程，双击打开原理图（`.eprj` 文件或从软件工程列表打开），再双击打开对应的空白 PCB 图
2. 在原理图界面点击菜单栏 **设计 → 更新转换原理图到PCB**
3. 等待加载完成，弹出变更清单窗口，点击 **应用更改**
4. 所有元件导入到 PCB，引脚之间出现飞线，每根飞线代表一个待连接的网络

**增删元件必须通过原理图操作**：在原理图中放置或删除元件，再执行“更新转换”同步到 PCB。直接在 PCB 中删除元件会导致原理图与 PCB 不一致，DRC 检查时会报错。

## 封装

封装是元件的实际外形尺寸。同一个电气值（例如 510Ω 电阻）可以采用不同的封装（如 0805、1206），它们在原理图中符号相同，但在 PCB 上大小不同，制造出来的实物也不同。

封装的选择在原理图绘制阶段完成，导入 PCB 时已确定。同一电气参数的元件应选用一致的封装，否则实物装配时会出现尺寸不匹配。

## PCB 图层

PCB 按图层组织不同功能区域，最常用的是**顶层**和**底层**。每个层面可再细分为以下子层：

| 子层 | 作用 |
|------|------|
| **铜箔层**（顶层/底层） | 实际的导电线路，铜皮经蚀刻后留下走线 |
| **阻焊层** | 覆盖在铜箔表面的绝缘层（类比电线外皮），有颜色的区域表示**没有阻焊层**（即裸露铜皮供焊接），无颜色区域覆盖阻焊 |
| **丝印层** | 打印在 PCB 表面的字符、标识、位号，与电路无关 |
| **助焊层/装配层** | 辅助生产贴装，一般用户不需要直接操作 |

**底层丝印层是镜像的**：从 PCB 正面看，底层丝印文字与顶层相反，制造时会自动处理为正像。在软件中切换到底层后点击“翻转板子”可预览正向效果。

## 绘制 PCB 的完整流程

### 过孔（Via）

过孔是连接PCB不同层铜箔的导电孔，用于在多层板中走线换层。在嘉立创EDA中按快捷键 V 或通过布线工具栏添加。

### 飞线（Ratline）

飞线是原理图中未连网络的引脚之间的逻辑连接示意线，在PCB中以细线显示。布局时应参考飞线走向，将有电气连接的元件就近摆放。

### 布局

导入元件后先进行布局，原则是：

- 将**飞线密集**的元件放在对应引脚附近，尽量减少飞线长度和交叉
- **晶振**必须紧贴芯片放置，**滤波电容**尽量贴近芯片电源引脚
- 按功能模块集中摆放（如 LDO 降压模块、复位电路、LED 指示等）
- 选中元件后按 **空格** 旋转（默认每次 90°），可在设置中改为 45°
- 超出单个模块的细节对齐问题不必一步到位，布线时还可微调

### 画板框

板框定义 PCB 的外形边界。

1. 点击工具栏 **板框** 工具（或从下拉三角选择矩形/圆形/多边形）
2. 在画布上左键点击起点，拖动到终点，再点击结束
3. 选中板框，右侧 **属性** 面板可设置 **圆角**（如 2mm），避免尖角割手
4. 默认单位是 mil，点击顶部单位切换按钮可切换为 **毫米**

### 布线

布线将各元件引脚按网络连通。优先使用**顶层**，空间不足时通过**过孔**切换到**底层**。

**基本操作**：

1. 点击工具栏 **单路布线**（或使用快捷键），鼠标变为布线光标
2. 左键单击一个焊盘开始走线，移动鼠标到目标焊盘，自动吸附后左键单击完成连接
3. 按 **右键** 取消当前线段。从空白处开始布线同样支持，但习惯上从焊盘开始更直观
4. 不同网络的焊盘之间会有白色方框警告阻止连接，防止短路

**切换图层与过孔**：

- 顶层走线遇到阻挡时，先左键固定当前位置，右键取消布线。在图层面板切换到底层，或使用快捷键切换
- 放置一个**过孔**（工具栏过孔工具），连接顶层到底层的铜皮
- 从过孔继续布线到目标焊盘。如果目标焊盘只存在于顶层（如贴片元件），需要再打一个过孔回到顶层
- **过孔不要在焊盘正上方**，应引出一小段线再打孔，否则焊接时焊锡可能沿孔流失

**线宽设置**：

- 布线时按 **Tab** 键弹出线宽输入框
- 选中已有线段，在右侧属性面板修改线宽。常用值：信号线 6~8 mil，电源线适当加粗
- 超出 DRC 允许范围时软件会提示

**走线规范**：

- 避免**锐角**和**直角**。锐角在生产时易造成蚀刻不良；直角在信号传输中会引起反射，导致信号失真。走线应使用 45° 折角
- 走线尽量贴着已有走线平行敷设，节省空间
- 芯片周围引脚密集，优先从芯片往外布线，先占满顶层，不够再用底层

### 铺铜

铺铜是将板面上未被走线占用的空白区域自动填充指定网络（通常是 GND）的铜皮。

**操作步骤**：

1. 点击工具栏 **铺铜** 工具，选择矩形（或适合板形的形状）
2. 用框选把整个板框包围在内
3. 弹出窗口中设置：
   - **图层**：选择要铺铜的层（顶层或底层）
   - **网络**：选择 GND
4. 点击确认，软件自动在空白区域填充 GND 铜皮
5. 顶层和底层分别执行一次上述操作

**铺铜的作用**：

- 省去手动连接所有 GND 引脚的工作量
- 增强 PCB 机械强度，防止板子弯曲变形
- 提高散热能力（铜皮导热优于玻纤基材）
- 减少信号干扰
- 避免细长走线在蚀刻时翘起或断裂

**注意事项**：被其他网络走线包围的孤立区域可能无法铺上 GND 铜皮，可通过打过孔将其与其他 GND 区域连通，然后**重建铺铜区域**（选中铺铜 → 属性 → 重建铺铜区域）。

### DRC 检查

DRC（Design Rule Check）是 PCB 生产前的最后一道自动校验，确保所有网络连接正确、间距满足安全要求。

**操作流程**：

1. 点击工具栏 **DRC** 图标
2. 下方弹出 DRC 结果面板，列出所有错误和警告
3. 双击具体的错误条目，画面自动定位到问题位置
4. 常见错误类型：
   - **间距错误**：两个不同网络的导体距离过近。将过孔或走线拖离即可
   - **连接性错误**：某些 GND 引脚因铺铜被分割而未连通。手动打过孔或补一段走线连接，再重建铺铜区域
5. 修复后点击 **清除错误**，再次运行 DRC 确认所有问题已消除
6. **不论改动多小（哪怕只加了一行丝印），发往生产前必须执行一次 DRC，确保零错误**

### 添加丝印

1. 切换到对应丝印层（顶层丝印层或底层丝印层）
2. 使用 **文本** 工具输入文字（如板名、版本号）
3. 在属性面板调整字高、线宽
4. **不要在铜箔层放置文字**，否则铺铜时会将其挖空，且铜面上的字符几乎不可辨认。务必放置在丝印层

## 常见错误与排查

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 导入 PCB 后元件不显示 | 未执行“更新转换原理图到 PCB” | 在原理图点击 设计 → 更新转换 |
| 有飞线但 GND 网络没连 | 未铺铜或铺铜配置错误 | 铺铜区域设置为 GND 网络，重建铺铜 |
| DRC 间距报错 | 走线/过孔与相邻导体太近 | 拖开过孔或走线，重建铺铜后重新 DRC |
| 在 PCB 中删除元件后原理图还在 | 误操作 | 必须从原理图删除后再更新转换 |
| 丝印文字在 3D 预览中不可见 | 文字放在了铜箔层而非丝印层 | 选中文字，在图层面板切换为丝印层 |
| 过孔与焊盘距离太近导致焊接不良 | 过孔打在焊盘上 | 引出短走线后再打孔 |
| 铺铜后出现孤立铜皮 | 该区域被其他网络包围 | 打过孔连通到 GND，重建铺铜 |
| 3D 预览中元件重叠 | 布局时元件放置过于拥挤 | 重新调整布局，保留安全间距 |
| 忘记设置板框导致切板偏位 | 导入PCB时未定义板框 | 先在机械层画闭合板框，再执行切板操作 |

## 检查与输出

- **3D 预览**：检查元件是否重叠、空间是否干涉、焊接面是否正确
- **保存工程**（Ctrl + S）
- **最终 DRC**：必须确保零错误后再交付生产

整个 PCB 绘制的核心就是**布局 → 画板框 → 布线 → 铺铜 → DRC 检查**，每个环节对应一组工具和规范，熟悉后本质上就是按网络表把引脚"连连看"。
