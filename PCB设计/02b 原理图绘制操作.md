# 原理图绘制操作

**前置知识**：已理解 02a 原理图基础概念
**本节目标**：掌握嘉立创 EDA 原理图绘制全流程，能独立完成原理图绘制并通过 DRC

## 创建工程

1. 打开立创 EDA，在「快速开始」中点击「新建工程」
2. 选择工程保存位置，输入工程名称，点击保存
3. 系统自动创建板子（Board），包含一张原理图和一张 PCB
4. 右键板子或原理图可以重命名

**工程结构：**

```
工程
 └─ 板子（Board）
     ├─ 原理图（Schematic）
     └─ PCB
```

一个原理图必须属于某个板子才能与 PCB 关联。独立的原理图文件无法生成 PCB。

## 放置元件

### 在立创商城搜索元件

1. 打开立创商城（LCSC）网页
2. 搜索元件型号或参数
3. 按销量排序，选择常用的型号
4. 使用筛选功能按封装、频率、阻值等参数精确查找
5. 复制该元件的 C 号

**C 号**是立创商城为每个元件分配的唯一编号。购买元件时必须以完整的型号名称为准，后缀不同的型号参数可能不同。

### 通过 C 号在立创 EDA 中放置

1. 点击工具栏的「元件」图标
2. 在搜索框中粘贴 C 号，回车搜索
3. 确认结果与 C 号匹配，点击「放置」
4. 在原理图区域单击左键放置元件
5. 按 ESC 退出放置模式

### 复制已有元件

原理图中已有同型号元件时，可以直接选中后 Ctrl+C / Ctrl+V 复制。系统自动为副本分配递增的位号。

也可以通过选中元件后在右侧属性面板复制供应商编号（C 号），用同样的方法搜索放置。直接从 C 号搜索购买元件也很方便。

### 晶振搜索示例

搜索晶振时需要注意区分有源晶振和无源晶振：

| 类型 | 引脚数 | 特点 |
|------|--------|------|
| 有源晶振 | 4 个 | 内部含振荡电路 |
| 无源晶振 | 2 个 | 需配合芯片内部振荡电路使用 |

以 32.768kHz 晶振为例：先搜索"晶振"，在类目中选择「无源晶振」，筛选频率为 32.768kHz，按销量排序后选择常用型号。

### 电阻搜索示例

搜索电阻时需指定：

- **阻值**：如 510Ω、10kΩ、1MΩ（大写 M 表示兆欧，小写 m 表示毫欧）
- **封装**：如 0805、0603

筛选时先用类目定位到贴片电阻（如贴片电阻 → 厚膜电阻），再设置具体参数。

### LED 搜索示例

搜索 LED 时需注意：

- 选择封装（建议与电阻统一，如 0805）
- 颜色可以按需求选择
- **检查封装极性**：立创商城上部分 LED 的封装正负极标记与实际方向相反。将 LED 导入 PCB 后检查封装符号：竖线加箭头，箭尾为负极，箭头指向为正极。如果箭头方向与引脚编号对应错误，焊接时需要手动调整方向。

## 连线

### 导线工具

1. 点击工具栏的「导线」图标（或按快捷键 W）
2. 单击元件引脚的灰色小点开始连线
3. 移动到目标引脚，再次单击完成
4. 按 ESC 退出导线模式

### 快速连接

两个引脚距离很近时，直接将它们拖动至重叠再松开，即可建立连接。

### 交叉与连接点

- 导线交叉处有红色圆点 → 两条线相连
- 导线交叉处无红色圆点 → 交叉但不连接
- 在一条已有导线上单击可以创建连接点，再引出分支

### 折线与导线的区别

- **导线（快捷键 W）**：建立电气连接，是电路的一部分
- **折线（快捷键 L）**：绘制分隔区域的装饰线，不表示任何电气连接

这两个工具不要混淆。

## 电源与地

### 使用电源符号

1. 点击工具栏的 VCC/GND 图标
2. 选择「放置 VCC」或「放置 GND」
3. 在原理图中单击放置

双击 VCC 符号可以修改网络名。当电路中有多种电压时（如 3.3V、5V、12V），分别使用不同的网络名便于区分。

### 直接使用网络标签

也可以放置一个普通网络标签，将其命名为 3.3V 或 GND，效果与电源符号相同。电源符号只是更便于识别。

### 芯片供电连接

以 STM32 为例：
- VDD 引脚接 3.3V（正极）
- VSS 引脚接 GND（负极）
- VBAT（电池备用供电引脚）如果不使用可以保持悬空，或放置非连接标识

每个电源引脚附近通常需要放置滤波电容（如 100nF），电容一端接电源，另一端接地。

## 网络标签的放置

1. 点击工具栏的「网络标签」图标
2. 输入网络名称
3. 单击放置在导线或引脚上
4. 按空格旋转标签方向

### 应用场景：引出芯片引脚

芯片的 I/O 引脚（如 PA0~PA9）如果全部用导线引出，原理图会非常拥挤。正确做法是：

1. 在每个芯片引脚上放置网络标签（PA0、PA1…）
2. 在排针引脚上也放置对应的标签
3. EDA 自动识别它们属于同一网络，无需画实际导线

### 应用场景：不同图页间连接

当原理图包含多个图页时，相同网络名的标签在不同图页之间也保持连接。例如图页 1 中 PA0 连接排针，图页 2 中 PA0 连接 STM32，它们属于同一个网络。

## DRC 检查

DRC（Design Rule Check，设计规则检查）用于检测原理图中的低级电气错误，在画完原理图后运行。

**检测内容：**
- 不同网络短接：两个不同的网络标签被同一根导线连接
- 引脚悬空：某个引脚未连接任何网络

**不检测内容：**
- 电路设计是否正确（如芯片是否接了正确的晶振、电阻值是否合适）。这些需要人工审查。

**操作步骤：**
1. 点击菜单「设计」→「检查 DRC」
2. 清空之前的警告信息
3. 点击「检查 DRC」开始检查
4. 查看结果：无错误/警告表示通过

**引脚悬空处理：** 如果某个引脚设计上就不需要连接，可以在该引脚上放置一个非连接标识（叉号），DRC 检查时就不会报错。不放置此标识不影响电路功能，但 DRC 会给出警告。

## 绘制流程

1. **创建工程**：新建工程，自动生成板子和原理图
2. **确定元件清单**：根据设计需求列出所有元件及其参数
3. **搜索放置元件**：在立创商城搜索元件，通过 C 号放置到原理图
4. **统一封装**：设置所有元件的封装尺寸，建议整板统一
5. **布局**：将元件摆放到合适位置，按功能模块分区
6. **连线**：使用导线工具连接近距离的引脚
7. **添加网络标签**：远距离连接或跨图页连接使用网络标签
8. **添加电源网络**：放置 VCC 和 GND 符号，连接芯片供电引脚
9. **添加文字标注**：用文字说明各模块功能
10. **DRC 检查**：运行设计规则检查，排除低级错误
11. **保存**：Ctrl+S 保存工程

## 常见错误
- 元件未连接网络标签
- 电源网络未标注（VCC/3V3/5V 等）
- DRC 检查报错未处理就导入 PCB
- 封装选择与实际元件不匹配
