## 什么是 PCB

**PCB（Printed Circuit Board，印刷电路板）** 的本质是将元器件之间的连线“印”在一块板子上。

在没有 PCB 时，搭建电路通常靠面包板插线或杜邦线一根一根连接。PCB 将所有这些连线固定在板内，省去了手工接线的步骤，长期使用比接线更稳定、更便捷。

> PCB 本质上就是把一根一根的杜邦线画在一块板子上，让它们在板内自行连通。

PCB 应用极广，几乎所有电子设备内部都含有 PCB——从复杂的主板到可调光 LED 灯，无一例外。

## 为什么选择嘉立创 EDA

PCB 设计领域的主流软件还有 **Altium Designer（AD）** 和 **Siemens PADS**。本课程选用嘉立创 EDA，原因如下：

- **国产免费**，安装和使用都更人性化
- **生态闭环**：嘉立创同时提供——立创商城（元器件采购）、PCB 板厂（制造）、SMT 贴片（自动焊接），从设计到拿货一条龙打通
- **入门友好**：掌握嘉立创 EDA 的设计思路后，再切换其他软件也很容易

## 软件安装

需要安装两个软件：

1. **嘉立创 EDA（桌面客户端）**——绘制原理图和 PCB
2. **嘉立创下单助手**——将 PCB 文件发给工厂制造

### 安装嘉立创 EDA

1. 浏览器搜索"嘉立创 EDA"，打开官网
2. 将鼠标悬停在"产品"上，选择**桌面客户端**（优先于在线编辑器，原因：稳定性更好、无需时时联网）
3. 选择**专业版**（标准版体验较差）
4. 根据系统（Windows / Linux / macOS）下载对应版本
5. 双击安装程序 → 下一步 → 同意协议 → 选择安装路径 → 创建桌面快捷方式 → 安装完成

**激活步骤：**

1. 首次运行弹出激活客户端提示，点击"设置" → "免费下载"
2. 登录账号，页面生成客户端激活文件，点击"下载文件"
3. 回到嘉立创 EDA，点击"导入激活文件"，选择下载的文件 → 打开 → 激活

**验证安装：**

新建工程 → 填写工程名 → 保存。此时原理图和 PCB 文件会自动生成。推荐选择"修改网络名"模式，点击确认即可。该模式允许在原理图中通过修改网络标签名来自动更新 PCB 中的连接，便于后期调整而不必重画走线。

### 安装下单助手

1. 浏览器搜索"嘉立创下单助手" → 打开官网
2. 点击"下载" → 根据操作系统选择版本
3. 下载后解压压缩包，双击 `.exe` 文件
4. 安装步骤全部默认下一步，取消勾选"开机启动" → 安装完成
5. 双击打开 → 微信扫码登录即可使用

> 嘉立创 EDA 也支持在线使用（官网有入口），但推荐使用桌面客户端。

## 总结

- PCB 是将连线固化在板上的技术，本质是替代手工接线，更稳定、更便捷
- 嘉立创 EDA 免费、国产、生态完整，适合入门
- 本节已完成两个客户端的安装，后续章节将正式开始原理图与 PCB 的绘制

## 常见错误
- 下载时选错版本（专业版 vs 标准版），建议选择专业版
- 安装路径含中文导致异常，建议使用纯英文路径
- 未安装下单助手，后续下单 Gerber 文件需要用到
