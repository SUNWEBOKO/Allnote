# 05 软件入门 安装界面与环境设置

> 前置要求：入门篇完成。本章对应课程第 12~14 课，进入强化篇软件实战：安装立创EDA专业版、认全界面、把设计环境一次调好。

## 1. 安装：选桌面客户端，不要在线版

官网下载时有两个选项：**在线编辑器**（浏览器里跑，卡顿且不稳定）与**桌面客户端**——务必选后者。安装流程：下载对应系统的专业版安装包（几百 MB，安装很快）→ 以管理员身份运行 → 选择安装位置 → 启动后登录账号；首次使用按官网提示下载**激活文件**完成激活。

**三种运行模式**（右上角齿轮 → 系统）：**全在线**（工程与个人库存服务器，任何电脑可用）、**半离线**（工程本地 + 可用在线系统库）、**全离线**（全本地，不能用在线库）。推荐**全在线模式**——省心且不占本地空间；需要归档时手动导出工程即可。同时记下**自动备份路径**：死机后可从该文件夹找回未保存的板子。

## 2. 界面导览

### 2.1 首页面板

新建工程（一切设计的第一步）、打开工程、新建符号/封装（自建元件库用，见 [06 章](06%20自建元件库%20绘制符号与封装.md)）、迁移标准版工程到专业版、导入 AD 工程（原理图 + PCB 打包 zip 上传）。

### 2.2 原理图界面

- **左侧导航栏**：所有工程 / 工程设计（当前工程的板子 → 原理图 + PCB）/ **常用库**（电阻电容等标准化元件，画图常从这里拿）/ 器件标准化（批量分配位号）；
- **右侧属性栏**：点画布显示图页属性、点元件显示元件属性；
- **底部面板**：库（全局搜元件）、日志（操作记录）、DRC、查找（全局搜索）；
- **菜单栏速览**：文件（新建/保存/导入导出）、编辑（撤销/复制）、视图（适应全部、`Q` 切换单位、网格/网点）、放置（导线、图形注释、**原理图转 PCB**）、设计（设计规则、检查 DRC、**交叉选择**、**布局传递**）、布局（对齐工具）、工具（封装管理器、器件管理器）、导出（网表、PDF）、下单（嘉立创下单助手）。

### 2.3 PCB 界面

比原理图多出**图层栏**（右侧，点击切换图层）；菜单新增：视图（2D/3D 预览）、放置（过孔、焊盘、板框、铺铜、文本/图片）、设计（从原理图导入变更、PCB 设计规则：安全间距等、网络类/差分类管理器）、布线（单路/差分/等长调节、布线角度与模式）、工具（测量、泪滴）。

一个板子的结构再强调一遍：**工程 → 板子 → 原理图（可多图页）+ PCB**。

## 3. 设计环境设置：一次调好，全程受益

设置 → 系统 → 通用。以下为推荐配置（有旧软件习惯的按自己偏好，没有的照抄）。

### 3.1 通用选项

| 分类 | 推荐设置 |
| --- | --- |
| 系统 | 国库管理简易模式；双击工程新窗口打开；画布缩放用滚轮 |
| 原理图 | 单位 mil；网格类型"使用网格"；十字光标大；默认网格 0.05、**Alt 吸附 0.01**（按住 Alt 临时细化网格）；移动符号导线默认跟随 |
| PCB | 网格显无；**新建 PCB 默认单位 mil，新建封装默认 mm**（画封装对照数据手册，手册是毫米）；每次旋转 90° |
| 布线 | **不勾选"优先放置盲埋孔"**（工艺贵，普通板用通孔即可）；保存前检查 DRC |
| 显示 | 主题选嘉立创EDA；未激活层透明度 60%（当前层更突出） |
| **快捷键** | 配置选**嘉立创EDA标准版**（好记顺手） |
| 顶部工具栏 | 按需勾选；**对齐相关全部勾上**（对齐操作高频，点按钮比背快捷键快） |
| 保存 | **开启自动保存（10 分钟）+ 自动备份**——防崩溃丢稿的生命线 |

### 3.2 设计规则（DRC 判据）

**原理图设计规则**：检查项全部勾选即可。（本课程会关掉"元件属性与供应商编号匹配"一项——它面向 SMT 贴片下单，自行焊接无意义，留着只会报警告。）

**PCB 设计规则**比原理图复杂，画板前先设好：

| 规则项 | 推荐值 | 说明 |
| --- | --- | --- |
| 安全间距 | 默认矩阵（导线-导线 6mil 量级） | 矩阵读法：**行与列的交叉格**就是两类对象间的最小间距（如"焊盘行 × 导线列"格 = 焊盘到导线间距） |
| 线宽 | 最小 5 / 最大 100 / **默认 10 mil** | 默认 10mil 即信号线宽 |
| 差分对 | 线宽同信号线、间距 6、误差 10mil | 差分要求高的项目把误差改 5mil |
| 过孔 | 外径 24 / 孔径 12 mil | 通孔默认值 |
| 铺铜 | 连接方式**发散**，发散线宽/间距 10、角度 90° | 直连焊接时散热太快需要大功率烙铁；发散即十字连接 |
| 阻焊拓展 | 2mil | 阻焊开窗比焊盘略大 |
| 网络规则 | 可按网络单独设置 | 如电源网络单独放宽线宽（见 [09 章](09%20项目一51核心板%20PCB布线.md)） |

## 4. 本章快捷键速查（强化篇通用）

| 快捷键 | 功能 | | 快捷键 | 功能 |
| --- | --- | --- | --- | --- |
| `Q` | mil / mm 单位切换 | | `Shift + X` | 交叉选择（原理图↔PCB 定位元件） |
| `Ctrl + S` | 保存 | | `Ctrl + Shift + X` | 布局传递（按原理图布局映射到 PCB） |
| `Alt`（按住） | 临时细化网格吸附 | | `R` | 快速放置矩形框 |

## 5. 检查点

- 说清全在线 / 半离线 / 全离线的差别与推荐选择；
- 自动备份路径在哪里设置、出事后怎么找回文件；
- 新建 PCB 与新建封装的默认单位为什么不同；
- 解释安全间距矩阵的读法，以及铺铜连接方式选"发散"的原因。
