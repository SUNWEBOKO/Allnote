# 13 项目二USB拓展坞 丝印DRC与导出

> 前置要求：布局布线完成（[12 章](12%20项目二USB拓展坞%20PCB布局与布线.md)）。本章对应课程第 28 课，也是整个入门+强化篇的收官：丝印、DRC、导出 Gerber。

## 1. 丝印调整

1. **功能丝印替换位号**：删除电源 LED 的位号，加文本 `POWER`（顶层丝印，高度约 60mil）——灯亮即通电；
2. **logo 与标题**：放置 → **图片**导入频道 logo（调整尺寸、层设为顶层丝印）；再导入文字图片横排在旁；放文本 `USB HUB` 标明板子功能，可勾选**反向**使文字底部填充更醒目；放在靠近板边的空白区；
3. **背面丝印**：复制这三个元素，属性改为**底层丝印**，`B` 切到底层摆放在空白处——背面也不空着；
4. 3D 预览检查正反面观感（浅色背景下黑色阻焊效果最佳），保存。

与项目一相同的丝印方法论：**位号可以删，功能标识必须留**——POWER、接口名、按键功能、引脚号，都是"不查原理图就能用板子"的关键。

## 2. DRC 检查

打开过滤显示铺铜区域 → DRC 面板 → 清除错误 → **检查 DRC** → 0 报错。

排错方法与项目一完全一致（[10 章](10%20项目一51核心板%20丝印DRC与打板.md) 的四步法：错误类型 → 点击对象定位 → 规则名称 → 解释中的实际/要求距离），画板全程开着实时 DRC 的话，此时通常一把过。

## 3. 导出生产文件

文件 → 导出 → **PCB 制版文件（Gerber）** → 选择保存位置 → 得到 Gerber 压缩包。

后续流程与项目一相同：嘉立创下单助手 → 领每月 2 次的 1~4 层免费打样券 → 上传 Gerber → 5 片、FR4、黑油、无 SMT → 用券 0 元下单 → 约 4~5 天收货。到货焊上 SL2.1A、Type-C、4 个 USB 母座与阻容，插上电脑，插拔 U 盘验证——你的第二个自制硬件就落地了。

## 4. 结课总结：你已完成什么

入门篇 + 强化篇共约 6 小时课程，跟着做下来你已经：

1. **掌握 PCB 设计的完整流程与方法**：需求 → 选型（数据手册）→ 原理图（模块化 + DRC）→ PCB（板框、布局、布线、包地、铺铜）→ 丝印 → DRC → Gerber 打样；
2. **独立完成两个实战项目**：51 单片机核心板（最小系统、按键、LED、上拉、排针）与 USB 拓展坞（差分信号、电源保护、多口布局）；
3. **熟悉立创EDA专业版**的核心操作：布局传递、交叉选择、差分布线、等长调节、禁止区域、铺铜重建、DRC 排错。

后续进阶路线（大师篇）：STM32 电赛开发板等复杂工程、蓝桥杯省赛/国赛真题、高速电路初步——把自己梦想中的 PCB 作品变为现实。

## 5. 检查点

- 独立完成本板丝印（POWER + logo + USB HUB + 背面复刻）；
- 完成一次 0 报错的 DRC，并说明实时 DRC 的价值；
- 导出 Gerber 并完整走一遍免费打样下单。
