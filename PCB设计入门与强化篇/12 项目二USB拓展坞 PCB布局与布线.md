# 12 项目二USB拓展坞 PCB布局与布线

> 前置要求：原理图 DRC 清零（[11 章](11%20项目二USB拓展坞%20选型与原理图.md)）。本章对应课程第 26、27 课：把拓展坞装进 30×100mm 的细长板框并完成布线——差分线第一次成为布线主角。

## 1. PCB 布局

### 1.1 板框与定位孔

转 PCB 前**再跑一遍原理图 DRC**。板框层画矩形：**宽 30mm × 高 100mm**（拓展坞专用的细长形），圆角 3mm；4 个 M3 定位孔（过孔外径 4 / 内径 3mm），坐标 (2.6, -2.6)、(2.6, -97.4)、(27.4, -97.4)、(27.4, -2.6)；与板框一起**锁定**。

### 1.2 布局要点（沿信号流向）

1. **Type-C 居中、略超出板框**——装外壳时插座不与外壳干涉；中心 X=15mm 精确定位；CC 下拉电阻放板边（给差分线让路）；
2. **电源链**：Type-C → 10µF（先大）→ 0.1µF（后小）→ 保险丝 → 电源指示灯 → 主控；滤波电容靠近各自供电对象；
3. **SL2.1A 放左侧**（USB 口在右侧），旋转到引脚朝向 Type-C 与 USB A 都顺的方向；**晶振不要贴板边**（贴边易电磁外泄），电容同理留边距；
4. **4 个 USB A 沿引脚顺序排列**在右侧板边：**接地焊盘贴板边**、留出空隙防外壳干涉；右对齐 + 垂直等间距，注意软件报错提示（离板边太近/互相干涉）及时移开；插 USB 设备不能打架；
5. **USB 滤波电容**：先大后小、贴近 USB 引脚；正面放不下的（第二个接口处）**放背面**，打过孔接 5V 引脚——不重要的元件为重要信号让位；
6. 精细化：对齐（顶对齐/左对齐/垂直等距）、丝印位号统一方向、GND 飞线先关掉。

## 2. PCB 布线

### 2.1 改规则：差分误差 5mil

设置 → 设计规则 → 差分对 → 单位 mil → **对内误差 5mil**（比项目一的 10mil 更严，照 [11 章](11%20项目二USB拓展坞%20选型与原理图.md) 的七原则）。

### 2.2 第一优先：六对差分线

设计 → 网络 → 差分对 → 添加 **6 对**：DP/DM（上行）、DP1~DP4/DM1~DM4（下行 4 对）、XTAL1/XTAL2（晶振）——**晶振也按差分对处理**，软件自动检查等长。

布线快捷键 **`Alt + D`（差分对布线）**：两线同时拉出并实时显示长度差：

- 自动出线若不是从焊盘**短边**引出，手动调整出线方向；
- 挡路的元件（滤波电容）挪到底层，为差分线让出通道——**不重要的线给重要的线让路**；
- 四对下行差分线尽量互相平行、上下对称；
- 长度差超标的（上行 DP/DM）用**等长调节**：布线 → 等长调节，框选区域自动生成**蛇形走线**给短线补长，直到误差 < 5mil 变绿。

### 2.3 次要信号线

电源指示灯、CC1/CC2（快充识别信号）：10mil 普通信号线直接连接，无特殊要求。

### 2.4 电源线：实心填充

电源网络用**实心填充（铺铜/填充区域-多边形）**连接——整块铜皮的载流能力远强于导线：

1. 把 +5V 网络的所有焊盘整片框住（含滤波电容）；
2. Type-C 右侧焊盘外扩一块填充，**打 3 个过孔**（外 24 / 内 12mil）连接左右两侧——**单个过孔载流弱，三个过孔并联载流强**；切底层用填充把 6 个过孔连成一片，实现顶层-底层电源互连；
3. 线宽照旧遵循**不超过焊盘宽度**：SL2.1A 焊盘宽 22mil → 到芯片的电源线取 22mil；到保险丝一段取 30mil；
4. 电流路径铁律不变：**输入滤波 → 保险丝 → USB 口旁滤波 → USB 口**；USB 口的滤波电容在背面，电源打过孔到背面先过电容再进接口；
5. 十字连接自动补泪滴。

### 2.5 GND：缝合孔 + 晶振包地 + 整板铺铜

1. **地过孔阵列**：`V` 放过孔（网络 GND），成组对齐（水平等距）铺满空白区；**电源附近、USB 引脚附近多加**（回流路径）；
2. **晶振包地**（与项目一相同）：一圈 GND 过孔包围晶振电路 + 粗地线（约 20mil）串联 + **禁止区域（多层，禁止铺铜）**罩住整个晶振区；
3. 工具 → 铺铜 → 矩形，顶层、底层各铺整板 GND；
4. 检查飞线归零 → 3D 预览验收。

## 3. 检查点

- 说出 Type-C"略超出板框"与 USB A"接地焊盘贴板边"各自的原因；
- 演示添加 6 对差分组并用 Alt+D 布线，把误差压进 5mil；
- 解释"单过孔载流弱、三过孔并联"以及实心填充的适用对象；
- 复述本板电源电流路径（含背面临时电容的处理）。
