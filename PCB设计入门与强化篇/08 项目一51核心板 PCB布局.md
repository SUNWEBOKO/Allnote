# 08 项目一51核心板 PCB布局

> 前置要求：原理图 DRC 清零（[07 章](07%20项目一51核心板%20选型与原理图.md)）。本章对应课程第 20 课：布局的通用要求 + 把 51 核心板的所有元件摆进 70×40mm 板框。

## 1. 布局的通用要求

蓝桥杯 EDA 组考题对布局的要求（同样适用于一切板子）：

1. **元器件相互平行或垂直排列**，整齐美观——不要东横西竖；
2. **排列紧凑、分布均匀、疏密一致**——不要留大片空白，也别局部堆死；
3. ~~所有元件放顶层~~——那是为回流焊大批量生产定的话；自己手焊放哪层都行。

再补三条实战原则：

4. **按电气与使用特点布局（人体工程学）**：接口、按键、排针放**板边**（Type-C 放板中间根本没法插线）；屏幕与主控放**中央**；电源电路放**电源输入旁**并注意电流路径与滤波电容位置；**晶振贴着单片机放**；
5. **元件是三维的**：注意元件高度——屏幕插座下方不能放高元件，否则装不上；
6. **模块化布局**：同一功能的电路放同一区域，方便布线与调试。

## 2. 转 PCB、板框与定位孔

1. 原理图界面先跑一遍 DRC 确认干净 → 工具栏**原理图转 PCB** → 应用修改，全部元件带飞线进入 PCB；
2. **板框**：切到板框层 → 放置 → 线条 → 矩形（起点对准原点）→ 属性里精确输入 **宽 70mm × 高 40mm**（免费打样上限 100×100mm）→ 右键 → 添加 → **圆角 3mm**（防划手 + 美观）；
3. **定位孔 ×4**：放置过孔，`Tab` 设**外径 4mm / 内径 3mm**（M3 螺丝孔），坐标参数化输入：

| 孔 | X (mm) | Y (mm) |
| --- | --- | --- |
| 左上 | 2.6 | -2.6 |
| 左下 | 2.6 | -37.4（=40-2.6） |
| 右上 | 67.4（=70-2.6） | -2.6 |
| 右下 | 67.4 | -37.4 |

4. 板框与定位孔全部选中 → 右键**锁定**，防止后续误拖。

## 3. 预布局：两个神级快捷键

| 快捷键 | 名称 | 作用 |
| --- | --- | --- |
| `Shift + X` | **交叉选择** | 原理图选中元件 ↔ PCB 高亮同一元件，双向定位 |
| `Ctrl + Shift + X` | **布局传递** | 原理图框选一个模块 → PCB 中元件按原理图相对位置自动摆放 |

先关掉 GND 的飞线（最后统一铺铜，飞线只会碍事）。然后按原理图的模块逐块布局传递：电源电路、按键、引脚引出、单片机、晶振、复位、按键检测、LED、排针——板外先摆成"拼装好的零件"，再整体上板。

## 4. 上板布局要点

1. **电源模块**：Type-C 与开关放板边（方便插线/拨动）；**CC 下拉电阻贴着 Type-C**；按电流流向排布：Type-C → 开关 → LDO → 输出；**滤波电容先大后小**——C2（10µF）远离芯片、C1（0.1µF）贴近芯片引脚；输出侧同理，3.3V 出来先过小电容再过大电容；
2. **主控**：单片机放板子中央（本板放在中轴线 Y=-20 上），两排排针贴板边对称放置，中间留丝印空间；串口排针放左侧空位；
3. **晶振**：必须贴近晶振引脚，并**与两引脚轴对称**——这样两根晶振线天然等长（为布线埋好伏笔，见 [09 章](09%20项目一51核心板%20PCB布线.md)）；
4. **P0 上拉电阻**：放 P0 口附近，本板挪到**底层**（属性 → 图层 → 底层，`B` 切换视角），贴近引脚与排针对齐；
5. **按键**：与晶振轴对称放置（2.0/2.1 引脚在上方，按键放右上方便走线）；
6. **LED**：放中间，3.3V 出线就近；位号先删，之后统一加功能丝印（POWER）；
7. 全程随手用**对齐工具**（顶对齐、水平/垂直等距分布、中心对称）+ 调整丝印位号位置；发现局部过密（左下角）就把按键挪到右上角平衡疏密。

## 5. 检查点

- 复述布局六要求，并各举一个本板的对应操作；
- 演示交叉选择与布局传递的完整操作；
- 说出滤波电容"先大后小"的物理含义（电流先经过大电容滤波再到小电容最后进芯片）；
