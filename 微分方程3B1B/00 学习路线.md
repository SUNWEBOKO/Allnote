# 微分方程 3B1B 学习路线：从变化率到矩阵指数

这个文件夹的主线是：

> 微分方程不是先求答案，而是先描述“一个量怎样变化”。

3Blue1Brown 风格的重点不是公式堆砌，而是几何直觉：变化率、向量场、相空间、热扩散、傅里叶分解、复指数和矩阵指数都在回答同一个问题：

> 如果知道每个状态下一步会怎么变，整个系统会怎样演化？

---

## 0. 学前需要知道什么

从 0 开始读，只需要先具备下面几个最低直觉：

| 概念 | 最低要求 |
| --- | --- |
| 函数 | 知道 $y=f(x)$ 表示输入和输出的关系 |
| 导数 | 知道导数表示变化率 |
| 积分 | 知道积分可以把变化率累积成总变化 |
| 向量 | 知道向量可以表示位置、速度或状态 |
| 复数 | 知道 $i^2=-1$，复数可以表示平面上的点 |
| 矩阵 | 知道矩阵可以把一个向量变成另一个向量 |

如果某个概念不熟，不必先补完整教材。读这些笔记时先抓直觉，遇到公式先问：变量是什么、变化率是什么、初始条件是什么。

---

## 1. 推荐阅读顺序

### 第一步：`01 微分方程概论.md`

目标：理解微分方程在描述“变化规律”，不只是求一个函数。

重点看：

- ODE 与 PDE 的区别；
- 单摆方程如何建立；
- 相空间和向量场；
- 为什么很多方程不能写出简单解析解，但仍然能研究。

读完应能说出：

> 微分方程给出的不是结果本身，而是每个状态下系统接下来怎么动。

### 第二步：`02 热方程与偏微分方程.md`

目标：从 ODE 走向 PDE，理解“整个函数随时间变化”。

重点看：

- 温度函数 $T(x,t)$ 为什么有两个变量；
- 偏导数表示只改变一个方向；
- 热方程为什么用二阶空间导数；
- 拉普拉斯算子的邻居平均直觉。

读完应能说出：

> 热方程描述的是每个点不断趋向周围平均值，所以温度分布会越来越平滑。

### 第三步：`03 热方程的求解方法.md`

目标：理解为什么正弦、余弦波适合解热方程。

重点看：

- 正弦/余弦二阶导后仍是自身的常数倍；
- 边界条件如何限制可用频率；
- 每个模态随时间指数衰减；
- 叠加原理如何构造一般解。

读完应能说出：

> 复杂温度分布可以拆成许多简单波形，每个波形按自己的速度衰减。

### 第四步：`04 复傅里叶级数分析.md`

目标：把傅里叶级数从热方程推广到旋转向量和画图。

重点看：

- 傅里叶级数如何表示复杂函数；
- 复指数为什么表示旋转；
- 系数 $c_n$ 为什么是“抓出某个频率”的平均值；
- 有限项逼近和不连续点的意义。

读完应能说出：

> 傅里叶级数是在把复杂对象拆成不同频率的简单振荡。

### 第五步：`05 指数函数几何意义.md`

目标：理解指数函数统一增长、衰减和旋转。

重点看：

- $x'=kx$ 与指数函数；
- $k<0$ 时的衰减；
- $z'=iz$ 为什么产生旋转；
- 欧拉公式的运动直觉。

读完应能说出：

> $e^{kt}$ 描述变化率与自身成正比；当 $k=i$ 时，这种变化表现为旋转。

### 第六步：`06 矩阵指数与微分方程.md`

目标：把指数函数推广到线性微分方程组。

重点看：

- 矩阵指数的泰勒级数定义；
- $\vec{x}'=A\vec{x}$ 的解为什么是 $e^{At}\vec{x}(0)$；
- 矩阵如何定义向量场；
- 旋转矩阵与矩阵版欧拉公式。

读完应能说出：

> 矩阵指数 $e^{At}$ 是线性系统的状态推进器。

## 2. 新手自测

1. ODE 和 PDE 的区别是什么？
2. 为什么单摆的状态不能只用角度 $\theta$ 描述，还要加上 $\dot\theta$？
3. 热方程中的 $\partial T/\partial t$ 和 $\partial^2T/\partial x^2$ 分别表示什么？
4. 为什么高频温度波形在热方程中衰减更快？
5. 傅里叶级数为什么能用来表示复杂函数？
6. $e^{it}$ 为什么对应复平面上的旋转？
7. 矩阵 $A$ 在方程 $\vec{x}'=A\vec{x}$ 中扮演什么角色？
8. 为什么 $e^{At}$ 可以理解为“沿着向量场走一段时间”？

第一次读只要能回答一半，就已经建立了主线。第二遍再回到例题和公式，会更容易真正吃透。
