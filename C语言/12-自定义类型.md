# 第 12 章：自定义类型：结构体、联合体、枚举与类型别名

## 本章目标

- 用 `struct` 把相关成员组织成一条记录，掌握访问、初始化、复制与传参；
- 用 `typedef` 为复杂类型起别名，让接口更可读；
- 理解 `union` 共享存储的语义与适用边界；
- 用 `enum` 表达有限状态，替代魔法数字；
- 了解位字段、弹性数组成员等进阶写法。

## 边界

`struct`/`union`/`enum` 与 `typedef` 在真实代码里几乎总是组合使用，因此合成一章。动态分配与释放规则沿用第 11 章；链表等自引用结构只需"能读懂"，不要求熟练实现。

## struct：把相关数据组成一条记录

内置类型只有数组能装多个值，但它要求元素同类型。现实对象（学生：学号 + 姓名 + 成绩）需要把不同类型组合在一起，`struct` 就是干这个的——它在很大程度上承担了其他语言"对象"的角色：

```c
struct fraction {
  int numerator;
  int denominator;
};
```

注意两点：类型名是 `struct fraction`（单独的 `fraction` 没有意义）；**结尾分号不能省略**。

使用：

```c
struct fraction f1;
f1.numerator = 22;       // 点运算符 . 访问成员（也称字段/属性）
f1.denominator = 7;
```

声明与初始化可以合并；大括号里的值按声明顺序对应，少了自动补 0；也可以用 `.成员名` 指定位置（推荐，顺序无关、可读性好）：

```c
struct car {
  char* name;
  float price;
  int speed;
};

struct car saturn = {"Saturn SL/2", 16000.99, 175};
struct car mazda  = {.speed=172, .name="Mazda 3"};   // 缺的 price 自动为 0

mazda.speed = 168;   // 事后还能改
```

类型声明与变量声明可合并；类型名只用一次时可以匿名：

```c
struct book { char title[500]; char author[100]; float value; } b1;

struct {
  char title[500];
  char author[100];
  float value;
} b1 = {"Harry Potter", "J. K. Rowling", 10.0};
```

有了下一节要学的 `typedef`，`struct book` 这种啰嗦的类型名才能变成一句话的名字。

## typedef：给类型起别名

```c
typedef type name;
```

用法一：**为 struct/union/enum 起简短的别名**（最常见，把 `struct` 关键字去掉）：

```c
typedef struct animal {
  char* name;
  int leg_count, speed;
} animal;

animal a = {"cat", 4, 10};     // 不必再写 struct animal

typedef struct {
  char *name;
  int leg_count, speed;
} animal;                      // 省略类型名：匿名 struct + 别名
```

用法二：**提升可读性**（`intptr` 是 `int*`，`STRING` 是 `char*`）、**简化复杂声明**、**方便统一改类型**（一处 typedef，多处生效）。可移植类型 `int32_t`、`size_t` 本质上都是 typedef（第 04 章）。

需要注意：typedef **不创建新类型**，只是别名；别名的对象是指针时（`typedef int* intptr;`），`intptr x, y;` 里的 x、y 都是指针，与 `int* x, y;` 不同——后者 y 是 int。

## struct 的复制

**struct 可以用 `=` 整体复制**（这一点和数组完全不同，数组只能逐元素或 memcpy）：

```c
struct cat { char name[30]; short age; } a, b;

strcpy(a.name, "Hula");
a.age = 3;

b = a;               // b 得到一份完整副本，各自独立
b.name[0] = 'M';
printf("%s\n", a.name);  // Hula（没变）
```

**警告**：如果成员本身是指针（如 `struct cat { char* name; ... }`），`=` 复制的是**指针值**（浅拷贝），两个变量共享同一块内存——修改经共享指针可见。深拷贝要自己决定复制规则。

不同 struct 类型之间不能互相赋值（即使成员长得一样）；标准也没有提供 struct 的比较运算符，比较要逐成员进行。

## struct 指针与箭头运算符

struct 传给函数默认也是传值拷贝，修改不影响外部。传指针则共享同一份数据：

```c
void happy(struct turtle* t) {
  t->age = t->age + 1;     // 等价于 (*t).age
}

happy(&myTurtle);          // 千万别漏 &：struct 名不是指针（与数组不同）
```

三条等价写法：`myStruct.prop == (*ptr).prop == ptr->prop`——变量用 `.`，指针用 `->`。注意 `*t.age` 是错的（`.` 优先级高于 `*`）。

## struct 的嵌套与自引用

成员可以是另一个 struct；访问嵌套成员用多点号；字符数组成员仍要 `strcpy` 赋值：

```c
struct student {
  struct name { char first[50]; char last[50]; } name;
  short age;
  char sex;
} student1;

student1.name = (struct name){"Harry", "Potter"};   // 或逐成员 strcpy
printf("%s\n", student1.name.first);
```

**自引用**：struct 可以包含指向同类型的指针（不能直接包含自身值，会无限递归）。这正是链表节点的写法：

```c
#include <stdio.h>
#include <stdlib.h>

struct node {
  int data;
  struct node* next;
};

struct node* head = malloc(sizeof(struct node));
head->data = 11;
head->next = malloc(sizeof(struct node));
head->next->data = 22;
head->next->next = NULL;

for (struct node* cur = head; cur != NULL; cur = cur->next)
  printf("%d\n", cur->data);
```

## 内存对齐：sizeof 是"对齐后"的大小

struct 占用的空间**不是各成员之和**，而是按最大对齐单位补齐：

```c
struct foo {          // 64 位机器
  int a;              // 4 字节
  char* b;            // 8 字节
  char c;             // 1 字节
};
sizeof(struct foo);   // 24，而不是 13
```

原因：成员按最大成员宽度对齐（成员从 8 的倍数地址开始），多出的空间是填充（padding）。这是为了对齐读写、提高速度。

**实用结论**：按占用空间从小到大声明成员，可以减少填充：

```c
struct foo { char c; int a; char* b; };   // 24 → 16 字节
```

## union：共享同一段存储

`union` 的所有成员（可以不同类型）**共用同一块内存**，大小 = 最长成员的大小。同一时刻只有一个成员的解读有意义——后面写入的会覆盖前面的：

```c
union quantity {
  short count;     // 2 字节
  float weight;    // 4 字节
  float volume;    // 4 字节
};

union quantity q;
q.count = 4;                 // 写 count
printf("%d\n", q.count);     // 4
printf("%f\n", q.weight);    // 未定义行为：现在读 weight 是垃圾值

q.weight = 0.5;              // 覆盖：count 的解读随之失去意义
```

初始化三种写法等价：`q.count = 4`、`{.count=4}`、`{4}`（给第一个成员）。union 也支持 `.`/`->` 访问、`typedef` 起别名、作为参数等一切 struct 用法。

**适用边界**：适合表达"互斥数据"（同一对象在不同场合是不同形态，如解释器里的值、网络协议的载荷）。若没有清晰的"当前是哪个成员"约定，不要拿 union 当普通业务数据——读错成员都是未定义行为。

## enum：命名一组整数常量

某类取值只有少数几种可能时（成绩等级、菜单选项、状态机），用 `enum` 定义，编译器自动从 0 递增编号：

```c
enum colors {RED, GREEN, BLUE};   // 0, 1, 2

enum colors color = BLUE;
printf("%i\n", color);            // 2
printf("%i\n", RED);              // 0：常量可直接用
```

规则：

- 常量名通常是全大写，遵守标识符规则；但 **enum 没有类型保护**——不同 enum 里的值照样可以互相比较、参与算术，因为它本质还是整数；
- 可以指定值，也可以只指定一部分（未指定的接续自增）：
  `enum { X = 2, Y = 18, Z = -2 };`、`enum { A, B, C = 4, D };`（D 是 5）
- 只想要一组常量时可以省去类型名：`enum { ONE, TWO };`
- 作用域与变量相同（顶层/块内）；
- 与 `typedef` 结合使用是最常见的形态：

```c
typedef enum { SHEEP, WHEAT, WOOD, BRICK, ORE } RESOURCE;
RESOURCE r = WOOD;
```

可以给常量赋相同的值（无害）；常用于 `switch` 分支的 case（可读性远胜魔法数字）。

## 进阶：位字段与弹性数组成员

**位字段（bit field）**：按二进制位定义存储，成员必须是整数类型：

```c
struct {
  unsigned int ab:1;   // 占 1 个二进制位
  unsigned int cd:1;
  unsigned int ef:1;
  unsigned int gh:1;
} synth;

synth.cd = 1;          // 整个结构只有 4 个位
```

宽度 0 的未命名位字段强制下一个字段换字节；未命名字段用于填充。

**弹性数组成员（flexible array member）**：无法预知数组长度时，把数组放到 struct 末尾且**不给长度**，分配时额外加上数组空间：

```c
struct vstring {
  int len;
  char chars[];        // 弹性成员：必须是最后一个成员，且前面至少还有一个成员
};

struct vstring* str = malloc(sizeof(struct vstring) + n * sizeof(char));
str->len = n;
```

## 本章小结

`struct` 组合一条记录，`union` 共享一段存储，`enum` 为状态提供名字，`typedef` 只创建别名。只要成员含指针，就必须额外设计复制和释放规则。
