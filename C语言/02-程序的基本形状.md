# 第 02 章：程序的基本形状与输出

## 本章目标

- 分清语句、表达式、语句块这三类基本结构；
- 学会写注释、使用空格与缩进；
- 会用 `printf()` 输出带占位符和格式的文本；
- 明白"标准库 + 头文件 + `#include`"这套调用自带功能的机制。

## 边界

本章只讲程序的最小组成单位。变量、运算符、流程控制从下一章开始展开；`printf()` 在此只讲常用占位符，全部的格式控制细节见第 10 章《标准输入输出与文本解析》。

## 语句：程序的最小动作

C 语言的代码由一行行语句（statement）组成。==语句是程序执行的一个操作命令，必须以分号结尾==（除非标准另有规定）。

```c
int x = 1;
```

上面是一条变量声明语句：声明整数变量 `x` 并赋值为 `1`。

==分号才是语句的边界，换行不是。多个语句可以挤在同一行：==

```c
int x; x = 1;
```

一个语句也可以拆成多行，编译器会忽略代码内部的换行：

```c
int x;
x
=
1
;
```

==单个分号也是合法的语句，叫"空语句"，什么都不做==（通常出现在 `for` 循环里，见第 06 章）：

```c
;
```

## 表达式：会求值的东西

表达式（expression）是一个计算式，用来获取值：

```c
1 + 2
```

表达式后面加分号也能成为语句，但结果被丢弃，没有实际作用：

```c
8;
3 + 4;
```

表达式与语句的区别有两点：

- 语句可以包含表达式，但表达式本身不构成语句；
- 表达式一定得出值，语句不一定——例如声明语句 `int x = 1;` 就没有返回值。

## 语句块：用大括号围出复合语句

多个语句可以用一对大括号 `{}` 包起来，组成语句块（复合语句，compound statement）。语法上它被视为一条复合语句，常在 `if`、循环、函数里使用：

```c
{
  int x;
  x = 1;
}
```

==注意：大括号的结尾不需要加分号。==

## 空格、缩进与空白行

空格用来帮助编译器区分语法单位；如果不用空格也能分清，空格就只是给人类看的。

```c
int x = 1;
// 等同于
int x=1;
```

多个空格等同于单个空格。缩进同理——编译器不在乎有没有缩进，缩进是为了人读代码。常见约定是每级缩进 4 个空格；本书为紧凑起见缩进 2 个空格：

```c
if (x > 0)
  printf("positive\n");
```

只含空格的空白行会被编译器完全忽略。

## 注释：写给人类的说明

注释是给读者看的，编译器会忽略。C 有两种注释写法。

==**块注释 `/* ... */`**：可以跨行，也可以插在行内：==

```c
/* 注释 */

int open(char* s /* file name */, int mode);
```

坑：忘记写结束符号 `*/` 时，注释会一直吞掉后面的代码——下面示例的原意是两处注释，第一处漏了结尾，结果把第二行代码也吞成了注释：

```c
printf("a "); /* 注释一
printf("b ");
printf("c "); /* 注释二 */
printf("d ");
```

**行注释 `// ...`**：C99 新增，从 `//` 到行尾都是注释，只能单行：

```c
// 这是一行注释

int x = 1; // 这也是注释
```

两种注释符号出现在双引号里面时是普通字符，没有注释作用：

```c
printf("// hello /* world */ ");  // 会原样输出
```

编译时注释会被替换成一个空格，所以 `min/* space */Value` 变成 `min Value` 而不是 `minValue`。

## printf()：向屏幕输出文本

`printf()` 是本书用得最多的函数，名字里的 `f` 代表 format（格式化）。它把文本输出到屏幕，但**不会自动换行**，需要自己加换行符 `\n`：

```c
printf("Hello World\n");
```

文本内部的换行也要靠 `\n`：

```c
printf("Hello\nWorld\n");
```

### 占位符

"占位符"指输出文本中可以被其他值替换的位置，写法是 `%` 加一个表示类型的字符。`%i` 表示代入整数，`%s` 表示代入字符串：

```c
// 输出 There are 3 apples
printf("There are %i apples\n", 3);

// 输出 Jane will come tonight
printf("%s will come tonight\n", "Jane");

// 输出 Ben says it is 21 o'clock
printf("%s says it is %i o'clock\n", "Ben", 21);
```

占位符与参数一一对应：有 `n` 个占位符，`printf()` 就要有 `n + 1` 个参数，少给了可能输出内存中的任意值。

常用占位符（按类型分，完整列表见第 10 章）：

| 占位符 | 含义 |
|---|---|
| `%i` `%d` | 十进制整数 |
| `%f` `%Lf` | 小数（double / long double） |
| `%c` | 字符 |
| `%s` | 字符串 |
| `%p` | 指针（内存地址） |
| `%o` `%x` | 八进制 / 十六进制整数 |
| `%u` | 无符号整数 |
| `%e` `%E` | 科学计数法浮点数 |
| `%zu` `%td` | size_t / ptrdiff_t 等专用类型 |
| `%%` | 输出一个百分号本身 |

宽度修饰符（`h`/`l`/`ll`）对应 short/long/long long，例如 `%ld` 是 long int，`%llu` 是 unsigned long long。

### 输出格式

**限定最小宽度**：`%5d` 表示宽度至少 5 位，不足时前面补空格，默认右对齐；加 `-` 号改为左对齐：

```c
printf("%5d\n", 123);   // 输出 "  123"
printf("%-5d\n", 123);  // 输出 "123  "
printf("%12f\n", 123.45); // 输出 "  123.450000"
```

**总是显示正负号**：加 `+`：

```c
printf("%+d\n", 12);   // 输出 +12
printf("%+d\n", -12);  // 输出 -12
```

**限定小数位数**：`%.2f` 表示小数点后两位；可与宽度结合：`%6.2f` 表示最小宽度 6、小数 2 位：

```c
printf("Number is %.2f\n", 0.5); // Number is 0.50
printf("%6.2f\n", 0.5);          // 输出 "  0.50"
```

==宽度和小数位数都可以用 `*` 代替，由参数传入==：

```c
printf("%*.*f\n", 6, 2, 0.5);  // 等同于 %6.2f
```

**只输出字符串开头部分**：`%.5s` 输出前 5 个字符：

```c
printf("%.5s\n", "hello world"); // 输出 hello
```

## 标准库与头文件

程序需要的功能不一定自己写——C 语言自带了一批，称为标准库（standard library）。标准库由标准规定，保证代码规范、可移植。

标准库按功能分为一个个头文件（header file，后缀 `.h`）。用某个功能前必须加载对应的头文件，加载命令是 `#include`：

```c
#include <stdio.h>
```

`printf()` 就定义在 `stdio.h` 里，所以用它之前必须先 `#include <stdio.h>`。注意 `#include` 语句**不需要分号结尾**，它的详细机制见第 13 章《预处理》。

## 本章小结

语句描述动作，表达式产生值，语句块把多条语句组合起来。`printf` 通过格式串输出数据，使用库函数前要包含对应头文件。

## 自查与练习

1. 写一个程序，用一条 `printf()` 输出三行文字，再用三条 `printf()` 实现同样效果，确认输出一致。
2. 用 `%5d`、`%-5d`、`%.2f`、`%6.2f`、`%+d` 各打印一次固定值，观察输出并核对宽度。
3. 故意写一个"参数少于占位符"的 `printf("x=%i\n")`，用 `-Wall -Wextra -Wpedantic` 编译，看编译器报什么警告。
