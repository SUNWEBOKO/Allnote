# 第 14 章：文件读写与持久化

## 本章目标

- 掌握文件操作三步曲：`fopen` → 读写 → `fclose`，每个环节都检查结果；
- 分清文本模式与二进制模式，知道何时用行读取、何时用 `fread`/`fwrite`；
- 掌握 `fgets`/`fputs`、`fprintf`/`fscanf`、`fgetc`/`fputc` 与错误处理（`feof`/`ferror`）；
- 会用 `fseek`/`ftell` 定位，用 `remove`/`rename` 管理文件。

## 边界

文件操作在 C 里是"薄封装"：所有函数都围绕一个 `FILE*` 指针。本章覆盖常用子集；`printf`/`scanf` 家族细节及 `sscanf` 已在第 10 章，本章只做对照。文件内容的解析规则（%d 跳空白、字符串按空白分词）沿用第 10 章。

## 三步曲：打开 → 读写 → 关闭

全部函数定义在 `stdio.h`。任何文件操作的骨架都一样：

```c
#include <stdio.h>

int main(void) {
  FILE* fp = fopen("hello.txt", "r");   // 第 1 步：打开
  if (fp == NULL) {                     // 打开失败（文件不存在/无权限）
    fprintf(stderr, "无法打开文件\n");
    return 1;
  }

  int c = fgetc(fp);                    // 第 2 步：读写
  printf("%c\n", c);

  fclose(fp);                           // 第 3 步：关闭（释放资源、落盘缓冲）
  return 0;
}
```

三条习惯：

1. **`fopen` 必须判 NULL**（文件不存在、权限不足都会失败）；
2. 读写函数**检查返回值**（读返回 EOF/NULL，写返回 EOF），不要假装一定成功；
3. `fclose` 失败也要检查（磁盘满等，写操作的错误常常到这里才暴露）。

`fclose(fp)` 成功返回 0，失败返回 EOF。不关文件会占用系统资源（同时打开的文件数有限制）。

## fopen()：模式决定一切

```c
FILE* fopen(char* filename, char* mode);
```

| 模式 | 行为 |
|---|---|
| `r` | 读。文件不存在 → NULL |
| `w` | 写。**存在则清空**重建，不存在则新建 |
| `a` | 追加写。指针指向文件尾，不存在则新建 |
| `r+` | 读写，指针在开头；文件不存在 → NULL |
| `w+` | 读写，**清空**重建（基本读不到旧内容） |
| `a+` | 读写追加，指针在尾部 |

后缀：`b` = 二进制模式（`rb`/`wb`，Windows 上必须；Linux 上无差别）；`x` = 独占模式（`wx`：文件已存在则失败）。

底层：`fopen` 为文件建立**缓冲区**，读写都是流模式——数据先进缓冲，填满再实际写入磁盘。这就是"打开一个流"的含义。

## 标准流与重定向

程序启动就有三个已打开的流，可直接当 FILE* 用：

- `stdin`（0）：标准输入，默认键盘；
- `stdout`（1）：标准输出，默认屏幕；
- `stderr`（2）：标准错误，默认屏幕（**错误信息应写这里**，不混入正常输出）。

Shell 可以把它们指向文件（重定向），程序本身不用改：

```bash
$ demo < in.dat        # stdin 读 in.dat
$ demo > out.dat       # stdout 写 out.dat（清空重建）
$ demo >> out.dat      # stdout 追加
$ demo 2> err.txt      # stderr 写 err.txt
$ demo < in.dat > out.dat 2> err.txt
$ random | sum         # 管道：random 的 stdout 流入 sum 的 stdin
```

`printf` 就是 `fprintf(stdout, ...)`，`perror`/`fprintf(stderr, ...)` 是把错误写到 2 号流。

## EOF：文件结束的哨兵

- 文件里**并没有** EOF 这个字节——它是读函数发现"读完了"时返回的哨兵值（`-1`）；
- 所以读取函数的返回值都是 `int`（而不是 char），才能容纳 EOF；
- 注意 `char` 是否带符号是实现相关的，**永远用 int 接收字符读取的返回值**。

```c
int c;                    // 不是 char！
while ((c = fgetc(fp)) != EOF) {
  putchar(c);
}
```

## 字符级读写

```c
int fgetc(FILE* stream);   // 读一个字符（int 返回）
int getc(FILE* stream);    // 同 fgetc，通常用宏实现
int fputc(int ch, FILE* stream);  // 写一个字符；失败返回 EOF
int putc(int ch, FILE* stream);
```

`getchar()` = `fgetc(stdin)`；`putchar(c)` = `fputc(c, stdout)`。

## 行级读写：fgets / fputs

`fgets(str, STRLEN, fp)`：最多读 `STRLEN-1` 个字符，遇到换行或文件尾停止，**换行符会存进字符串**，末尾自动补 `\0`。返回 `str` 或 NULL（读到尾/失败）。

`fputs(str, fp)`：写字符串，**不加**换行——与 `fgets` 成对使用正好对称。

读文件所有行：

```c
char s[1024];            // 必须足够装下一行
while (fgets(s, sizeof s, fp) != NULL) {
  printf("%d: %s", ++linecount, s);
}
```

从键盘读整行（比 `scanf` 可控，第 10 章已详述其边界问题）：

```c
fgets(words, 10, stdin);
```

## 格式化读写：fprintf / fscanf

```c
int fprintf(FILE* stream, const char* format, ...);
int fscanf(FILE* stream, const char* format, ...);
```

- `fprintf(fp, "Sum: %d\n", sum);` 写文件；`fprintf(stderr, "...")` 报错；
- `fscanf(fp, "%d%d", &i, &j);` 按格式从文件读，规则与 `scanf` 完全一致（占位符、指针参数、空白处理）；
- 返回值 = 成功赋值的变量个数，**失败返回 EOF**；循环读直到不等于期望个数为止：

```c
int num; char name[50];
while (fscanf(fp, "%d %s", &num, name) == 2) {
  printf("%d %s\n", num, name);
}
```

前提是你知道文件的格式；格式错一位就解析错位。

## 二进制读写：fread / fwrite

```c
size_t fread(void* ptr, size_t size, size_t nmemb, FILE* fp);
size_t fwrite(const void* ptr, size_t size, size_t nmemb, FILE* fp);
```

按字节读写，**不解读内容**——适合把数组、整个 struct 一次落盘：

```c
fwrite(arr, sizeof(arr[0]), sizeof(arr)/sizeof(arr[0]), fp);   // 整个数组
fwrite(&s, sizeof(s), 1, fp);   // 一个 struct

fread(arr, sizeof(double), 10, fp);   // 读回 10 个 double
```

- 返回值是成功读/写的**成员个数**，小于 nmemb 说明出错或到文件尾——必须检查；
- 二进制模式用 `wb`/`rb` 打开；文件里可能含 `\0`，不能用文本/字符串函数处理；
- **警告**：struct 里含指针时（如 `char* name`）别直接写入——指针值在下次运行时毫无意义。要持久化数据本身（数组、拷贝文本），而不是地址。
- 二进制文件 + `fread` 是"快"，文本文件 + `fprintf`/`fgets` 是"可读、可移植"。

## 错误与结尾判断：feof / ferror / clearerr

读函数返回 EOF 有两种原因：到文件尾，或出错。`feof(fp)` 与 `ferror(fp)` 帮你区分（非零为真）：

```c
if (fscanf(fp, "%d", &n) != 1) {
  if (ferror(fp))  printf("IO 错误\n");
  if (feof(fp))    printf("到文件结尾\n");
  clearerr(fp);    // 清除两个指示器，便于后续操作
}
```

两个指示器一旦置位会保持，`clearerr()` 清零。

## 定位：fseek / ftell / rewind

每个流有一个内部位置指示器，记录下次读写从哪开始；顺序读写自动推进，也可以用定位函数跳转：

```c
long int fseek(FILE* stream, long offset, int whence);
```

- `whence`：`SEEK_SET`（开头）/ `SEEK_CUR`（当前位置）/ `SEEK_END`（末尾）；
- `offset`：字节偏移，可为正负：

```c
fseek(fp, 0L, SEEK_SET);     // 回到开头
fseek(fp, 0L, SEEK_END);     // 跳到末尾
fseek(fp, 10L, SEEK_SET);    // 第 10 个字节
fseek(fp, -10L, SEEK_END);   // 倒数第 10 字节
```

- 成功返回 0，失败非 0；
- **最好只用于二进制文件**：文本文件有编码/换行转换，字节位置不可靠；
- 超大文件用 `fgetpos`/`fsetpos`（`fpos_t` 类型保存位置）规避 long 范围限制。

`ftell(fp)` 返回当前位置字节数；`rewind(fp)` = 回到开头（并清错误指示器）。记录→回来：

```c
long pos = ftell(fp);
// ... 中间读了一些数据 ...
fseek(fp, pos, SEEK_SET);    // 回到之前的位置
```

文件大小：`fseek(fp, 0L, SEEK_END); long size = ftell(fp);`

## 删除与改名：remove / rename

```c
int remove(const char* filename);          // 删文件，成功 0
int rename(const char* old, const char* new);  // 改名/移动
```

先 `fclose` 再操作（开着的文件删不掉/改不了名）；不能改到已存在的名字上。

## 标准库速查：stdio.h 常用函数

| 类别 | 函数 | 返回值约定 |
|---|---|---|
| 打开/关闭 | `fopen` / `fclose` / `freopen` | NULL / 0 |
| 单个字符 | `fgetc`/`getc`/`fputc`/`putc` | 字符或 EOF |
| 整行 | `fgets`/`fputs` | 指针 / 非负或 EOF |
| 格式化 | `fprintf`/`fscanf`/`printf`/`scanf`/`snprintf`/`sscanf` | 写的字符数 / 赋值个数 / EOF |
| 二进制块 | `fread`/`fwrite` | 实际读写的成员个数 |
| 状态 | `feof`/`ferror`/`clearerr` | 非零为真 / 无 |
| 定位 | `fseek`/`ftell`/`rewind`/`fgetpos`/`fsetpos` | 0 / 位置 / 无 |
| 管理 | `remove`/`rename`/`tmpfile` | 0 |

`snprintf`（第 09 章）对应写内存，`sscanf` 对应读内存，是文件操作的同族兄弟。
