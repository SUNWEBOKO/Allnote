# 第 09 章：字符串

## 本章目标

- 理解 C 字符串的本质：带 `\0` 结束符的字符数组；
- 区分字符数组与字符指针两种声明方式及其差异；
- 掌握 `strlen`、`strcpy`、`strcat`、`strcmp` 及带 `n` 的安全版本；
- 掌握 `printf`/`scanf` 之外的文本格式化工具 `sprintf`/`snprintf`；
- 会用字符串数组组织一组文本。

## 关键约束

**C 没有单独的字符串类型。** 字符串就是字符数组 + 结束符。什么时候 `strlen` 返回不可靠的值、什么时候缓冲区溢出，是本章练习的重点。

## 简介：字符数组与 \0

字符串"Hello"实际存储为 `{'H','e','l','l','o','\0'}`——结尾有一个二进制全 0 的字节 `\0`（ASCII 0，不同于字符 `'0'`，其 ASCII 是 48）。**所有字符串都以 `\0` 结束**，靠它判断字符串在哪里结束，所以：

```c
char localString[10];
```

10 个成员的数组最多容纳 9 个字符的字符串（最后一个位置给 `\0`）。

双引号是字符串字面量的简写，编译器自动补 `\0`：

```c
{'H', 'e', 'l', 'l', 'o', '\0'}   // 等价于
"Hello"
```

注意事项：

- 双引号是字符串，单引号是字符，不能互换：`'Hello'` 报错；`"a"` 是 2 字节，`'a'` 是 1 字节；
- 字符串内含双引号要转义：`"She replied, \"It does.\""`；
- 长字符串可在行尾用 `\` 折行（续行后不能有缩进），或利用"相邻字符串字面量自动合并"：

```c
char greeting[50] = "Hello, "
  "how are you "
  "today!";
```

`%s` 占位符输出字符串：`printf("%s\n", "hello world");`

## 两种声明方式

```c
char s[14] = "Hello, world!";   // 写法一：字符数组
char* s = "Hello, world!";      // 写法二：字符指针
```

**写法一（数组）**：可省略长度（`char s[] = "Hello, world!";` 编译器自动算 14）；长度可大于内容（富余位置补 `\0`）；**长度不能小于内容**，`char s[5] = "hello";` 会编译报错（装不下 `\0`）。

**写法二（指针）**：字符串字面量存在内存的常量区，**不可修改**，因此 `s[0] = 'z'` 是错误写法（未定义行为）。声明时加 `const` 让编译器替你把关：

```c
const char* s = "Hello, world!";   // 明确只读
```

两个差异汇总：

| | 字符数组 `char s[]` | 字符指针 `char* s` |
|---|---|---|
| 内容可修改 | 可以 | 不可以（常量区） |
| 可指向别的字符串 | 不可以（数组名绑定地址） | 可以 `s = "world"` |
| 重新赋值 | 不允许 `s = "abc"` | `=` 只是换指向 |

数组想要新内容，要用 `strcpy()`，它是在原地址写入，不是改地址。

## strlen()：字符串长度

返回字符串的字节长度（**不含 `\0`**），原型在 `string.h`：

```c
#include <string.h>

size_t strlen(const char* s);

char* str = "hello";
int len = strlen(str);  // 5
```

`strlen`（实际内容长度）与 `sizeof`（变量占用字节数）是两回事：

```c
char s[50] = "hello";
strlen(s);   // 5
sizeof(s);   // 50
```

体会原理——遍历到 `\0` 停：

```c
int my_strlen(char *s) {
  int count = 0;
  while (s[count] != '\0') count++;
  return count;
}
```

## 字符串的复制

数组不能用 `=` 复制（`str2 = str1` 报错；指针 `s2 = s1` 只是共享地址，不是复制内容）。复制内容用 `strcpy`：

```c
char* strcpy(char dest[], const char source[]);

char t[100];
strcpy(t, "Hello, world!");   // 内容拷贝到 t
t[0] = 'z';                   // 不影响源
```

**安全前提：dest 的空间必须装得下源字符串**（含 `\0`），否则溢出。常见风险写法：把未初始化的指针当目标：

```c
char* str;
strcpy(str, "hello world");   // 错误：str 指向随机地址
```

`strcpy` 返回目标指针，可嵌套使用（`strcpy(str1, strcpy(str2, "abcd"))`）或用于指定起始位置写入：

```c
char* s1 = "beast";
char s2[40] = "Be the best that you can be.";
strcpy(s2 + 7, s1);   // 从第 7 位开始覆盖
puts(s2);             // Be the beast
```

### 带 n 版本：strncpy()

多一个上限参数 `n`（最多复制 n 个字符）。**坑**：达到 n 而源没复制完时，目的字符串**没有 `\0`**，必须自己补：

```c
strncpy(str1, str2, sizeof(str1) - 1);
str1[sizeof(str1) - 1] = '\0';
```

也可用来拷贝片段：

```c
char s1[40];
char s2[12] = "hello world";
strncpy(s1, s2, 5);
s1[5] = '\0';
printf("%s\n", s1); // hello
```

## 字符串的连接

`strcat(s1, s2)` 把 s2 追加到 s1 末尾（修改 s1，不动 s2）。**必须确保 s1 的空间够**，否则溢出危险：

```c
char s1[12] = "hello";
char s2[6] = "world";
strcat(s1, s2);   // s1 变成 "helloworld"
```

安全版 `strncat`，第三参数是"还能追加的最大字符数"：`sizeof(str1) - strlen(str1) - 1`。`strncat` **总是**自动补 `\0`，与 `strncpy` 不同：

```c
char s1[10] = "Monday";
char s2[8] = "Tuesday";
strncat(s1, s2, 3);   // s1 剩余 3 个位置：MondayTue
```

## 字符串的比较

**字符串不能直接用 `==` 比较**（那是在比较指针地址，不是内容）。用 `strcmp`，按字典序返回：

- 相等 → 0
- s1 小于 s2 → 负值
- s1 大于 s2 → 正值

```c
strcmp(s1, s2) // 0：内容相同
strcmp(s1, s3) // 大于 0
strcmp(s3, s1) // 小于 0
```

字符本身就是小整数，比较字符用 `==`，不要放进 `strcmp`。

`strncmp(s1, s2, n)` 只比较前 n 个字符：

```c
if (strncmp(s1, s2, 5) == 0)
  printf("They all have hello.\n");
```

## sprintf() / snprintf()：格式化到字符串

`sprintf` 像 `printf`，但把格式化结果写进字符串（原型在 `stdio.h`）：

```c
char s[40];
sprintf(s, "%s %s", "hello", "world");   // s = "hello world"
```

它有和 `strcpy` 一样的溢出风险（不管装不装得下都写）。**一律用 `snprintf`**：多一个参数 `n`，最多写 n-1 个字符，并始终补 `\0`：

```c
int snprintf(char* s, size_t n, const char* format, ...);

snprintf(s, sizeof(s), "%s %s", "hello", "world");
```

返回值是"本应写入的字符数"（不含 `\0`）：非负且小于 n 才说明完整写入了。

## 字符串数组

一组字符串 = 二维字符数组，或更省空间的指针数组：

```c
char weekdays[][10] = {
  "Monday", "Tuesday", "Wednesday", "Thursday",
  "Friday", "Saturday", "Sunday"
};

char* weekdays2[] = {      // 每个成员是指向字符串的指针
  "Monday", "Tuesday", /* ... */
};

for (int i = 0; i < 7; i++)
  printf("%s\n", weekdays[i]);
```

固定列宽版本浪费空间（所有行按最长行分配）；指针数组按需指向字面量，但内容只读。

## 标准库速查：string.h 常用函数

| 函数 | 作用 | 注意 |
|---|---|---|
| `strlen(s)` | 内容长度（不含 `\0`） | 返回 size_t |
| `strcpy(d, s)` / `strncpy(d, s, n)` | 复制 | 检查目标空间；strncpy 不自动补 `\0` |
| `strcat(d, s)` / `strncat(d, s, n)` | 追加 | 检查剩余空间；strncat 总补 `\0` |
| `strcmp(a, b)` / `strncmp(a, b, n)` | 字典序比较 | 相等返回 0 |
| `strchr(s, c)` | 找第一个字符 c 的位置 | 返回指针，找不到返回 NULL |
| `strrchr(s, c)` | 找最后一个字符 c | 同上 |
| `strstr(hay, needle)` | 找子串 | 返回子串起始指针或 NULL |
| `strtok(s, delim)` | 按分隔符拆分子串 | 会修改原字符串，非线程安全 |
| `memset(p, c, n)` | 把前 n 字节设为 c | 常用清零：`memset(buf, 0, sizeof buf)` |
| `memcpy(d, s, n)` | 前 n 字节复制 | 见第 11 章内存操作 |

捕获字符串存在与否的模式，搭配 `if` 判断返回值：

```c
char* p = strstr("hello world", "world");
if (p != NULL)
  printf("found: %s\n", p);   // found: world
```
