# 第 05 章：表达式与运算符

## 本章目标

- 掌握算术、自增自减、关系、逻辑运算符的语义和求值顺序；
- 会拆解混合表达式，理解优先级与结合性的影响；
- 了解位运算与逗号运算符的适用场景。

## 边界

运算符与类型转换联动时，以第 04 章的规则为准；编译器不做类型检查的地方（如整数除法），本章再次强调。

## 算术运算符

算术运算符分一元（一个运算数）和二元（两个运算数）：

| 运算符 | 作用 | 类别 |
|---|---|---|
| `-` | 取负 | 一元 |
| `+` | 无效果（可省略） | 一元 |
| `+` `-` `*` | 加、减、乘 | 二元 |
| `/` | 除法 | 二元 |
| `%` | 求余（取模） | 二元 |

```c
int x = -12;      // 一元负号
int num = 5;
printf("%i\n", num * num); // 25
```

### 整数除法：最大的坑

两个整数相除是**整除**，小数部分直接丢弃。即使赋给浮点变量也一样：

```c
float x = 6 / 4;
printf("%f\n", x); // 1.000000，不是 1.5
```

想要浮点除法，两个运算数至少一个是浮点数：

```c
float x = 6.0 / 4;   // 1.5
```

这个坑在百分比计算里尤其常见：

```c
int score = 5;
score = (score / 20) * 100;   // 整除得 0，结果 0
score = (score / 20.0) * 100; // 改为浮点除法，得 25
```

### 求余 %

`%` 只能用于整数，返回整除的余数。结果的符号**由第一个运算数决定**：

```c
int x = 6 % 4;   // 2
11 % -5;   // 1
-11 % 5;   // -1
-11 % -5;  // -1
```

### 复合赋值

变量对自己运算有简写：`+=`、`-=`、`*=`、`/=`、`%=`：

```c
i += 3;  // i = i + 3
i /= 2;  // i = i / 2
```

## 自增自减：位置决定时机

`++` 和 `--` 对变量加 1 / 减 1，但**放在变量前后执行时机不同**：

- 前缀 `++i`：先自增，再取新值参与运算；
- 后缀 `i++`：先取旧值参与运算，再自增。

```c
int i = 42;
int j = (i++ + 10);   // j = 52，之后 i = 43
int k = (++i + 10);   // i 先变成 44，k = 54
```

把自增混在大表达式里很容易读错。推荐拆开写：

```c
j = (i + 10);
i++;
```

## 关系运算符

比较运算返回 `0`（假）或 `1`（真）：`>` `<` `>=` `<=` `==` `!=`。

两个常见错误：

**（1）`==` 与 `=` 混淆。** 赋值表达式的值等于赋入的值，所以 `if (x = 3)` 恒为真（x 被赋成 3，值非零）。把常量放左边可以防错：

```c
if (3 == x) ...   // 误写成 if (3 = x) 时编译器报错
```

**（2）关系运算符连用不符合直觉。** `i < j < k` 按 `(i < j) < k` 计算——`i < j` 的结果是 0 或 1，再与 k 比较。判断区间要写成：

```c
i < j && j < k
```

## 逻辑运算符

`!`（非）、`&&`（与）、`||`（或）。任何非零值算真，`0` 算假：

```c
if (x < 10 && y > 20) ...
if (!(x < 12)) ...    // 注意 ! 优先级高于 <，需要括号
```

**短路求值**：逻辑运算符保证先算左边，左边已能决定结果时右边不再执行。这既是特性也是隐患：

```c
if (number != 0 && 12/number == 2)  // number 为 0 时安全：右边不会执行
```

```c
while ((x++ < 10) && (x + y < 20))  // 隐患：左边先改 x，右边用的是新值
```

## 位运算符

位运算直接操作二进制位，**只能用于整数**：

| 运算符 | 语义 |
|---|---|
| `~` | 按位取反（一元）：0↔1 |
| `&` | 按位与：两位都 1 才 1 |
| `|` | 按位或：有 1 即 1 |
| `^` | 按位异或：有且仅有一个 1 才 1 |
| `<<` `>>` | 左移 / 右移 |

```c
10010011 & 00111101;  // 00010001
10010011 | 00111101;  // 10111111
10010011 ^ 00111101;  // 10101110
10001010 << 2;        // 1000101000（左移一位相当于乘以 2）
10001010 >> 2;        // 00100010（右移一位相当于除以 2）
```

要点：

- 移位运算符可以带复合赋值 `<<=`、`>>=`、`&=`、`|=`、`^=`；
- 右移**最好只用于无符号整数**——负数右移时符号位的处理由系统决定，结果不可移植；
- `~` 不改变变量本身，只返回新值。

## 逗号运算符

逗号把多个表达式连成一条语句，从左到右依次执行，**整条表达式的值是最后那个表达式的结果**：

```c
x = 10, y = 20;

int x;
x = (1, 2, 3);   // x 等于 3
```

日常代码很少用，主要在 `for` 循环头部组合多个表达式（见第 06 章）。

## 优先级与结合性

优先级决定谁先算，结合性决定同级运算符从左还是从右算。部分优先级从高到低：

1. 圆括号 `()`
2. 自增自减 `++` `--`
3. 一元 `+` `-`（及 `!`、`~`、`*`、`&` 等）
4. 乘除余 `*` `/` `%`
5. 加减 `+` `-`
6. 移位 `<<` `>>`
7. 关系 `<` `>` `<=` `>=`
8. 相等 `==` `!=`
9. 位与 `&`
10. 位异或 `^`
11. 位或 `|`
12. 逻辑与 `&&`
13. 逻辑或 `||`
14. 赋值 `=`（右结合）
15. 逗号 `,`

```c
3 + 4 * 5;        // 先乘后加：23
int x = (3 + 4) * 5;  // 括号改变顺序：35
5 * 6 / 2;        // 同级左结合：15
```

结论：**不必背全优先级，遇到复杂表达式就加圆括号**，既避免歧义也提高可读性。

1. 不运行，口算 `7 / 2`、`7.0 / 2`、`7 / 2.0`、`-7 % 2` 各是多少，再写程序验证。
2. `int x = 5; int y = x-- + --x;` 编译时会收到未定义行为警告吗？用 `-Wall` 验证后，把表达式改写成明确的步骤。
3. 用位运算实现：判断一个整数是奇数还是偶数（`x & 1`），并左移 1 位验证乘以 2。
4. 解释 `if (a = 0)` 为什么恒为假，以及如何避免写出这种代码。
