# 第 03 章：变量、作用域与存储属性

## 本章目标

- 掌握标识符命名规则、声明、初始化与赋值；
- 理解文件作用域和块作用域，能判断一个名字在哪里可用；
- 理解存储期（生存期）与链接属性，掌握 `auto`、`static`、`extern`、`register`；
- 掌握 `const`、`volatile` 这两个修饰可修改性/优化行为的说明符。

## 边界

- 指针类型的声明细节见第 11 章；`restrict` 在第 11 章结合动态内存讲解；
- `static`/`extern` 在多文件工程中的应用（第 15 章）只引用本章结论，不再重复展开；
- 函数级的说明符用法（如 `static` 限定函数、参数 `const`）在本章带过，详细语境见第 08 章。

## 变量：内存区域的名字

==变量（variable）可以理解成一块内存区域的名字==。通过变量名可以引用这块内存，读取或改写里面的值。值可以变化，所以叫变量；不会变化的就是常量。

## 变量名：标识符规则

变量名是标识符（identifier），命名有严格规范：

- 只能由==字母（大小写均可）、数字和下划线==组成；
- 不能以数字开头；
- 长度一般不超过 63 个字符。

下面都是无效变量名：

```c
$zj
j**p
2cat
Hot-tab
tax rate
don't
```

变量名区分大小写：`star`、`Star`、`STAR` 是三个不同的变量。

关键字（keyword）不能用作变量名，它们有特殊含义。C 语言的主要关键字如下：

> auto, break, case, char, const, continue, default, do, double, else, enum, extern, float, for, goto, if, inline, int, long, register, restrict, return, short, signed, sizeof, static, struct, switch, typedef, union, unsigned, void, volatile, while

另外，以两个下划线开头、或一个下划线加大写字母开头的名字是系统保留的，不要使用。

## 声明与初始化

C 语言要求变量==先声明后使用==。声明时指定类型（type），把类型告诉编译器：

```c
int height;
```

同类型变量可以一行声明多个：

```c
int height, width;
```

声明语句以分号结尾，类型在运行时不可更改。

**关键点：声明不等于赋值。** C 在声明时分配内存，但不清除内存里的旧值——未赋值的变量是一个随机的值，必须先赋值再使用：

```c
int num;      // num 此刻是随机值
num = 42;     // 赋值后才可靠
```

==声明与赋值可以合并为初始化，多变量也可以同行初始化：==

```c
int num = 42;
int x = 1, y = 2;
```

## 赋值与左值

赋值通过 `=` 完成，两侧类型应一致；虽然 C 会自动转换，但应避免隐式混搭（转换规则见第 04 章）。

==**赋值表达式本身有返回值**，等于等号右边的值，因此可以嵌套和连写：==

```c
int x, y;
x = 1;
y = (x = 2 * x);   // y 也是 2

int a, b, c;
a = b = c = 3;     // 从右向左，逐个赋值
```

由此引出左值（left value）与右值（right value）概念：能放在 `=` 左边的值（一般是变量）叫左值，能放在右边的叫右值。`x = 1` 合法，`1 = x` 报错，就是因为 `1` 不是左值。

## 作用域：一个名字在哪里有效

作用域（scope）是变量生效的范围。C 的变量主要有两种作用域。

**文件作用域（file scope）**：在源码顶层声明的变量，从声明位置到文件结束都有效：

```c
int x = 1;

int main(void) {
  printf("%i\n", x);  // main 可以读取 x
}
```

**块作用域（block scope）**：大括号 `{}` 围成的作用域。块内声明的变量只在本块有效，块外不可见：

```c
int a = 12;

if (a == 12) {
  int b = 99;
  printf("%d %d\n", a, b);  // 12 99
}

printf("%d\n", a);  // 12
printf("%d\n", b);  // 出错：b 已超出作用域
```

块可以嵌套，规则是：内层能读外层，外层不能读内层；内层与外层同名时，==内层覆盖外层（阴影，shadowing）：==

```c
{
  int i = 10;

  {
    int i = 20;
    printf("%d\n", i);  // 20
  }

  printf("%d\n", i);  // 10
}
```

函数体和 `for` 循环也是块作用域——循环外读不到循环变量：

```c
for (int i = 0; i < 10; i++)
  printf("%d\n", i);

printf("%d\n", i); // 出错
```

## 存储属性：说明符管什么

C 允许在声明变量时加上==说明符（specifier）==，告知编译器额外的行为信息。按"它们影响什么"可分成四类：

| 说明符               | 管什么      | 作用                  |
| ----------------- | -------- | ------------------- |
| `auto`、`register` | 存储位置     | 栈上自动分配 / 提示放寄存器     |
| `static`          | 生存期（存储期） | 局部变量跨调用保留；全局变量限当前文件 |
| `extern`          | 链接属性     | 声明"变量在别处定义"         |
| `const`           | 可修改性     | 只读                  |
| `volatile`        | 可优化性     | 禁止编译器缓存/优化读取        |

### auto：默认行为，通常省略

`auto` 说明变量由编译器在所在作用域自动分配，退出作用域自动释放。只要不是 `extern` 变量，默认都是这样，所以实际从不写：

```c
auto int a;
// 等同于
int a;
```

### register：提示编译器放进寄存器

`register` 提示编译器该变量常用、应提供最快的读取速度。编译器可以忽略。它只对块内变量有效，且**不能取地址**（寄存器没有内存地址）：

```c
register int a;
int *p = &a;  // 报错
```

现代编译器优化能力很强，`register` 已基本是装饰品。

### const：只读变量

`const` 表示变量只读，修改会报编译错误：

```c
const double PI = 3.14159;
PI = 3;              // 报错

const int arr[] = {1, 2, 3, 4};
arr[0] = 5;          // 报错
```

**指针的 const 要看 `*` 的位置**——这是最容易出错的点：

```c
const int * x;   // const 在 * 前：指向的值 *x 不可改（还可写作 int const * x）
int * const x;   // const 在 * 后：指针本身（存的地址）不可改
const char * const x;  // 两者都不可改
```

```c
int p = 1;
const int* x = &p;
(*x)++;   // 报错：*x 只读

int* const y;
y++;      // 报错：地址不可改
```

一个常见用途是保护函数参数——参数声明为 `const`，调用者就知道函数不会改动它：

```c
void find(const int* arr, int n);
```

还有一条连带规则：指针指向 `const` 变量时，通过这个指针也不能改值：

```c
const int i = 1;
int* j = &i;   // 编译警告/错误：丢掉 const 限定
*j = 2;        // 不应发生
```

### static：两种位置，两种语义

**（1）局部变量加 `static`**：变量从"每次进入函数新建"变成"整个程序生命周期只初始化一次"，退出函数后值保留，相当于只有函数自己可见的全局变量（详见第 08 章）：

```c
void count(void) {
  static int n = 0;   // 只初始化一次
  n++;
  printf("%d\n", n);
}
```

**（2）全局变量/函数加 `static`**：限定只在本文件可见，其他源文件不能引用（不会被链接）。

`static` 变量的初始化只能用常量，不能用变量：

```c
int n = 10;
static int m = n;  // 报错：必须用常量初始化
```

函数也可以声明为 `static`，表示该函数只在当前文件使用，其他文件可以定义同名函数：

```c
static int g(int i);
```

### extern：声明"定义在别处"

`extern` 表示该变量在其他文件里定义，当前文件只为它声明、不分配空间，常用于多文件共享变量：

```c
extern int a;
```

如果声明的同时初始化，`extern` 就失效——等于普通定义，这防止多个 `extern` 对同一变量重复初始化：

```c
extern int i = 0;  // extern 无效，等同于 int i = 0;
```

函数默认就是 `extern`（可被外部文件共享），通常省略；只有想限定当前文件时才写 `static`：

```c
extern int f(int i);
// 等同于
int f(int i);
```

### volatile：别优化我

`volatile` 表示变量可能在其他程序（硬件、信号处理等）的意料之外发生改变，禁止编译器把它放进缓存，每次使用都重新读取：

```c
volatile int foo;
```

没有 `volatile` 时，编译器可能把两次读取合成一次：

```c
int foo = x;
// 中间没有修改 x 的语句
int bar = x;   // 编译器可能直接复用 x 的缓存值
```

如果 `x` 声明为 `volatile`，编译器就强制每次都从内存读取，因为 `x` 可能已被外部改变。硬件设备编程中很常用。
