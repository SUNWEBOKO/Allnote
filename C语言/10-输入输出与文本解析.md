# 第 10 章：标准输入输出与文本解析

## 本章目标

- 理解缓存与字节流的工作方式，明白"流只能读一次"；
- 掌握 `scanf()` 的占位符、宽度限制与返回值检查；
- 掌握 `getchar`/`putchar`、`puts` 并与 `printf` 家族做取舍；
- 学会"先读整行、再解析"的安全输入模式（`fgets` + `sscanf`）；
- 会用 ctype.h 做字符分类。

## 关键约束

**每次读取/解析都要检查是否成功。** `scanf`/`sscanf` 的返回值是成功赋值的个数；输入与格式不符时它不会报错，只静默失败，留下未初始化的变量——这是程序产生"随机值"的常见来源。

## 缓存与字节流

I/O 函数并不是每次直接读写磁盘/终端，而是通过**缓存**（buffer）间接通信：程序把数据写进内存缓存，缓存满了一次性落盘；读取时磁盘先填缓存，程序从缓存取。内存比磁盘快很多，缓存减少了慢速设备访问次数。

这种"处理一块、再取下一块"的持续读写模式叫**字节流**（stream）：对程序而言，输入输出是一股持续的数据流。**流的两个性质**：

- 读取是顺序的、只能读一次——读过就没了（不同于可以随意定位的文件）；
- `stdin`（标准输入）、`stdout`（标准输出）、`stderr`（标准错误）三个流由程序启动时自动打开，本书已默认使用。

## printf()：格式化输出

`printf()` 已在第 02 章详述。补充一个常用组合：宽度 + 精度（`%6.2f`）、`%c`、`%s`、`%p`、`%x`、`%zu`。**它返回写入的字符数**，实践中一般直接忽略（少见需要用它判断输出是否成功）。

## scanf()：格式化输入

`scanf()` 按格式串解读用户输入并存入**变量地址**（所以要对普通变量加 `&`，但字符串数组名本身就是地址，不加）：

```c
scanf("%d", &i);

char name[20];
scanf("%s", name);   // 字符数组/指针不用 &
```

多个占位符依次提取：

```c
scanf("%d%d%f%f", &i, &j, &x, &y);
// 输入 1 -20 3.4 -4.0e3 → i=1, j=-20, x=3.4, y=-4.0e3
```

### 关键行为

- **数值占位符自动跳过空白**（空格、制表符、换行）；分几行输入与一行输入等价；
- 解读从上次停止的位置继续——`-13.45e12# 0` 用 `%d%f` 读，`%d` 读 `-13`，`%f` 从 `.45e12` 继续读（`.` 是浮点合法字符），`#` 处停止；
- **返回成功赋值的个数**：匹配失败时停在失败处返回已成功数；文件结尾时返回 `EOF`。检查它是"输入是否可靠"的第一道防线：

```c
int n = scanf("%d", &i);
if (n != 1) { /* 输入无效，处理错误 */ }
```

### 占位符速查

`%c` 字符、`%d` 整数、`%lf` double（与 printf 不同，scanf 的 double 用 `%lf` 而非 `%f`）、`%f` float、`%Lf` long double、`%s` 字符串、`%[]` 字符集合匹配（如 `%[0-9]`）。

**两点易错**：

- 除 `%c` 外，占位符都跳过起首空白；`%c` 直接读当前字符。想跳过空白读字符：`scanf(" %c", &ch)`（格式串前加空格）；
- `%s` 读到**空白字符**为止（空格、换行、制表都算），所以它读不了含空格的文本；且**不检查目标数组长度**——必须用宽度限制 `%[m]s`：

```c
char name[11];
scanf("%10s", name);   // 最多 10 个字符 + 自动补 \0
```

### 赋值忽略符 *

格式与输入可能对不齐时（如日期可能是 `2020-01-01` 或 `2020/01/01`），用 `%*c` 跳过任意一个分隔字符：

```c
scanf("%d%*c%d%*c%d", &year, &month, &day);
```

`*` 加在占位符百分号后面，表示"解读但丢弃，不赋值"。

## 逐字符与整行输入

### getchar() / putchar()

`getchar()` 读取一个字符，**不跳过空白**；返回类型是 `int`（不是 char），因为失败时返回 `EOF`（通常是 -1）：

```c
int ch;
ch = getchar();           // 必须用 int 接收，才能表示 EOF
putchar(ch);             // 输出一个字符，等同 printf("%c", ch)
```

常用于循环与跳过逻辑：

```c
int ch;
while (getchar() != '\n')  ;   // 跳过当前行剩余部分
while ((ch = getchar()) == ' ')
  ;                             // 跳过空格，结束后 ch 是第一个非空格字符

int len = 0;
while ((ch = getchar()) != '\n' && ch != EOF) len++; // 数一行的字节数
```

单字符操作优先用它们——通常以宏实现，比 `scanf`/`printf` 快。

### puts()：字符串 + 自动换行

```c
puts("Here are some messages:");   // 输出后自动加 \n
```

成功返回非负整数，失败返回 `EOF`。与 `printf("%s\n", ...)` 等价。

### gets() 已废弃，用 fgets()

`gets()` 从 stdin 读整行（丢弃换行、末尾补 `\0`），**不检查数组长度**，早已从标准中移除，不要用它。整行输入的标准答案是 `fgets()`（正式讲解在第 14 章，这里先给最小用法）：

```c
char line[100];
if (fgets(line, sizeof(line), stdin) != NULL)
  /* line 里有一整行，注意末尾带 \n */
```

### 推荐的输入闭环：先读行，再解析

直接 `scanf` 的痛点：失败的字符留在流里污染后续读取；`%d` 遇字母等"看起来像数字开头"的输入无法恢复。可靠模式是**先 `fgets` 读整行（保证不溢出），再 `sscanf` 解析（可重复尝试、可检查）**：

```c
char line[100];
int grade;

printf("Please enter your grade: ");
if (fgets(line, sizeof(line), stdin) == NULL) {
  printf("input error\n");
  return 1;
}

if (sscanf(line, "%d", &grade) != 1) {
  printf("invalid number\n");
  return 1;
}

// 使用 grade
```

`line` 中的换行与这行解析无关——`sscanf` 的数值占位符会跳过空白。

## sscanf()：从字符串解析

`sscanf()` 与 `scanf()` 同源，但从**字符串**取数据（原型在 `stdio.h`）：

```c
int sscanf(const char* s, const char* format, ...);

sscanf(line, "%d%d", &i, &j);
```

与 `scanf` 的关键差异：数据源是内存中的字符串，**可以反复使用**（不像流读过就没了）。

## 标准库速查：ctype.h 字符分类

`ctype.h` 提供字符测试与转换函数，参数都是 `int`（允许传 `EOF`），命中返回非零、否则返回 0：

| 测试函数 | 判断 | | 测试函数 | 判断 |
|---|---|---|---|---|
| `isalpha` | 字母 | | `isdigit` | 数字 |
| `isalnum` | 字母或数字 | | `isxdigit` | 十六进制数字 |
| `islower` | 小写字母 | | `isupper` | 大写字母 |
| `isspace` | 空白（空格/换行/制表等） | | `isblank` | 空格或水平制表 |
| `isprint` | 可打印字符 | | `ispunct` | 标点（非空格字母数字） |
| `iscntrl` | 控制字符 | | `isgraph` | 空格以外的可打印字符 |

转换函数（**不修改原字符**，返回新值）：

- `tolower(ch)`：大写转小写，否则原样返回；
- `toupper(ch)`：小写转大写，否则原样返回。

```c
#include <stdio.h>
#include <ctype.h>

int main(void) {
  int ch = getchar();
  if (ch != EOF && isalpha((unsigned char)ch))
    printf("it is an alpha character.\n");
  else
    printf("it is not an alpha character.\n");
  return 0;
}
```

典型用法：校验输入"全是数字"（`isdigit`）、统一大小写再比较（`tolower` + `strcmp`）。

## 本章小结

输入函数可能失败，也可能留下未消费的字符。对新手最稳妥的模式是“先用 `fgets` 读一行，再解析并检查返回值”，字符读取则用 `int` 接收 `EOF`。
