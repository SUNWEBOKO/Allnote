# 第 04 章：数据类型、转换与数值边界

## 本章目标

- 掌握字符、整数、浮点、布尔四类基本类型及其范围；
- 掌握字面量的类型推断与后缀；
- 理解溢出、`sizeof`、`size_t` 与可移植类型；
- 掌握类型自动转换的方向与陷阱，以及显式转换的写法。

## 边界

复杂数据类型（数组、指针、结构体）在后续章节展开；本章只讲基本类型和数值语义。

## 类型：数据的最基本属性

C 语言的每一种数据都有类型（type），编译器必须知道类型才能操作数据。类型即"相似数据共同的特征"，一旦知道一个值的类型，就知道它的取值范围和操作方式。

基本数据类型有三种：字符（char）、整数（int）和浮点数（float），复杂类型都基于它们构建。

## 字符类型

字符就是单个字符，用 `char` 声明，字符常量放在单引号里：

```c
char c = 'B';
```

计算机内部，==`char` 用一个字节（8 位）存储==，**按整数处理**：每个字符对应一个整数（ASCII 码），比如 `'B'` 是 66。所以在字符的范围内，整数与字符可以互换：

```c
char c = 66;
// 等同于
char c = 'B';
```

字符可以参加数学运算，视同小整数：

```c
char a = 'B';  // 66
char b = 'C';  // 67
printf("%d\n", a + b); // 133
```

`char` 默认是否带符号由系统决定（可能是 signed 也可能是 unsigned），这一点与 `int` 不同——`int` 恒等于 `signed int`。

字符常量可以转义。单引号本身、以及 ASCII 控制字符，都要用 `\` 转义：

- `\a` 警报、`\b` 退格、`\n` 换行、`\t` 制表符、`\r` 回车、`\f` 换页、`\v` 垂直制表、`\0` null 字符（注意：不等于数字 0）
- 也可以直接用八进制/十六进制编码：`'\102'` 与 `'\x42'` 都等于 `'B'`

```c
char t = '\'';   // 单引号本身
char x = '\102'; // 八进制
char x = '\x42'; // 十六进制
```

## 整数类型

`int` 表示整数，但**不同计算机的 `int` 宽度不一样**（常见 4 字节，也可能 2 或 8 字节）。可表示范围：

- 16 位：-32,768 ～ 32,767
- 32 位：-2,147,483,648 ～ 2,147,483,647
- 64 位：±9.2 × 10^18

### signed 与 unsigned

- `signed`：带正负号（`int` 默认如此，省略不写）
- `unsigned`：只有零和正数，同样位宽下最大值扩大一倍

```c
unsigned int a;
unsigned a;        // int 可省略
signed char c;     // -128 ～ 127
unsigned char c;   // 0 ～ 255
```

### 整数子类型

| 类型 | 简写 | 宽度 |
|---|---|---|
| `short int` | `short` | 不多于 int，一般 2 字节 |
| `long int` | `long` | 不少于 int，至少 4 字节 |
| `long long int` | `long long` | 多于 long，至少 8 字节 |

都默认带符号，可与 `unsigned` 组合（`unsigned long long` 等），也可省略 `int`（`short a; long b;`）。

选择原则：需要 32 位就用 `long`，需要 64 位就用 `long long`（保证"不少于"），只需要 8 位用 `char`、16 位用 `short`。

### 极限值常量

头文件 `limits.h` 提供各类型的极限值常量，写可移植代码时应使用它们而不是自己记数字：`SCHAR_MIN/MAX`、`SHRT_MIN/MAX`、`INT_MIN/MAX`、`LONG_MIN/MAX`、`LLONG_MIN/MAX`，无符号对应 `UCHAR_MAX`、`USHRT_MAX`、`UINT_MAX`、`ULONG_MAX`、`ULLONG_MAX`。

### 整数的进制

- 八进制：前缀 `0`，如 `012`（=10）
- 十六进制：前缀 `0x`/`0X`，如 `0x1A2B`（=6699）
- 二进制 `0b` 前缀不属于标准（部分编译器支持）

进制只是书写方式，存储形式都是二进制；不同进制可混用：`10 + 015 + 0x20` 合法。

`printf()` 进制占位符：`%d` 十进制、`%o` 八进制、`%x` 十六进制；`%#o`、`%#x` 显示前缀（`0144`、`0x64`）。

## 浮点数类型

带小数点的数值都是浮点数，以 m × b^e 形式存储，是精度与范围的折中，所以**浮点运算是近似值**：`0.1 + 0.2` 不等于 `0.3`，比较浮点值不要用 `==`。

| 类型 | 宽度 | 有效数字 |
|---|---|---|
| `float` | 4 字节 | 约 6 位 |
| `double` | 8 字节 | 约 15 位 |
| `long double` | 通常 16 字节 | 更多 |

科学计数法用 `e` 分隔系数和指数，`e` 前后不能有空格：

```c
double x = 123.456e+3;  // 123.456 × 10^3
double y = .3E6;        // 首尾 0 可省略
```

## 布尔类型

C 最初没有独立布尔类型：整数 `0` 表示假，所有非零值表示真。C99 起有 `_Bool`，而 `stdbool.h` 提供更友好的别名：

```c
#include <stdbool.h>

bool flag = false;
if (flag) {
  printf("true\n");
}
```

## 字面量的类型与后缀

字面量（literal）是代码里直接出现的值，编译器必须为它指定类型。规则：十进制整数默认 `int`（太大依次升为 `long`、`long long`）；小数默认 `double`。

需要指定其他类型时用后缀：

| 后缀 | 作用 |
|---|---|
| `f` / `F` | float |
| `l` / `L` | 整数 long；小数 long double |
| `ll` / `LL` | long long |
| `u` / `U` | unsigned int（可与其他后缀组合：`UL`、`ULL`） |

```c
long int      x = 1234L;
unsigned long long int y = 1234ULL;
float         z = 3.14f;
long double   w = 3.14L;
```

建议用大写 `L`，小写 `l` 容易与数字 1 混淆。

## 溢出

值超出类型范围就是溢出（overflow/underflow）。编译器**不会报错**，而是丢弃超出的二进制位，结果往往出乎意料：

```c
unsigned char x = 255;
x = x + 1;
printf("%d\n", x); // 0（256 的最高位被丢弃）
```

无符号类型尤其容易踩坑——它永远不小于 0：

```c
for (unsigned int i = n; i >= 0; --i)  // 死循环：i 减到 0 后再减 1 回到最大值
```

判断无符号加法是否溢出，不能直接比较"相加结果 > 最大值"（结果已经溢出回绕），要先做差值比较：

```c
if (ui > UINT_MAX - sum) too_big();   // 正确
else sum = sum + ui;
```

## sizeof 与 size_t

`sizeof` 返回某种类型或某个值占用的字节数：

```c
sizeof(int);      // 通常是 4
sizeof(i);        // 变量也行
sizeof(3.14);     // 8：小数默认为 double
```

`sizeof` 的返回类型系统相关，标准用别名 `size_t` 统一（定义在 `stddef.h`，引入 `stdio.h` 会自动带上）。`printf()` 用 `%zu`（部分实现用 `%zd`）输出；`SIZE_MAX` 是 `size_t` 的最大值。

## 类型的自动转换

### 赋值时

赋值会把右边的值转成左边变量的类型：

- 浮点给整数：**直接丢弃小数部分，不是四舍五入**（`int x = 12.99;` → 12）
- 整数给浮点：自动转浮点（`24` → `24.0`）
- 窄类型给宽类型：提升（`char` → `int`）
- 宽类型给窄类型：降级，可能截断产生意外值（`int 321` 赋给 `char` 得 65）

跨类型赋值有数据丢失风险，应尽量避免，或对意图清楚的转换用显式写法。

### 混合运算时

不同类型同时计算，先统一类型再运算，规则：

1. 整数与浮点混合：整数转浮点；
2. 不同浮点：窄的转宽的；
3. 不同整数：窄的提升为宽的，**有时 signed 会转成 unsigned**。

第 3 条是最常见的坑——signed 转 unsigned 后，负数变成巨大的正数：

```c
int a = -5;
if (a < sizeof(int))   // size_t 是无符号，-5 被转为 4294967291
  do_something();      // 不执行
```

结论：避免有符号与无符号整数混合运算。

### 宽 < int 的整数运算

宽度小于 `int` 的整数（`char`、`short`）做运算时，结果自动提升为 `int`：

```c
unsigned char a = 66;
if ((-a) < 0) printf("negative\n");  // 输出 negative：-a 是 int 类型
```

### 函数传参

参数和返回值会自动转成函数定义里声明的类型，所以函数原型要写对。

## 类型的显式转换

避免歧义时用手动转换（casting），在值前加 `(type)`：

```c
(unsigned char) ch
long int y = (long int) 10 + 12;
```

## 可移植类型：stdint.h

`int` 宽度不定，需要精确位宽时用 `stdint.h` 的类型别名：

- **精确宽度**：`int8_t`、`int16_t`、`int32_t`、`int64_t`（及 `uint8_t`…`uint64_t`）
- **最小宽度**：`int_least8_t` 等（不小于指定宽度）
- **最快宽度**：`int_fast8_t` 等（满足宽度且运算最快）
- **指针相关**：`intptr_t`、`uintptr_t`（能存下指针的整数）
- **最大宽度**：`intmax_t`、`uintmax_t`（能存下任何整数）

```c
#include <stdint.h>

int32_t x32 = 45933945;   // 保证 32 位
printf("%d\n", x32);
```

## 标准库速查：math.h 常用函数

`math.h` 提供数学函数。绝大多数函数有 float 版（`f` 后缀）和 long double 版（`l` 后缀），如 `pow()`、`powf()`、`powl()`。使用前 `#include <math.h>`，编译时可能需链接数学库（如 `gcc main.c -lm`）。

**常用函数一览：**

| 类别 | 函数 | 说明 |
|---|---|---|
| 幂与根 | `pow(x, y)`、`sqrt(x)`、`cbrt(x)` | x 的 y 次方、平方根、立方根 |
| 绝对值 | `fabs(x)` | 浮点绝对值（整数绝对值用 `abs()`，在 stdlib.h） |
| 舍入 | `ceil(x)`、`floor(x)`、`round(x)`、`trunc(x)` | 向上/向下/四舍五入/截断（都返回浮点数） |
| 取余 | `fmod(x, y)` | 浮点取余（`%` 只用于整数） |
| 三角 | `sin(x)`、`cos(x)`、`tan(x)`、`asin()`、`acos()`、`atan()`、`atan2()` | 参数为弧度 |
| 指数对数 | `exp(x)`、`log(x)`、`log10(x)`、`log2(x)` | e^x、自然对数、常用对数、以 2 为底 |
| 极值 | `fmax(x, y)`、`fmin(x, y)` | 取大 / 取小 |
| 勾股 | `hypot(x, y)` | 斜边 √(x²+y²) |
| 分类 | `isfinite()`、`isinf()`、`isnan()`、`fpclassify()` | 判断值是普通/无限/非数字/哪种分类 |

```c
#include <math.h>
#include <stdio.h>

int main(void) {
  printf("%.0f\n", pow(3, 4));   // 81
  printf("%f\n", sqrt(3.0));     // 1.732051
  printf("%f\n", fmod(5.5, 2.2));// 1.100000（符号随被除数）
  printf("%d\n", isnan(sqrt(-1)));  // 1：负数的平方根是 NaN
  return 0;
}
```

要点：

- `fmod()` 返回值符号与被除数相同；`round_nearest` 式"四舍五入到最近整数"可用 `round()`；
- 结果超出可表示范围时返回 `HUGE_VAL`（math.h 中定义的 double 值）；结果小到无法表示时返回 0；
- `isnan()`/`isinf()` 等分类函数常用于先验证输入再计算，避免把 NaN 传染到整个计算结果。

## 本章小结

类型决定数据如何解释、占用多少空间以及可表示的范围。涉及转换、溢出和 `sizeof` 时，要以实际类型和边界值验证，不凭平台经验猜测。

## 自查与练习

1. 写程序打印 `sizeof(char)`、`sizeof(short)`、`sizeof(int)`、`sizeof(long)`、`sizeof(long long)`、`sizeof(float)`、`sizeof(double)`，对比你机器的实际宽度。
2. 验证 `int x = 12.99;` 得到 12；`(int)0.999` 与 `round(0.999)` 结果的差别。
3. 写一个有符/无符号混合比较的表达式，用 `-Wall -Wextra -Wpedantic` 编译，看编译器是否给出有符号性警告。
4. 用 `math.h` 计算直角三角形斜边（`hypot`）和角度（`atan2`），打印直角转换结果。
