# 第 11 章：指针与动态内存

## 本章目标

- 建立"变量 = 地址 + 类型"的模型，掌握 `*`（解引用）与 `&`（取地址）；
- 掌握指针的初始化纪律与指针运算规则；
- 理解栈与堆：自动存储期 vs 动态分配；
- 掌握 `malloc`/`calloc`/`realloc`/`free`，建立"谁分配谁释放"的资源所有权意识；
- 掌握 `memcpy` 家族与 `restrict` 的含义。

## 关键约束

本章是 C 的安全核心，三条铁律：

1. 指针必须**先初始化再使用**（指向有效对象，或 NULL）；
2. 分配可能失败，**必须检查返回值**；
3. **释放后的内存绝不能再访问**，也不要重复释放。

## 指针：存地址的变量

指针是一个值，代表一个内存地址，相当于指向某个地址的路标。`int*` 表示"指向 int 的指针"：

```c
int* intPtr;
```

书写上 `*` 的位置很灵活（`int *intPtr`、`int* intPtr` 都行），但要注意：一行声明两个指针时，两个都得带 `*`：

```c
int *foo, *bar;   // 正确：两个指针
int* foo, bar;    // 错误：bar 是 int
```

指针的指针用两个 `*`：`int** foo;`。

### * 运算符：解引用

`*` 除了声明指针，还用作运算符，取出指针指向地址里的值：

```c
void increment(int* p) {
  *p = *p + 1;   // 修改 p 指向的那个值
}
```

### & 运算符：取地址

`&` 取出变量的内存地址。两者互为逆运算（`i == *(&i)` 恒成立）：

```c
int x = 1;
increment(&x);
printf("%d\n", x); // 2
```

"函数内改调用者数据"的唯一途径就是传地址（第 08 章已用 `Swap` 演示）。

## 指针的初始化：最重要的一条纪律

声明的指针变量里存的是随机地址，**绝不能拿未初始化的指针直接读写**：

```c
int* p;
*p = 1;   // 错误：p 指向随机地址
```

正确做法：先让它指向一块已分配的内存，或初始化为 NULL：

```c
int* p = NULL;      // 安全的"空指针"：不指向任何对象
int* q = &someVar;  // 指向现有变量
```

`NULL` 是值为 0 的常量，读写它会产生错误（而不是悄悄破坏内存），所以"初始化为 NULL"是防御惯用法。

## 指针的运算

指针本质是无符号整数，但加减规则不是整数规则：

**（1）指针 ± 整数：按"单位"移动**，单位大小 = 指向类型的字节数：

```c
short* j = (short*)0x1234;
j + 1;    // 0x1236：short 占 2 字节，移动 2 字节
j - 1;    // 0x1232
```

**（2）两个指针相加非法**；同类型指针相减返回距离（元素个数，`ptrdiff_t` 类型，`%td` 输出）：

```c
short* j1 = (short*)0x1234;
short* j2 = (short*)0x1236;
ptrdiff_t dist = j2 - j1;   // 1（相隔一个 short 单位）
```

**（3）指针比较**：比较地址大小，用于判断遍历是否越界（第 07 章 `sum(start, end)` 模式）。

指针与数组的等式 `a[i] == *(a + i)` 恒成立（第 07 章）；`char* s` 指向常量字符串时内容只读（第 09 章）。

## 内存模型：栈与堆

C 的内存管理分两部分：

- **自动存储期（栈，stack）**：函数内部的局部变量，进入函数分配、离开函数自动释放。程序员不插手。
- **动态分配（堆，heap）**：程序运行期间按需向系统要的内存，**用完必须自己还**，否则一直占用直到程序退出——这叫**内存泄漏**（memory leak）。

两级规则："栈上自动，堆上手动"。函数返回后栈上变量失效（第 08 章"不要返回局部变量的指针"）；堆内存在 `free` 之前一直有效。

## void 指针：无类型的地址

`void*` 只有地址信息、没有类型信息，不能解引用（不知道怎样解读数据），但可以保存任意类型指针、也可以转回任意类型指针：

```c
int x = 10;
void* p = &x;        // 任何指针可赋给 void*
int* q = p;          // void* 也可赋回具体类型
```

`char a = 'X'; printf("%c\n", *p);` 会**编译报错**（不能解引用 void*）。malloc 等内存函数的返回值都是 void*，原因就在此。

## malloc()：按字节要内存

```c
#include <stdlib.h>

void* malloc(size_t size);

int* p = malloc(sizeof(int));        // 4 字节，够放一个 int
*p = 12;

int* arr = malloc(10 * sizeof(int)); // 动态数组：10 个 int
for (int i = 0; i < 10; i++)
  arr[i] = i * 5;
```

- 参数是要分配的**字节数**，永远用 `sizeof` 计算，不要写死数字；
- 返回值是 void*，实践中常显式转型（`(int*)`）增加可读性；
- **可能失败**：返回 NULL。用之前必须检查：

```c
int* p = malloc(n * sizeof(int));
if (p == NULL) {
  // 分配失败：条理清楚地处理（报错、清理、退出），不能继续用 p
}
```

- `malloc` **不初始化内存**，里面是旧值，自己负责放入有意义的初值：
  `char* p = malloc(4); strcpy(p, "abc");`

## calloc()：分配并清零

`calloc(n, size)` 两个参数（数量、单位字节数），并把内存**全部初始化为 0**：

```c
int* p = calloc(10, sizeof(int));
// 等同于
int* p = malloc(10 * sizeof(int));
memset(p, 0, 10 * sizeof(int));
```

## realloc()：改大小

调整已分配内存块的大小，返回新地址（可能需要搬家，数据自动搬过去）：

```c
int* b = malloc(10 * sizeof(int));
b = realloc(b, 2000 * sizeof(int));   // 注意直接覆盖的写法有风险，见下
```

要点：

- 第一个参数也可以是 NULL（等于 malloc）；第二个参数为 0 会释放内存块；
- **可能失败**：失败时返回 NULL，**原内存块不变**。所以不能直接 `p = realloc(p, ...)` 覆盖——失败会把原来的指针弄丢。安全模式：

```c
float* new_p = realloc(p, 40 * sizeof(float));
if (new_p == NULL) {
  // 失败：p 仍然有效，可以继续使用/释放
  return 1;
}
p = new_p;   // 成功后再替换
```

- `realloc` 不初始化新增部分。

## free()：还内存

```c
void free(void* block);

int* p = malloc(sizeof(int));
*p = 12;
free(p);       // 归还堆内存
```

三条纪律：

1. 释放后**不能再用** `p`（悬垂指针，dangling pointer）——把释放后的指针设为 NULL 是自我保护习惯；
2. 不能对同一指针 `free` 两次；
3. 典型泄漏：函数内分配后忘记释放，指针一消失就再也找不回那块内存：

```c
void gobble(double arr[], int n) {
  double* temp = malloc(n * sizeof(double));
  // ... 没写 free(temp)：每次调用泄漏一块
}
```

所有权口诀：**谁分配，谁负责释放**；释放后立刻置 NULL。

## restrict：唯一访问通道的承诺

`restrict` 只能修饰指针，向编译器承诺："这块内存只有这一个指针访问"。有了这个承诺编译器才能大胆优化；**撒谎是未定义行为**：

```c
int* restrict p = malloc(sizeof(int));

int* q = p;
*q = 0;   // 未定义行为：p 承诺了唯一性，却出现了第二条访问路径
```

`memcpy` 的原型参数就带 restrict，意味着目标与源不允许重叠。

## memcpy / memmove / memcmp：内存级操作

定义在 `string.h`，操作以"字节数"为单位，与内容类型无关。

**memcpy(dest, src, n)**：把 src 起的 n 字节拷到 dest（**不允许重叠**）：

```c
char s[] = "Goats!";
char t[100];
memcpy(t, s, sizeof(s));   // 7 字节，含 \0

char* c = malloc(len);
memcpy(c, s, len);         // 复制字符串的好选择：比 strcpy 快且不依赖 \0 扫描
```

**memmove(dest, src, n)**：与 memcpy 相同，但**允许目标与源重叠**（如数组内平移）：

```c
int a[100];
memmove(&a[0], &a[1], 99 * sizeof(int));   // 全体前移一位

char x[] = "Home Sweet Home";
printf("%s\n", (char*) memmove(x, &x[5], 10));  // Sweet Home Home
```

**memcmp(s1, s2, n)**：按字节字典序比较 n 个字节；相同返回 0，s1 大返回正，否则负：

```c
memcmp(s1, s2, 7) == 0  // 可比较中间嵌 \0 的区域（strcmp 做不到）
```

## 标准库速查：stdlib.h 常用函数

| 函数 | 作用 | 注意 |
|---|---|---|
| `abs(x)` / `labs(x)` / `llabs(x)` | int / long / long long 绝对值 | math.h 的 `fabs` 用于浮点 |
| `atoi(s)` / `atol(s)` / `atoll(s)` | 字符串转整数 | **不检测错误**：非数字串返回 0，不做范围检查 |
| `strtol(s, &end, base)` | 字符串转 long，带错误检测 | `end` 记录解析停止位置，能发现非法字符 |
| `strtod(s, &end)` | 字符串转 double | 同上 |
| `rand()` / `srand(seed)` | 伪随机数 [0, RAND_MAX] | 先 `srand(time(NULL))` 打底 |
| `exit(code)` | 立即终止程序 | 已见第 08 章；`EXIT_SUCCESS`/`EXIT_FAILURE` |
| `getenv(name)` | 读环境变量 | 找不到返回 NULL（第 16 章展开） |
| `system(cmd)` | 执行系统命令 | 谨慎使用，依赖环境 |
| `malloc`/`calloc`/`realloc`/`free` | 动态内存 | 本章主题 |
| `qsort(arr, n, size, cmp)` | 数组排序（快速排序） | 回调比较函数 `int cmp(const void*, const void*)` |
| `bsearch(key, arr, n, size, cmp)` | 有序数组二分查找 | 返回匹配项指针或 NULL |

**数字解析的推荐姿势**：不要用 `atoi`（静默吞错），用 `strtol` 并检查它是否解析完毕：

```c
#include <stdlib.h>
#include <stdio.h>

int main(void) {
  char* line = "42abc";
  char* end;
  long v = strtol(line, &end, 10);
  if (end == line) {
    printf("没有解析到任何数字\n");
    return 1;
  }
  if (*end != '\0') {
    printf("解析到 %ld，但后面有残留：%s\n", v, end);
  }
  return 0;
}
```

`qsort` 使用示例（结合函数指针，见第 08 章）：

```c
int cmp_int(const void* a, const void* b) {
  int x = *(const int*)a;
  int y = *(const int*)b;
  return (x > y) - (x < y);
}

int arr[] = {5, 2, 9, 1};
qsort(arr, 4, sizeof(int), cmp_int);   // arr 变为 1 2 5 9
```
