# 第 06 章：条件、分支与循环

## 本章目标

- 掌握 `if`/`else`/`switch` 的判定与分支写法；
- 掌握 `while`、`do...while`、`for` 三种循环及应用场景；
- 会用 `break`、`continue` 精确控制循环流程；
- 了解 `goto` 的合法用途。

## 边界

循环的终止条件是本章重点：循环必须能向终止条件推进，先写清"循环变量怎么变化"，再写循环体。

## if 语句

`if` 根据条件的真假（非 0 为真、0 为假）决定是否执行指定语句。**条件必须放在圆括号里**：

```c
if (x == 10)
  printf("x is 10\n");

if (line_num == MAX_LINES) {
  line_num = 0;
  page_num++;
}
```

多条语句必须用大括号包成复合语句。

`if...else` 处理"成立/不成立"两个分支；`else if` 连用构成多重判断：

```c
if (expression)
  statement
else if (expression)
  statement
else
  statement
```

**`else` 总是与最近的 `if` 匹配**——这是最容易踩的坑：

```c
if (number > 6)
  if (number < 12)
    printf("more than 6, less than 12\n");
else
  printf("wrong number\n");   // 这个 else 匹配内层 if！
```

加上大括号即可消除歧义（也让读者看清意图）：

```c
if (number > 6) {
  if (number < 12) {
    printf("more than 6, less than 12\n");
  }
} else {
  printf("wrong number\n");
}
```

## 三元运算符 ?:

用表达式形式写"二选一"选择，值是非零条件时取表达式 2、否则取表达式 3。适合给变量赋二选一的值：

```c
(i > j) ? i : j;

// 等同于
if (i > j)
  return i;
else
  return j;
```

## switch 语句

多个离散值的分支判断，用 `switch` 比一长串 `else if` 清晰：

```c
switch (grade) {
  case 0:
    printf("False");
    break;
  case 1:
    printf("True");
    break;
  default:
    printf("Illegal");
}
```

规则：

- `expression` 与 `case` 值匹配时进入对应分支；都不匹配时执行 `default`（可选）；
- 每个分支结尾要有 `break`，否则会**继续穿透执行**下一个分支；
- 多个 `case` 共用一个语句体时，利用穿透特性连写（`case 0:` 不放语句、紧跟 `case 1:`）；
- `case` 后面的语句体不需要大括号，这正是需要 `break` 的原因；
- `default` 习惯放在最后，末尾可省 `break`；
- `switch` 只适合判断整数（或枚举值，见第 12 章），不能判断"范围"，范围判断用 `if...else if`。

## while 循环

先判断条件，满足才执行循环体，循环体可能一次也不执行：

```c
while (expression)
  statement;
```

```c
i = 0;
while (i < 10) {
  printf("i is now %d!\n", i);
  i++;
}
```

条件恒真就是无限循环，常用于"直到满足某条件才退出"的程序（配合 `break`）：

```c
while (1) {
  // ...
}
```

## do...while：至少执行一次

先执行循环体，再判断条件。适合"必须做一次，然后根据结果决定是否继续"的场景：

```c
do
  statement
while (expression);   // 注意分号

i = 10;
do --i;
while (i > 0);        // 循环到 i 为 0
```

## for 循环

最常用的定次循环。圆括号里三个表达式各司其职：

1. `initialization`：初始化，只执行一次；
2. `continuation`：每轮开头判断，为真才执行循环体；
3. `action`：每轮结束后执行，让循环变量向终点推进。

```c
for (int i = 10; i > 0; i--)
  printf("i is %d\n", i);
```

三个表达式都可以省略（分号保留），`for (;;)` 是无限循环。每个表达式内可用逗号放多个语句：

```c
for (i = 0, j = 999; i < 10; i++, j--) {
  printf("%d, %d\n", i, j);
}
```

在 `for` 声明里的循环变量（如 `int i`）离开循环就失效（块作用域）。

## break：跳出循环或 switch

`break` 立即跳出**最内层**的 `while`/`do...while`/`for`/`switch`。它不能用于跳出 `if`（`if` 不是循环或 switch 结构）：

```c
while ((ch = getchar()) != EOF) {
  if (ch == '\n') break;   // 读到换行就停止
  putchar(ch);
}
```

```c
if (n > 2) break;  // 无效：break 不能跳出 if
```

## continue：跳过本轮剩余部分

`continue` 结束当前这一轮循环体，回到循环头部进入下一轮：

```c
while ((ch = getchar()) != '\n') {
  if (ch == '\t') continue;  // 丢弃制表符
  putchar(ch);
}
```

区别记忆：`break` 退出整个循环；`continue` 只跳过本轮。

## goto：最后的手段

`goto` 跳到本函数内的标签处。它破坏结构化流程，一般不要用，但有两个公认合理场景：

**（1）从多层嵌套循环中整体跳出**：

```c
for (...) {
  for (...) {
    while (...) {
      if (some_error_condition)
        goto bail;
    }
  }
}
bail:
// 错误处理
```

**（2）统一错误出口**（多个失败点跳到同一条清理路径）：

```c
if (do_something() == ERR) goto error;
if (do_something2() == ERR) goto error;
// ...
error:
// 统一的错误处理
```

注意：`goto` 只能在同一个函数内跳转。

## 本章小结

分支决定走哪条路径，循环决定重复多少次。写循环时先明确初始化、继续条件和更新动作，并为输入异常准备退出路径。

## 自查与练习

1. 用 `if...else if` 把 0–100 的成绩映射为 A–F 五个等级，用边界值 59.9、60、89.9、90、100、100.1 逐一验证只有一个等级命中。
2. 用 `for` 求一组固定成绩的平均分、最大值和最小值；再改用 `while` 重写一遍。
3. 用 `switch` 实现一个菜单（1 查看、2 录入、3 退出），默认分支提示输入无效。
4. 写一个 `do...while` 读取整数直到输入奇数为止的程序，说明为什么这里不能简单换成 `while`。
