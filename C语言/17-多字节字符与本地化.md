# 第 17 章：多字节字符、宽字符与本地化文本

## 本章目标

- 建立"字符 ≠ 字节"的模型：多字节字符（UTF-8）下 `strlen` 是字节数而非字符数；
- 掌握宽字符 `wchar_t` 与 `L` 前缀，以及宽/窄字符的转换函数；
- 会用 `setlocale` 把程序切换到本地化环境；
- 掌握时间处理的常用函数（time.h 速查）。

## 边界

本章只讲"能跑、能读懂"的级别：中文文本的输入输出、转换，加上时间处理速查。字符集内部的编码细节（UCS-2 vs UTF-16 等）不展开。**默认建议**：现代项目用 UTF-8 源码 + `setlocale(LC_ALL, "")`，这是成本最低的中文方案。

## Unicode 与编码

C 诞生时只有 ASCII（0–127，一字节一个字符）。非英语字符（中文就有几万个）需要多个字节，各国早期编码混乱，后来统一到 **Unicode**：给每个字符一个编号，称为**码点**（code point），记作 `U+0041` 这种十六进制形式；U+0000–U+007F 与 ASCII 重合。

Unicode 提供三种表示法（编码）：

- **UTF-8**：1–4 字节变长；ASCII 部分仍 1 字节，与 ASCII 完全兼容，**使用最广**；
- UTF-16：基本平面 2 字节、其余 4 字节；
- UTF-32：统一 4 字节。

相关宏：`MB_LEN_MAX`（limits.h，任意地区最大的字节长度）、`MB_CUR_MAX`（stdlib.h，当前地区的字节长度）。

## 字符的转义表示

```c
printf("ABC\n");
printf("\101\102\103\n");   // 八进制 \ddd
printf("\x41\x42\x43\n");   // 十六进制 \xhh
printf("\u2620");           // 码点 \u + 4 位十六进制
printf("\U00002620");       // 码点 \U + 8 位十六进制（都输出 ☠）
```

`\u`/`\U` 不能表示 ASCII 字符（码点 < 0xA0），`$`、`@`、反引号三个除外。

## 多字节字符：一个汉字不是 char

```c
char* s = "\u6625\u5929";   // 春天
printf("%s\n", s);
```

UTF-8 环境下也可以直接写字面量 `"春天"`（源文件按 UTF-8 保存即可）。要点：

- **`strlen(s)` 返回字节数**：`"春天"` 是 6 字节，不是 2 个字符——字符与字节不再一一对应；
- 所有面向单字节的字符串函数（`strchr`、`strtok`、`toupper`、`isalpha` 等）在多字节字符串上**会得出错误结果**；
- 处理前先切换本地化环境：

```c
#include <locale.h>
setlocale(LC_ALL, "");          // 使用系统默认本地化（Windows 中文系统即 UTF-8）
// 或指定：setlocale(LC_ALL, "zh_CN.UTF-8");
```

- 字符串字面量可加 `u8` 前缀强制 UTF-8：`char* s = u8"春天";`；
- 输出多字节字符时，务必先 `setlocale`，否则终端/printf 可能把它按字节乱打。

## 宽字符：wchar_t 与 L 前缀

多字节字符是变长的，处理麻烦（要逐字判断字节数）。C 提供了**宽字符**：每个字符固定宽度（2 或 4 字节），类型 `wchar_t`（wchar.h）：

```c
wchar_t c = L'牛';        // 字面量加 L 前缀
wchar_t* s = L"春天";

printf("%lc\n", c);       // 占位符 %lc 打印宽字符
printf("%ls\n", s);       // %ls 打印宽字符串
```

- 宽字符串以宽空字符 `L'\0'` 结尾；
- 处理宽字符串要用 wchar.h 里专门的函数（`wcscpy`、`wcslen`、`wcscmp`……），**不能**用 `strcpy`/`strlen`；
- `wcslen(s)` 返回字符个数（2），这才是"两个汉字"的正确计数。

## 宽 ↔ 窄转换（stdlib.h）

| 函数 | 作用 | 返回值 |
|---|---|---|
| `mblen(s, n)` | 判断 s 第一个多字节字符占几字节 | 字节数；0 空字符；-1 非法 |
| `mbtowc(&wc, s, n)` | 多字节字符 → 宽字符 | 字节数或 -1 |
| `wctomb(char* mb, wc)` | 宽字符 → 多字节字符 | 字节数或 -1 |
| `mbstowcs(wcs, mbs, n)` | 多字节字符串 → 宽字符串（n 是最大字符数） | 字符数或 -1 |
| `wcstombs(mbs, wcs, n)` | 宽字符串 → 多字节字符串（n 是最大字节数） | 字节数或 -1 |

转换前必须先 `setlocale(LC_ALL, "")`，否则用 C 默认 locale 可能转失败。字符串版两函数第一个参数传 NULL 可先量出所需缓冲区大小。

```c
setlocale(LC_ALL, "");
wchar_t wcs[20];
char* mbs = "天气不错";
int n = mbstowcs(wcs, mbs, 20);   // n = 4：成功转换 4 个字符
printf("%ls\n", wcs);             // 天气不错
```

## 标准库速查：time.h 常用函数

| 函数 | 作用 | 要点 |
|---|---|---|
| `time(&t)` | 当前日历时间（秒，自 1970-01-01 UTC） | 返回 `time_t` |
| `clock()` | 程序启动以来的 CPU 时间 | 单位是 `CLOCKS_PER_SEC`，算耗时用 |
| `difftime(t1, t0)` | 两个 time_t 的秒差 | `double` |
| `localtime(&t)` | time_t → 本地时间 `struct tm*` | 返回静态内存（`%ld` 秒数），用一次复制走 |
| `gmtime(&t)` | time_t → UTC 的 struct tm | 同上 |
| `mktime(&tm)` | struct tm → time_t | 可规范化/算星期 |
| `asctime(&tm)` | struct tm → 固定格式字符串 | 格式丑（`Thu Nov 18 17:37:02 2021` 带换行） |
| `ctime(&t)` | time_t → 同款字符串 | 是 `asctime(localtime(&t))` 的组合 |
| `strftime(buf, size, fmt, &tm)` | struct tm → 自定义格式字符串 | **最常用**，`%Y-%m-%d %H:%M:%S` 等 |

`struct tm` 字段：`tm_year`（**从 1900 起**，加 1900）、`tm_mon`（**0–11**，加 1）、`tm_mday`、`tm_hour`、`tm_min`、`tm_sec`、`tm_wday`（0=周日）等——两个偏移陷阱记住。

```c
#include <stdio.h>
#include <time.h>

int main(void) {
  time_t now = time(NULL);             // 常用写法：NULL 表示不要回写
  struct tm* local = localtime(&now);

  printf("%d-%02d-%02d %02d:%02d:%02d\n",
    local->tm_year + 1900, local->tm_mon + 1, local->tm_mday,
    local->tm_hour, local->tm_min, local->tm_sec);

  char buf[64];
  strftime(buf, sizeof buf, "%Y-%m-%d %H:%M:%S", local);
  printf("%s\n", buf);                 // 一行搞定，可自定义格式
  return 0;
}
```
