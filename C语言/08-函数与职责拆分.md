# 第 08 章：函数、接口与职责拆分

## 本章目标

- 掌握函数定义、调用、原型、返回值与参数传递；
- 理解"传值"语义，会用指针参数修改调用者数据；
- 掌握函数原型解决"先使用、后定义"的问题；
- 了解函数指针、`exit()`、可变参数等进阶写法；
- 用清晰接口把重复计算从 `main()` 中拆出来。

## 边界

`static`、`extern`、`const` 说明符的完整语义在第 03 章，本章只讲它们在函数语境下的应用，不重复讲解。

## 函数的定义与调用

函数是一段可重复执行的代码，接受参数、返回结果：

```c
int plus_one(int n) {
  return n + 1;
}
```

定义要点：

1. **返回值类型**在最前（这里是 `int`）；没有返回值用 `void`；
2. **参数**在圆括号里声明，每个都要写类型和名字；没有参数写成 `void`；
3. **函数体**在大括号里，大括号后不加分号；
4. `return` 给出返回值，执行到它就结束函数；`void` 函数可以省略 `return` 或写 `return;`。

调用时参数个数必须与定义一致：

```c
int a = plus_one(13);   // 14
plus_one(2, 2);         // 报错：参数多了
plus_one();             // 报错：参数少了
```

函数必须先声明后使用，且只能声明在顶层（不能嵌套定义在其他函数里）。递归（函数调用自身）是合法的：

```c
unsigned long Fibonacci(unsigned n) {
  if (n > 2)
    return Fibonacci(n - 1) + Fibonacci(n - 2);
  else
    return 1;
}
```

## main()：程序入口

程序由 `main()` 启动，返回值作为整个程序的退出状态——`0` 表示成功，非零表示出错（详见第 16 章）：

```c
int main(void) {
  printf("Hello World\n");
  return 0;
}
```

`main()` 可以省略 `return 0`（编译器自动补 0），但其他函数没有这个待遇，建议统一写 `return`。

## 参数的传值语义

传参传入的是**值的拷贝**（传值调用），函数内部改参数不影响调用者的变量：

```c
void increment(int a) {
  a++;
}

int i = 10;
increment(i);
printf("%d\n", i); // 10，i 没变
```

想改变调用者的变量，**只有一条路：传地址**（指针参数），并用 `*` 解引用操作：

```c
void Swap(int* x, int* y) {
  int temp;
  temp = *x;
  *x = *y;
  *y = temp;
}

int a = 1;
int b = 2;
Swap(&a, &b);    // a、b 真正交换
```

传值还有一个推论：**函数不要返回内部变量的指针**——函数结束时内部变量就销毁了，返回的地址是无效的：

```c
int* f(void) {
  int i;
  return &i;   // 错误：i 已随函数结束而消失
}
```

（想在函数间共享数据要用 `static` 变量或动态内存，见第 11 章。）

## 函数指针

函数本身是内存里的一段代码，可以用指针指向它：

```c
void print(int a) {
  printf("%d\n", a);
}

void (*print_ptr)(int) = &print;
```

**关键词法陷阱**：`(*print_ptr)` 必须放圆括号里，否则 `int` 参数列表的优先级更高，`void* print_ptr(int)` 就变成了"返回 void 指针的函数"。

函数名本身就是函数地址（`print` 与 `&print` 等价），所以以下调用方式全部合法：

```c
print(10);
(*print)(10);
(&print)(10);
(*print_ptr)(10);
print_ptr(10);
```

函数指针的典型用途：作为参数传递"策略"。例如 `qsort()` 就接收一个比较函数指针（见第 11 章 stdlib 速查）：

```c
int compute(int (*myfunc)(int), int, int);
```

## 函数原型：先使用、后定义

C 要求先声明后使用。所有函数都在 `main()` 之前完整定义会破坏"入口在前"的阅读习惯，办法是**开头只给出原型**（返回值 + 参数类型，加参数名也可，以分号结尾），实现放后面：

```c
int twice(int num);     // 原型

int main(void) {
  return twice(10);
}

int twice(int num) {    // 实现
  return 2 * num;
}
```

每个源文件头部给出所有函数原型是多文件工程的常规做法（第 15 章）。

## exit() 与 atexit()

`exit()`（原型在 `stdlib.h`）立即终止整个程序，参数作为程序退出状态。约定用两个常量：

```c
exit(EXIT_SUCCESS);   // 成功，等价 0
exit(EXIT_FAILURE);   // 失败，等价 1
```

在 `main()` 里 `exit()` 等价于 `return`；在其他函数里调用 `exit()` 会直接结束整个程序（可用来做深层的错误退出）。`atexit()` 登记退出前的收尾函数（无参数、无返回值）：

```c
void print(void) { printf("something wrong!\n"); }

atexit(print);
exit(EXIT_FAILURE);
```

## 函数处的说明符应用

**`static` 局部变量：跨调用保留。** 函数内加 `static` 的变量只初始化一次，两次调用之间值保留（对照第 03 章，这里是它最典型的应用场景）：

```c
void counter(void) {
  static int count = 1;   // 只初始化一次
  printf("%d\n", count);
  count++;
}

counter();  // 1
counter();  // 2
counter();  // 3
```

注意 `static` 变量的初始化必须用常量；它在块作用域内默认值是 0：

```c
static int foo;   // 等于 static int foo = 0;
```

**`static` 函数**：只在本文件可见（详见第 15 章）。

**`static` 参数数组**：`int sum_array(int a[static 3], int n)` 里的 `static 3` 只是告诉编译器"数组至少 3 个元素"，提示优化，不改变行为；多维数组参数只对第一维有效。

**`const` 参数**：函数不改其指向值时加 `const`（`void find(const int* arr, int n);`），等于把接口承诺写进原型签名。指针 const 两种位置的含义见第 03 章。

**`extern` 函数**：函数原型默认就是 `extern`（外部可见），写不写一样；`static` 是其对立面。

## 可变参数

参数数量不定时用省略号 `...`（必须放在参数序列末尾）：

```c
int printf(const char* format, ...);
```

配合 `stdarg.h` 的四个宏操作可变参数：

- `va_list`：可变参数对象类型；
- `va_start(ap, last)`：初始化，`last` 是 `...` 前那个参数，用于定位；
- `va_arg(ap, type)`：依次取出一个参数（指定类型），内部指针自动后移；
- `va_end(ap)`：清理。

```c
#include <stdarg.h>

double average(int i, ...) {
  double total = 0;
  va_list ap;
  va_start(ap, i);
  for (int j = 1; j <= i; ++j)
    total += va_arg(ap, double);
  va_end(ap);
  return total / i;
}
```

`...` 前至少要有一个具名参数，否则无法定位起点。取出的类型必须与实际传入类型一致，否则是未定义行为。
