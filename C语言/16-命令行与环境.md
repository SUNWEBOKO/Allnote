# 第 16 章：命令行参数、退出状态与环境

## 本章目标

- 掌握 `main` 的 `argc`/`argv` 形态，写出可配置的命令行工具；
- 理解退出状态约定（0 成功、非 0 失败），并正确使用 `exit`/`return`；
- 会用 `getenv` 读取环境变量。

## 边界

本章把"程序如何被外界调用"讲清楚：参数从哪来、结果往哪报、环境信息怎么读。字符串数组的遍历沿用第 07 章，指针数组是 `char*` 的数组——`argv` 就是"指针数组"的第一个实战例子。

## 入口参数：argc 与 argv

`main` 有两个标准形态，用来接收**命令行参数**：

```c
int main(int argc, char* argv[]) { ... }
```

- `argv`：一个字符串指针数组，`argv[0]` 是程序名，`argv[1]` 起是每个命令行参数；
- `argc`：数组里元素的个数（至少为 1，因为 argv[0] 恒在）；
- 也可以写成等价形式 `char** argv`（指向指针的指针，第 11 章）。

```c
#include <stdio.h>

int main(int argc, char* argv[]) {
  for (int i = 0; i < argc; i++)
    printf("arg %d: %s\n", i, argv[i]);
  return 0;
}
```

运行 `./a.out hello world 42`：

```text
arg 0: ./a.out
arg 1: hello
arg 2: world
arg 3: 42
```

注意：参数都是**字符串**（`"42"`），要当数字用必须自己转换（`atoi`/`strtol`，见第 11 章速查）。

## 参数解析的基本模式

先检查参数个数，再按需转换——**缺参数务必给用户提示而非悄悄出错**：

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char* argv[]) {
  if (argc < 3) {
    fprintf(stderr, "用法: %s <文件名> <次数>\n", argv[0]);
    return 1;
  }
  char* filename = argv[1];
  long count = strtol(argv[2], NULL, 10);
  printf("将处理 %s %ld 次\n", filename, count);
  return 0;
}
```

用 `strtol` 而不是 `atoi` 解析数字（能发现非法输入，atoi 静默返回 0）。

## 退出状态：把成败告诉系统

`main` 的返回值成为程序的**退出状态**（exit status），shell 通过它判断程序成败：

- **0 = 成功**；**非 0 = 失败**（具体数值是约定，如 1、2 各自代表不同错误）；shell 里用 `$?` 查看，`&&`/`||` 也依赖它；
- `main` 里 `return 0;` 与调用 `exit(EXIT_SUCCESS);` 等价；
- `exit(code)`（stdlib.h）可以在**任意函数里**立即终止整个程序：
  - `EXIT_SUCCESS`（0）/ `EXIT_FAILURE`（1）两个标准宏；
  - exit 前会执行收尾（关闭已打开的流、调用 `atexit` 登记的函数），比直接从函数返回"逃逸"更受控；
  - 失败路径惯用 `exit(EXIT_FAILURE)` 或 `return 1`：文件打不开、参数非法、内存分配失败等。

```c
FILE* fp = fopen("data.txt", "r");
if (fp == NULL) {
  fprintf(stderr, "无法打开 data.txt\n");
  exit(EXIT_FAILURE);
}
```

错误信息写 `stderr`（第 14 章），退出码非 0，失败才"可见、可脚本化"。

## 环境变量：getenv

程序运行环境提供一组 `名称=值` 的配置（PATH、HOME、LANG 等），用 `getenv(name)` 读取：

```c
#include <stdlib.h>
#include <stdio.h>

char* path = getenv("PATH");
if (path != NULL)
  printf("PATH = %s\n", path);
else
  printf("PATH 未设置\n");
```

- 找不到返回 NULL，**必须检查**再使用；
- 环境变量是"运行期配置"：同一程序不同终端跑结果可以不同，适合做默认值（如数据目录、语言）；
- 只读是主流用法（`putenv`/`setenv` 修改受权限与实现限制，尽量避免）。

把第 14 章的"标准流重定向"与本章合起来看：程序与外界的接口就是 输入流 + 输出流 + 参数 + 环境 + 退出码 这几条通道。

## 本章小结

命令行参数、标准流、环境变量和退出码构成程序与外界的基本接口。错误应写到 `stderr`，成功与失败要用稳定的退出状态表达。

## 自查与练习

1. 写 `cp 工具`：`cp <源文件> <目标文件>`，缺参数时打印用法并返回非 0；成功打印复制字节数返回 0。用 `echo $?` 验证退出码。
2. 扩展练习 1：`cp -v <源> <目标>` 支持 `-v` 详细模式（用 `strcmp` 判断参数，第 09 章）。
3. 写一个程序读取 `LANG` 环境变量并按它决定提示语言；未设置时用默认语言并提示。
4. 解释 `argv[0]` 在"用法: %s <参数>"提示中的作用，以及为什么不要写死程序名。
5. 说明 `return 1` 与 `exit(EXIT_FAILURE)` 的异同（能否在中途函数里用、能否期待收尾）。
