## 1. 傅里叶变换回顾与数值实现

### 1.1 从复积分到实部/虚部分解

连续傅里叶变换定义为：  
$F(j\omega) = \int_{-\infty}^{\infty} f(t)\, e^{-j\omega t}\, dt$

利用欧拉公式 $e^{-j\omega t} = \cos(\omega t) - j\sin(\omega t)$，可拆分为实部与虚部：  
$F(j\omega) = \underbrace{\int_{-\infty}^{\infty} f(t)\cos(\omega t)\,dt}_{\text{实部：余弦投影}} \;-\; j\underbrace{\int_{-\infty}^{\infty} f(t)\sin(\omega t)\,dt}_{\text{虚部：正弦投影}}$

**关键结论（奇偶性与频谱的对应）：**

- 若 $f(t)$ 为**偶函数** → 积分 $\int f(t)\sin(\omega t)dt = 0$，**频谱只有实部**，虚部为零。
- 若 $f(t)$ 为**奇函数** → $\int f(t)\cos(\omega t)dt = 0$，**频谱只有虚部**，实部为零。
- **时域平移**：$f(t-\tau)$ 的傅里叶变换为 $e^{-j\omega\tau}F(j\omega)$，乘上的复指数会使实部与虚部发生混合（频谱旋转）。

**直观例子**：

- 宽度为1的偶矩形脉冲：频谱全部落在实平面。
- 从 $-1$ 到 $0$ 为 $-1$，$0$ 到 $1$ 为 $1$ 的奇对称矩形：频谱只落在虚平面。
- 将偶矩形右移 $0.5$ 秒：不再是偶函数，频谱在实部和虚部间旋转。

### 1.2 数值积分实现思路

计算机处理连续积分需要**时间离散**和**频率离散**：

| 连续变量 | 离散化策略 |
| --- | --- |
| 时间 $t$ | 截取有限区间 $[t_{\min}, t_{\max}]$，以步长 $\Delta t$ 采样 |
| 频率 $\omega$（或 $f$） | 取频率范围 $[f_{\min}, f_{\max}]$，以 $\Delta f$ 采样，$\omega = 2\pi f$ |

数值积分（矩形法）形式为：  
$\operatorname{Re}[F(j\omega_i)] \approx \sum_{n} f(t_n)\cos(\omega_i t_n)\,\Delta t$  
$\operatorname{Im}[F(j\omega_i)] \approx -\sum_{n} f(t_n)\sin(\omega_i t_n)\,\Delta t$

**实现思路**：
- 用 `linspace` 在时间区间生成 N 个采样点
- 按上述矩形法累加求实部和虚部
- 对每个频率点循环计算，得到频谱向量

### 1.3 多频信号分解实例

**信号**：$f(t) = \cos(4\pi t) + \sin(8\pi t) + \sin(12\pi t + \frac{\pi}{4})$

- $\cos(4\pi t)$：偶函数，仅在**实部**出现两个峰（$\pm 2\text{Hz}$）
- $\sin(8\pi t)$：奇函数，仅在**虚部**出现两个峰（$\pm 4\text{Hz}$）
- $\sin(12\pi t + \frac{\pi}{4}) = \frac{\sqrt{2}}{2}\sin(12\pi t) + \frac{\sqrt{2}}{2}\cos(12\pi t)$，**实部与虚部均有分量**（$\pm 6\text{Hz}$）

> 结论：复频谱的实部对应余弦分量，虚部对应正弦分量；相位信息编码在实虚部的比例中。

## 2. 傅里叶变换的局限性

### 2.1 绝对可积条件

傅里叶变换积分存在的必要条件：  
$\int_{-\infty}^{\infty} |f(t)|\, dt < \infty \quad \text{（能量有限）}$

**反例**：$f(t)=t^2$、$e^{2t}$ 等无界增长函数，积分发散；即使 $\sin(\omega_0 t)$、$\cos(\omega_0 t)$ 这类周期信号，严格来说也不满足绝对可积，其傅里叶变换仅在**广义函数**意义下存在（结果为冲激函数）。

### 2.2 核心矛盾

傅里叶变换要求信号能量有限，但工程中大量信号（阶跃、指数增长、多项式）不满足此条件，亟需扩展变换工具。

## 3. 拉普拉斯变换的引入与定义

### 3.1 核心思想：用指数衰减“压住”发散

为使无界函数可积，在原信号上乘以**指数衰减因子** $e^{-\sigma t}$（$\sigma>0$）：  
$g(t) = f(t)\, e^{-\sigma t}$  
只要 $\sigma$ 足够大，就能让大多数增长函数在 $t\to\infty$ 时衰减至零，从而满足绝对可积。然后对 $g(t)$ 做傅里叶变换：  
$\int_{-\infty}^{\infty} f(t) e^{-\sigma t} e^{-j\omega t} dt = \int_{-\infty}^{\infty} f(t) e^{-(\sigma + j\omega)t} dt$

### 3.2 拉普拉斯变换定义

令复频率 $s = \sigma + j\omega$，得到**单边拉普拉斯变换**（假定 $t<0$ 时 $f(t)=0$）：  

$$
\boxed{F(s) = \mathcal{L}\{f(t)\} = \int_{0^-}^{\infty} f(t)\, e^{-st}\, dt}
$$

反变换为：  

$$
f(t) = \frac{1}{2\pi j} \int_{\sigma - j\infty}^{\sigma + j\infty} F(s)\, e^{st}\, ds \quad \text{（工程中主要用查表法）}
$$

**与傅里叶变换的关系**：

- 当 $\sigma=0$（即 $s=j\omega$）时，拉普拉斯变换退化为（单边）傅里叶变换。
- 拉普拉斯变换 = 先乘以衰减因子 $e^{-\sigma t}$，再做傅里叶变换。

## 4. 拉普拉斯变换的核心性质

### 4.1 常用变换对（单边，$t\ge 0$）

| 时域 $f(t)$ | 复频域 $F(s)$ | 收敛域 (ROC) |
| --- | --- | --- |
| $u(t)$（单位阶跃） | $\dfrac{1}{s}$ | $\operatorname{Re}(s)>0$ |
| $e^{-at}$ | $\dfrac{1}{s+a}$ | $\operatorname{Re}(s)>-a$ |
| $t^n$ ($n\ge0$) | $\dfrac{n!}{s^{n+1}}$ | $\operatorname{Re}(s)>0$ |
| $\sin(\omega t)$ | $\dfrac{\omega}{s^2+\omega^2}$ | $\operatorname{Re}(s)>0$ |
| $\cos(\omega t)$ | $\dfrac{s}{s^2+\omega^2}$ | $\operatorname{Re}(s)>0$ |
| $e^{-at}\sin(\omega t)$ | $\dfrac{\omega}{(s+a)^2+\omega^2}$ | $\operatorname{Re}(s)>-a$ |
| $e^{-at}\cos(\omega t)$ | $\dfrac{s+a}{(s+a)^2+\omega^2}$ | $\operatorname{Re}(s)>-a$ |

> **记忆技巧**：时域乘 $e^{-at}$ → 频域将 $s$ 替换为 $s+a$（频移性质）。

### 4.2 线性性质

$\mathcal{L}\{a f_1(t) + b f_2(t)\} = a F_1(s) + b F_2(s)$

**示例**：$f(t)=2 - e^{2t} + 5e^{-2t}\cos(3t)$  
$F(s) = \frac{2}{s} - \frac{1}{s-2} + \frac{5(s+2)}{(s+2)^2+9}$

### 4.3 微分性质（重点）

$$
\boxed{\mathcal{L}\{f'(t)\} = sF(s) - f(0^+)}
$$
$$
\mathcal{L}\{f''(t)\} = s^2 F(s) - s f(0^+) - f'(0^+)
$$

**物理意义**：求导会丢失原函数中的直流/常数分量（类比：$(x^2)' = 2x$，积分回去得 $x^2 + C$）。$-f(0^+)$ 正是用于补偿这一初值影响的修正项，把丢失的积分常数“补”回来。

### 4.4 积分性质

$$
\boxed{\mathcal{L}\left\{\int_0^t f(\tau)\, d\tau\right\} = \frac{F(s)}{s}}
$$

### 4.5 收敛域 (ROC)

使积分 $\int_0^\infty |f(t)e^{-st}| dt < \infty$ 成立的 $s$ 的范围。  
**确定方法**：

1. 找出 $F(s)$ 的所有极点（分母为零的点）。
2. 对于因果信号，ROC 为最右侧极点以右的半平面：$\operatorname{Re}(s) > \max\{\operatorname{Re}(p_i)\}$。

**示例**：对 4.2 节中的 $F(s) = \frac{2}{s} - \frac{1}{s-2} + \frac{5(s+2)}{(s+2)^2+9}$  
极点：$s_1=0,\; s_2=2,\; s_{3,4}=-2\pm 3j$ → 最右侧极点实部为 $2$ → ROC: $\operatorname{Re}(s) > 2$。

## 5. 拉普拉斯变换解线性微分方程

### 5.1 核心思想与流程

利用拉氏变换将微分方程转化为 $s$ 域的代数方程，解出 $X(s)$ 后再反变换回时域。

**通用步骤**：

1. 对方程两边取拉普拉斯变换，利用微分性质代入初值。
2. 整理得到 $X(s) = \dfrac{N(s)}{D(s)}$。
3. 部分分式展开。
4. 查表反变换得全响应 $x(t)$。

**响应分解**：

- **自由响应**（齐次解）：由系统极点决定，对应初始状态。
- **强迫响应**（特解）：由输入 $f(t)$ 决定，与输入同频的稳态响应。
- **全响应** = 自由响应 + 强迫响应。

### 5.2 例题：弹簧-质量-阻尼系统

系统方程：$\ddot{x}(t) + 3\dot{x}(t) + 2x(t) = 10\sin(2t)$  
初始条件：$x(0)=1,\; \dot{x}(0)=2$，求全响应 $x(t)$。

#### 解法一：经典时域法

1. **强迫响应**（特解）：设 $x_p = A\sin(2t) + B\cos(2t)$，代入方程比较系数得：  
   $\begin{cases} -2A - 6B = 10 \\ 6A - 2B = 0 \end{cases} \;\Rightarrow\; A = -0.5,\; B = -1.5$  
   故 $x_p(t) = -0.5\sin(2t) - 1.5\cos(2t)$。
2. **自由响应**（齐次解）：特征方程 $s^2+3s+2=0 \Rightarrow s_1=-1,\; s_2=-2$，  
   $x_h(t) = C_1 e^{-t} + C_2 e^{-2t}$
3. **全响应**：$x(t) = C_1 e^{-t} + C_2 e^{-2t} - 0.5\sin(2t) - 1.5\cos(2t)$  
   代入 $x(0)=1$：$C_1 + C_2 - 1.5 = 1 \Rightarrow C_1 + C_2 = 2.5$  
   求导：$\dot{x}(t) = -C_1 e^{-t} - 2C_2 e^{-2t} - \cos(2t) + 3\sin(2t)$  
   代入 $\dot{x}(0)=2$：$-C_1 - 2C_2 - 1 = 2 \Rightarrow -C_1 - 2C_2 = 3$  
   联立解得：$C_1 = 8,\; C_2 = -5.5$。  

   **正确解**：  
   $x(t) = 8e^{-t} - 5.5e^{-2t} - 0.5\sin(2t) - 1.5\cos(2t)$

#### 解法二：拉普拉斯变换法

1. 方程两边取拉氏变换（利用微分性质）：  
   $[s^2 X(s) - s x(0) - \dot{x}(0)] + 3[s X(s) - x(0)] + 2X(s) = \frac{20}{s^2+4}$
2. 代入 $x(0)=1,\; \dot{x}(0)=2$：  
   $(s^2+3s+2)X(s) - (s+2) - 3 = \frac{20}{s^2+4}$  
   $\Rightarrow (s^2+3s+2)X(s) = s+5 + \frac{20}{s^2+4}$
3. 解出：  
   $X(s) = \frac{s+5}{(s+1)(s+2)} + \frac{20}{(s+1)(s+2)(s^2+4)}$  
   通分后：  
   $$X(s) = \frac{s^3+5s^2+4s+40}{(s+1)(s+2)(s^2+4)}$$
4. **部分分式展开**（令 $X(s) = \frac{A}{s+1} + \frac{B}{s+2} + \frac{Cs+D}{s^2+4}$）：  
   待定系数解得：  
   $A = 8,\quad B = -5.5,\quad C = -1.5,\quad D = -1$  
   故  
   $X(s) = \frac{8}{s+1} - \frac{5.5}{s+2} - \frac{1.5s + 1}{s^2+4}$
5. 查表反变换：
   - $\dfrac{8}{s+1} \;\leftrightarrow\; 8e^{-t}$
   - $\dfrac{-5.5}{s+2} \;\leftrightarrow\; -5.5e^{-2t}$
   - $-\dfrac{1.5s}{s^2+4} \;\leftrightarrow\; -1.5\cos(2t)$
   - $-\dfrac{1}{s^2+4} = -0.5\cdot\dfrac{2}{s^2+4} \;\leftrightarrow\; -0.5\sin(2t)$  

   **得到全响应**：  
   $x(t) = 8e^{-t} - 5.5e^{-2t} - 0.5\sin(2t) - 1.5\cos(2t), \quad t\ge 0$

> **拉氏法优势**：初值自动嵌入，无需猜测特解形式，步骤机械，特别适合编程实现。

## 6. 频域几何解释：极点的几何意义与频率响应

系统特征方程 $s^2+3s+2=0$ 的极点为 $p_1=-1,\; p_2=-2$。输入频率 $\omega=2$，在 $s$ 平面上考察从极点到 $j\omega = j2$ 的向量：

- 从 $-1$ 到 $j2$：长度 $\sqrt{5}$，角度 $\arctan(2/1) \approx 63.43^\circ$
- 从 $-2$ 到 $j2$：长度 $2\sqrt{2}$，角度 $\arctan(2/2) = 45^\circ$

**幅频特性**：系统传递函数 $H(s) = \frac{1}{(s+1)(s+2)}$，在 $s=j2$ 处的幅值为：  
$$
|H(j2)| = \frac{1}{|j2+1|\cdot|j2+2|} = \frac{1}{\sqrt{5} \cdot 2\sqrt{2}} \approx 0.1581
$$
输出强迫响应振幅：$10 \times 0.1581 \approx 1.581$，恰等于 $\sqrt{(-0.5)^2+(-1.5)^2} \approx 1.581$。

**相频特性**：相位滞后为两向量角度之和的负值：  
$$
\phi = -(63.43^\circ + 45^\circ) = -108.43^\circ
$$
与强迫响应 $1.581\sin(2t - 108.43^\circ)$ 相吻合。

> **核心结论**：正弦输入下，稳态响应的幅值增益和相位滞后完全由 $s=j\omega$ 处极点向量的几何特征决定——这是频域分析法的几何基础。

## 7. 易错点与注意事项

| 易错/易混点 | 正确理解 |
| --- | --- |
| 傅里叶变换 vs 拉普拉斯变换 | 傅里叶是拉氏在 $\sigma=0$ 的特例；拉氏可处理更广泛的信号 |
| 单边变换默认假设 | 工程中默认 $t<0$ 时 $f(t)=0$（已乘 $u(t)$） |
| 微分性质中的初值 | $\mathcal{L}\{f'\} = sF(s) - f(0^+)$，**减号**且需用 $0^+$ 时刻值 |
| 部分分式展开：复极点 | 保留二次因式 $\frac{Cs+D}{s^2+\omega^2}$ 形式，不要拆成一次复指数；注意正弦项的系数匹配（$\frac{\omega}{s^2+\omega^2}$） |
| 收敛域 | 收敛域不包含极点；因果信号 ROC 在最右侧极点右侧；同一 $F(s)$ 配合不同 ROC 对应不同时域函数 |
| 初值代算 | 经典解法代入初始条件时，必须同时满足位移和速度两个初值条件 |

## 8. 一页速记

**傅里叶 → 拉普拉斯**：乘 $e^{-\sigma t}$ 驯服发散函数  

**定义**：
$$
F(s) = \int_{0^-}^{\infty} f(t) e^{-st} dt,\quad s = \sigma + j\omega
$$

**核心性质**：

- 线性：$\mathcal{L}\{af+bg\} = aF + bG$
- 微分：$\mathcal{L}\{f'\} = sF - f(0^+)$
- 积分：$\mathcal{L}\{\int f\} = F/s$
- 频移：$\mathcal{L}\{e^{-at}f\} = F(s+a)$

**常用变换对**：

- $u(t) \leftrightarrow 1/s$
- $e^{-at} \leftrightarrow 1/(s+a)$
- $\sin(\omega t) \leftrightarrow \omega/(s^2+\omega^2)$
- $\cos(\omega t) \leftrightarrow s/(s^2+\omega^2)$

**解微分方程四步**：

1. 两边取拉氏变换 → 代数方程
2. 代入初值
3. 解出 $X(s) = N(s)/D(s)$
4. 部分分式 + 查表 → $x(t)$

**响应分解**：全响应 = 自由响应（极点决定）+ 强迫响应（输入频率决定）  
**收敛域**：因果信号 $\operatorname{Re}(s) > \max\{\text{极点实部}\}$；系统稳定 ⇔ 所有极点位于左半平面  
**频域几何**：$|H(j\omega)| = \prod \frac{1}{|j\omega - p_i|}$，$\angle H(j\omega) = -\sum \angle(j\omega - p_i)$

**记忆口诀**：  
“傅里叶怕增长，拉氏乘衰减；  
微分变乘法，初值别漏减；  
极点定响应，收敛看右边；  
解方程四步走，查表最省力。”
