# 08 神经网络结构与工作原理

## 本章定位

前面已经认识了感知机和神经网络的基本概念。本章进一步说明多层网络如何组织参数、数据如何在层与层之间传递、PyTorch 中全连接层的维度如何理解，以及分类模型的输出为什么通常叫 logits。

## 从感知机到多层网络

单个感知机只能输出一个数。多个感知机并排组成一层，就能输出一个向量。多层这样的结构串联起来，就形成神经网络。

```text
输入向量
-> 第 1 个全连接层
-> 激活函数
-> 第 2 个全连接层
-> 激活函数
-> 输出层
```

每一层都做两件事：

1. 线性变换：重新组合上一层特征。
2. 非线性激活：增强表达能力。

## 批量输入的形状

深度学习训练通常不是一次处理一个样本，而是一次处理一个 batch。对于表格数据，输入张量常见形状为：

```text
batch_size × input_dim
```

例如鸢尾花项目中，每个样本有 4 个特征，若 `batch_size=16`，输入形状就是：

```text
16 × 4
```

模型会并行处理这 16 个样本，输出形状为：

```text
16 × 3
```

其中 3 表示三个鸢尾花类别的得分。

## 全连接层的数学形式

一层全连接网络可以写成：

$$
\boldsymbol{Y} = \boldsymbol{X}\boldsymbol{W}^{T} + \boldsymbol{b}
$$

其中：

- $\boldsymbol{X}$：输入，形状为 `(batch_size, in_features)`。
- $\boldsymbol{W}$：权重，形状为 `(out_features, in_features)`。
- $\boldsymbol{b}$：偏置，形状为 `(out_features,)`。
- $\boldsymbol{Y}$：输出，形状为 `(batch_size, out_features)`。

PyTorch 中：

```python
layer = nn.Linear(in_features=4, out_features=12)
```

表示输入维度为 4，输出维度为 12。若输入是 `(16, 4)`，输出就是 `(16, 12)`。

## 为什么权重形状是反的

很多初学者以为 `nn.Linear(4, 12)` 的权重形状应是 `(4, 12)`，但 PyTorch 中实际是：

```text
12 × 4
```

原因是 PyTorch 的前向计算写作：

$$
\boldsymbol{Y} = \boldsymbol{X}\boldsymbol{W}^{T} + \boldsymbol{b}
$$

当 $\boldsymbol{X}$ 形状是 `(16, 4)`，$\boldsymbol{W}^{T}$ 形状是 `(4, 12)`，矩阵乘法后输出 `(16, 12)`。

因此排查维度错误时，最重要的是检查：

```text
上一层 out_features == 下一层 in_features
```

## 前向传播示例

以鸢尾花分类网络为例：

```python
import torch.nn as nn


class IrisNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(4, 12),
            nn.ReLU(),
            nn.Linear(12, 6),
            nn.ReLU(),
            nn.Linear(6, 3),
        )

    def forward(self, x):
        return self.net(x)
```

如果输入形状为 `(16, 4)`，每层形状变化为：

```text
(16, 4)
-> Linear(4, 12)
-> (16, 12)
-> ReLU
-> (16, 12)
-> Linear(12, 6)
-> (16, 6)
-> ReLU
-> (16, 6)
-> Linear(6, 3)
-> (16, 3)
```

ReLU 不改变张量形状，只改变数值。

## 输出层与 logits

分类模型的最后一层通常输出 logits，也就是未归一化的类别得分。对于三分类任务，模型输出可能是：

```text
[2.1, -0.3, 0.8]
```

这三个数还不是概率，但数值越大表示模型越倾向该类别。推理时可以直接取最大值索引：

```python
pred = logits.argmax(dim=1)
```

训练时如果使用 `nn.CrossEntropyLoss`，不要在模型最后手动加 `Softmax`。因为 `CrossEntropyLoss` 内部已经包含 `LogSoftmax + NLLLoss` 的组合，直接传 logits 更稳定。

## 参数、超参数与可学习参数

需要区分：

- **参数**：模型训练中自动学习的数值，如权重和偏置。
- **超参数**：训练前人为设定的配置，如学习率、隐藏层节点数、batch size、epoch 数。
- **可学习参数**：`requires_grad=True` 且会被优化器更新的参数。

在 PyTorch 中查看参数：

```python
for name, param in model.named_parameters():
    print(name, param.shape, param.requires_grad)
```

这对理解模型结构和排查参数是否参与训练很有帮助。

## 训练和推理时的模式

PyTorch 模型有两种常用模式：

```python
model.train()
model.eval()
```

`model.train()` 用于训练阶段，`model.eval()` 用于验证和推理阶段。对于只含 `Linear` 和 `ReLU` 的简单 MLP，两者表现差别不明显；但如果模型包含 Dropout、BatchNorm 等层，模式切换会直接影响输出。

验证和推理时还应关闭梯度：

```python
model.eval()
with torch.inference_mode():
    logits = model(x)
```

这样可以减少内存占用，避免不必要的计算图构建。

## 本章速记

- 神经网络按 batch 并行处理样本。
- `nn.Linear(in_features, out_features)` 的输出维度是 `out_features`。
- PyTorch 的 Linear 权重形状是 `(out_features, in_features)`。
- 分类模型通常输出 logits，训练时直接交给 `CrossEntropyLoss`。
- 训练用 `model.train()`，验证/推理用 `model.eval()` 并关闭梯度。
