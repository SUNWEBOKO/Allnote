# 04 深度学习架构与生命周期

## 深度学习项目的生命周期

一个完整的深度学习项目包含四个核心阶段：建模（Modeling）、训练（Training）、验证（Validation）和测试推理（Test/Inference）。这四个阶段构成一个循环迭代的流程，贯穿从任务设计到模型部署的全过程。

### 建模（Modeling）

建模是深度学习生命周期的第一个阶段。其核心任务是根据当前项目的具体需求，选择或设计一个合适的网络架构。深度学习模型本质上都是基于神经网络的算法，而神经网络算法具有多种变体，每种变体适用于不同的任务场景和数据类型。建模阶段定义的是"我们用什么结构去解决问题"，是整个项目的骨架。

常见的神经网络变体及其典型应用场景如下表所示：

| 算法 | 主要应用领域 | 典型任务 |
|------|-------------|---------|
| 卷积神经网络（CNN） | 计算机视觉 | 图片识别、图片分割、目标检测、目标追踪、图片生成 |
| 循环神经网络（RNN） | 自然语言处理（NLP） | 文本处理、序列建模 |
| 自编码器（Autoencoder） | 生成模型 | 图片生成、信号生成、文本生成 |
| Transformer | NLP / 多模态 | 文本问答、机器翻译、图文理解 |
| 生成对抗网络（GAN） | 生成模型 | AI换脸、风格迁移、虚拟人物生成 |
| 图神经网络（GNN） | 图数据 | 社交网络分析、蛋白质分子互作网络特征提取 |
| 扩散模型（Diffusion Model） | 生成模型 | 图片生成、AI虚拟人物生成 |
| 深度强化学习（Deep RL） | 决策与交互 | 游戏AI、机器人控制 |

卷积神经网络（CNN）主要处理图片类数据，其应用覆盖了计算机视觉领域的大部分方向，包括图像分类、分割、检测和生成等。循环神经网络（RNN）则专注于文本领域的序列建模任务。自编码器和生成对抗网络都属于生成模型，前者可生成图片、信号和文本，后者在AI换脸和虚拟人物生成方面有广泛应用。

Transformer最初起源于NLP领域，但其强大的特征提取能力使其近年扩展至多模态任务，许多大规模语言模型（如ChatGPT）的底层均由多个Transformer模块堆叠而成。图神经网络处理的是图结构数据（如社交网络中个体之间的关系、蛋白质分子的相互作用网络），通过在图数据上提取特征来完成节点分类、链接预测等任务。

扩散模型是近年兴起的生成模型方向，其生成的图像质量在逼真度上有显著突破。深度强化学习则是将神经网络与强化学习结合，适用于需要智能体与环境交互并获得激励或惩罚的决策类问题，例如训练游戏Agent自主完成闯关任务。

### 训练（Training）

训练阶段的目标是使用数据来更新模型内部的参数（权重），使模型的预测能力不断提升。在深度学习中，最常见的训练方式是有监督训练。

有监督训练的过程可以用"考试"来类比：模型就是考生，训练数据就是带有标准答案的考卷。模型对自己的答案（预测值）与标准答案（真值，ground truth）进行比较，根据差距来调整自己的知识（参数），使下一次的预测更准确。在有监督学习中，每条训练数据都包含输入和对应的标签，标签通常是人工标注的。例如在目标检测任务中，标注人员会在图片上用框标出物体的位置和类别，这些标注信息就是模型学习的"标准答案"。

具体而言，训练开始时模型的参数 $\theta$ 是随机初始化的，因此此时的预测结果非常不准确。通过定义损失函数来衡量预测值 $\hat{y}$ 与真值 $y$ 之间的差距，可以将"让模型更准"的目标转化为"最小化损失函数"的数学问题。最基本的损失函数之一是均方误差（MSE）：

$$
\mathcal{L} = \frac{1}{2}(\hat{y} - y)^2
$$

这里的 $\frac{1}{2}$ 系数是为了后续求导时消去平方项产生的 2，使梯度表达式 $\frac{\partial \mathcal{L}}{\partial \hat{y}} = \hat{y} - y$ 更加简洁。它不影响优化方向，因为常数倍缩放不改变函数的极小值位置。

为了最小化损失函数，需要使用梯度下降算法（Gradient Descent）来更新参数。梯度是偏导数的集合，对于一个函数在某一点的梯度方向是函数值增长最快的方向。为了找到损失函数的极小值，需要沿着梯度的反方向更新参数。更新公式为：

$$
\theta_{\text{new}} = \theta_{\text{old}} - \eta \cdot \nabla \mathcal{J}(\theta)
$$

其中 $\theta_{\text{old}}$ 是当前时刻的参数，$\theta_{\text{new}}$ 是更新后的参数，$\eta$ 是学习率（learning rate），$\nabla \mathcal{J}(\theta)$ 是损失函数对参数的梯度。学习率控制参数更新的步长：学习率过大可能导致参数跳过最优值，学习率过小则收敛速度慢。整个训练过程是一个迭代循环：计算预测值 → 计算损失 → 求梯度 → 更新参数 → 重复上述步骤，直到模型的预测精度达到满意水平。

除了有监督训练，还有无监督训练和半监督训练。无监督训练的特点是无需人工标注标签，标签可以从数据本身构造。以完形填空任务为例：从一句文本中抠掉部分单词，将剩余文本送入模型，要求模型预测被抠掉的单词，而被抠掉的单词本身就是天然的标签。这种方式在大语言模型（如BERT、GPT）的预训练中被广泛使用。半监督训练介于两者之间，同时使用少量有标签数据和大量无标签数据。一种常用的方法是伪标签法：先用少量有标签数据训练一个模型，再用该模型对无标签数据进行预测，将预测结果作为伪标签，然后合并所有数据重新训练，从而提升模型性能。

训练阶段有一个关键原则：深度学习是数据驱动的算法。对于同一模型，数据量越大、质量越高，最终能达到的性能就越好。数据是深度学习训练的"血液"，是一切性能提升的基础。

### 验证（Validation）

验证阶段使用一个独立的数据集——验证集（validation set）——来评估模型在训练过程中的表现。验证集必须是从未在训练阶段使用过的数据，这样才能真实反映模型对未知数据的泛化能力。这就像日常学习中的周考、月考、期中期末考试，目的是检验当前的学习水平，判断学习方法是否有效。

验证的主要目的是防止过拟合（overfitting）。过拟合是指模型在训练集上表现很好，但在新数据上泛化能力差的不良现象。通过观察验证集上的准确率变化趋势，可以判断模型是否开始过拟合，从而及时调整训练策略（如提前停止训练、调整正则化参数等）。同时，验证集的结果也可以用于模型超参数的调优。

### 测试推理（Test / Inference）

测试阶段是在模型训练全部完成后，使用测试集（test set）对模型进行最终的性能评估。测试集同样必须是模型从未见过的数据，且在整个训练和调参过程中都不能使用。类比来说，验证集是平时的月考和期中考试，而测试集就是高考——只能做一次，且结果最具权威性。

测试通过后，模型进入推理阶段。推理（inference），也被称为前向传播（forward propagation）或模型预测，指的是将训练好的模型部署到真实场景中，输入新数据并获得预测结果。在推理阶段，模型的参数已固定（不再更新），只用于计算输出。模型可以部署在不同的硬件终端上，如服务器、个人电脑、移动设备甚至嵌入式设备。

推理阶段主要关注两个核心指标：推理速度（延迟）和预测准确度。在实际工程项目中，往往需要根据部署环境对模型结构进行压缩或加速优化，以在速度和精度之间取得平衡。

### 验证与测试的评判指标

验证集和测试集使用相似的评判指标，具体选择取决于任务类型是分类问题还是回归问题。

分类问题的评估不能仅看预测是否正确，还需要区分不同类型的错误——正类被误判为负类、负类被误判为正类，这两者的代价往往不同。例如在医疗诊断中，漏诊（假阴性）的代价通常远大于误诊（假阳性）。混淆矩阵（confusion matrix）正是对这四种组合情况的系统统计：

|  | 预测为正类 | 预测为负类 |
|--|-----------|-----------|
| 真实为正类 | TP（真阳性） | FN（假阴性） |
| 真实为负类 | FP（假阳性） | TN（真阴性） |

基于混淆矩阵可以衍生出以下关键指标：

- **准确率（Accuracy）**：模型预测正确的结果占总样本的比例，即 $\frac{TP + TN}{TP + TN + FP + FN}$。
- **精准率（Precision）**，又称查准率：模型预测为正类且实际也为正类的比例，即 $\frac{TP}{TP + FP}$。
- **召回率（Recall）**，又称查全率：实际为正类且被模型正确预测的比例，即 $\frac{TP}{TP + FN}$。

在实际应用中，仅凭准确率一个指标可能产生误导。例如在一个正负样本极不平衡的数据集（100个病人中仅10人患病）中，一个"永远预测为没病"的傻瓜模型也能达到90%的准确率，但其精准率和召回率均为0。因此需要综合多个指标来判断模型的实际性能。

此外，ROC曲线（Receiver Operating Characteristic curve）和AUC（Area Under the Curve）也是分类问题中常用的评价工具。ROC曲线以假阳率（FPR，即 $\frac{FP}{FP + TN}$）为横轴、真阳率（TPR，即 $\frac{TP}{TP + FN}$）为纵轴绘制，AUC表示曲线下方的面积。AUC越大，模型性能越好。

对于回归问题，常用的评价指标包括均方误差（MSE）和均方根误差（RMSE）。MSE的公式即为前述的损失函数形式 $\frac{1}{N}\sum(\hat{y} - y)^2$，RMSE则在其基础上开根号。这些指标的值越小，说明模型的预测值与真实值越接近，模型性能越好。

### 四个阶段的循环与迭代

深度学习的生命周期并不是单向的线性流程。在实际项目中，验证结果往往会反馈到建模和训练阶段：如果验证集表现不佳，可能需要调整网络结构、修改超参数、增加数据量或使用正则化手段，然后重新训练和验证，直到测试结果满足预期。这种迭代循环是深度学习工程实践中的常态。
