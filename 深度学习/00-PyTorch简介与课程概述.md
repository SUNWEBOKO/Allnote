# 00 PyTorch简介与课程概述

## PyTorch框架简介

PyTorch是一个由Facebook（现Meta）于2017年1月发布的开源深度学习框架。它的核心设计理念是将深度学习领域中常见的功能和算法，以类或函数的形式进行封装。开发者在使用这些功能时，无需从底层手动实现，只需调用框架内对应的封装接口即可完成功能搭建，从而大幅提升编程效率。

与 TensorFlow 相比，PyTorch 采用动态计算图机制——每次前向传播都重新构建计算图，可以在运行时动态修改网络结构，调试时能直接打印中间张量的值。这让 PyTorch 在研究场景中更受青睐，学术论文的代码实现绝大多数都基于 PyTorch。TensorFlow 默认使用静态图（先建图后执行），在工业部署方面有一定优势，但调试和灵活性不如 PyTorch。此外 PyTorch 还配套了丰富的生态库：`torchvision`（图像）、`torchaudio`（音频）、`torchtext`（文本）和 `transformers`（大模型），覆盖了深度学习主要应用领域的常用数据集和预训练模型。

## PyTorch版本发展历程

### PyTorch 1.0

PyTorch 1.0于2018年12月发布，是一次重大的版本更迭。它同时保留了PyTorch之前版本的灵活性和Caffe框架的生产效率，在动态图的易用性和静态图的高性能之间取得了平衡。

### PyTorch 2.0

PyTorch 2.0是在1.0发布四年之后（2023年3月）推出的又一个重大版本更新。相比前代版本，2.0具有三个核心特点。

**更快的训练速度。** 随着深度学习模型规模不断扩大、训练数据量日益增长，一个模型的训练周期可能长达数周甚至数月。PyTorch 2.0在训练速度上的显著提升，对于加速大型模型的开发迭代和项目推进非常有帮助。

**更强的可用性。** PyTorch 2.0提供了多种版本以适应不同硬件环境，包括CPU版本、GPU版本、分布式训练版本等。无论用户的个人计算机配置高端、配置一般，还是较为老旧甚至没有独立显卡，都能够安装和部署PyTorch框架进行深度学习的开发和学习。

**百分之百向下兼容。** 这是PyTorch 2.0最重要的设计原则之一。无论用户是刚入门PyTorch的新手，还是已经使用该框架一段时间的开发者，都可以放心地将PyTorch版本升级到2.0，而无需担心版本更迭导致原有功能不可用或已有项目无法运行。

## 课程内容概览

本教程定位为PyTorch 2.0的快速入门指南，面向零基础的深度学习初学者，全程通过 Anaconda + Jupyter Notebook / VS Code 完成环境搭建和代码编写。课程的主要内容包括三个部分。

### 第一部分：环境配置

首先讲解PyTorch 2.0的开发环境搭建。这一部分包含如何使用Anaconda管理Python环境，以及如何使用Jupyter Notebook和VS Code等主流IDE进行代码编写。同时，还会讲解PyTorch 2.0不同版本（CPU版、GPU版等）的安装方法。

### 第二部分：神经网络基础

神经网络是深度学习的基石。本部分将从理论基础出发，讲解神经网络的核心概念，包括感知机、神经网络的层级结构以及神经网络如何进行特征提取等。更重要的是，会使用PyTorch实际搭建一个神经网络模型，将理论与代码实践相结合。

### 第三部分：鸢尾花分类实战项目

本部分带领大家使用PyTorch 2.0完整实现一个鸢尾花识别项目，涵盖以下完整流程：

- 自定义数据集的加载
- 网络模型的搭建
- 模型训练
- 模型验证

**关于数据集加载的特别说明。** 许多入门教程倾向于推荐使用PyTorch封装好的函数进行数据集加载，但这要求数据集必须符合特定的规则和格式。而在实际项目中，手头的数据集往往不符合这些预设格式，无法直接使用封装好的接口。本教程的一个特色在于，会教大家如何实现自定义数据集的加载，使学员具备处理真实项目数据的能力。

### 项目背景简介

鸢尾花分类是一个经典的机器学习入门项目。数据集中每行样本的前四列代表鸢尾花的四种特征：花萼宽度、花萼长度、花瓣宽度、花瓣长度。花萼是鸢尾花上半部分较细长的组织，花瓣则是下方较圆的部分。根据这四个特征，可以对鸢尾花的种类进行分类。课程会设计一个神经网络，接收这四种特征作为输入，输出对应类别的预测结果。

通过从头到尾完成这个项目，学员可以深入理解PyTorch在深度学习中所扮演的角色和发挥的作用，即使完全零基础，也能在学完后自主完成一些简单的深度学习项目。
