# 00 PyTorch 简介与课程概述

## 本章定位

本章先建立学习 PyTorch 前的整体认识：PyTorch 是什么、为什么适合深度学习入门、这套课程会按什么路线展开，以及最后的鸢尾花分类项目要解决什么问题。

学完本章后，应能回答三个问题：

- PyTorch 在深度学习项目中负责哪些工作。
- PyTorch 与传统手写算法、TensorFlow 等框架的差异在哪里。
- 后续课程如何从环境配置过渡到神经网络理论和完整项目实践。

## PyTorch 是什么

PyTorch 是 Meta 维护的开源深度学习框架。它把深度学习中常见的底层能力封装成稳定的 API，例如张量运算、自动求导、神经网络层、损失函数、优化器、数据加载器和 GPU 加速。学习者不需要从零实现矩阵求导、反向传播和参数更新，就能把主要精力放在模型结构、数据处理和训练流程上。

可以把 PyTorch 理解为深度学习工程中的“基础设施”：

- `torch.Tensor` 负责表示和计算数据。
- `torch.autograd` 负责自动计算梯度。
- `torch.nn` 负责搭建神经网络层和损失函数。
- `torch.optim` 负责封装参数更新算法。
- `torch.utils.data` 负责数据集和批量加载。
- `torchvision`、`torchaudio` 等生态库负责常见领域的数据集、模型和预处理工具。

## PyTorch 的核心优势

### 动态计算图

PyTorch 采用动态计算图机制。每次前向传播时，框架都会根据实际执行的 Python 代码即时构建计算图。这样做的直接好处是调试直观：可以像普通 Python 程序一样打印中间变量、打断点、改分支逻辑。

对初学者来说，这比先声明整张图再运行的静态图模式更容易理解。对研究者来说，动态计算图也更适合快速尝试新结构和新训练策略。

### 与 Python 生态贴合

PyTorch 的写法接近普通 Python。模型通常继承 `nn.Module`，数据集通常继承 `Dataset`，训练循环就是清晰的 `for epoch`、`for batch`。这种风格降低了从 Python 基础过渡到深度学习工程的门槛。

### 研究与工程兼顾

PyTorch 早期以研究灵活性著称，后来在部署、编译优化、分布式训练和生产服务方面也不断增强。PyTorch 2.x 引入了 `torch.compile` 等能力，在尽量保持原有代码写法的前提下提升训练和推理性能。

## PyTorch 版本理解

学习时不必死记具体小版本号，重点理解版本选择原则：

- 优先安装官网推荐的 Stable 稳定版。
- 新项目优先使用 Python 与 PyTorch 当前稳定版本兼容的组合。
- 已有项目以项目说明中的版本为准，避免随意升级破坏环境。
- CPU 与 GPU 版本的差异主要在计算后端，不改变大多数 PyTorch 代码写法。

PyTorch 2.x 相比 1.x 的核心变化，是在保持大部分 API 兼容的同时增强性能优化能力。课程中的基础代码不依赖复杂新特性，因此只要安装的是 PyTorch 2.x 稳定版，基本都能顺利运行。

## 课程路线

本课程按“环境 -> 理论 -> 代码 -> 项目”的顺序推进。

### 第一部分：环境配置

先完成 Anaconda、PyTorch、Jupyter Notebook / VS Code 的安装与配置。环境部分的目标不是追求复杂，而是建立一个可重复、可切换、可验证的开发环境，避免后续代码运行时被版本和解释器问题卡住。

### 第二部分：神经网络基础

随后进入神经网络理论，包括感知机、全连接层、激活函数、前向传播、损失函数、反向传播、梯度下降和卷积神经网络。理论部分会尽量围绕“数据如何变成预测结果”“参数如何被训练出来”这两条主线展开。

### 第三部分：PyTorch 训练流程

在理解基本原理后，开始使用 PyTorch 搭建模型、定义损失函数、选择优化器、编写训练循环，并学习 `Dataset` 与 `DataLoader` 如何把原始数据组织成模型可以使用的批量数据。

### 第四部分：鸢尾花分类实战

最后用 Iris 鸢尾花数据集完成一个端到端分类项目。项目会覆盖：

- 读取 CSV 数据。
- 将文本标签转换为数字标签。
- 特征标准化。
- 自定义 `Dataset`。
- 划分训练集、验证集和测试集。
- 搭建多层感知机分类模型。
- 编写训练、验证、测试流程。
- 保存和加载模型权重。

## 鸢尾花项目背景

Iris 数据集共有 150 条样本，包含三种鸢尾花，每条样本有 4 个数值特征：

- 花萼长度。
- 花萼宽度。
- 花瓣长度。
- 花瓣宽度。

模型的任务是根据这 4 个特征预测花属于哪一类。这个项目规模小、结构完整，很适合作为 PyTorch 入门项目：它不会被庞大的数据处理淹没，又能完整呈现深度学习项目从数据到模型再到评估的基本链路。

## 本章速记

- PyTorch 的核心价值是封装张量计算、自动求导、网络层、优化器和数据加载。
- 动态计算图让 PyTorch 更容易调试，也更适合入门和研究。
- 学习 PyTorch 不只是记 API，更重要的是理解训练链路：数据 -> 模型 -> 损失 -> 梯度 -> 参数更新 -> 评估。
- 鸢尾花项目会作为贯穿后续实践的最小完整案例。
