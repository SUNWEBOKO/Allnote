## 使用 `nn.Module` 构建神经网络模型

### 模型类的定义与继承

在 PyTorch 中，自定义神经网络模型需要继承 `torch.nn.Module` 这个基类。`nn.Module` 封装了网络层管理、参数注册、前向传播调度等核心功能，所有自定义网络都应通过继承它来获得这些能力。

```python
class IrisNet(nn.Module):
    def __init__(self, in_dim, h1_dim, h2_dim, out_dim):
        super(IrisNet, self).__init__()
        self.layer1 = nn.Linear(in_dim, h1_dim)
        self.layer2 = nn.Linear(h1_dim, h2_dim)
        self.layer3 = nn.Linear(h2_dim, out_dim)

    def forward(self, x):
        x = self.layer1(x)
        x = self.layer2(x)
        x = self.layer3(x)
        return x
```

### `__init__` 方法：定义网络层级结构

`__init__` 是类的初始化方法，在创建模型实例时自动调用。它接收四个参数：

- `in_dim`：输入特征维度，即每条数据包含的特征数量。对于鸢尾花数据集，每个样本有 4 个特征（花萼长度、花萼宽度、花瓣长度、花瓣宽度），因此传入 4。
- `h1_dim` 和 `h2_dim`：两个隐藏层的节点数量，是超参数，可根据任务复杂度自由设定。
- `out_dim`：输出维度，即分类的类别数。鸢尾花数据集有 3 个品种，因此传入 3。

在 `__init__` 内部，首先调用 `super().__init__()` 执行父类的构造方法，这是 PyTorch 正确注册网络参数的固定写法，必须保留。随后使用 `nn.Linear` 定义三个全连接层，分别命名为 `layer1`、`layer2` 和 `layer3`。

### `nn.Linear` 全连接层

`nn.Linear(in_features, out_features)` 是 PyTorch 中最基础的网络层，实现了一个线性变换：

$$y = xW^T + b$$

其中 $W$ 是权重矩阵，$b$ 是偏置向量。`in_features` 指定输入特征的数量，`out_features` 指定输出特征的数量。`nn.Linear` 内部会自动创建并管理这两个可训练参数。

在本模型中，第一层从 `in_dim` 个输入特征映射到 `h1_dim` 个隐藏节点；第二层从 `h1_dim` 映射到 `h2_dim`；第三层从 `h2_dim` 映射到 `out_dim` 个输出节点。维度必须层层匹配：前一层的输出特征数必须等于后一层的输入特征数，否则前向传播时会产生维度不匹配的错误。

### `forward` 方法：定义前向传播逻辑

`forward` 方法定义了数据从输入到输出的计算流程。当调用模型实例（如 `model(x)`）时，PyTorch 会自动执行 `forward` 中的代码。该方法接收一个参数 `x`，代表输入数据张量。

数据的前向传播顺序为：输入 $x$ 先经过第一层全连接层得到中间结果，该结果作为第二层的输入，同理依次传递至第三层，最后将第三层的输出作为模型的最终预测结果返回。每层的输出覆盖变量 `x`，通过链式传递完成整个计算图。

当前这个简单的网络在隐藏层之后没有添加激活函数，因此每一层都是纯粹的线性变换。三个线性层堆叠在数学上等价于一个单层的线性变换：

$$
y = \boldsymbol{W}_3(\boldsymbol{W}_2(\boldsymbol{W}_1 x + \boldsymbol{b}_1) + \boldsymbol{b}_2) + \boldsymbol{b}_3
= (\boldsymbol{W}_3 \boldsymbol{W}_2 \boldsymbol{W}_1) x + (\boldsymbol{W}_3 \boldsymbol{W}_2 \boldsymbol{b}_1 + \boldsymbol{W}_3 \boldsymbol{b}_2 + \boldsymbol{b}_3)
$$

无论堆叠多少线性层，最终结果仍然是输入 $x$ 的一个线性函数，表达能力与单层网络没有区别。在实际应用中，必须在隐藏层后面加入非线性激活函数（如 ReLU）来打破这种线性等价，否则深层网络的表达能力不会超过单层。

## 计算环境（设备）设置

模型训练可以在 CPU 或 GPU 上进行。PyTorch 通过 `torch.device` 来统一管理计算设备。使用 `torch.cuda.is_available()` 可以检测当前机器是否安装了可用的 GPU（NVIDIA CUDA 设备）。该函数返回布尔值 `True` 或 `False`。

利用 Python 的三目运算符，可以一行代码完成设备选择：若 CUDA 可用，则使用 `"cuda"`，否则使用 `"cpu"`。这样无论用户的硬件环境如何，代码都能自动适配并正常运行。

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
```

定义好 `device` 后，后续的模型和数据都需要通过 `.to(device)` 方法移动到指定设备上，确保所有计算在同一个设备中完成。

## 数据集的加载与划分

### 加载自定义数据集

首先实例化之前定义好的自定义数据集类，传入数据文件的路径，将 CSV 文件中的数据加载为 PyTorch 的 `Dataset` 对象。

```python
custom_dataset = IrisDataset(data_path="./data/iris.csv")
```

### 统计与按比例划分

加载完成后，通过 `len(custom_dataset)` 获取数据总条数。为了评估模型性能，需要将原始数据集划分为训练集、验证集和测试集三个部分。

划分比例通常为：训练集占 70%，验证集占 20%，测试集占 10%。具体做法是先计算出训练集和验证集的样本数量，剩余的作为测试集。

```python
total_len = len(custom_dataset)
train_size = int(total_len * 0.7)
val_size = int(total_len * 0.2)
test_size = total_len - train_size - val_size
```

使用 `int()` 取整确保样本数为整数，测试集的大小则直接从总数中减去前两者得到，避免因取整导致的数据丢失。

### `random_split` 随机切分

PyTorch 的 `torch.utils.data.random_split` 提供了现成的随机切分功能。它接收两个参数：原始数据集和一个包含各子集大小的列表（或元组），返回切分后的多个子数据集。该函数内部会随机打乱索引并按照指定大小分配，确保划分的随机性。

```python
from torch.utils.data import random_split

train_dataset, val_dataset, test_dataset = random_split(
    custom_dataset, [train_size, val_size, test_size]
)
```

`random_split` 返回的是 `Subset` 对象，可以直接传递给 `DataLoader` 进行后续的批量加载。

## 使用 `DataLoader` 进行批量封装

### 批量的概念与 `batch_size`

训练神经网络时，通常不会一次性将所有数据送入模型。当数据集规模很大时，全量数据同时计算会导致显存或内存溢出（Out of Memory）。因此需要将数据划分为多个小批次（mini-batch），每次只用一个批次的数据进行前向传播和梯度更新。

`batch_size` 就是每个批次包含的样本数量。本项目中训练集的 `batch_size` 设为 16，即每次从中随机抽取 16 个样本进行训练。

### `shuffle` 参数

`DataLoader` 的 `shuffle` 参数控制是否在每个 epoch（训练轮次）开始时打乱数据顺序。设为 `True` 时，模型在每轮训练中看到的批次数据顺序都不同，这有助于提高模型的泛化能力，防止对数据顺序产生依赖。若设为 `False`，则每次按固定顺序取数据。

```python
train_loader = DataLoader(train_dataset, batch_size=16, shuffle=True)
```

验证集和测试集不需要参与训练，也无需打乱顺序。验证时可以逐条进行更细致的评估，因此其 `batch_size` 通常设为 1，`shuffle` 设为 `False`。

```python
val_loader = DataLoader(val_dataset, batch_size=1, shuffle=False)
test_loader = DataLoader(test_dataset, batch_size=1, shuffle=False)
```

通过 `DataLoader` 封装后，可以直接用 `for batch in train_loader` 的方式逐个批次地获取数据和标签，大大简化了训练循环的编写。

## 训练集、验证集与测试集的概念

训练集（Training Set）相当于日常学习和练习题，模型用它来学习数据中的规律并更新参数。验证集（Validation Set）相当于周考或月考，用于在训练过程中评估模型性能、调整超参数，可以在训练过程中多次使用。测试集（Test Set）相当于高考，用于最终评估模型的真实泛化能力，整个项目生命周期中只应使用一次。

验证集和测试集的共同点是都能反映模型在当前数据上的性能表现，但测试集更具权威性，因为模型从未接触过测试集中的样本，而验证集的结果可能在反复调参过程中被间接"泄露"到模型选择中。
