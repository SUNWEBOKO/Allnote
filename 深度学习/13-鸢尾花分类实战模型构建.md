# 13 鸢尾花分类实战：模型构建

## 本章定位

数据加载完成后，需要搭建一个能接收 4 维特征、输出 3 类得分的神经网络。本章完成模型类、设备选择、数据集划分和 `DataLoader` 封装，为下一章训练脚本做准备。

## 导入依赖

```python
import torch

```

其中：

## 模型输入与输出

鸢尾花分类任务的维度非常清楚：

- 输入维度：4，对应 4 个花朵特征。
- 输出维度：3，对应 3 个鸢尾花类别。

模型输出的是 logits，形状为：

```text
batch_size × 3
```

每一行代表一个样本在 3 个类别上的得分。训练时直接把 logits 传给 `nn.CrossEntropyLoss`。

## 模型结构

使用一个小型多层感知机：

```text
4 -> 12 -> ReLU -> 6 -> ReLU -> 3
```

这个结构对 Iris 这类小数据集已经足够。隐藏层太大反而容易过拟合。

建议把以下代码保存为 `model.py`：

```python
import torch.nn as nn


class IrisNet(nn.Module):
    def __init__(self, input_dim=4, hidden1_dim=12, hidden2_dim=6, output_dim=3):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden1_dim),
            nn.ReLU(),
            nn.Linear(hidden1_dim, hidden2_dim),
            nn.ReLU(),
            nn.Linear(hidden2_dim, output_dim),
        )

    def forward(self, x):
        return self.net(x)
```

## 为什么隐藏层要加 ReLU

如果只堆叠多个 `Linear` 层，中间没有激活函数，整个网络仍然等价于一个线性层，表达能力不会真正增强。

加入 ReLU 后：

$$
\text{ReLU}(x)=\max(0,x)
$$

网络获得非线性表达能力，可以学习更复杂的决策边界。

输出层后面不加 ReLU，也不加 Softmax。原因是：

- 输出层需要保留每个类别的原始得分。
- `CrossEntropyLoss` 内部会处理 softmax 相关计算。
- 推理时直接 `argmax(dim=1)` 取最高得分类别即可。

## 数据集划分

加载完整数据集：

```python
dataset = IrisDataset("./data/iris.csv")
```

按 70% / 20% / 10% 划分训练集、验证集、测试集：

```python
total_len = len(dataset)
train_size = int(total_len * 0.7)
val_size = int(total_len * 0.2)
test_size = total_len - train_size - val_size
```

对于 Iris 的 150 条样本，结果是：

```text
训练集 105
验证集 30
测试集 15
```

使用固定随机种子，让每次划分可复现：

```python
generator = torch.Generator().manual_seed(42)

train_dataset, val_dataset, test_dataset = random_split(
    dataset,
    [train_size, val_size, test_size],
    generator=generator,
)
```

`random_split` 返回的是 `Subset`，它内部保存了原始数据集和对应索引。

## 关于标准化

为了避免数据泄漏，标准化不能在完整数据集上直接计算均值和标准差。正确顺序是：

```text
先划分数据集
-> 只用训练集计算 mean/std
-> 同一组 mean/std 应用于训练、验证、测试
```

下一章训练脚本会用 `train_dataset.indices` 从原始数据集中取出训练特征，计算标准化参数。

## DataLoader 封装

```python
train_loader = DataLoader(train_dataset, batch_size=16, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=32, shuffle=False)
test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)
```

说明：

- 训练集需要 `shuffle=True`，每个 epoch 打乱顺序。
- 验证集和测试集不需要打乱。
- 验证/测试可以使用更大的 batch，因为不需要反向传播。
- Windows 入门阶段可先不设置 `num_workers`，默认 `0` 最稳定。

## 本章速记

- Iris 模型输入维度是 4，输出维度是 3。
- 隐藏层后加 ReLU，输出层后不加 Softmax。
- `random_split` 可配合固定随机种子复现划分。
- 标准化应在划分后只用训练集统计量。
- 训练集 `shuffle=True`，验证/测试 `shuffle=False`。
