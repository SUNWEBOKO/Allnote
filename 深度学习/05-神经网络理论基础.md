# 05 神经网络理论基础

## 为什么需要神经网络

在传统的机器学习方法中，处理图像识别、自然语言处理等复杂任务时存在明显的局限性。以图像分类为例，传统方法需要人工设计特征提取器（如边缘检测、纹理分析等），再将这些特征输入分类器。这种方式不仅依赖领域专家的经验，而且泛化能力有限——针对某一类图像设计的特征，往往无法迁移到其他任务中。

神经网络的提出不依赖人工预设的特征规则，而是通过端到端的学习方式，自动从原始数据中逐层提取出从低级到高级的特征表达。这种数据驱动的特征学习能力，使神经网络成为深度学习时代最核心的算法基础。

## 神经网络的核心思想

神经网络的设计灵感来源于生物神经系统。人脑中有约 $10^{11}$ 个神经元，它们通过突触相互连接，构成一个庞大的信息处理网络。每个神经元接收来自其他神经元的电信号，当累积的信号强度超过某一阈值时，该神经元被激活并向下传递信号。

神经网络的计算方式模仿了这一机制。在网络中，**输入层**负责接收原始数据（如图像的像素值、文本的词向量），**输出层**输出最终的计算结果，而中间的**隐藏层**则负责将输入数据逐层变换，提取出对任务有用的特征。数据从输入层流向输出层的整个过程称为**前向传播**（forward propagation）。

## 神经网络的三层结构

一个典型的神经网络由三层基本结构组成：

- **输入层**（input layer）：网络的第一层，负责接收数据或特征。输入层的节点数通常等于数据特征的维度。
- **隐藏层**（hidden layer）：输入层和输出层之间的所有层。隐藏层对输入数据进行线性变换和非线性激活，提取出更高层级的抽象特征。
- **输出层**（output layer）：网络的最后一层，输出计算结果。输出层的节点数和激活函数根据具体任务决定（如分类任务用 Softmax，回归任务用线性激活）。

隐藏层的层数和每层的节点数都是**超参数**，可以由开发者手动设定。一个神经网络可以只包含一层隐藏层（称为浅层网络），也可以包含几十层、上百层甚至上千层隐藏层。隐藏层越多，网络能表达的函数空间越大，理论上可以逼近任意复杂的函数。

## 深度学习与神经网络的关系

深度学习与神经网络本质上属于同一类算法。所谓"深度"（deep），指的是神经网络的隐藏层数量很多。当隐藏层数达到成百上千层时，这样的复杂神经网络就被称为**深度学习模型**。

深度学习模型的核心优势在于其分层特征提取能力。浅层网络往往只能学到简单的特征模式，而深层网络可以通过逐层组合低级特征来形成高度抽象的表示。例如在图像任务中，第一层隐藏层可能学习到边缘和角点，中间层组合出纹理和形状，深层则能够识别出物体部件甚至完整物体。

## 神经网络的变体算法

基于神经网络的基本结构，衍生出了大量针对特定任务设计的变体算法。以下是几种常见的深度学习模型：

- **卷积神经网络（CNN）**：专为图像数据设计，通过卷积核在空间上共享参数，大幅减少了参数量，擅长提取图像的局部特征。
- **循环神经网络（RNN）**：适合处理序列数据（如文本、时间序列），通过循环连接保留历史信息，能够建模数据的时序依赖关系。
- **生成对抗网络（GAN）**：由生成器和判别器两个网络组成，通过对抗训练学习数据的分布，主要用于图像生成等任务。
- **自编码器（Autoencoder）**：通过编码器-解码器结构学习数据的压缩表示，常用于降维、去噪和生成任务。
- **Transformer**：基于自注意力机制（self-attention），彻底抛弃了循环结构，擅长并行处理序列数据。当前大语言模型（如 ChatGPT）的底层即由多层 Transformer 堆叠而成。
- **图神经网络（GNN）**：用于处理图结构数据（如社交网络、蛋白质互作网络），通过消息传递机制聚合邻居节点信息。

这些变体算法都建立在神经网络的基本框架之上，因此统称为深度学习模型。

## 神经元与感知机

要理解神经网络如何对数据进行处理，需要深入到其最基本的计算单元——**神经元**（neuron），也叫**节点**（node）。每个节点本质上是一个**感知机模型**（perceptron）。

一个感知机接收多个输入 $x_1, x_2, \dots, x_n$，每个输入对应一个权重 $w_1, w_2, \dots, w_n$，加上一个偏置 $b$，经过加权求和后再通过激活函数得到输出：

$$
z = \sum_{i=1}^{n} w_i x_i + b
$$
$$
a = f(z)
$$

其中 $f$ 是激活函数（如 Sigmoid、ReLU、Tanh 等）。激活函数的引入使得神经网络具备了非线性表达能力——如果没有激活函数，多层线性变换的堆叠本质上仍然等价于单层线性变换。原因可以从矩阵乘法看出：三层线性层 $y = \boldsymbol{W}_3(\boldsymbol{W}_2(\boldsymbol{W}_1 \boldsymbol{x} + \boldsymbol{b}_1) + \boldsymbol{b}_2) + \boldsymbol{b}_3$ 可以合并为 $y = (\boldsymbol{W}_3 \boldsymbol{W}_2 \boldsymbol{W}_1) \boldsymbol{x} + (\boldsymbol{W}_3 \boldsymbol{W}_2 \boldsymbol{b}_1 + \boldsymbol{W}_3 \boldsymbol{b}_2 + \boldsymbol{b}_3)$，即一个新的线性变换。无论堆叠多少层，表达能力都和单层一样。激活函数通过在每个线性层之间引入非线性截断（如 ReLU 将负数置零），打破了这种等价性，使深层网络的表达能力远超单层。

多个感知机按层组织并连接起来，就构成了完整的神经网络。通过反向传播算法（backpropagation），网络可以逐层计算损失函数对每个权重和偏置的梯度，进而利用梯度下降法更新参数，最终使模型从数据中学习到有效的特征表达和映射关系。

## PyTorch 对神经网络的封装

PyTorch 提供了 `torch.nn` 模块来简化神经网络的构建。开发者只需定义网络层结构和前向传播逻辑，PyTorch 会自动处理权重初始化、梯度计算和参数更新等底层细节。

一个典型的多层感知机（MLP）在 PyTorch 中的实现如下：

```python
import torch
import torch.nn as nn

class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 256)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(256, 128)
        self.fc3 = nn.Linear(128, 10)

    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        x = self.relu(x)
        x = self.fc3(x)
        return x
```

`nn.Linear` 对应全连接层，其内部封装了权重矩阵 $W$ 和偏置向量 $b$，前向计算等价于 $y = xW^T + b$。`nn.ReLU` 是激活函数 $f(x) = \max(0, x)$。通过继承 `nn.Module` 并实现 `forward` 方法，PyTorch 能够自动利用反向传播计算梯度，开发者无需手动推导导数公式。

这种高度封装的 API 设计，使从理论到实践的转换变得直观高效，也是 PyTorch 适合入门的重要原因。
