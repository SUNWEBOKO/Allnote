# 05 神经网络理论基础

## 本章定位

神经网络是深度学习的基本模型。它的核心思想并不神秘：把输入数据经过一层层可学习的线性变换和非线性变换，最终得到预测结果。本章建立神经网络的基本概念，为后续感知机、前向传播、反向传播和 PyTorch 模型实现做准备。

## 为什么需要神经网络

传统机器学习往往依赖人工特征。以图像分类为例，过去常需要人为设计边缘、纹理、颜色直方图等特征，再把这些特征输入分类器。问题是人工特征强依赖经验，对任务变化不够适应。

神经网络的优势在于**自动学习特征表示**。它可以直接从原始数据或低级特征出发，通过多层变换逐步提取更有用的表示：

```text
原始输入 -> 低级特征 -> 中级组合 -> 高级语义 -> 预测结果
```

在图像中，浅层可能学习边缘和角点，中层可能学习纹理和局部形状，深层可能学习物体部件甚至完整类别特征。这种分层表示能力，是深度学习有效的关键原因。

## 神经网络的基本结构

一个典型前馈神经网络由三类层组成：

- **输入层**：接收数据。节点数等于输入特征维度。
- **隐藏层**：执行主要计算。可以有一层或多层。
- **输出层**：产生最终结果。输出维度由任务决定。

例如鸢尾花分类中，每个样本有 4 个特征，类别数为 3。一个简单网络可以写成：

```text
输入层 4 维 -> 隐藏层 12 维 -> 隐藏层 6 维 -> 输出层 3 维
```

输出层的 3 个值通常不是直接概率，而是每个类别的得分（logits）。训练时可直接送入 `nn.CrossEntropyLoss`，推理时取最大得分类别作为预测结果。

## 神经元：最小计算单元

神经网络中的一个节点可以看作一个神经元。它接收多个输入，对输入做加权求和，加上偏置，再经过激活函数：

$$
z = \sum_{i=1}^{n} w_i x_i + b
$$

$$
a = f(z)
$$

其中：

- $x_i$ 是第 $i$ 个输入特征。
- $w_i$ 是该特征对应的权重。
- $b$ 是偏置。
- $z$ 是线性组合结果。
- $f$ 是激活函数。
- $a$ 是神经元输出。

权重决定“哪些特征重要”，偏置决定“整体判断门槛”，激活函数决定“是否引入非线性”。

## 线性层与矩阵表示

实际神经网络不会一个节点一个节点地手动计算，而是用矩阵一次性表示整层计算。设输入为 $\boldsymbol{x}$，权重矩阵为 $\boldsymbol{W}$，偏置为 $\boldsymbol{b}$，则一层全连接网络可以写为：

$$
\boldsymbol{z} = \boldsymbol{x}\boldsymbol{W}^{T} + \boldsymbol{b}
$$

$$
\boldsymbol{a} = f(\boldsymbol{z})
$$

PyTorch 中的 `nn.Linear(in_features, out_features)` 正是对这个计算的封装。它内部维护权重和偏置，训练时自动更新。

## 激活函数为什么必要

如果没有激活函数，多层线性层堆叠仍然等价于一层线性层。例如：

$$
\boldsymbol{y}
= \boldsymbol{W}_2(\boldsymbol{W}_1\boldsymbol{x} + \boldsymbol{b}_1) + \boldsymbol{b}_2
= (\boldsymbol{W}_2\boldsymbol{W}_1)\boldsymbol{x} + (\boldsymbol{W}_2\boldsymbol{b}_1 + \boldsymbol{b}_2)
$$

这仍然是 $\boldsymbol{x}$ 的线性函数。也就是说，不加非线性时，网络再深也只是一个线性模型，无法表达复杂决策边界。

常见激活函数包括：

| 激活函数 | 公式 | 特点 |
|---|---|---|
| Sigmoid | $\sigma(x)=\frac{1}{1+e^{-x}}$ | 输出在 0 到 1，早期常用，深层网络中易梯度消失 |
| Tanh | $\tanh(x)$ | 输出在 -1 到 1，零中心，但仍可能梯度消失 |
| ReLU | $\max(0,x)$ | 简单高效，现代网络常用 |
| Leaky ReLU | $x>0$ 时为 $x$，否则为 $\alpha x$ | 缓解 ReLU 负半轴恒为 0 的问题 |

入门项目中最常用 ReLU。

## 深度学习与神经网络的关系

深度学习通常指使用多层神经网络进行表示学习。这里的“深度”主要指网络层数较多，而不是某个固定层数阈值。

浅层网络也能做很多任务，但深层网络有更强的层级表示能力。它可以把简单特征逐步组合成复杂特征，在图像、语音、文本和多模态任务中表现尤其突出。

## 常见神经网络变体

神经网络的基本思想可以适配不同数据结构，由此形成多种模型：

- **MLP**：多层感知机，适合表格数据和低维特征。
- **CNN**：卷积神经网络，适合图像和局部空间结构。
- **RNN/LSTM/GRU**：循环网络，适合序列数据。
- **Transformer**：基于自注意力，适合文本、图像和多模态任务。
- **Autoencoder**：编码器-解码器结构，适合降维、去噪和异常检测。
- **GAN / Diffusion**：生成模型，适合图像、音频、视频等生成任务。
- **GNN**：图神经网络，适合社交网络、分子结构等图数据。

它们的底层都离不开“参数化函数 + 损失函数 + 梯度优化”这一训练框架。

## PyTorch 中的神经网络

在 PyTorch 中，自定义神经网络通常继承 `nn.Module`：

```python
import torch
import torch.nn as nn


class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(784, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 10),
        )

    def forward(self, x):
        return self.net(x)
```

关键点：

- 网络层要在 `__init__` 中定义，这样 PyTorch 才能注册参数。
- 前向传播逻辑写在 `forward` 中。
- 调用 `model(x)` 时，PyTorch 会自动执行 `forward`。
- 反向传播时，PyTorch 会根据计算图自动计算可训练参数的梯度。

## 本章速记

- 神经网络通过多层变换自动学习特征。
- 单个神经元的核心计算是加权求和、加偏置、过激活函数。
- 激活函数是非线性表达能力的来源。
- `nn.Linear` 封装全连接层，`nn.Module` 封装模型结构。
- 输出层的维度由任务决定：分类看类别数，回归看目标维度。
