# 12 鸢尾花分类实战：数据加载

## 本章定位

从本章开始进入鸢尾花分类项目。第一步是把原始 CSV 数据读成 PyTorch 能训练的张量，并封装为 `Dataset`。这一章重点修正数据加载链路中的几个关键细节：特征只能取前 4 列，标签要映射为一维整数类别，`__getitem__` 应直接返回张量而不是 Python 列表。

## Iris 数据集结构

Iris 数据集包含 150 条样本，三种类别各 50 条：

- `Iris-setosa`
- `Iris-versicolor`
- `Iris-virginica`

每条样本有 4 个数值特征：

| 列 | 含义 |
|---|---|
| 0 | 花萼长度 |
| 1 | 花萼宽度 |
| 2 | 花瓣长度 |
| 3 | 花瓣宽度 |
| 4 | 类别标签 |

模型输入应该是前 4 列，标签应该是第 5 列。不要把标签列误读进特征，否则模型输入维度会从 4 变成 5，后续网络结构和任务定义都会错。

## 自定义 Dataset 的职责

PyTorch 的 `Dataset` 负责定义“如何根据索引拿到一个样本”。自定义数据集通常完成：

- 检查数据文件是否存在。
- 读取 CSV。
- 将文本标签映射为数字类别。
- 将特征转为 `float32` 张量。
- 将标签转为 `int64` 一维张量。
- 实现 `__len__` 和 `__getitem__`。

标准化建议放在数据划分之后，用训练集统计量完成，避免验证集和测试集信息泄漏到训练过程。本章的 `Dataset` 只负责读取原始数值特征。

```python

```

说明：

- `Path` 用于处理文件路径。
- `pandas` 用于读取 CSV。
- `torch` 用于构造张量。
- `Dataset` 是自定义数据集基类。

## 标签映射

神经网络不能直接处理字符串标签，需要把三种花名映射为整数：

```python
LABEL_TO_INDEX = {
    "Iris-setosa": 0,
    "Iris-versicolor": 1,
    "Iris-virginica": 2,
}
```

对于多分类任务，`nn.CrossEntropyLoss` 要求标签是类别编号，而不是 one-hot 向量。因此标签应是：

```text
0 / 1 / 2
```

张量形状应为：

```text
(样本数,)
```

而不是：

```text
(样本数, 1)
```

## 完整 Dataset 实现

建议把以下代码保存为 `data_loader.py`：

```python
from pathlib import Path

import pandas as pd
import torch
from torch.utils.data import Dataset


class IrisDataset(Dataset):
    label_to_index = {
        "Iris-setosa": 0,
        "Iris-versicolor": 1,
        "Iris-virginica": 2,
    }

    feature_columns = [
        "sepal_length",
        "sepal_width",
        "petal_length",
        "petal_width",
    ]

    def __init__(self, data_path):
        self.data_path = Path(data_path)
        if not self.data_path.exists():
            raise FileNotFoundError(f"数据集路径不存在: {self.data_path}")

        df = pd.read_csv(
            self.data_path,
            header=None,
            names=[*self.feature_columns, "label"],
        )

        features = df[self.feature_columns].to_numpy(dtype="float32")
        labels = df["label"].map(self.label_to_index)

        if labels.isna().any():
            unknown_labels = sorted(df.loc[labels.isna(), "label"].unique())
            raise ValueError(f"发现未知标签: {unknown_labels}")

        self.features = torch.from_numpy(features)
        self.labels = torch.tensor(labels.to_numpy(dtype="int64"))

    def __len__(self):
        return len(self.labels)

    def __getitem__(self, index):
        return self.features[index], self.labels[index]
```

## 代码关键点

### 路径检查

```python
self.data_path = Path(data_path)
if not self.data_path.exists():
    raise FileNotFoundError(f"数据集路径不存在: {self.data_path}")
```

如果路径错误，直接抛出清晰异常，比后面让 `pandas` 报复杂错误更容易定位问题。

### 只读取前 4 列作为特征

```python
features = df[self.feature_columns].to_numpy(dtype="float32")
```

这里明确选择 4 个特征列，避免把 `label` 列混入输入。最终 `self.features` 的形状应是：

```text
(150, 4)
```

### 标签是一维 int64

```python
self.labels = torch.tensor(labels.to_numpy(dtype="int64"))
```

最终 `self.labels` 的形状应是：

```text
(150,)
```

这正好匹配 `CrossEntropyLoss` 的要求。

### `__getitem__` 返回张量

```python
return self.features[index], self.labels[index]
```

不要把样本转成 `list`。`DataLoader` 会自动把多个样本堆叠成 batch 张量，保持张量格式更稳定。

## 配合 DataLoader 使用

```python
from torch.utils.data import DataLoader

from data_loader import IrisDataset


dataset = IrisDataset("./data/iris.csv")
loader = DataLoader(dataset, batch_size=16, shuffle=True)

for features, labels in loader:
    print(features.shape)
    print(labels.shape)
    break
```

期望形状：

```text
torch.Size([16, 4])
torch.Size([16])
```

这说明一个 batch 中有 16 条样本，每条样本 4 个特征，标签是一维类别编号。

## 标准化放在哪里

神经网络通常喜欢尺度相近的输入特征。鸢尾花的 4 个特征都以厘米为单位，但数值范围仍有差异，标准化有助于训练稳定。

严格做法是：

1. 先划分训练集、验证集、测试集。
2. 只用训练集计算均值和标准差。
3. 用训练集的均值和标准差变换训练、验证、测试数据。

不要用全量数据计算均值和标准差，否则验证集和测试集的统计信息会泄漏到训练过程。

标准化会在训练脚本中完成，本章 Dataset 只负责原始数据读取。

## 本章速记

- Iris 模型输入是前 4 列特征，标签是第 5 列。
- 标签要从字符串映射为 `0/1/2`。
- `CrossEntropyLoss` 需要一维 `int64` 标签。
- `Dataset.__getitem__` 返回单个样本张量和标签张量。
- 标准化应在划分数据集后，用训练集统计量完成。
