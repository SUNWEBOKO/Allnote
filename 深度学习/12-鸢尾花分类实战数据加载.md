# 12 鸢尾花分类实战数据加载

## Iris 数据集简介

Iris（鸢尾花）数据集是机器学习领域最经典的入门数据集之一。该数据集包含三种鸢尾花：Setosa、Versicolour 和 Virginica，每种花各有 50 个样本，共计 150 个样本。每个样本由四个特征描述：花萼长度、花萼宽度、花瓣长度、花瓣宽度。标签为花的种类名称，属于多分类问题。神经网络的任务就是根据这四个特征预测花朵的类别。

## 自定义数据集加载的实现步骤

在 PyTorch 中，自定义数据集需要编写一个继承自 `torch.utils.data.Dataset` 的类，并重写三个核心方法：`__init__`、`__len__` 和 `__getitem__`。这是 PyTorch 的强制规定，`DataLoader` 在后续批量加载数据时会依赖这些方法。

### 导入依赖

首先导入所需的库：`torch` 用于张量操作和神经网络构建，`os` 用于文件路径的判断，`pandas` 用于读取 CSV 格式的数据集，`numpy` 用于数值计算和数据转换。

```python
import torch
import os
import pandas as pd
import numpy as np
```

### 继承 Dataset 类

新建一个类（例如 `IrisDataLoader`），继承自 `torch.utils.data.Dataset`。在这个类中必须实现三个函数：`__init__` 用于初始化数据集路径并完成数据加载，`__len__` 用于返回数据集大小，`__getitem__` 用于根据索引返回一个样本及其对应标签。

```python
from torch.utils.data import Dataset

class IrisDataset(Dataset):
    def __init__(self, data_path):
        super().__init__()
        ...
    
    def __len__(self):
        ...
    
    def __getitem__(self, index):
        ...
```

### __init__ 方法：加载与预处理

`__init__` 接受一个参数 `data_path`（数据集的存储路径），将其保存为成员变量 `self.data_path`。使用 `os.path.exists()` 检查路径是否存在，若不存在则抛出异常提示用户。

通过 `pd.read_csv()` 读取 CSV 文件。由于原始数据没有列名，需手动为五列数据指定名称，用 0 到 4 的整数作为列名。前四列为特征，最后一列为标签（花朵名称）。

```python
def __init__(self, data_path):
    self.data_path = data_path
    if not os.path.exists(self.data_path):
        raise FileNotFoundError(f"数据集路径不存在: {self.data_path}")
    
    df = pd.read_csv(self.data_path, names=[0, 1, 2, 3, 4])
```

标签是文字形式的花朵名称，神经网络只能处理数值，因此需要定义文字类别到数值的映射关系。定义一个字典，将三种花名分别映射为 0、1、2。然后使用 pandas 的 `map` 方法，按照字典规则将最后一列的文本全部替换为对应的数值。

```python
    label_mapping = {'Iris-setosa': 0, 'Iris-versicolor': 1, 'Iris-virginica': 2}
    df[4] = df[4].map(label_mapping)
```

接下来从 DataFrame 中分离特征和标签。特征为前四列（索引 0 到 4），标签为最后一列（索引 4 到末尾）。使用 `df.loc[]` 进行行列切片，第一个参数为行范围（`:` 表示所有行），第二个参数为列范围。

```python
    data = df.loc[:, :4].values
    label = df.loc[:, 4:].values
```

pandas 的 DataFrame 类型不能直接被 PyTorch 使用，需要先转为 numpy 数组，再转为 PyTorch 的 Tensor。特征使用 float32 类型，标签使用 int64 类型。在转换之前，可以对特征做 Z-score 归一化（减去均值除以标准差），使数据分布服从均值为 0、方差为 1 的标准正态分布，这有利于提升神经网络训练中的数值稳定性和收敛性能。

```python
    data = (data - np.mean(data, axis=0)) / np.std(data, axis=0)
    self.data = torch.from_numpy(data.astype(np.float32))
    self.label = torch.from_numpy(label.astype(np.int64))
```

最后统计样本数量，可以直接通过标签的长度得到，保存为 `self.data_number`。

```python
    self.data_number = len(self.label)
    print(f"当前数据集的大小: {self.data_number}")
```

### __len__ 方法：返回数据集大小

`__len__` 方法只需返回 `self.data_number`，即数据集的样本总数。PyTorch 在通过 `DataLoader` 迭代数据时需要知道这个长度，以便按 batch 大小对数据进行封装和分发。

```python
def __len__(self):
    return self.data_number
```

### __getitem__ 方法：按索引获取样本

`__getitem__` 接收一个 `index` 参数，用于定位具体某个样本。`self.data[index]` 和 `self.label[index]` 返回的是对应索引位置的一个样本，通过 `list()` 转换为 Python 列表后返回。返回的数据和标签通过同一个 index 一一对应。

```python
def __getitem__(self, index):
    data = list(self.data[index])
    label = list(self.label[index])
    return data, label
```

### 完整代码

综合以上步骤，完整的自定义数据集加载类如下：

```python
import torch
import os
import pandas as pd
import numpy as np
from torch.utils.data import Dataset

class IrisDataset(Dataset):
    def __init__(self, data_path):
        self.data_path = data_path
        if not os.path.exists(self.data_path):
            raise FileNotFoundError(f"数据集路径不存在: {self.data_path}")
        
        df = pd.read_csv(self.data_path, names=[0, 1, 2, 3, 4])
        
        label_mapping = {'Iris-setosa': 0, 'Iris-versicolor': 1, 'Iris-virginica': 2}
        df[4] = df[4].map(label_mapping)
        
        data = df.loc[:, :4].values
        label = df.loc[:, 4:].values
        
        data = (data - np.mean(data, axis=0)) / np.std(data, axis=0)
        self.data = torch.from_numpy(data.astype(np.float32))
        self.label = torch.from_numpy(label.astype(np.int64))
        
        self.data_number = len(self.label)
        print(f"当前数据集的大小: {self.data_number}")
    
    def __len__(self):
        return self.data_number
    
    def __getitem__(self, index):
        data = list(self.data[index])
        label = list(self.label[index])
        return data, label
```

## 数据集划分：训练集与测试集

在训练神经网络之前，需要将数据集划分为训练集和测试集。训练集用于模型参数的学习，测试集用于评估模型在未见数据上的泛化能力。Iris 数据集共 150 个样本，通常按 7:3 或 8:2 的比例划分。划分时需要注意保持各类别样本的均衡，避免某一类在训练集或测试集中占比过大。

划分操作可以在 `__init__` 中完成，也可以在外部通过索引切片实现。一种常见的做法是在 `__init__` 中新增一个 `train` 参数，根据该参数决定加载训练集还是测试集，并将对应的数据和标签保存为成员变量。

## PyTorch 的 Dataset 与 DataLoader 配合使用

自定义的 `Dataset` 类完成后，需要配合 `DataLoader` 才能高效地批量加载数据。`DataLoader` 接收一个 `Dataset` 对象，并通过设置 `batch_size`、`shuffle` 等参数控制数据加载方式。

```python
from torch.utils.data import DataLoader

dataset = IrisDataset("iris.data")
train_loader = DataLoader(dataset, batch_size=16, shuffle=True)
```

使用 `DataLoader` 后，每次迭代会返回一个 batch 的数据和标签，模型按 batch 进行前向传播和反向传播。`shuffle=True` 会在每个 epoch 开始前打乱数据顺序，防止模型学到数据排列中的虚假模式。
