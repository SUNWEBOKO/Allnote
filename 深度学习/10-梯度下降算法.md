# 10 梯度下降算法

## 本章定位

梯度下降是神经网络训练的核心优化思想。损失函数告诉我们“当前模型错得多严重”，梯度告诉我们“参数应该往哪个方向改”。本章解释梯度、学习率、参数更新公式，以及常见优化器之间的区别。

## 梯度是什么

对于多元函数 $f(x_1,x_2,\dots,x_n)$，梯度是所有偏导数组成的向量：

$$
\nabla f =
\left(
\frac{\partial f}{\partial x_1},
\frac{\partial f}{\partial x_2},
\dots,
\frac{\partial f}{\partial x_n}
\right)
$$

梯度方向是函数值增长最快的方向。若要让函数值下降，应沿梯度的反方向移动。

在训练神经网络时，函数就是损失函数，变量就是模型所有参数。

## 梯度下降公式

参数更新公式为：

$$
\theta_{t+1} = \theta_t - \eta \nabla_{\theta}\mathcal{L}(\theta_t)
$$

其中：

- $\theta_t$：第 $t$ 次更新前的参数。
- $\theta_{t+1}$：更新后的参数。
- $\eta$：学习率。
- $\mathcal{L}$：损失函数。
- $\nabla_{\theta}\mathcal{L}$：损失对参数的梯度。

负号表示沿梯度反方向更新，从而使损失下降。

对于单个权重和偏置：

$$
w_{t+1}=w_t-\eta\frac{\partial\mathcal{L}}{\partial w_t}
$$

$$
b_{t+1}=b_t-\eta\frac{\partial\mathcal{L}}{\partial b_t}
$$

## 学习率的作用

学习率 $\eta$ 控制每次参数更新的步长。

学习率过大：

- 更新步子太大。
- 可能越过最优区域。
- 损失可能震荡甚至发散。

学习率过小：

- 更新非常慢。
- 训练时间长。
- 可能长时间停在低效区域。

实际训练中，学习率通常是最重要的超参数之一。常见经验范围是 $10^{-1}$ 到 $10^{-5}$，但最终仍要根据模型、数据和优化器调试。

## 三种梯度下降形式

### 批量梯度下降 BGD

每次用全部训练样本计算梯度：

```text
全部训练集 -> 一个梯度 -> 更新一次参数
```

优点是梯度稳定；缺点是数据量大时计算慢、内存占用高。

### 随机梯度下降 SGD

每次只用一个样本计算梯度：

```text
一个样本 -> 一个梯度 -> 更新一次参数
```

优点是更新快、带有随机性；缺点是梯度噪声大，训练曲线波动明显。

### 小批量梯度下降 Mini-batch GD

每次用一个 batch 计算梯度：

```text
一小批样本 -> 一个平均梯度 -> 更新一次参数
```

这是深度学习中最常用的方式。它兼顾计算效率、梯度稳定性和 GPU 并行能力。

PyTorch 的 `DataLoader(batch_size=...)` 配合训练循环，默认就是 mini-batch 训练。

## SGD 与 Adam

PyTorch 中常用优化器包括：

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
```

和：

```python
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
```

SGD 直接按梯度方向更新，概念简单，常用于需要精细调参的场景。Adam 会根据梯度的一阶矩和二阶矩自适应调整每个参数的步长，通常收敛更快，入门项目更容易获得稳定结果。

鸢尾花分类这类小项目中，SGD 和 Adam 都可以使用；课程中使用 Adam 更省调参。

## 梯度下降的训练链路

一次 mini-batch 更新包含：

```text
取 batch
-> 前向传播
-> 计算损失
-> 反向传播得到梯度
-> 优化器更新参数
```

PyTorch 代码结构：

```python
optimizer.zero_grad(set_to_none=True)
outputs = model(inputs)
loss = loss_fn(outputs, labels)
loss.backward()
optimizer.step()
```

其中 `loss.backward()` 负责求梯度，`optimizer.step()` 负责更新参数。

## 常见训练现象

### 损失持续下降

说明模型正在学习，训练基本正常。还需要看验证集表现，确认不是只记住训练集。

### 损失不下降

可能原因：

- 学习率太小。
- 模型结构过弱。
- 数据或标签有问题。
- 特征尺度差异过大，未标准化。
- 损失函数和输出格式不匹配。

### 损失变成 NaN

可能原因：

- 学习率过大。
- 输入数据存在 NaN 或 Inf。
- 数值不稳定。
- 除以 0 或取非法对数。

### 训练准确率高、验证准确率低

通常是过拟合。可尝试减少模型复杂度、增加数据、正则化、早停或数据增强。

## 本章速记

- 梯度指向函数增长最快方向，梯度下降沿反方向更新参数。
- 学习率决定每次更新步长。
- 深度学习实际最常用 mini-batch 梯度下降。
- `loss.backward()` 计算梯度，`optimizer.step()` 更新参数。
- Adam 更省调参，SGD 更基础但常需要细调学习率。
