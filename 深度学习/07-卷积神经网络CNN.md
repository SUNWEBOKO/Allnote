# 07 卷积神经网络 CNN

## 本章定位

卷积神经网络（Convolutional Neural Network, CNN）是处理图像数据的经典模型。它利用图像的局部相关性，通过卷积核在空间上滑动来提取特征，避免了全连接网络直接处理图像时参数量过大的问题。本章重点理解卷积、通道、步长、填充、池化、打平和感受野。

## 为什么图像任务需要 CNN

如果把一张 $224\times224\times3$ 的彩色图像直接打平成向量，输入维度就是 150528。若接一个 1000 节点的全连接层，仅权重就有：

$$
150528 \times 1000 = 150{,}528{,}000
$$

参数量巨大，训练成本高，也不符合图像本身的结构。

图像有两个重要性质：

- **局部相关性**：相邻像素共同形成边缘、纹理、角点等局部特征。
- **平移稳定性**：同一个特征出现在图像不同位置时，仍应被识别。

CNN 通过局部连接和权值共享利用这两个性质。

## CNN 的典型结构

一个简单 CNN 图像分类流程为：

```text
输入图像
-> 卷积层
-> 激活函数
-> 池化层
-> 多次重复卷积/激活/池化
-> 打平 Flatten
-> 全连接层
-> 输出类别得分
```

卷积和池化负责提取图像特征，全连接层负责根据这些特征完成分类。

## 卷积核与局部计算

卷积核（kernel/filter）是一个小矩阵，例如 $3\times3$、$5\times5$。它在图像上滑动，每到一个位置，就与覆盖区域做对应元素相乘并求和：

$$
o = \sum_{i=1}^{k_h}\sum_{j=1}^{k_w} w_{ij}x_{ij} + b
$$

其中 $w_{ij}$ 是卷积核参数，$x_{ij}$ 是输入局部区域像素或特征值，$b$ 是偏置。

卷积核中的参数不是人工指定的固定模板，而是在训练中学习出来的。浅层卷积核可能学习边缘、角点、颜色变化；深层卷积核可能响应更复杂的局部结构。

## 滑动窗口与特征图

卷积核从图像左上角开始，按设定步长滑动，依次计算输出值。所有输出值按空间位置排列，形成一张特征图（feature map）。

一张特征图表示“某一种卷积核在图像各位置检测到的响应强度”。响应越大，说明该位置越符合这个卷积核学习到的特征模式。

## 输出尺寸公式

设输入尺寸为 $H\times W$，卷积核大小为 $K_h\times K_w$，填充为 $P_h,P_w$，步长为 $S_h,S_w$，则输出尺寸为：

$$
H_{\text{out}} =
\left\lfloor
\frac{H + 2P_h - K_h}{S_h}
\right\rfloor + 1
$$

$$
W_{\text{out}} =
\left\lfloor
\frac{W + 2P_w - K_w}{S_w}
\right\rfloor + 1
$$

在 PyTorch 中，`nn.Conv2d` 会按这个公式计算输出高宽。调试 CNN 维度时，这个公式非常常用。

## 填充 Padding

填充是在输入边缘补像素，最常见的是零填充。

填充有两个作用：

- 减少边缘信息损失，让边缘像素也能被更多次参与计算。
- 控制输出特征图尺寸。

例如输入大小不变、卷积核为 $3\times3$、步长为 1 时，设置 `padding=1` 可以让输出高宽与输入高宽一致。

## 步长 Stride

步长表示卷积核每次移动多少个像素。步长越大，输出特征图越小，计算量也越低。

常见选择：

- `stride=1`：细致扫描，保留更多空间信息。
- `stride=2`：同时完成特征提取和下采样。

如果步长过大，可能跳过重要局部信息。

## 权值共享

同一个卷积核在整张图像上滑动时，使用的是同一组参数。这就是权值共享。

权值共享带来两个好处：

- 参数量大幅减少。
- 同一种特征无论出现在图像哪个位置，都能被同一个卷积核识别。

与全连接层相比，CNN 不需要为每个空间位置单独学习一套参数。

## 多通道输入

彩色图像通常有 3 个通道：RGB。卷积核也必须覆盖输入的所有通道。

对于输入形状：

```text
C_in × H × W
```

一个卷积核的形状是：

```text
C_in × K_h × K_w
```

它会对所有输入通道分别卷积，再把结果相加，输出一张特征图。

如果使用 $C_{\text{out}}$ 个卷积核，就会得到 $C_{\text{out}}$ 张特征图。因此 `nn.Conv2d` 的输出通道数等于卷积核个数。

PyTorch 中：

```python
nn.Conv2d(in_channels=3, out_channels=64, kernel_size=3, padding=1)
```

表示输入有 3 个通道，输出 64 个通道，也就是学习 64 个不同卷积核。

## 池化层

池化（pooling）用于压缩特征图尺寸，保留主要信息。常见方式：

- **最大池化**：取窗口内最大值。
- **平均池化**：取窗口内平均值。

最大池化常用于保留最强特征响应。例如卷积已经检测到某个局部边缘，最大池化会保留该区域最显著的响应，同时降低空间分辨率。

示例：

```python
nn.MaxPool2d(kernel_size=2, stride=2)
```

这会把高宽各缩小约一半。

## 感受野

感受野（receptive field）指某一层的一个输出位置能对应到原始输入中的多大区域。

浅层卷积的感受野小，看到的是边缘、角点等低级特征；深层卷积经过多层堆叠后，感受野变大，能组合出更高层语义。

这就是 CNN 的层级特征提取：

```text
边缘/角点 -> 纹理/局部形状 -> 部件 -> 类别语义
```

## 打平 Flatten

卷积阶段输出通常是三维特征图：

```text
通道数 × 高 × 宽
```

全连接层需要二维输入：

```text
batch_size × 特征维度
```

因此需要打平：

```python
x = torch.flatten(x, start_dim=1)
```

`start_dim=1` 表示保留 batch 维度，只把每个样本的通道、高、宽展平成一个向量。

## PyTorch 中的简单 CNN

```python
import torch
import torch.nn as nn


class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),
            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(32 * 8 * 8, 128),
            nn.ReLU(),
            nn.Linear(128, 10),
        )

    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x
```

如果输入图像是 `3×32×32`，两次 `2×2` 最大池化后高宽变为 `8×8`，所以全连接层输入维度是 `32 * 8 * 8`。

## 本章速记

- CNN 适合图像，因为图像具有局部相关性和平移稳定性。
- 卷积核局部滑动，输出特征图。
- 多个卷积核产生多个输出通道。
- Padding 控制边缘和输出尺寸，Stride 控制滑动步幅。
- Pooling 压缩空间尺寸，Flatten 连接卷积特征和全连接分类器。
- 调试 CNN 时重点看张量形状：`batch × channel × height × width`。
