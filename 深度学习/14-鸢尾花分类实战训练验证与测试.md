## 本章定位

本章把前面完成的数据加载和模型构建串成完整训练脚本。目标是得到一条清晰、可复现、无数据泄漏的 PyTorch 训练链路：

```text
读取数据 -> 划分数据集 -> 用训练集统计量标准化 -> 训练 -> 验证 -> 保存最佳权重 -> 测试
```

## 固定随机种子

Iris 数据集很小，随机划分和随机初始化都会影响结果。为了让实验尽量可复现，先固定随机种子：

```python
def set_seed(seed=42):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    if torch.cuda.is_available():
        torch.cuda.manual_seed_all(seed)
```

固定随机种子不能保证所有 GPU 运算完全一致，但足以让入门项目的结果更稳定。

## 构建数据加载器

先加载原始数据，再划分训练集、验证集和测试集：

```python
def build_dataloaders(data_path, batch_size=16, seed=42):
    dataset = IrisDataset(data_path)

    total_len = len(dataset)
    train_size = int(total_len * 0.7)
    val_size = int(total_len * 0.2)
    test_size = total_len - train_size - val_size

    generator = torch.Generator().manual_seed(seed)
    train_dataset, val_dataset, test_dataset = random_split(
        dataset,
        [train_size, val_size, test_size],
        generator=generator,
    )

    train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)
    val_loader = DataLoader(val_dataset, batch_size=32, shuffle=False)
    test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

    return dataset, train_dataset, train_loader, val_loader, test_loader
```

返回 `dataset` 和 `train_dataset` 是为了后面计算标准化参数。

## 只用训练集计算标准化参数

标准化应只使用训练集统计量：

```python
def compute_standardizer(dataset, train_dataset):
    train_features = dataset.features[train_dataset.indices]
    mean = train_features.mean(dim=0)
    std = train_features.std(dim=0)
    std[std == 0] = 1.0
    return mean, std
```

训练、验证、测试都使用同一组 `mean/std`：

$$
x_{\text{std}} = \frac{x - \mu_{\text{train}}}{\sigma_{\text{train}}}
$$

这样不会把验证集或测试集信息泄漏给训练过程。

## 推理/评估函数

评估函数用于验证集和测试集。它不计算梯度，也不更新参数：

```python
def evaluate(model, data_loader, device, mean, std):
    model.eval()
    correct = 0
    total = 0

    mean = mean.to(device)
    std = std.to(device)

    with torch.inference_mode():
        for features, labels in data_loader:
            features = features.to(device)
            labels = labels.to(device)

            features = (features - mean) / std
            logits = model(features)
            preds = logits.argmax(dim=1)

            correct += (preds == labels).sum().item()
            total += labels.size(0)

    return correct / total
```

关键点：

- `model.eval()` 切换到评估模式。
- `torch.inference_mode()` 关闭梯度追踪。
- `argmax(dim=1)` 从 logits 中取最高得分类别。
- 返回正确数除以总样本数，即准确率。

## 单个 epoch 的训练函数

```python
def train_one_epoch(model, data_loader, loss_fn, optimizer, device, mean, std, epoch, epochs):
    model.train()
    running_loss = 0.0
    correct = 0
    total = 0

    mean = mean.to(device)
    std = std.to(device)

    progress = tqdm(data_loader, desc=f"Epoch {epoch}/{epochs}", ncols=100)
    for features, labels in progress:
        features = features.to(device)
        labels = labels.to(device)

        features = (features - mean) / std

        optimizer.zero_grad(set_to_none=True)
        logits = model(features)
        loss = loss_fn(logits, labels)
        loss.backward()
        optimizer.step()

        batch_size = labels.size(0)
        running_loss += loss.item() * batch_size
        correct += (logits.argmax(dim=1) == labels).sum().item()
        total += batch_size

        progress.set_postfix(
            loss=running_loss / total,
            acc=correct / total,
        )

    return running_loss / total, correct / total
```

训练步骤顺序为：

```text
标准化输入 -> 清空梯度 -> 前向传播 -> 计算损失 -> 反向传播 -> 更新参数
```

## 主函数

```python
def main(data_path="./data/iris.csv", learning_rate=0.005, epochs=30, seed=42):
    set_seed(seed)

    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    print(f"Using device: {device}")

    dataset, train_dataset, train_loader, val_loader, test_loader = build_dataloaders(
        data_path=data_path,
        batch_size=16,
        seed=seed,
    )

    mean, std = compute_standardizer(dataset, train_dataset)

    model = IrisNet().to(device)
    loss_fn = nn.CrossEntropyLoss()
    optimizer = torch.optim.Adam(model.parameters(), lr=learning_rate)

    save_dir = Path("results") / "weights"
    save_dir.mkdir(parents=True, exist_ok=True)
    best_path = save_dir / "iris_net_best.pth"

    best_val_acc = -1.0

    for epoch in range(1, epochs + 1):
        train_loss, train_acc = train_one_epoch(
            model=model,
            data_loader=train_loader,
            loss_fn=loss_fn,
            optimizer=optimizer,
            device=device,
            mean=mean,
            std=std,
            epoch=epoch,
            epochs=epochs,
        )

        val_acc = evaluate(model, val_loader, device, mean, std)

        if val_acc > best_val_acc:
            best_val_acc = val_acc
            torch.save(model.state_dict(), best_path)

        print(
            f"Epoch {epoch:02d} | "
            f"train_loss={train_loss:.4f} | "
            f"train_acc={train_acc:.3f} | "
            f"val_acc={val_acc:.3f}"
        )

    state_dict = torch.load(best_path, map_location=device, weights_only=True)
    model.load_state_dict(state_dict)

    test_acc = evaluate(model, test_loader, device, mean, std)
    print(f"Best Val Acc: {best_val_acc:.3f}")
    print(f"Test Acc: {test_acc:.3f}")
```

说明：

- 每个 epoch 后在验证集上评估。
- 只保存验证准确率最高的权重。
- 训练结束后加载最佳权重，再在测试集上做最终评估。
- 测试集不参与训练，也不参与模型选择。

## 常见运行错误

### `mat1 and mat2 shapes cannot be multiplied`

通常是输入维度和第一层 `Linear` 不匹配。Iris 输入应是 4 维，检查 Dataset 是否误把标签列也读进了特征。

### `expected scalar type Long`

`CrossEntropyLoss` 的标签必须是 `int64` / `torch.long`。检查 Dataset 中标签转换。

### `0D or 1D target tensor expected`

标签形状错误。应为 `(batch_size,)`，不是 `(batch_size, 1)`。

### CUDA 设备不一致

模型、输入、标签要在同一个设备。训练和评估函数里都应执行 `.to(device)`。

### 每次准确率波动大

Iris 数据集很小，验证集和测试集样本数更少，准确率波动正常。重点看代码链路是否正确，而不是单次结果的小数点。

## 本章速记

- 训练集、验证集、测试集职责必须分清。
- 标准化只用训练集统计量，避免数据泄漏。
- 训练时 `model.train()`，验证/测试时 `model.eval()`。
- 训练链路：清梯度 -> 前向 -> 损失 -> 反向 -> 更新。
- 保存验证集表现最好的权重，再在测试集上做最终评估。
