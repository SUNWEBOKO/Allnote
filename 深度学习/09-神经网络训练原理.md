# 09 神经网络训练原理

## 本章定位

神经网络训练的本质，是用数据不断调整模型参数，使模型输出越来越接近真实标签。本章从训练目标、损失函数、前向传播、反向传播和参数更新五个环节解释完整训练链路。

## 为什么需要训练

新建模型时，权重和偏置通常是随机初始化的。随机参数不包含任何任务知识，因此模型一开始的预测没有可靠意义。

训练要做的事情是：

```text
随机参数 -> 根据数据计算损失 -> 根据梯度更新参数 -> 更有用的参数
```

经过多轮迭代后，模型逐渐学到输入特征和标签之间的规律。

## 有监督训练

课程中的鸢尾花分类属于有监督学习。每条样本都包含：

- 输入特征 $x$：花萼长度、花萼宽度、花瓣长度、花瓣宽度。
- 标签 $y$：鸢尾花类别。

模型根据输入得到预测 $\hat{y}$，再把预测与真实标签比较。比较结果由损失函数量化。

## 损失函数

损失函数（loss function）把“预测错得有多严重”变成一个数字。损失越小，说明模型越接近目标。

### 回归任务：均方误差

回归任务常用均方误差：

$$
\mathcal{L}_{\text{MSE}} =
\frac{1}{N}\sum_{i=1}^{N}(\hat{y}_i-y_i)^2
$$

它衡量预测值和真实值之间的平方误差。

### 分类任务：交叉熵

多分类任务常用交叉熵损失。若模型输出 logits，经 softmax 转换得到类别概率 $p_k$，真实类别为 $c$，单样本交叉熵为：

$$
\mathcal{L}_{\text{CE}} = -\log p_c
$$

预测给真实类别的概率越高，损失越小；概率越低，损失越大。

PyTorch 中使用：

```python
loss_fn = nn.CrossEntropyLoss()
loss = loss_fn(logits, labels)
```

注意：`CrossEntropyLoss` 接收的是 logits 和一维类别编号标签，不需要提前做 softmax，也不需要把标签转成 one-hot。

## 前向传播

前向传播（forward propagation）是模型从输入计算到输出的过程：

```text
输入 batch
-> 网络层计算
-> 得到 logits / 预测值
-> 计算损失
```

在 PyTorch 中通常写为：

```python
logits = model(inputs)
loss = loss_fn(logits, labels)
```

前向传播不仅得到输出，也会构建计算图。计算图记录了张量之间的计算关系，后续反向传播会沿着这张图计算梯度。

## 反向传播

反向传播（backpropagation）利用链式法则，计算损失函数对每个可学习参数的梯度。

在 PyTorch 中：

```python
loss.backward()
```

执行后，每个可学习参数的 `.grad` 中会保存对应梯度。开发者不需要手动推导每一层的导数，Autograd 会自动完成。

## 参数更新

有了梯度后，优化器根据梯度更新参数。最基本的梯度下降形式是：

$$
\theta_{\text{new}} = \theta_{\text{old}} - \eta \nabla_{\theta}\mathcal{L}
$$

其中：

- $\theta$：模型参数。
- $\eta$：学习率。
- $\nabla_{\theta}\mathcal{L}$：损失对参数的梯度。

PyTorch 中：

```python
optimizer.step()
```

会按照优化器规则更新参数。

## 为什么要清空梯度

PyTorch 默认会累加梯度，而不是自动覆盖。这是为了支持梯度累积等训练技巧。但普通训练中，每个 batch 更新前都要清空上一轮梯度：

```python
optimizer.zero_grad()
```

否则当前 batch 的梯度会和历史梯度叠加，导致参数更新错误。

更现代的写法是：

```python
optimizer.zero_grad(set_to_none=True)
```

它通常更节省内存。

## 一个训练 step 的顺序

标准顺序如下：

```python
model.train()

for inputs, labels in train_loader:
    inputs = inputs.to(device)
    labels = labels.to(device)

    optimizer.zero_grad(set_to_none=True)
    logits = model(inputs)
    loss = loss_fn(logits, labels)
    loss.backward()
    optimizer.step()
```

链路是：

```text
清空梯度 -> 前向传播 -> 计算损失 -> 反向传播 -> 更新参数
```

## epoch、batch 与 iteration

- **batch**：一次送入模型的一小批样本。
- **iteration / step**：模型完成一个 batch 的前向、反向和参数更新。
- **epoch**：模型完整遍历一遍训练集。

例如训练集有 1000 个样本，`batch_size=100`，则 1 个 epoch 包含 10 个 iteration。

## 验证不更新参数

验证阶段只评估模型表现，不计算梯度，不更新参数：

```python
model.eval()

with torch.inference_mode():
    for inputs, labels in val_loader:
        logits = model(inputs)
        pred = logits.argmax(dim=1)
```

训练和验证必须分开，否则验证集会参与参数更新，评估结果就不再客观。

## 本章速记

- 训练目标是最小化损失函数。
- 前向传播负责得到预测和损失。
- 反向传播负责计算梯度。
- 优化器负责根据梯度更新参数。
- 每个 batch 更新前必须清空梯度。
- 分类任务使用 `CrossEntropyLoss` 时，模型输出 logits，标签是一维类别编号。
