# 模电重写计划（语言风格与组织格式优化）

> [!abstract] 一句话概括
> 12 篇模电讲义内容已验收合格，本次只动"怎么写、怎么排"：按升级后的 studynotes-writing 技能逐篇重写语言风格与页面组织，SVG 引用、例题、数值、链接一律原样保留。

## 1 背景与诊断

对 01、09 两篇的深度阅读 + 其余各篇抽查，确认问题不在知识内容，而在表达层：

| 问题 | 具体表现 |
|---|---|
| 语言密度过高 | 长句堆叠，一段回答两个问题；破折号"——"连用；正文里用"A → B → C"箭头链代替句子 |
| 缺少教学引导 | 节首直接抛定义或表格，没有"为什么需要它"的缺口句；读者被动接收 |
| 视觉锚点缺失 | 无 Obsidian callout；例题只是加粗埋在正文里；易错点与普通正文无法区分 |
| 页面骨架松散 | 学习目标堆到 11 条；小结为纯编号罗列；自测答案直接可见，不能先测后看；无上一篇/下一篇导航 |

## 3 新风格规范摘要（重写执行标准）

1. **语气**：老师陪读口吻，"你/我们"；先讲为什么再讲是什么；每节用 1 句话制造缺口再解答；删"显然/简单"类填充词；同一概念只用一个术语。
2. **段落与标点**：一段一主题、中心句在段首、段落 ≤7 行；"——"每段至多 1 次；正文禁用箭头链（表格/推导步骤内可用）；加粗每段 ≤3 处，只标术语和结论。
3. **页面骨架**：H1 → `[!abstract]` 一句话概括 → 上一篇/下一篇导航 → 学习目标（3–7 条，动词开头）→ 先备知识 → 正文（`NN.M` 编号，每节先引导句）→ 本篇小结（概念/方法/易错分组）→ 自测题（`> [!success]- 答案要点` 折叠）→ 下节预告。
4. **Callout 映射**：`[!tip]` 直觉口诀、`[!warning]` 易错（错误动作→为何错→纠正→防复发）、`[!example] 例 N：标题`、`[!info]` 章间联系；每篇 6–12 个。
5. **例题格式**：题目完整 → 解完整 → "要点"一句收尾；核心方法首例保持完整推导深度。

## 4 硬约束（每篇重写前后必须校验）

- 全部 `[[wiki 链接]]` 保留并可用；H1 与文件名一致；正文"第X章"文字表述不改。
- 事实、数值、例题、推导结论不改写不删减；节号如合并/拆分，正文"见 X.X"引用同步清扫。
- 终审：LaTeX 裸命令/定界符扫描、残留话术扫描、代码围栏配对。
