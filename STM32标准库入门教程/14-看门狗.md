# 第 14 章 独立看门狗与窗口看门狗



## 本章闭环

让程序按期喂狗正常运行，故意阻塞后由看门狗复位，并在重启后读取复位来源。

## 1. IWDG

![IWDG 框图](../assets/ppt/slide-188.png)

IWDG 使用独立 LSI 时钟，主时钟异常时仍能工作。近似超时时间：

$$
T_{IWDG}=\frac{PR\,(RL+1)}{f_{LSI}}
$$

![IWDG 超时时间](../assets/ppt/slide-190.png)

课程示例以约 40 kHz LSI、16 分频、`RL=2499` 得到约 1 s；LSI 偏差较大，产品设计要留裕量并实测。

```c
IWDG_WriteAccessCmd(IWDG_WriteAccess_Enable);
IWDG_SetPrescaler(IWDG_Prescaler_16);
IWDG_SetReload(2499);
IWDG_ReloadCounter();
IWDG_Enable();
```

启用后通常只能靠复位停止。喂狗点应证明关键任务都健康，而不是在一个高优先级定时中断中无条件喂狗。

## 2. WWDG

![WWDG 工作窗口](../assets/ppt/slide-192.png)

WWDG 不仅防止“太晚喂”，也防止“太早喂”。其计数时钟来自 PCLK1：

$$
T=\frac{4096\times WDGTB\times (N+1)}{PCLK1}
$$

![WWDG 时间计算](../assets/ppt/slide-193.png)

课程示例使用 `PCLK1=36 MHz`、分频 8、启动计数值 `0x40|54`、窗口值 `0x40|21`，形成约 30~50 ms 的允许喂狗窗口。

```c
RCC_APB1PeriphClockCmd(RCC_APB1Periph_WWDG, ENABLE);
WWDG_SetPrescaler(WWDG_Prescaler_8);
WWDG_SetWindowValue(0x40 | 21);
WWDG_Enable(0x40 | 54);
/* 进入窗口后 */
WWDG_SetCounter(0x40 | 54);
```

## 3. 如何选择

![IWDG 与 WWDG 对比](../assets/ppt/slide-194.png)

IWDG 独立、简单、低功耗模式下仍可工作，适合作为最后一道恢复保障。WWDG 能发现任务运行过快或调度异常，但依赖 PCLK1，窗口计算和调度要求更严格。

## 4. 复位诊断

启动后用 `RCC_GetFlagStatus(RCC_FLAG_IWDGRST/WWDGRST)` 记录复位来源，处理后调用 `RCC_ClearFlag()`。产品中应把复位原因和少量故障上下文保存到后备域或 Flash，避免“自动恢复了但不知道为何复位”。

## 5. 验收与排错

正常喂狗数分钟不复位；故意阻塞后在预计时间内复位，并正确显示复位来源。复位过快先查 LSI/PCLK1、预分频和公式中的 `+1`；WWDG 一喂就复位通常是喂得太早；始终不复位则查是否真正使能以及阻塞路径是否仍在喂狗。

## 本章小结

看门狗不是修复 bug，而是限制故障持续时间。合理的超时、可信的健康判据和复位诊断缺一不可。
