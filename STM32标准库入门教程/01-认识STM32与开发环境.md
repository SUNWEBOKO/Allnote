# 第 1 章 认识 STM32 与开发环境

## 本章闭环

本章不急着写外设代码。完成后，你要能识别 STM32F103C8T6 的资源、最小系统、电源与下载接口，并准备好 Keil5、器件支持包、ST-Link 驱动和串口驱动。

![STM32F103C8T6 主要参数](../assets/ppt/slide-007.png)

## 1. STM32F103C8T6 是什么

它是 ST 基于 ARM Cortex-M3 内核设计的 32 位微控制器。本文按参考资料中的 `STM32F103C8` 工程组织，目标器件为 STM32F103C8T6（中容量产品）：最高 72 MHz、20 KB SRAM、64 KB Flash、2.0~3.6 V 供电、LQFP48 封装。`STM32` 是芯片家族，`Cortex-M3` 是处理器内核，二者不要混为一谈。

片上外设通过总线连接到内核。CPU 执行程序，Flash 保存程序，SRAM 保存运行时数据；GPIO、TIM、ADC、USART 等外设则完成引脚、计时、采样和通信任务。

![STM32 系统结构](../assets/ppt/slide-010.png)

## 2. 引脚图要读出什么

![STM32F103C8T6 引脚定义](../assets/ppt/slide-011.png)

查引脚表时至少确认四件事：

1. 引脚编号与端口名，例如芯片第几个脚对应 `PA9`。
2. 默认功能与复用功能，例如 `PA9` 可作 USART1_TX。
3. 电源脚，包括 `VDD/VSS`、模拟电源 `VDDA/VSSA`、后备电源 `VBAT`。
4. 调试脚，包括 `PA13/SWDIO`、`PA14/SWCLK`。初学阶段不要占用它们。

## 3. 最小系统

![STM32F103 最小系统电路](../assets/ppt/slide-013.png)

让 MCU 稳定运行至少需要：

- 3.3 V 电源和每组电源脚附近的去耦电容；
- 复位电路；
- 启动配置 `BOOT0/BOOT1`；
- 时钟源。课程板通常带 8 MHz 高速晶振和 32.768 kHz 低速晶振；
- SWD 下载调试接口。

正常从用户 Flash 启动时，`BOOT0=0`。串口 ISP 下载通常需要把 `BOOT0` 拉高，下载完成后再恢复为 0 并复位。

## 4. 软件安装顺序

1. 安装 Keil MDK（参考工程由较早版本创建，新版 MDK 可直接打开并升级工程）。
2. 安装 STM32F1 器件支持包，建工程时选择 `STM32F103C8`。
3. 安装 ST-Link 驱动；参考资料中也有使用 J-Link/ULINK 的旧工程，调试器按手头硬件选择。
4. 安装 USB 转串口模块对应驱动，常见芯片为 CH340。
5. 连接下载器，在设备管理器确认未出现黄色叹号。

Keil 中下载器选择 `ST-Link Debugger`；`Settings -> Flash Download` 中选择适合 STM32F10x 中容量器件的 Flash 算法，并勾选 `Reset and Run`。

## 5. 首次上电检查

先不下载程序，用万用表确认板上 3.3 V 与 GND 没有短路，3.3 V 电压正常。再连接 SWD：`3.3V`、`GND`、`SWDIO(PA13)`、`SWCLK(PA14)`，并保持 `BOOT0=0`。若下载器无法识别芯片，依次检查供电、共地、SWD 两根线、复位线和 Keil 中的目标型号。

## 本章小结

STM32 项目首先是电气系统，其次才是代码。能正确识别电源、启动、时钟、复用功能和调试口，后续外设配置才有可靠基础。
