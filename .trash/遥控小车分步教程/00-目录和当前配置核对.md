# 遥控小车分步教程：目录和最终配置

这套项目只实现蓝牙遥控开环控制：手机发送摇杆数据，STM32 直接换算左右电机 PWM。编码器、速度 PID、MPU6050 和 OLED 均不参与控制。

对于需要驾驶者实时操纵的小车，这样已经足够。速度 PID 适合解决“给定转速后自动保持”“负载变化时仍维持直线”等问题；本项目没有这些目标，因此不再增加反馈链路。

## 0.1 教程目录

按下面的顺序验证：

1. `01-驱动接入与第一次编译.md`
   - 核对电机、蓝牙驱动和 CMake 构建配置。
   - 完成第一次编译。
2. `02-电机开环测试.md`
   - 单独验证 TIM3 PWM 和四个电机方向脚。
   - 确定左右轮及正反方向。
3. `03-蓝牙开环遥控.md`
   - 接收手机摇杆包并控制左右轮。
   - 加入 500 ms 通信超时停车。
   - 这是项目的最终实现。

每一步只验证一条链路。电机测试通过后再接蓝牙，定位问题会简单很多。

## 0.2 最终 CubeMX 配置

当前 `Car.ioc` 只保留下列外设：

| 功能 | 配置 |
|---|---|
| 芯片 | STM32F103C8T6 |
| 系统时钟 | HSE 8 MHz，PLL x9，SYSCLK 72 MHz |
| 调试口 | SWD：PA13、PA14 |
| 左电机 PWM | TIM3_CH1 / PA6 |
| 右电机 PWM | TIM3_CH2 / PA7 |
| 电机方向脚 | PB12、PB13、PB14、PB15 |
| 蓝牙串口 | USART1：PA9 TX、PA10 RX，9600，开启接收中断 |

TIM3 的计数周期为 `3600 - 1`。定时器时钟为 72 MHz，因此 PWM 频率为：

```text
72 MHz / 3600 = 20 kHz
```

20 kHz 高于常见可听频段，适合直流电机 PWM 控制。


## 0.3 电机驱动映射

D153C 驱动使用：

```text
PA6  / TIM3_CH1 -> 左电机 PWM
PB12             -> 左电机 IN1
PB13             -> 左电机 IN2

PA7  / TIM3_CH2 -> 右电机 PWM
PB14             -> 右电机 IN1
PB15             -> 右电机 IN2
```

电机 PWM 命令范围为 `-1000..1000`：

```text
正数 -> 正转
负数 -> 反转
0    -> 滑行停止
```

如果实际电机方向相反，使用 `d153c_motor_invert()` 修正，不需要改控制算法。

## 0.5 蓝牙控制协议

手机端发送带方括号的数据包：

```text
[joystick,left_x,left_y,right_x,right_y]
```

当前只使用：

```text
left_y  -> 前进和后退
right_x -> 左转和右转
```

例如：

```text
[joystick,0,100,0,0]   前进
[joystick,0,-100,0,0]  后退
[joystick,0,0,-100,0]  左转
[joystick,0,0,100,0]   右转
[joystick,0,0,0,0]     停止
```

摇杆输入会限制在 `-100..100`，中心 `±8` 作为死区。连续 500 ms 没有收到有效摇杆包时，程序自动停止两个电机。

## 0.6 最终通过标准

项目完成时应满足：

1. `cmake --build --preset Debug` 成功生成 `Car.elf`。
2. 上电后蓝牙串口收到 `BT ready`。
3. 前进、后退、左右转和摇杆回中动作正确。
4. 停止发送摇杆包 500 ms 后，小车自动停车。
5. 工程中不再初始化编码器、I2C、TIM1、TIM2 或 TIM4。
