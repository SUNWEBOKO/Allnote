# 02 电机开环测试

本步只验证电机驱动。先不连接蓝牙，确保左右轮、正反方向和停止动作都正确。

通过标准：

```text
左、右电机都能正转、反转、停止，并且电机编号与实际左右轮一致。
```

## 2.1 接线与安全准备

| 功能 | STM32 引脚 |
|---|---|
| 左电机 PWM | PA6 / TIM3_CH1 |
| 右电机 PWM | PA7 / TIM3_CH2 |
| 左电机 IN1 | PB12 |
| 左电机 IN2 | PB13 |
| 右电机 IN1 | PB14 |
| 右电机 IN2 | PB15 |

接线前断开电源。STM32 和电机驱动可以使用不同电源，但必须共地：

```text
STM32 GND <-> 电机驱动 GND <-> 电池负极
```

第一次烧录时把车架起来，让轮子悬空。

## 2.2 加入电机头文件

打开 `Core/Src/main.c`，在 `USER CODE BEGIN Includes` 中加入：

```c
#include "d153c_motor.h"
```

## 2.3 初始化电机驱动

在 `USER CODE BEGIN 2` 中调用：

```c
d153c_motor_init();
```

函数会启动 TIM3 的两个 PWM 通道，并把左右电机先置为滑行停止。

## 2.4 临时测试代码

在主循环的 `USER CODE BEGIN 3` 中临时加入：

```c
d153c_motor_drive(D153C_MOTOR_A, 300);
d153c_motor_drive(D153C_MOTOR_B, 300);
HAL_Delay(1500);

d153c_motor_drive(D153C_MOTOR_A, 0);
d153c_motor_drive(D153C_MOTOR_B, 0);
HAL_Delay(800);

d153c_motor_drive(D153C_MOTOR_A, -300);
d153c_motor_drive(D153C_MOTOR_B, -300);
HAL_Delay(1500);

d153c_motor_drive(D153C_MOTOR_A, 0);
d153c_motor_drive(D153C_MOTOR_B, 0);
HAL_Delay(1500);
```

烧录后应循环执行：

```text
正转 1.5 秒
停止 0.8 秒
反转 1.5 秒
停止 1.5 秒
```

## 2.5 确认左右轮

如果不确定 A/B 对应关系，分别测试：

```c
d153c_motor_drive(D153C_MOTOR_A, 300);
d153c_motor_drive(D153C_MOTOR_B, 0);
```

以及：

```c
d153c_motor_drive(D153C_MOTOR_A, 0);
d153c_motor_drive(D153C_MOTOR_B, 300);
```

最终应确定：

```text
D153C_MOTOR_A = 左轮
D153C_MOTOR_B = 右轮
```

如果接线相反，优先整理电机线或 PWM 通道；也可以在后续控制层交换 A/B，但文档默认采用上面的对应关系。

## 2.6 修正电机方向

项目约定：

```text
duty > 0 -> 小车前进方向
duty < 0 -> 小车后退方向
```

如果左轮方向相反，在初始化后加入：

```c
d153c_motor_invert(D153C_MOTOR_A, true);
```

如果右轮方向相反：

```c
d153c_motor_invert(D153C_MOTOR_B, true);
```

反相设置必须放在 `d153c_motor_init()` 之后、进入主循环之前。

## 2.7 常见问题

### 两个电机都不动

依次检查：

1. 电机驱动是否供电。
2. 电机驱动与 STM32 是否共地。
3. `d153c_motor_init()` 是否执行。
4. PA6、PA7 是否仍配置为 TIM3 PWM。
5. PB12~PB15 是否配置为推挽输出。

### 只有一侧转动

交换左右电机线测试。如果故障跟着电机移动，检查电机和线缆；如果故障固定在驱动通道，检查 PWM、方向线和驱动模块。

### 低占空比不转

直流减速电机需要克服静摩擦。初次测试使用 `250..400`，不要直接给满幅 `1000`。

### 上电后立即转动

`gpio.c` 应在初始化输出模式前先把 PB12~PB15 拉低：

```c
HAL_GPIO_WritePin(GPIOB,
                  GPIO_PIN_12 | GPIO_PIN_13 | GPIO_PIN_14 | GPIO_PIN_15,
                  GPIO_PIN_RESET);
```

## 2.8 完成本步

确认电机后，删除主循环中的临时往返测试，只保留：

```c
d153c_motor_init();
```

以及实际需要的 `d153c_motor_invert()`。然后进入 `03-蓝牙开环遥控.md`。
