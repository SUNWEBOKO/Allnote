## 2 三条主线

**计算线：行列式 → 矩阵 → 初等变换与秩。** 行列式把方阵压缩成一个数，给出可逆性的第一个判据；矩阵把线性变换写成系数表；初等变换把矩阵化为行最简形，使秩、行列式和方程组求解都变成可执行流程。

**结构线：向量组 → 线性方程组 → 向量空间。** 线性表出与线性相关性描述向量组内部的依赖关系；极大无关组给出向量组的秩；齐次与非齐次方程组的解结构把“有多少解”写成基础解系与特解；向量空间再把这一切提升为基、维数与坐标。第 05 章的过渡矩阵把两组基联系起来，为第 06 章的相似变换做准备。

**标准形线：特征值 → 相似对角化 → 二次型。** 特征值刻画线性变换中方向不变的向量；相似对角化把同一变换化到对角形式；实对称矩阵可以正交对角化，二次型因此能化为平方和，并由惯性指数与正定性读出符号结构。

## 3 统一记号

| 记号 | 含义 |
| --- | --- |
| $\det(A)$ | 方阵的行列式 |
| $A^T$、$A^{-1}$ | 转置矩阵、逆矩阵 |
| $A^*$ | 伴随矩阵，由代数余子式矩阵转置得到 |
| $r(A)$ | 矩阵的秩 |
| $[A\mid b]$ | 线性方程组的增广矩阵 |
| $I$、$O$ | 单位矩阵、零矩阵 |
| $F_{ij}$、$F_i(k)$、$F_{ij}(k)$ | 交换、倍乘、倍加初等矩阵 |
| $P$ | 过渡矩阵或可逆矩阵，按上下文区分 |
| $\Lambda$ | 对角矩阵 |
| $\operatorname{span}\{\alpha_1,\ldots,\alpha_m\}$ | 向量组的张成空间 |
| $\dim V$ | 空间 $V$ 的维数 |
| $\mathcal C(A)$、$\mathcal N(A)$ | 列空间、零空间 |
| $\mathcal C(A^T)$、$\mathcal N(A^T)$ | 行空间、左零空间 |
| $\operatorname{tr}(A)$ | 矩阵的迹，主对角线元素之和 |
| $E_\lambda$ | 特征值 $\lambda$ 的特征子空间 |
| $g_\lambda$、$a_\lambda$ | 几何重数、代数重数 |
| $\Delta_k$ | 第 $k$ 个顺序主子式 |
| $p,q,s$ | 正、负、零惯性指数 |
| $A\succ0$ | 实对称矩阵 $A$ 正定 |

约定：

- 行列式只对方阵定义；$\det(A)\ne0$ 与 $A$ 可逆等价。
- 向量默认写成列向量，行向量用转置表示；$n$ 维空间默认 $\mathbb R^n$。
- 矩阵乘法 $AB$ 表示先作用 $B$、再作用 $A$，右边矩阵先靠近向量。
- 初等矩阵用 $F_{ij}$、$F_i(k)$、$F_{ij}(k)$ 表示，分别对应交换、倍乘、倍加；左乘作行变换，右乘作列变换。
- 相似、合同、等价分别写成 $B=P^{-1}AP$、$B=C^TAC$、$B=PAQ$；相似与合同要求同阶方阵，等价要求同型矩阵，其中的 $P,C,Q$ 均可逆。
- 二次型的矩阵总取实对称矩阵；交叉项系数平分到两个对称位置。
- 特征多项式用 $\det(\lambda I-A)$，特征值按代数重数计；实对称矩阵的特征向量默认取实向量。

## 4 常用结论速查

| 主题 | 结论 |
| --- | --- |
| 方阵可逆 | $\det(A)\ne0\iff r(A)=n\iff Ax=\boldsymbol 0$ 只有零解 $\iff$ 列向量线性无关 $\iff$ 行等价于 $I$ |
| 逆矩阵 | $A^{-1}=\dfrac{1}{\det(A)}A^*$；$[A\mid I]\to[I\mid A^{-1}]$；$(AB)^{-1}=B^{-1}A^{-1}$ |
| 伴随矩阵 | $AA^*=A^*A=\det(A)I$ |
| 行列式 | $\det(AB)=\det(A)\det(B)$；$\det(kA)=k^n\det(A)$；$\det(A^T)=\det(A)$ |
| 范德蒙德 | $\prod_{1\le j<i\le n}(a_i-a_j)$ |
| 分块 | $\det\begin{pmatrix}A&C\\O&B\end{pmatrix}=\det(A)\det(B)$ |
| 乘积的秩 | $r(AB)\le\min\{r(A),r(B)\}$ |
| 秩的和 | $r(A+B)\le r(A)+r(B)$ |
| 乘积秩的下界 | $r(AB)\ge r(A)+r(B)-n$（$A$ 为 $m\times n$，$B$ 为 $n\times s$） |
| 方程组有解 | $r(A)=r([A\mid b])$ |
| 唯一解 | $r(A)=r([A\mid b])=n$ |
| 无穷多解 | $r(A)=r([A\mid b])<n$ |
| 齐次解空间 | 基础解系含 $n-r(A)$ 个向量 |
| 非齐次通解 | 一个特解加导出齐次方程组的通解 |
| 秩—零度定理 | $\dim\mathcal C(A)+\dim\mathcal N(A)=n$ |
| 特征值之和（按代数重数计） | $\sum\lambda_i=\operatorname{tr}(A)$ |
| 特征值之积（按代数重数计） | $\prod\lambda_i=\det(A)$ |
| 可对角化 | $A$ 有 $n$ 个线性无关的特征向量 $\iff$ 每个特征值 $g_\lambda=a_\lambda$ |
| 实对称矩阵 | 必可正交对角化，$Q^TAQ=\Lambda$ |
| 二次型标准形 | 配方法或正交变换 $x=Qy$ |
| 惯性定理 | $r(A)=p+q$，$n=p+q+s$；合同当且仅当 $p,q$ 相同 |
| 正定判据（实对称 $A$） | 全部特征值大于 $0$（等价于全部顺序主子式大于 $0$） |

## 5 术语对照

| 概念 | 不同说法 | 关系 |
| --- | --- | --- |
| 秩 | 非零子式最高阶数、阶梯形非零行数、极大无关组向量个数、行空间与列空间维数 | 五者相等 |
| 可逆 | 非奇异、满秩、行列式非零、齐次方程只有零解、行等价于 $I$ | 对 $n$ 阶方阵等价 |
| 基础解系 | 齐次解空间的一组基 | 向量个数为 $n-r(A)$ |
| 标准形 | 二次型的平方和形式、相似对角化的 $\Lambda$ | 前者系数不唯一，后者对角元是特征值 |
| 规范形 | 系数只取 $\pm1$ 的标准形 | 由正、负惯性指数唯一决定 |
| 相似与合同 | $B=P^{-1}AP$ 与 $B=C^TAC$ | 正交矩阵下重合；一般互不替代 |
| 几何重数 | 特征子空间的维数 | $1\le g_\lambda\le a_\lambda$ |
