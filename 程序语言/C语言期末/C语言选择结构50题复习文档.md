## 二、运算符与表达式

### 核心知识点

1. **运算符优先级（从高到低）**：
   `!`（逻辑非）> 算术运算符 > 关系运算符 > `&&` > `||` > 条件运算符 > 赋值运算符

2. **关系表达式**：结果为 `int` 类型，成立为 **1**，不成立为 **0**

3. **逻辑运算符短路特性**：
   - `A && B`：A 为假时，B 不执行
   - `A || B`：A 为真时，B 不执行

4. **条件运算符**：C 语言中**唯一的三目运算符**，格式：`条件 ? 表达式1 : 表达式2`

5. **浮点数比较**：不能直接用 `==` 或 `!=`，应判断两数之差的绝对值是否小于一个极小值（如 `fabs(a - b) < 1e-7`）

6. **等于判断**：用 `==`，不要误写为赋值号 `=`；Yoda 风格 `if (0 == x)` 可避免此错误

## 三、if 选择结构

### 核心知识点

1. **单分支 if**：`if (条件) 语句;`，仅条件为真时执行
2. **双分支 if-else**：`if (条件) 语句1; else 语句2;`，二选一执行
3. **复合语句**：多条语句必须用 `{}` 包裹，形成一个整体
4. **else 配对规则**：**与最近的未配对 if 结合**，这是悬空 else 问题的根源
5. **用 `{}` 包裹语句的目的**：避免悬空 else，保证逻辑清晰

## 四、多分支选择结构

### 核心知识点

**else-if 多分支：**

- 格式：`if (条件1) 语句1; else if (条件2) 语句2; ... else 语句n;`
- 特点：**仅进入第一个满足条件的分支**
- 优点：避免嵌套过深，逻辑清晰
- 适用场景：多条件互斥的多路选择

**switch 多分支：**

- 格式：`switch (表达式) { case 常量1: 语句1; break; ... default: 语句n; }`
- 表达式类型：只能是 **int 或 char 类型**
- case 后必须是 **常量**，不能是变量或表达式
- **break 的作用**：跳出 switch 分支；无 break 会发生 **case 穿透**，执行后续所有 case 语句
- default：处理所有未匹配的情况，位置任意
- 适用场景：**固定值的多路选择**

## 五、其他重要知识点

### 核心知识点

1. **短路求值**：`||` 左真则右不执行，`&&` 左假则右不执行——利用此特性可保护右侧表达式不被执行（如避免除零、空指针解引用）。
2. **字符与数字的关系**：数字字符 `'0'` ~ `'9'` 的 ASCII 码连续递增，可用 `ch >= '0' && ch <= '9'` 判断。
3. **除零保护**：除法运算前必须判断除数是否为 0，否则程序会崩溃。
4. **选择结构应用场景**：需要根据条件选择不同执行路径时使用，如闰年判断、成绩等级划分等。

| 7 | 判断 ch 为数字字符的正确表达式是() | D `ch >= '0' && ch <= '9'` | 数字字符的 ASCII 码连续 |

## 六、高频易错点总结

| 编号 | 易错点 | 典型错误 | 正确做法 |
|------|--------|----------|----------|
| 1 | **等于判断** | `if (x = 5)` 赋值而非判断 | `if (x == 5)` 或用 Yoda 风格 `if (5 == x)` |
| 2 | **逻辑短路** | 忽略 `&&` 和 `||` 短路特性 | 右边表达式含赋值/自增时务必警惕是否会被跳过 |
| 3 | **case 穿透** | 忘记写 `break` | 每个 case 结束时检查是否需要 `break`，除非故意穿透 |
| 4 | **悬空 else** | else 与错误的外层 if 配对 | 用 `{}` 明确层级结构 |
| 5 | **浮点数比较** | 直接用 `==` 比较浮点数 | `fabs(a - b) < 1e-7` |
| 6 | **switch 表达式类型** | 使用 float、double 等不支持的类型 | switch 表达式必须是 int 或 char |
| 7 | **case 后用变量** | `case n:` 其中 n 是变量 | case 后必须是编译时常量 |
| 8 | **关系表达式连写** | 用 `a < b < c` 表示区间 | 应写为 `a < b && b < c` |
| 9 | **else-if 误解** | 以为多个分支都会被检查 | 仅进入第一个满足条件的分支 |
| 10 | **分号误用** | `if (条件); {语句}` 空语句 | `if` 后直接加分号会形成空语句体 |
