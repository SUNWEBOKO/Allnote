# C 语言数组与函数复习讲义

## 一、数组的基本概念

C 语言的基本数据类型包括 `int`、`char`、`long`、`float`、`double` 等。普通变量一次只能保存一个值。例如：

```c
int a = 10;
```

这个变量 `a` 只能存放一个整数。如果现在需要保存一组同类型的数据，比如 10 个学生的成绩、20 个整数、100 个字符，就不能再一个一个定义变量，否则代码会非常繁琐。为了解决"批量存储同类型数据"的问题，C 语言引入了数组。

数组是由一系列**类型相同**的数据元素按照顺序排列组成的数据结构。组成数组的每一个数据对象称为数组元素。可以把数组想象成一排连续的盒子，每个盒子中存放一个同类型的数据，每个盒子都有自己的编号，这个编号称为**下标**。

需要特别注意：**C 语言数组下标从 0 开始**。也就是说，第一个元素的下标是 `0`，第二个元素的下标是 `1`，依次类推。如果一个数组有 5 个元素，那么它的合法下标是：

```c
0, 1, 2, 3, 4
```

而不是 `1, 2, 3, 4, 5`。

## 二、一维数组的定义

一维数组的定义格式为：

```c
元素类型 数组名[元素个数];
```

例如：

```c
int number[5];
```

这行代码定义了一个名为 `number` 的整型数组，它可以存放 5 个 `int` 类型的数据。由于数组下标从 0 开始，所以这 5 个元素分别是：

```c
number[0]
number[1]
number[2]
number[3]
number[4]
```

其中，`number[0]` 是第一个元素，`number[4]` 是第五个元素。

注意，`number[5]` 不是第五个元素，而是越界访问。因为 `number[5]` 表示第六个元素，但这个数组一共只有 5 个元素。数组越界会访问到不属于该数组的内存空间，可能导致程序运行错误、数据混乱，甚至程序崩溃。因此在考试和实际编程中都要特别注意数组下标范围。

## 三、一维数组的初始化

定义数组之后，可以在定义时直接给数组元素赋初值，这叫数组初始化。标准写法如下：

```c
int a[5] = {1, 2, 3, 4, 5};
```

这表示定义了一个长度为 5 的整型数组 `a`，并依次赋值：

```c
a[0] = 1;
a[1] = 2;
a[2] = 3;
a[3] = 4;
a[4] = 5;
```

如果初始化时给出的数据个数少于数组长度，剩余元素会自动补 0。例如：

```c
int b[5] = {1, 2};
```

这个数组实际内容为：

```c
b[0] = 1;
b[1] = 2;
b[2] = 0;
b[3] = 0;
b[4] = 0;
```

如果在定义数组时同时给出了初始化列表，也可以省略方括号中的数组长度，由编译器根据初始化元素个数自动推断。例如：

```c
int c[] = {1, 2, 3};
```

这里数组 `c` 的长度自动确定为 3，相当于：

```c
int c[3] = {1, 2, 3};
```

但是，如果初始化元素个数超过数组长度，则是错误的。例如：

```c
int d[5] = {1, 2, 3, 4, 5, 6};
```

数组 `d` 只有 5 个元素，但初始化列表中给出了 6 个数据，超出了数组容量，因此这种写法是错误的。

## 四、数组长度的要求

在常见 C 语言考试语境中，定义数组时，数组长度通常要求是**正整数常量表达式**。例如：

```c
int a[5];
int b[1 + 1];
int c[2 * 2];
```

这三种写法通常都可以接受。虽然 `1 + 1`、`2 * 2` 是表达式，但它们在编译时可以确定结果，所以属于常量表达式。

但是下面这种写法在许多基础考试中通常认为不符合要求：

```c
int x = 5;
int a[x];
```

因为 `x` 是变量，不是常量表达式。

注意：较新的 C 标准中存在"变长数组"概念，在某些编译器和标准下可以使用变量作为局部数组长度。但在大多数 C 语言基础考试、期末考试和选择题中，通常按照"数组长度必须是正整数常量表达式"来判断。

## 五、数组元素的使用与遍历

数组元素的使用方式和普通变量很像。只要通过数组名加下标，就可以访问某个元素。例如：

```c
int numbers[5];

numbers[0] = 10;
printf("%d", numbers[0]);
```

这里先将数组第一个元素赋值为 `10`，然后通过 `printf` 输出它。

如果想依次访问数组中的所有元素，通常使用循环。因为数组下标连续，所以 `for` 循环非常适合遍历数组。例如：

```c
#include <stdio.h>

int main(void)
{
    int numbers[5] = {1, 2, 3, 4, 5};

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    return 0;
}
```

这个循环从 `i = 0` 开始，到 `i < 5` 结束，依次访问 `numbers[0]` 到 `numbers[4]`，正好覆盖数组的全部合法下标。

数组遍历时最容易出错的是循环边界。对于长度为 `n` 的数组，合法下标是 `0` 到 `n - 1`，因此循环条件通常写成：

```c
i < n
```

而不是：

```c
i <= n
```

如果写成 `i <= n`，最后一次会访问 `a[n]`，这就越界了。

## 六、一维数组常见考点

### 6.1 判断数组定义是否正确

例如：

```c
int m[5];
```

这是最标准的一维数组定义，正确。

```c
char b[] = {'a', 'b', 'c'};
```

这也是正确的。虽然方括号里没有写长度，但后面有初始化列表，编译器可以根据初始化元素个数推断数组长度。

```c
int c[10] = {1, 2, 3, 4};
```

这也是正确的。数组长度为 10，初始化时只给了 4 个元素，剩下的元素自动补 0。

```c
int d[];
```

这是错误的。因为既没有指定数组长度，也没有初始化列表，编译器无法确定数组到底有多少个元素。

因此要记住：**一维数组可以省略长度，但前提是定义时必须同时初始化。**

### 6.2 判断数组初始化是否正确

数组初始化必须使用花括号 `{}`，不能使用普通小括号 `()`。例如：

```c
int a[3] = (1, 2, 3);
```

这是错误的。

正确写法应为：

```c
int a[3] = {1, 2, 3};
```

如果有初始化列表，可以省略数组长度：

```c
int a[] = {1, 2, 3};
```

这也是正确的。

数组名后面必须使用方括号 `[]` 表示数组长度，不能使用花括号或小括号。例如：

```c
int a{10};
```

这不是 C 语言中定义数组的正确写法。正确形式应为：

```c
int a[10];
```

### 6.3 判断数组元素引用是否正确

如果有：

```c
int a[10];
```

那么数组 `a` 的合法下标是 `0` 到 `9`。

```c
a[10]
```

是错误的，因为它越界了。

```c
a[3.5]
```

也是错误的，因为数组下标必须是整数类型表达式，不能是浮点数。

```c
a(5)
```

也是错误的，因为访问数组元素必须使用方括号，不是小括号。

正确访问方式类似于：

```c
a[5]
```

只要下标在合法范围内，就是正确的。

### 6.4 数组下标嵌套引用

有时题目会出现类似：

```c
a[a[i]]
```

这种写法看起来复杂，但本质上只需要从内到外计算。

假设：

```c
int i = 10;
```

并且已知：

```c
a[10] = 9;
a[9] = 6;
```

那么：

```c
a[a[i]]
```

应先计算内部的 `a[i]`。因为 `i = 10`，所以：

```c
a[i] = a[10] = 9
```

于是原表达式变成：

```c
a[9]
```

又因为：

```c
a[9] = 6
```

所以最终结果为 `6`。

这类题的关键是：**先算方括号里面的表达式，再根据结果访问外层数组元素。**

### 6.5 通过循环给数组赋值

例如：

```c
#include <stdio.h>

int main(void)
{
    int number[5];

    for (int i = 0; i < 5; i++)
    {
        number[i] = i * 10 - 2;
    }

    printf("%d", number[3]);

    return 0;
}
```

循环执行后：

```c
number[0] = 0 * 10 - 2 = -2;
number[1] = 1 * 10 - 2 = 8;
number[2] = 2 * 10 - 2 = 18;
number[3] = 3 * 10 - 2 = 28;
number[4] = 4 * 10 - 2 = 38;
```

所以 `printf("%d", number[3]);` 的输出结果是：

```c
28
```

### 6.6 多个数组配合计算

看下面这段代码：

```c
#include <stdio.h>

int main(void)
{
    int i, k = 5;
    int a[10], p[3];

    for (i = 0; i < 10; i++)
    {
        a[i] = i;
    }

    for (i = 0; i < 3; i++)
    {
        p[i] = a[i * (i + 1)];
    }

    for (i = 0; i < 3; i++)
    {
        k = k + p[i] * 2;
    }

    printf("%d", k);

    return 0;
}
```

第一个循环执行后：

```c
a[0] = 0;
a[1] = 1;
a[2] = 2;
...
a[9] = 9;
```

第二个循环给数组 `p` 赋值：

当 `i = 0` 时：

```c
p[0] = a[0 * (0 + 1)] = a[0] = 0;
```

当 `i = 1` 时：

```c
p[1] = a[1 * (1 + 1)] = a[2] = 2;
```

当 `i = 2` 时：

```c
p[2] = a[2 * (2 + 1)] = a[6] = 6;
```

所以：

```c
p[0] = 0;
p[1] = 2;
p[2] = 6;
```

第三个循环更新 `k`：

初始时：

```c
k = 5;
```

第一次循环：

```c
k = 5 + p[0] * 2 = 5 + 0 * 2 = 5;
```

第二次循环：

```c
k = 5 + p[1] * 2 = 5 + 2 * 2 = 9;
```

第三次循环：

```c
k = 9 + p[2] * 2 = 9 + 6 * 2 = 21;
```

因此最终输出结果是：

```c
21
```

## 七、二维数组的基本概念

前面的一维数组可以看作一排盒子。如果数组的元素本身又是数组，就形成了二维数组。二维数组可以理解为"数组的数组"，也可以直观地看成一个表格，有行、有列。

二维数组的定义格式为：

```c
元素类型 数组名[行数][列数];
```

例如：

```c
int matrix[3][4];
```

这定义了一个 3 行 4 列的整型二维数组，一共有：

```c
3 * 4 = 12
```

个元素。

二维数组通过两个下标访问元素，第一个下标表示行，第二个下标表示列。例如：

```c
matrix[0][0]
```

表示第 1 行第 1 列的元素。

```c
matrix[1][2]
```

表示第 2 行第 3 列的元素。

同样要注意，二维数组的行下标和列下标也都是从 0 开始的。对于：

```c
int matrix[3][4];
```

合法行下标是：

```c
0, 1, 2
```

合法列下标是：

```c
0, 1, 2, 3
```

## 八、二维数组的初始化

二维数组最标准的初始化写法是使用嵌套花括号：

```c
int a[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

这表示二维数组 `a` 有 2 行 3 列：

```c
第 1 行：1  2  3
第 2 行：4  5  6
```

也可以省略内部花括号，按顺序依次填入：

```c
int b[2][3] = {1, 2, 3, 4, 5, 6};
```

它与上面的初始化效果相同：

```c
第 1 行：1  2  3
第 2 行：4  5  6
```

如果初始化数据不足，也会自动补 0。例如：

```c
int c[2][3] = {1, 2, 3, 4, 5};
```

数组一共有 6 个元素，但只给了 5 个初值，所以最后一个元素补 0：

```c
第 1 行：1  2  3
第 2 行：4  5  0
```

二维数组初始化时，可以省略第一维，也就是行数。例如：

```c
int d[][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

这是正确的。编译器可以根据初始化列表推断出这个数组有 2 行，每行 3 列。

但是不能省略第二维，也就是列数。例如：

```c
int e[2][] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

这是错误的。

二维数组以及更高维数组有一个非常重要的规则：

**只有第一个方括号中的大小可以在初始化时省略，后面的维度不能省略。**

也就是说：

```c
int a[][3];      // 在有初始化或作为函数参数时常见
int a[2][];      // 错误
int a[][];       // 错误
```

## 九、二维数组常见考点

### 9.1 计算二维数组元素个数

例如：

```c
int a[3][4];
```

这个数组有 3 行 4 列，所以一共有：

```c
3 * 4 = 12
```

个元素。

### 9.2 根据初始化结果判断元素值

例如：

```c
int a[3][4] = {
    {1, 2},
    {0},
    {4, 6, 8, 10}
};
```

可以把它画成表格来理解。

第一行 `{1, 2}` 中只给了两个数，所以后面补 0：

```c
1  2  0  0
```

第二行 `{0}` 只给了一个 0，其余补 0：

```c
0  0  0  0
```

第三行 `{4, 6, 8, 10}` 正好填满：

```c
4  6  8  10
```

所以整个数组为：

```c
a[0][0] = 1;   a[0][1] = 2;   a[0][2] = 0;   a[0][3] = 0;
a[1][0] = 0;   a[1][1] = 0;   a[1][2] = 0;   a[1][3] = 0;
a[2][0] = 4;   a[2][1] = 6;   a[2][2] = 8;   a[2][3] = 10;
```

如果题目问：

```c
a[1][2]
```

它表示第 2 行第 3 列，对应值为 `0`。

如果题目问：

```c
a[2][1]
```

它表示第 3 行第 2 列，对应值为 `6`。

这类题建议直接画表格，把数据填进去，然后按下标找元素。

### 9.3 判断二维数组定义是否正确

例如：

```c
int a[][3] = {1, 2, 3, 4, 5, 6};
```

这是正确的，因为只省略了第一维，第二维列数 `3` 没有省略。

```c
int a[2][] = {1, 2, 3, 4, 5, 6};
```

这是错误的，因为省略了第二维。

```c
int a[][] = {1, 2, 3, 4, 5, 6};
```

这也是错误的，因为第二维同样没有给出。

```c
int a[2, 3];
```

这是错误的。C 语言二维数组不能把行数和列数写在同一个方括号里，必须写成：

```c
int a[2][3];
```

## 十、数组综合编程题：最小值与第一个数交换

题目：从键盘输入 10 个数存放在数组中，将最小值与第一个数交换，输出交换后的所有数组元素。

这道题的思路可以分成四步。

第一步，定义一个长度为 10 的数组，用来保存输入的 10 个整数。

第二步，用循环和 `scanf` 依次输入 10 个数。

第三步，遍历数组，找到最小值所在的下标。这里通常定义一个变量 `minIndex`，用来记录当前最小元素的下标。初始时可以认为第一个元素最小，所以令：

```c
minIndex = 0;
```

然后从第二个元素开始比较，如果发现某个元素比当前最小元素还小，就更新 `minIndex`。

第四步，把 `a[0]` 和 `a[minIndex]` 交换，然后输出整个数组。

完整代码如下：

```c
#include <stdio.h>

int main(void)
{
    int a[10];
    int minIndex = 0;
    int temp;

    printf("请输入10个整数：\n");

    for (int i = 0; i < 10; i++)
    {
        scanf("%d", &a[i]);
    }

    for (int i = 1; i < 10; i++)
    {
        if (a[i] < a[minIndex])
        {
            minIndex = i;
        }
    }

    temp = a[0];
    a[0] = a[minIndex];
    a[minIndex] = temp;

    printf("交换后的数组为：\n");

    for (int i = 0; i < 10; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}
```

这里的核心是：

```c
if (a[i] < a[minIndex])
{
    minIndex = i;
}
```

`minIndex` 不是保存最小值本身，而是保存最小值的下标。这样后面才能通过下标找到这个元素，并与第一个元素交换。

交换两个变量时，常用临时变量 `temp`：

```c
temp = a[0];
a[0] = a[minIndex];
a[minIndex] = temp;
```

如果不用临时变量，直接赋值很容易把原来的值覆盖掉。

## 十一、函数的基本概念

函数是 C 语言中非常重要的概念。C 语言程序的基本组成单位就是函数。一个函数可以看作具有特定功能的一段代码块，它可以被多次调用，从而避免重复编写相同的代码。

一个函数通常可以理解为一个"盒子"：调用函数时，可以给它输入一些数据；函数执行过程中会完成某些操作；执行结束后，函数可以返回一个结果。

函数定义的一般格式为：

```c
返回类型 函数名(参数列表)
{
    函数体;
}
```

例如，定义一个求两个整数之和的函数：

```c
int add(int x, int y)
{
    int result;
    result = x + y;
    return result;
}
```

其中：

```c
int
```

是返回类型，表示函数最终返回一个 `int` 类型的值。

```c
add
```

是函数名。

```c
int x, int y
```

是参数列表，表示调用这个函数时需要传入两个整型数据。

函数体中的：

```c
return result;
```

表示把 `result` 的值作为函数结果返回。

这个函数也可以简写为：

```c
int add(int x, int y)
{
    return x + y;
}
```

## 十二、函数的调用

定义函数之后，可以在其他地方调用它。函数调用的一般格式为：

```c
函数名(实际参数);
```

例如：

```c
int a;
a = add(2, 3);
```

这里调用了 `add` 函数，并传入两个参数 `2` 和 `3`。调用时，实参会按照位置传递给形参：

```c
2 传给 x
3 传给 y
```

函数内部计算：

```c
x + y = 2 + 3 = 5
```

然后通过 `return` 返回结果，最终赋值给变量 `a`，所以 `a` 的值为 `5`。

完整代码如下：

```c
#include <stdio.h>

int add(int x, int y)
{
    return x + y;
}

int main(void)
{
    int a;

    a = add(2, 3);

    printf("%d", a);

    return 0;
}
```

输出结果为：

```c
5
```

## 十三、形参和实参

在函数定义中出现的参数称为**形式参数**，简称形参。例如：

```c
int add(int x, int y)
```

这里的 `x` 和 `y` 就是形参。形参本身只是函数内部使用的临时变量名，它们在函数被调用之前没有具体值。

在函数调用时传入的具体数据称为**实际参数**，简称实参。例如：

```c
add(2, 3)
```

这里的 `2` 和 `3` 就是实参。

可以这样理解：形参是"占位用的变量"，实参是"真正传进去的数据"。

## 十四、函数声明

C 语言程序从上往下编译。如果在 `main` 函数中调用某个函数，而这个函数的定义写在 `main` 后面，那么在调用时，编译器还不知道这个函数是什么，就可能报错。

例如：

```c
#include <stdio.h>

int main(void)
{
    int a;
    a = add(2, 3);
    printf("%d", a);
    return 0;
}

int add(int x, int y)
{
    return x + y;
}
```

在许多现代 C 编译环境中，这种写法会出错或至少产生严重警告。因为 `main` 调用 `add` 时，`add` 还没有被声明。

解决方法是在 `main` 前面添加函数声明，也叫函数原型：

```c
int add(int x, int y);
```

完整代码如下：

```c
#include <stdio.h>

int add(int x, int y);

int main(void)
{
    int a;
    a = add(2, 3);
    printf("%d", a);
    return 0;
}

int add(int x, int y)
{
    return x + y;
}
```

函数声明只需要告诉编译器函数的返回类型、函数名和参数类型即可，所以也可以写成：

```c
int add(int, int);
```

在函数声明中，参数名可以省略；但在函数定义中，参数名通常不能省略，因为函数体内要使用这些参数。

函数声明也可以写在 `main` 函数内部，只要它出现在函数调用之前即可。例如：

```c
int main(void)
{
    int add(int, int);

    int a = add(2, 3);
    printf("%d", a);

    return 0;
}
```

这种写法语法上可以，但更常见、更规范的方式是把函数声明写在 `main` 函数之前。

## 十五、函数常见考点

### 15.1 函数定义在 `main` 后面但没有声明

如果一个函数写在 `main` 后面，并且在调用前没有函数声明，通常认为是错误的。

例如：

```c
int main(void)
{
    fn(2, 3);
    return 0;
}

int fn(int a, int b)
{
    return a + b;
}
```

这类题在考试中经常出现。判断时要看：**函数调用之前，编译器是否已经见过该函数的声明或定义。**

### 15.2 有返回值的函数可以不接收返回值

例如：

```c
int fn(int a, int b)
{
    return a + b;
}

int main(void)
{
    fn(2, 3);
    return 0;
}
```

虽然 `fn` 返回了一个整数，但调用时没有用变量接收它，这在语法上是可以的。只是返回值被忽略了。

所以不能因为"函数有返回值但没有接收"就判断它错误。

### 15.3 函数声明中可以只写参数类型

例如：

```c
int fn(int, int);
```

这是合法的函数声明。

下面这样也合法：

```c
int fn(int x, int y);
```

声明中的参数名可以和定义中的参数名不同。例如：

```c
int fn(int i, int y);

int fn(int a, int b)
{
    return a + b;
}
```

这是正确的。因为形参名只是函数内部使用的代号，声明中的参数名和定义中的参数名不必完全一致。

### 15.4 嵌套函数调用

看下面这段代码：

```c
#include <stdio.h>

int fn(int a, int b)
{
    if (a > b)
    {
        return a;
    }
    else
    {
        return b;
    }
}

int main(void)
{
    int x = 3, y = 8, z = 6;
    int result;

    result = fn(fn(x, y), 2 * z);

    printf("%d", result);

    return 0;
}
```

函数 `fn` 的作用是返回两个数中较大的一个。

先计算内部函数：

```c
fn(x, y) = fn(3, 8)
```

因为 `8` 更大，所以返回 `8`。

原表达式变成：

```c
fn(8, 2 * z)
```

又因为：

```c
z = 6
```

所以：

```c
2 * z = 12
```

于是继续计算：

```c
fn(8, 12)
```

较大值是 `12`，所以最终输出：

```c
12
```

嵌套函数调用的关键是：**先算最内层函数，再把返回值代入外层函数。**

## 十六、自定义函数判断素数

题目：编写程序，自定义一个函数，用来判断一个整数是否为素数。主函数输入一个数，输出它是否为素数。

素数是指大于 1，并且只能被 1 和它本身整除的自然数。例如 `2`、`3`、`5`、`7` 是素数，`1` 不是素数，`4`、`6`、`8`、`9` 也不是素数。

判断一个数 `number` 是否为素数，可以按照以下思路：

如果 `number <= 1`，它一定不是素数。

如果 `number > 1`，就判断它能不能被除 `1` 和它本身之外的数整除。只要存在一个数能整除它，它就不是素数；如果一直找不到这样的数，它就是素数。

代码如下：

```c
#include <stdio.h>

int isPrimeNumber(int number)
{
    if (number <= 1)
    {
        return 0;
    }

    for (int i = 2; i * i <= number; i++)
    {
        if (number % i == 0)
        {
            return 0;
        }
    }

    return 1;
}

int main(void)
{
    int n;

    printf("请输入一个整数：");
    scanf("%d", &n);

    if (isPrimeNumber(n))
    {
        printf("%d 是素数\n", n);
    }
    else
    {
        printf("%d 不是素数\n", n);
    }

    return 0;
}
```

这里用 `return 1` 表示"是素数"，用 `return 0` 表示"不是素数"。因为在 C 语言中，`0` 表示假，非 `0` 表示真，所以可以直接写：

```c
if (isPrimeNumber(n))
```

当函数返回 `1` 时，条件成立；当函数返回 `0` 时，条件不成立。

循环条件写成：

```c
i * i <= number
```

是一个优化写法。因为如果一个数 `number` 有因数，那么至少有一个因数不大于它的平方根。因此只需要判断到平方根附近即可，不必一直判断到 `number - 1`。

如果考试刚开始学习函数，也可以写成更直观的版本：

```c
for (int i = 2; i < number; i++)
{
    if (number % i == 0)
    {
        return 0;
    }
}
```

这个版本更容易理解，但效率略低。

## 十七、`void` 函数

如果一个函数不需要返回值，可以把返回类型写成 `void`。`void` 表示空类型，也就是函数执行完后不返回任何结果。

例如：

```c
void printHello(void)
{
    printf("Hello\n");
}
```

这个函数只负责输出内容，不需要把某个值返回给调用者，所以返回类型为 `void`。

如果函数没有参数，也可以写成：

```c
void printHello()
{
    printf("Hello\n");
}
```

但在标准 C 风格中，更推荐明确写成：

```c
void printHello(void)
```

表示这个函数不接收任何参数。

## 十八、数组作为函数参数

数组也可以作为函数参数。例如，定义一个函数，用来输出数组中的所有元素：

```c
#include <stdio.h>

void printArray(int array[], int size)
{
    for (int i = 0; i < size; i++)
    {
        printf("%d ", array[i]);
    }
}

int main(void)
{
    int numbers[5] = {1, 2, 3, 4, 5};
    int size;

    size = sizeof(numbers) / sizeof(numbers[0]);

    printArray(numbers, size);

    return 0;
}
```

这里：

```c
void printArray(int array[], int size)
```

表示 `printArray` 函数接收一个整型数组和一个整数 `size`。其中 `array` 表示数组，`size` 表示数组元素个数。

调用函数时，只需要写数组名：

```c
printArray(numbers, size);
```

不能写成：

```c
printArray(numbers[], size);
```

也不能写成：

```c
printArray(numbers[5], size);
```

因为传入数组时，实参位置写数组名即可。

这里通过：

```c
sizeof(numbers) / sizeof(numbers[0])
```

计算数组元素个数。

`sizeof(numbers)` 表示整个数组占用的字节数。

`sizeof(numbers[0])` 表示数组中一个元素占用的字节数。

两者相除，就得到数组元素个数。

例如，如果 `int` 占 4 个字节，`numbers` 有 5 个元素，那么：

```c
sizeof(numbers) = 20
sizeof(numbers[0]) = 4
20 / 4 = 5
```

所以数组长度为 5。

注意：这种 `sizeof` 计算数组长度的方法，只能在数组仍然是"真正数组"的地方使用，例如在 `main` 函数中定义的 `numbers`。如果数组作为函数参数传入函数，在函数参数中它会退化为指针，此时在函数内部使用 `sizeof(array)` 不能得到原数组总大小。因此实际编程中，数组作为函数参数时，通常要额外传入数组长度 `size`。

## 十九、数组参数写法的注意点

数组作为函数参数时，常见写法有两种：

```c
void printArray(int array[], int size);
```

也可以写成：

```c
void printArray(int array[5], int size);
```

在很多初学课程中，会说第一种写法表示数组长度不固定，第二种写法表示数组长度为 5。但从 C 语言本质上看，在函数参数位置：

```c
int array[]
```

和：

```c
int array[5]
```

都会被调整为类似：

```c
int *array
```

也就是说，`int array[5]` 并不会真正强制传入的数组一定长度为 5。数组长度仍然需要通过额外参数传入，或者由程序员自己保证。

因此更推荐写成：

```c
void printArray(int array[], int size)
```

这样语义更清楚：数组负责传数据，`size` 负责告诉函数数组有多少个元素。

## 二十、函数参数传递：普通变量与数组的区别

C 语言函数参数传递有一个非常重要的原则：**C 语言本质上都是值传递。**

但是普通变量和数组作为参数时表现不同。

普通变量作为参数时，函数得到的是实参值的一份拷贝。函数内部修改形参，不会影响主函数中的实参。

例如：

```c
#include <stdio.h>

void change(int a)
{
    a = 2;
}

int main(void)
{
    int a = 1;

    change(a);

    printf("%d", a);

    return 0;
}
```

很多初学者可能以为输出是 `2`，但实际输出是：

```c
1
```

原因是调用：

```c
change(a);
```

时，`main` 中的 `a` 的值 `1` 被复制了一份传给 `change` 函数的形参 `a`。虽然两个变量都叫 `a`，但它们不是同一个变量。`change` 函数内部修改的是自己的形参 `a`，不会影响 `main` 函数中的实参 `a`。

如果希望改变主函数中的变量，一种方法是使用函数返回值：

```c
#include <stdio.h>

int change(int a)
{
    a = 2;
    return a;
}

int main(void)
{
    int a = 1;

    a = change(a);

    printf("%d", a);

    return 0;
}
```

此时输出为：

```c
2
```

数组作为参数时，情况不同。数组名作为实参传入函数时，会退化为数组首元素的地址。函数虽然接收到的也是地址值的一份拷贝，但通过这个地址可以访问并修改原数组中的元素。

例如：

```c
#include <stdio.h>

void change(int b[])
{
    b[0] = 2;
}

int main(void)
{
    int b[1] = {0};

    change(b);

    printf("%d", b[0]);

    return 0;
}
```

输出结果是：

```c
2
```

因为 `change` 函数通过数组首地址找到了 `main` 函数中的原数组，并修改了它的第一个元素。

所以考试中常总结为：

普通变量作为参数时，形参变化不影响实参。

数组作为参数时，函数中修改数组元素会影响原数组。

更严格地说，C 语言没有真正的"引用传递"，数组作为参数时发生的是"数组名退化为指针，指针值被传入函数"。但在基础考试中，通常理解为"数组传地址"即可。

## 二十一、数组作为函数参数的例题

看下面代码：

```c
#include <stdio.h>

void function(int a[])
{
    for (int i = 0; i < 4; i++)
    {
        a[i] = i;
    }
}

int main(void)
{
    int b[4];

    function(b);

    for (int i = 0; i < 4; i++)
    {
        printf("%d", b[i]);
    }

    return 0;
}
```

`function` 函数的参数是数组。函数内部通过循环执行：

```c
a[0] = 0;
a[1] = 1;
a[2] = 2;
a[3] = 3;
```

由于数组作为参数传入时，函数可以修改原数组内容，所以 `main` 函数中的数组 `b` 也被修改了。

最终输出结果为：

```c
0123
```

## 二十二、普通变量作为函数参数的例题

看下面代码：

```c
#include <stdio.h>

void function(int x)
{
    x = 10;
    printf("%d,", x);
}

int main(void)
{
    int x = 20;

    function(x);

    printf("%d", x);

    return 0;
}
```

调用 `function(x)` 时，`main` 中的 `x` 的值 `20` 被复制给函数形参 `x`。函数内部执行：

```c
x = 10;
```

修改的是形参 `x`，不会影响主函数中的 `x`。

所以函数内部先输出：

```c
10,
```

回到 `main` 后，主函数中的 `x` 仍然是 `20`，继续输出：

```c
20
```

因此最终输出结果为：

```c
10,20
```

## 二十三、本节核心总结

数组用于存储一组类型相同的数据。一维数组可以看作一排连续的数据，二维数组可以看作表格。数组下标从 0 开始，长度为 `n` 的数组合法下标是 `0` 到 `n - 1`，越界访问是数组题中最常见的错误。

一维数组初始化时，如果初值不足，剩余元素自动补 0；如果给出初始化列表，可以省略数组长度。二维数组初始化时，只有第一维可以省略，后面的维度不能省略。

遍历数组通常使用 `for` 循环，循环变量一般从 `0` 开始，条件写成 `i < 数组长度`。处理二维数组时，常用双重循环，外层控制行，内层控制列。

函数是具有特定功能的代码块，可以提高代码复用性。函数定义包括返回类型、函数名、参数列表和函数体。函数调用时，实参按照位置传递给形参。如果函数定义写在调用之后，需要提前写函数声明。

普通变量作为函数参数时，函数内部修改形参不会影响实参；数组作为函数参数时，函数可以通过数组地址修改原数组元素。数组作为函数参数时通常需要额外传入数组长度，因为函数内部无法可靠地通过 `sizeof` 得到原数组元素个数。
