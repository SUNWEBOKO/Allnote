# C语言运算符：算术、关系与逻辑运算复习讲义

## 本节主线

本节介绍C语言中四类核心运算符：算术运算符处理数值计算，赋值与复合赋值运算符简化计算与赋值操作，关系运算符比较大小，逻辑运算符组合多个条件。理解每类运算符的优先级规则、掌握与数学习惯不同的C语言特殊规定，并能通过"代入求值、逐步拆解"的方法准确计算复杂表达式的值，是期末考试选择题和读程序题的关键。

## 1. 算术运算符与基本运算规则

### 1.1 五种基本算术运算符

C语言提供了五种基本的算术运算符，用来处理常规的数学计算。它们分别是：

- `+`：加法运算符，如 `3 + 2` 结果为 `5`
- `-`：减法运算符，如 `5 - 2` 结果为 `3`
- `*`：乘法运算符，如 `3 * 4` 结果为 `12`
- `/`：除法运算符
- `%`：求余运算符（模运算符）

这几类运算符的写法与用法和数学中的习惯基本一致，但也有C语言自身的特殊规定，这些规定正是考试的易错点。

### 1.2 整数除法的截断规则（考试核心陷阱）

C语言规定：当除法运算符 `/` 两边的操作数**都是整数**时，执行的是整数除法，结果**必然是一个整数**。具体的处理方式是直接截断小数部分，而不是四舍五入。这是本章最容易出错的知识点之一。

举个例子：

- `5 / 2`：正常数学结果应为 `2.5`，但因为 `5` 和 `2` 都是整型，所以C语言直接把小数部分丢弃，结果得到 `2`。
- `10 / 3`：结果应为 `3`，而不是 `3.333...`

那么，什么时候才能保留小数部分呢？只要除号两边的操作数中**至少有一个是浮点数（如 float 或 double 类型）**，除法就会按浮点数除法进行，结果能够保留小数。

- `5.0 / 2`：结果为 `2.5`。因为 `5.0` 是一个浮点数，所以整条表达式按浮点运算处理。
- `5 / 2.0`：结果同样是 `2.5`，道理同上。

这个规则在做题目时需注意。很多程序运行结果与预期不符，根源就在于忽略了数据类型对除法行为的影响。

### 1.3 求余运算符 `%` 的使用限制

`%` 是求余运算符，它求得的是整数除法之后的余数。例如 `10 % 3`，10除以3商3余1，因此结果为 `1`。

求余运算符有一个严格的使用限制：**`%` 两边的操作数必须都是整数。** 在数学中，求余这个概念本质上就是针对整数除法而言的，无法对小数进行带余除法。所以像 `10.0 % 3` 这样的写法在C语言中是错误的，考试中如果看到这种表达式，可以直接判定为语法错误。

### 1.4 例题 1：整数除法对复杂表达式的影响

**题目**：表达式 `3 * 20 / 4 % 10` 的值是多少？表达式 `10 / 3 * 9 % 10 / 2` 的值是多少？

**分析思路**：考察算术运算符的同级从左往右规则，以及 `/` 在整数间的截断规则。

**解答**：
-   **第一个表达式 `3 * 20 / 4 % 10`**
    1.  `3 * 20 = 60`
    2.  `60 / 4 = 15`
    3.  `15 % 10 = 5`
    最终结果为 `5`。

-   **第二个表达式 `10 / 3 * 9 % 10 / 2`**
    1.  `10 / 3`：这里 `10` 和 `3` 都是整数，因此执行整数除法，结果为 `3`。
    2.  `3 * 9 = 27`
    3.  `27 % 10 = 7`
    4.  `7 / 2`：`7` 和 `2` 都是整数，整数除法的结果为 `3`。
    最终结果为 `3`。

**易错点**：在做 `10 / 3` 这一步时，不自觉地按数学习惯得到 `3.33...`，然后用这个小数去乘9，算出一个不同的结果。需注意：**先看数据类型，再定计算规则**。

## 2. 赋值运算符与复合赋值运算符

### 2.1 赋值运算符 `=` 的本质

赋值运算符 `=` 的作用，是把**等号右边的值**赋给**等号左边的变量**。这里有两个关键点必须清楚：

1.  **左边必须是一个变量**，不能是常量或表达式。例如 `7 = x;` 是错误的，因为 `7` 是一个常量，不能把一个值赋给一个常量。
2.  **赋值表达式的值**就是等号左边变量被赋予的那个新值。虽然考试不常直接问这个概念，但理解它有助于看懂复杂的连续赋值。

关于连续赋值，要注意区分两种情况：

- **在变量定义时，不允许连续初始化。** 也就是说，`int x = y = 10;` 这种写法是错误的。初始化只能逐个进行。
- **在变量定义完成之后，允许连续赋值。** 例如：
  ```c
  int x, y;
  x = y = 10;  // 这是正确的。等价于 y = 10; x = y;
  ```
  连续赋值的求值顺序是**从右向左**结合的。先把 `10` 赋给 `y`，这个赋值表达式的值就是 `10`，然后再把这个 `10` 赋给 `x`。

### 2.2 复合赋值运算符：一种简写规则

为了让代码更简洁，C语言提供了复合赋值运算符。它的本质是把一次算术运算和一次赋值操作合并到了一起。

最经典的例子是 `a = a + 2;`，它可以简写为 `a += 2;`。这两种写法是**完全等价**的。

理解了加法的形式，其他运算也遵循完全相同的模式：

- `a -= 2;` 等价于 `a = a - 2;`
- `a *= 2;` 等价于 `a = a * 2;`
- `a /= 2;` 等价于 `a = a / 2;`
- `a %= 2;` 等价于 `a = a % 2;`

这种运算符在处理复杂表达式的计算题时经常出现。解题的唯一可靠方法，就是**从右往左，将复合赋值运算符"完整展开"成它的等价形式**。

### 2.3 例题 2：复合赋值与自减运算符的结合

**题目**：若有定义 `int m = 5, y = 2;`，计算表达式 `y += y -= m *= y` 之后，`y` 的值是多少？

**分析思路**：本题考察复合赋值的展开和从右向左的计算顺序。核心方法是将每一个复合赋值运算符都展开成它等价的简单赋值形式。

**解答**：
1.  **从右向左看，找到最右边的复合赋值运算 `m *= y`。**
    它等价于 `m = m * y`。将当前值 `m=5`, `y=2` 代入，得到 `m = 5 * 2 = 10`。
    此时，`m` 的值更新为 10。整个表达式可以看作变成了 `y += y -= 10`。
2.  **接着处理 `y -= 10`。**
    它等价于 `y = y - 10`。将当前值 `y=2` 代入，得到 `y = 2 - 10 = -8`。
    此时，`y` 的值更新为 -8。整个表达式现在变成了 `y += -8`。
3.  **最后处理 `y += -8`。**
    它等价于 `y = y + (-8)`。将当前值 `y = -8` 代入，得到 `y = -8 + (-8) = -16`。

**答案**：表达式计算结束后，`y` 的值为 `-16`。

**易错点**：没有严格按照"从右向左"的顺序展开，而是先把右边的 `y` 误认为初始值 `2` 来计算 `m *= y` 之外的运算，导致结果错误。每一步展开后，变量的值都已经发生了改变，必须用最新值参与下一步计算。

## 3. 算术表达式求值的优先级与结合性

当多个运算符出现在同一个表达式中时，C语言会按照一套固定的规则来决定先算谁、后算谁，这套规则就是**优先级**和**结合性**。

**优先级**决定哪个运算符先参与运算——优先级高的运算符先于优先级低的运算符计算。**结合性**则解决优先级相同时的计算顺序问题——大多数运算符从左往右结合，赋值运算符等少数运算符从右往左结合。两者配合，即可唯一确定任意表达式的求值顺序。

对于算术运算符，规则与数学中的习惯高度一致：

- **先乘除，后加减。** `*`、`/`、`%` 的优先级高于 `+` 和 `-`。
- **同优先级从左往右。** 如果表达式中只剩同一优先级的运算符（比如只有加和减，或只有乘和除与求余），则按照从左到右的顺序依次计算。

更重要的是，当算术运算符和其他类型运算符混用时，优先级规则如下（**此规则覆盖后续所有章节，务必记住**）：

**算术运算符 > 关系运算符 > 逻辑运算符（`&&` 和 `||`，不含 `!`），赋值运算符优先级最低。**

这个总优先级顺序是分析一切复杂表达式的纲领。

## 4. 自增自减运算符：`++` 与 `--`

### 4.1 前缀形式与后缀形式的根本区别

自增（`++`）和自减（`--`）运算符让变量自身加1或减1。它们可以放在变量的前面（前缀），也可以放在后面（后缀），而这两种写法的区别是考试反复考察的核心。

假设有一个整型变量 `a`，我们来看看四种情况：

| 表达式 | 核心行为 | 表达式自身的计算结果 | 变量 `a` 的最终值 |
| :--- | :--- | :--- | :--- |
| `++a` (前缀) | **先加后用** | `a+1` (加1之后的新值) | `a+1` |
| `a++` (后缀) | **先用后加** | `a` (加1之前的旧值) | `a+1` |
| `--a` (前缀) | **先减后用** | `a-1` (减1之后的新值) | `a-1` |
| `a--` (后缀) | **先用后减** | `a` (减1之前的旧值) | `a-1` |

我们可以通过一个具体的例子来彻底理解。设 `a` 初始值为 `5`：

- **`b = ++a;`** ：这是**前缀**，遵循"**先加后用**"。先把 `a` 加 `1` 变成 `6`，然后再使用这个新值 `6` 赋给 `b`。结果：`a=6, b=6`。
- **`b = a++;`** ：这是**后缀**，遵循"**先用后加**"。先使用 `a` 的旧值 `5` 赋给 `b`，然后再把 `a` 加 `1` 变成 `6`。结果：`a=6, b=5`。

自减运算符 `--` 的原理完全相同，只是把"加1"换成"减1"。

`++` 和 `--` 运算符不仅可以用于整型变量，同样也可以用于浮点型（float, double）变量。其效果是让浮点变量的值增加或减少1.0。考试中若有选项声称"只能用于整数"，那是错误的。

### 4.2 口诀记忆

为应对考试，可以牢固记忆这个口诀：

- **加加在前，先加后用；加加在后，先用后加。**
- **减减在前，先减后用；减减在后，先用后减。**

在表达式中见到 `++` 或 `--`，第一反应就应该是判断它是前缀还是后缀，然后套用口诀。

## 5. 逗号表达式与强制类型转换

### 5.1 逗号运算符与逗号表达式

逗号运算符 `,` 的优先级是所有运算符中**最低**的。由一对圆括号括起来的、用逗号分隔的多个表达式，称为逗号表达式。其一般形式为：

`(表达式1, 表达式2, ..., 表达式n)`

逗号表达式的求值规则是：**从左到右依次计算每一个表达式，而整个逗号表达式的值，就等于最右边那个表达式的值。**

例如：`(2, 3, 4)`，依次计算 `2`, `3`, `4`，而整个表达式的值就是 `4`。

### 5.1.1 有括号与无括号的区别

这是一个常见的陷阱。我们对比下面两条语句：

- `z = (2, 3, 4);` 这里有括号，因此 `(2, 3, 4)` 是一个完整的逗号表达式，它的值是 `4`，赋值给 `z`，`z` 的值为 `4`。
- `z = 2, 3, 4;` 这里没有括号，情况就完全不同了。由于逗号优先级最低，这句话会被解读为三个独立的表达式：
  1.  `z = 2`  （赋值表达式，`z` 被赋予2）
  2.  `3`      （一个单纯的数值，不产生任何影响）
  3.  `4`      （同上）
  因此，变量 `z` 的值最终为 `2`。

记住这个关键点：**只有当被赋值号和逗号同时出现时，必须立刻比较逗号和赋值号的优先级。由于逗号优先级最低，赋值操作会优先结合。**

### 5.2 强制类型转换

强制类型转换可以将一个表达式的值**临时**地转换为另一种指定的类型。其语法格式是在表达式前加上用括号括起来的目标类型名：

`(目标类型) 表达式`

例如，`(int) 3.14` 会将浮点数 `3.14` 强制转换为整型。转换规则是**直接截断小数部分**，而不是四舍五入。无论小数部分是 `.14` 还是 `.99`，结果都是 `3`。

### 5.2.1 强制类型转换的语法陷阱

- **正确格式**：目标类型名必须写在括号里，如 `(int)f` 是正确的。
- **错误格式**：
  - `int(f)`：没有这种语法结构。
  - `int(3.14)`：同样错误，不能把数值常量放在括号里，企图让类型名变成函数一样。
  考试中这类干扰选项出现频率很高，务必记住强制类型转换的唯一合法形式是 `(类型)表达式`。

### 5.3 例题 3：逗号表达式与自增运算符的综合题

**题目**：执行语句 `x = (a=3, b=a--);` 后，`x`, `a`, `b` 的值依次是多少？

**分析思路**：本题检验逗号表达式的求值规则和"先用后减"规则的综合运用。

**解答**：
1.  这是一个逗号表达式，它的值是最右边表达式的值，然后赋给 `x`。
2.  从左到右计算逗号内的表达式：
    -   第一个表达式 `a=3`，`a` 变为 `3`。
    -   第二个表达式 `b=a--`。这里的 `a--` 是后缀自减，遵循"**先用后减**"。
        -   "先用"：将 `a` 的当前值 `3` 赋给 `b`，所以 `b=3`。
        -   "后减"：赋值完成后，`a` 自减1，变为 `2`。
3.  现在，逗号表达式内 `a=3` 和 `b=a--` 都已计算完毕。这整个逗号表达式的值，就是最右边表达式 `b=a--` 的值，即 `b` 被赋予的值 `3`。
4.  最后，将这个值 `3` 赋给 `x`，所以 `x=3`。

**答案**：最终结果为 `x=3, a=2, b=3`。

## 6. 关系运算符与关系表达式

### 6.1 六种关系运算符

关系运算符用来比较两个值的大小，结果是一个逻辑真或假。在C语言中，关系运算符共六种：

| 运算符 | 含义 | 示例 |
| :--- | :--- | :--- |
| `>` | 大于 | `9 > 8` |
| `<` | 小于 | `8 < 9` |
| `>=` | 大于或等于 | `10 >= 9` |
| `<=` | 小于或等于 | `9 <= 10` |
| `==` | 等于 | `10 == 10` |
| `!=` | 不等于 | `9 != 10` |

这里有一个**致命的混淆点**：`=` 是赋值运算符，`==` 是等于关系运算符。它们的作用天差地别，绝对不能混淆。在 `if` 条件中误写 `if (a = 5)` 而本意是 `if (a == 5)`，是一个经典且极难调试的逻辑错误。考试中，看到单个 `=` 立刻要反应是"赋值"，看到两个 `=` 才是"比较是否相等"。

### 6.2 关系表达式的值：只有 1 和 0

由关系运算符连接起来的表达式叫关系表达式。它的结果**有且仅有两种可能**：

- 如果比较关系成立，结果为"真"，用整型数字 `1` 表示。
- 如果比较关系不成立，结果为"假"，用整型数字 `0` 表示。

例如：
- `9 > 8` 的结果是 `1`。
- `7 < 6` 的结果是 `0`。
- `(a=10) == 10` ，如果 `a` 的值确实是 `10`，则结果为 `1`。

需要说明的是，C89 标准中没有内置的布尔类型（`bool` 是 C99 才引入的），因此C语言传统上用整数 `1` 和 `0` 来表示逻辑真和假。任何关系表达式的值，不是 1，就是 0。

### 6.3 连续比较的陷阱：从编程角度理解

如果写出 `x < y < z` 这样的表达式，C语言的解释方式与数学是完全不同的。

假设 `x=1, y=0, z=2`，计算 `x < y < z`。
- **错误思路（数学思维）**：1 < 0 < 2 显然是错的，结果应为 0（假）。
- **正确思路（C语言思维）**：C语言会依照**从左往右**的结合性和优先级规则来计算。
  1.  先计算 `x < y`，即 `1 < 0`。这个关系表达式为假，结果为 `0`。
  2.  然后，表达式变为 `0 < z`，即 `0 < 2`。这个关系表达式为真，最终结果为 `1`。

因此，这段代码的最终结果是 `1`（真），与数学直觉相悖。**不要在C语言中写出 `x < y < z` 这种链式比较来表达"变量y介于x和z之间"的意图。** 正确的做法是使用逻辑运算符。

## 7. 逻辑运算符与逻辑表达式

逻辑运算符专门用来连接两个或多个关系表达式，以表达更复杂的条件。

### 7.1 三种逻辑运算符

| 运算符 | 名称 | 功能说明 |
| :--- | :--- | :--- |
| `&&` | 逻辑与（AND） | 两边表达式**均为真**，整个表达式才为真。否则为假。 |
| `\|\|` | 逻辑或（OR） | 两边表达式**至少有一个为真**，整个表达式即为真。否则为假。 |
| `!` | 逻辑非（NOT） | 对紧跟其后的表达式取反。真变假，假变真。 |

**逻辑运算是建立在关系运算基础上的。** 运算规则可以总结为：
-   `&&` (与)：全真才真，一假全假。
-   `||` (或)：一真即真，全假才假。
-   `!` (非)：真假互换。

### 7.2 "非零即为真"原则

逻辑运算符的操作数不仅可以是关系表达式（结果为1或0），也可以是任意数值。当操作数是数值时，C语言遵循"**非零即为真**"（或"零为假"）的原则：

- 任何**非零**的数值（如 1, -5, 3.14），在被当做逻辑量使用时，都被视为"真"。
- 只有数值 `0` 和浮点数 `0.0`，才被视为"假"。

基于此，`!6` 的计算过程是：`6` 非零，所以为"真"。`!` 对"真"取反，结果为"假"，即 `0`。所以 `!6` 的值是 `0`。这个知识点经常作为逻辑运算的基础考点来考察。

### 7.3 综合优先级排序（最终版）

现在我们可以给出一个更清晰的综合优先级排序，从上到下优先级逐渐降低：

1.  **逻辑非 `!`**（最高，仅次于一元的 `++`/`--` 等）
2.  **算术运算符** (`*`, `/`, `%`, `+`, `-`)
3.  **关系运算符** (`>`, `<`, `>=`, `<=`, `==`, `!=`)
4.  **逻辑与 `&&`**
5.  **逻辑或 `||`**
6.  **赋值运算符** (`=`, `+=`, `-=` 等) 和 **逗号运算符** (最低)

记住，在一团乱麻的表达式面前，解题第一步永远是**按照这个优先级表来划分运算顺序**。

## 8. 逻辑表达式的经典题型与短路原则

### 8.1 如何正确表示"X 介于 Y 和 Z 之间"

这是逻辑运算符最直接的应用。要表达数学中的 `Y ≤ X ≤ Z`，在C语言中不能写成 `Y <= X <= Z`。正确的写法是使用逻辑与 `&&`，将两个关系表达式连接起来：

`Y <= X && X <= Z`

这表示"`X` 大于等于 `Y`" **同时** "`X` 小于等于 `Z`" 这两个条件都成立。

类似的，所有涉及"同时满足"的复合条件，都需要用 `&&` 来连接。例如经典的闰年判断（年份能被4整除**且**不能被100整除，**或者**能被400整除），最终的复杂表达式就是由多个关系表达式通过 `&&` 和 `||` 组合而成。

### 8.2 逻辑运算的"短路原则"（考试算法题核心）

这是C语言为提高执行效率而做的规定，在读程序结果题中经常出现。短路原则是指，在计算 `&&` 和 `||` 表达式时，一旦能根据当前已算出的部分确定整个表达式的最终结果，就不再计算剩下的部分。

- **`表达式A && 表达式B` 的短路**：
  如果计算完 `A` 发现其值为"假"（即 `0`），那么无论 `B` 是什么结果，整个 `&&` 表达式的结果都必然是"假"。因此，`B` **不会被执行**。

- **`表达式A || 表达式B` 的短路**：
  如果计算完 `A` 发现其值为"真"（即非 `0`），那么无论 `B` 是什么结果，整个 `||` 表达式的结果都必然是"真"。因此，`B` **不会被执行**。

### 8.3 例题 4：短路原则与赋值操作

假设 `a=1, b=5, c=3, d=2, m=2, n=2`，看这个表达式 `(m = a > b) && (n = c > d)`。
1.  先计算左侧的 `m = (a > b)`。已知 `1 > 5` 为假（值为0），赋值后 `m` 的值为 `0`。
2.  对于 `&&` 运算符，左侧结果为 `0`，此时已能确定整个表达式为假。
3.  短路发生，右侧的 `n = c > d` **根本不会被执行**。
4.  因此，变量 `n` 的值保持原样，仍为 `2`。

**结论**：在做包含逻辑运算符且右侧含赋值、自增/自减等操作的题目时，需先判断左侧表达式的结果，如果满足短路条件，右侧一切操作都不会执行。这是C语言的标准行为，不是程序错误。
