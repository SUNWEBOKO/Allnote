## 一、C语言程序的基本结构

学习 C 语言时，最先要掌握的是一个最基本的程序结构。几乎所有初学者都会从下面这段程序开始：

```c
#include <stdio.h>
int main(){ 
   printf("hello c");
   return 0;
}
```

这段代码虽然很短，但是包含了 C 语言程序最核心的几个组成部分：头文件包含、`main` 函数、函数体、输出语句和返回语句。

在 C 语言中，程序的执行入口是 `main` 函数。当程序开始运行时，并不是从文件中的第一行普通代码随意执行，而是从 `main` 函数开始执行；当 `main` 函数执行结束时，整个程序通常也就结束了。因此可以记住一个非常重要的考点：

**C语言程序总是从 `main` 函数开始执行。**

一个完整的 C 程序中通常有且只能有一个 `main` 函数。虽然程序可以包含很多其他函数，但 `main` 函数是程序的入口函数。

函数是构成 C 语言程序的基本单位。现在还没有系统学习函数时，可以先简单理解为：函数就是一段具有特定功能的程序代码。以后学习函数时，会进一步理解函数的定义、调用、参数和返回值。

在上面的代码中：

```c
int main(){    ...}
```

其中一对花括号 `{ }` 表示函数体。函数体里面写的是这个函数要执行的语句。例如：

```c
printf("hello c");
```

这一句的作用是输出字符串 `hello c`。

而第一行：

```c
#include <stdio.h>
```

表示包含标准输入输出头文件。因为 `printf` 函数的声明在 `stdio.h` 这个头文件中，所以如果想正常使用 `printf`，通常需要在程序开头写上：

```c
#include <stdio.h>
```

这里的 `stdio.h` 很容易被误写成 `studio.h`。`stdio` 是 standard input/output 的缩写，表示"标准输入输出"，不是英文单词 `studio`。考试或编程时一定要注意不要拼错。

## 二、基本程序结构中的常见易错点

初学 C 语言时，最容易犯的错误主要集中在拼写、符号和语句格式上。

首先，`stdio.h` 不能写成 `studio.h`。正确写法是：

```c
#include <stdio.h>
```

错误写法是：

```c
#include <studio.h>
```

其次，`main` 不能随意写错。例如把 `main` 写成 `mian`、`mai` 或其他形式，都会导致程序入口无法正确识别。

再次，`return 0;` 中 `return` 和 `0` 中间必须有空格，不能写成：

```c
return0;
```

因为 `return0` 会被看成一个整体标识符，而不是 `return` 关键字加数字 `0`。

最后，C语言中的语句一般要以英文分号 `;` 结尾。例如：

```c
printf("hello c");
return 0;
```

如果漏掉分号，程序通常会编译报错。注意这里必须是英文分号 `;`，不能写成中文分号 `；`。

## 三、典型例题：程序入口与基本单位

### 例题1：什么是构成 C 语言程序的基本单位？

**答案：函数。**

解析：C语言程序由一个或多个函数组成。函数是 C 语言程序的基本单位，其中 `main` 函数是程序的入口函数。

### 例题2：C语言程序从哪里开始执行？

**答案：从 `main` 函数开始执行。**

解析：无论 `main` 函数是否写在源文件最前面，程序运行时都从 `main` 函数开始执行。

### 例题3：以下说法正确的是？

A. C语言程序总是从第一个定义的函数开始执行。  
B. 在 C 语言程序中，要调用的函数必须写在 `main` 函数中进行定义。  
C. C语言程序总是从 `main` 函数开始执行。  
D. C语言程序的 `main` 函数必须放在程序的开始部分。

**答案：C。**

解析：A 错，程序不是从第一个定义的函数开始执行，而是从 `main` 函数开始执行。B 错，函数可以定义在 `main` 函数外部。D 错，`main` 函数不一定必须写在程序最前面。

## 四、关键字与标识符

### 4.1 关键字

关键字是 C 语言本身已经规定好的、具有特殊含义的单词。这些单词不能被用户拿来随便命名变量或函数。

例如常见的 C 语言关键字有：

```c
int return char float double short long unsigned for while if else switch case break continue void struct union
```

注意：`int`、`return`、`for`、`while` 等是 C 语言关键字。

但是需要特别纠正一个容易混淆的点：`main` 不是 C 语言关键字，它是一个特殊的函数名；`include` 也不是 C 语言关键字，它属于预处理指令中的一部分。考试中如果严格问"C语言关键字"，应以标准关键字表为准。

### 4.2 标识符

在编程中，我们经常需要给变量、函数等命名，这些名字就叫做标识符。

合法标识符必须满足三条规则：

第一，标识符只能由字母、数字和下划线 `_` 构成。

第二，标识符不能以数字开头。

第三，标识符不能是 C 语言关键字。

例如：

```c
x sum count a123 _str1 num_2
```

这些都是合法标识符。

而下面这些是不合法的：

```c
3abc a+b x-y case for a%b
```

其中，`3abc` 错在以数字开头；`a+b`、`x-y`、`a%b` 错在包含了加号、减号、百分号等非法字符；`case` 和 `for` 错在它们是 C 语言关键字。

## 五、典型例题：标识符判断

### 例题4：下列 C 语言用户标识符中合法的是？

A. `3ax`  
B. `x`  
C. `case`  
D. `e-2`  
E. `union`

**答案：B。**

解析：`3ax` 以数字开头，不合法；`case` 和 `union` 是关键字，不合法；`e-2` 中有减号，不合法；`x` 符合标识符规则，因此合法。

### 例题5：下列选项中正确的 C 语言标识符是？

A. `%x`  
B. `a+b`  
C. `a123`  
D. `123`

**答案：C。**

解析：`%x` 中有 `%`，不合法；`a+b` 中有 `+`，不合法；`123` 以数字开头，不合法；`a123` 只由字母和数字组成，且不以数字开头，也不是关键字，因此合法。

### 例题6：下列四组字符串中，都可以作为 C 语言程序标识符的是？

A. `printf`，`_3d`，`db8`，`abc`  
B. `i/a`，`am`，`one_half`，`star$`，`3pai`  
C. `str_1`，`cpp`，`pow`，`while`  
D. 含有特殊符号如 `#`、`.` 等的一组字符串

**答案：A。**

解析：A 中所有标识符均合法。`printf` 不是 C 语言关键字，它是标准库函数名，虽然不建议随意用作变量名，但从标识符规则本身看是合法的。`_3d` 以下划线开头是允许的。B 中有 `/`、`$`，并且 `3pai` 以数字开头。C 中 `while` 是关键字。D 中出现了 `#`、`.` 等非法字符。

## 六、进制基础

十进制使用数字 `0` 到 `9`，规则是"逢十进一"。

计算机相关内容中，还经常会遇到二进制、八进制和十六进制。

二进制使用 `0` 和 `1`，例如：

```c
10100110
```

八进制使用 `0` 到 `7`，例如：

```c
257
```

但是 `815` 不是合法的八进制数，因为八进制中没有数字 `8`。

十六进制使用 `0` 到 `9` 以及 `A` 到 `F`。其中：

- A 表示 10
- B 表示 11
- C 表示 12
- D 表示 13
- E 表示 14
- F 表示 15

例如：

```c
FF15D
```

可以作为十六进制数的形式。

## 七、C语言中的整数常量表示

在标准 C 语言中，整数常量常见的写法包括十进制、八进制和十六进制。

十进制整数正常书写即可，例如：

```c
10
123
```

八进制整数以前导 `0` 开头，例如：

```c
017
010
```

注意：`010` 在 C 语言中不是十进制的 10，而是八进制的 `10`，换算成十进制是 8。

十六进制整数以前缀 `0x` 或 `0X` 开头，例如：

```c
0x10
0X1F
```

其中 `0x10` 表示十六进制的 `10`，换算成十进制是 16。

标准 C 的整数常量主要掌握十进制、八进制、十六进制。补充说明：一些现代编译器或标准扩展可能支持 `0b1010` 这样的二进制写法，不过基础考试一般不以它作为标准 C 的常规写法。

### 例题7：下面关于 C 语言数值表示方法正确的是？

A. `0x10` 表示十六进制。  
B. `010` 表示十进制的 10。  
C. `101010` 是合法的二进制写法。  
D. `10` 表示十六进制的 10。

**答案：A。**

解析：`0x10` 是十六进制写法；`010` 是八进制，不是十进制；`101010` 在普通 C 语言中会被看作十进制整数，不是二进制写法；`10` 默认是十进制整数。

## 八、变量的概念与声明

变量是程序运行过程中可以保存数据、并且其值可以改变的量。

例如：

```c
int count;
```

这行代码声明了一个名为 `count` 的整型变量。

如果声明变量时直接给它一个初始值，叫做初始化。例如：

```c
int number = 100;
```

这表示声明一个整型变量 `number`，并将它初始化为 `100`。

之后还可以重新给变量赋值：

```c
number = 200;
```

这表示把变量 `number` 的值修改为 `200`。

这里要注意两个概念：

```c
int number = 100;
```

这是"声明并初始化"。

```c
number = 200;
```

这是"赋值"。

变量使用时必须遵守一个重要规则：

**变量必须先声明，后使用。**

例如：

```c
int x;
x = 10;
```

这是正确的。

但是：

```c
x = 10;
```

如果前面没有声明过 `x`，就是错误的。

## 九、变量声明的常见写法与易错点

多个变量可以在一条语句中同时声明，中间用逗号隔开：

```c
int a, b, c;
```

这表示同时声明三个整型变量 `a`、`b`、`c`。

错误写法如下：

```c
int a; b; c;
```

这并不表示同时声明了 `a`、`b`、`c`。因为第一个分号已经结束了 `int a;` 这条声明语句，后面的 `b;` 和 `c;` 并没有类型说明，因此不是正确的变量声明。

声明变量时不能漏掉分号：

```c
int a
```

这是错误的，正确写法应为：

```c
int a;
```

同一个作用域中，变量不能重复声明。例如：

```c
int a = 10;
int a = 20;
```

这是错误的，因为 `a` 被重复声明了。

还要注意，C 语言不允许用下面这种方式连续初始化：

```c
int x = y = 10;
```

这通常是错误的，因为在声明 `x` 时，`y` 尚未被正确声明。

但是，如果 `x` 和 `y` 已经声明过，则可以连续赋值：

```c
int x, y;
x = y = 10;
```

这是正确的。它的执行逻辑是先把 `10` 赋给 `y`，再把 `y` 的值赋给 `x`，最终 `x` 和 `y` 都是 `10`。

### 例题8：下面的变量声明中正确的是？

A. `int : a;`  
B. `int a; b; c;`  
C. `int a`  
D. `int a, b, c;`

**答案：D。**

解析：A 中冒号错误；B 只有 `a` 被正确声明，`b` 和 `c` 没有类型说明；C 缺少分号；D 是多个变量同时声明的正确写法。

### 例题9：下面的变量声明和赋值中正确的是？

A. `int x = y = 10;`  
B. `int a = 10; int a = 20;`  
C. `int x, y; x = y = 10;`  
D. `x = 10;`

**答案：C。**

解析：A 是错误的连续初始化写法；B 重复声明变量 `a`；D 中 `x` 未声明就使用；C 先声明 `x` 和 `y`，再连续赋值，是正确的。

## 十、C语言的数据类型

在基础阶段，常见的数据类型主要包括字符型、整型和浮点型。

在通常的 32 位环境下，可以按下面方式记忆：

| 类型 | 类型名 | 常见字节数 | 说明 |
| --- | --- | --- | --- |
| 字符型 | `char` | 1 | 存放单个字符 |
| 短整型 | `short` | 2 | 存放整数 |
| 整型 | `int` | 4 | 存放整数 |
| 长整型 | `long` | 4 | 存放整数，具体大小与系统有关 |
| 单精度浮点型 | `float` | 4 | 存放小数 |
| 双精度浮点型 | `double` | 8 | 存放小数，精度通常高于 `float` |

注意：不同编译器、不同平台下，部分类型占用字节数可能不同。考试如果明确说"通常 32 位环境下"，一般按上表记忆。

字节数越大，通常能表示的范围越大；对于浮点类型来说，通常精度也更高。例如 `double` 比 `float` 占用更多字节，因此它通常能表示更高精度的小数。

## 十一、无符号类型 `unsigned`

`unsigned` 表示"无符号"。被 `unsigned` 修饰的数据类型不能表示负数，只能表示大于等于 0 的数。

例如普通的：

```c
int a;
```

可以表示正数、0 和负数。

而：

```c
unsigned int b;
```

只能表示非负整数，也就是 `0` 和正整数，不能表示负数。

### 例题10：通常 32 位环境下，`int` 和 `char` 分别占多少字节？

**答案：`int` 通常占 4 字节，`char` 占 1 字节。**

### 例题11：`sizeof(double)` 的值通常是多少？

**答案：8。**

解析：`sizeof` 用来获取某种类型或某个变量所占用的字节数。通常情况下，`double` 占 8 字节，所以 `sizeof(double)` 的值通常是 8。

## 十二、字符型 `char`

字符型用于存放单个字符，用关键字 `char` 表示。字符常量必须用单引号括起来。

例如：

```c
'A' 'B' 'C' '1' '2'
```

定义字符变量的写法如下：

```c
char c = 'A';
```

这表示定义一个字符型变量 `c`，并把字符 `'A'` 赋给它。

注意：单引号中通常只能放一个字符。例如：

```c
'A'
```

是字符常量。

而：

```c
'AB'
```

在基础考试语境下通常认为不符合"单个字符"的要求，不应这样写。

字符串要用双引号，例如：

```c
"A"
"hello"
```

其中 `"A"` 是字符串，不是字符；`'A'` 才是字符。

## 十三、字符的本质：ASCII码

在 C 语言中，字符本质上是以整数编码形式存储的。常见编码表是 ASCII 码表。

例如字符 `'A'` 对应的 ASCII 十进制值是 65，也可以用十六进制 `0x41` 或八进制转义 `'\101'` 表示。

下面两种写法在效果上可以等价：

```c
char c = 'A';
```

和：

```c
char c = 65;
```

因为 ASCII 码中十进制 65 对应的字符就是大写字母 `A`。

需要重点记忆三组常见 ASCII 范围：

- 字符 `'0'` 到 `'9'`：ASCII 值为 48 到 57
- 字符 `'A'` 到 `'Z'`：ASCII 值为 65 到 90
- 字符 `'a'` 到 `'z'`：ASCII 值为 97 到 122

这些范围经常用于考试题，尤其是字符与数字之间的转换、大写字母与小写字母之间的转换。

例如：

```c
'A' + 32
```

结果对应小写字母 `'a'`。

因为 `'A'` 的 ASCII 值是 65，而 `'a'` 的 ASCII 值是 97，两者相差 32。

因此：

```c
char c = 'A' + 32;
```

此时 `c` 的值就是 `'a'`。

## 十四、字符数字与真正数字的转换

这是字符型中非常经典的考点。

如果有：

```c
char c = '9';
```

此时 `c` 存储的是字符 `'9'`，不是整数 `9`。字符 `'9'` 的 ASCII 值是 57。

如果直接计算：

```c
c * 5
```

实际相当于：

```c
57 * 5
```

结果是 285，而不是 45。

如果想把字符 `'9'` 转换成真正的整数 `9`，应该写：

```c
int a = c - '0';
```

因为：

```c
'9' - '0' = 57 - 48 = 9
```

然后再计算：

```c
int b = a * 5;
```

结果就是：

```c
45
```

完整代码如下：

```c
char c = '9';
int a = c - '0';
int b = a * 5;
```

这个技巧可以推广：

- `'7' - '0' = 7`
- `'6' - '0' = 6`
- `'3' - '0' = 3`

所以要把字符数字转成真正的整数数字，只需要减去字符 `'0'`。

## 十五、转义字符

有些字符不能直接写出来，或者直接写出来会产生歧义，这时需要使用转义字符。转义字符以反斜杠 `\` 开头。

常见转义字符包括：

| 转义字符 | 含义 |
| --- | --- |
| `'\0'` | 空字符，数值为 0 |
| `'\n'` | 换行 |
| `'\''` | 单引号字符 |
| `'\"'` | 双引号字符 |
| `'\\'` | 反斜杠字符 |

例如：

```c
printf("hello\nc");
```

其中 `\n` 表示换行。

虽然 `'\n'` 看起来由两个字符组成：反斜杠和 `n`，但在 C 语言中它整体表示一个字符，即换行符。

### 八进制转义字符

八进制转义字符形式如下：

```c
'\141'
```

这里的 `141` 是八进制数。八进制 `141` 对应十进制 97，而 ASCII 码十进制 97 对应小写字母 `'a'`，所以：

```c
'\141'
```

表示字符 `'a'`。

### 十六进制转义字符

十六进制转义字符形式如下：

```c
'\x6d'
```

其中 `x` 表示后面是十六进制数。十六进制 `6d` 对应的 ASCII 字符是小写字母 `'m'`，所以：

```c
'\x6d'
```

表示字符 `'m'`。

注意：十六进制转义字符中必须写 `x`，例如 `'\x6d'`，不能直接写成 `'\6d'`。

## 十六、典型例题：字符型

### 例题12：已知 `ch` 是字符型变量，下面不正确的赋值语句是？

A. `ch = 'a+b';`  
B. `ch = '\0';`  
C. `ch = '7' + '9';`  
D. `ch = 5 + 9;`

**答案：A。**

解析：A 中单引号内包含多个普通字符，不符合字符常量的基本要求。B 中 `'\0'` 是转义字符，合法。C 中字符可以参与加法运算，虽然结果未必是常见可显示字符，但语法上可以。D 中字符型变量本质上可以存储整数编码，因此把整数表达式赋给 `char` 在语法上可以。

### 例题13：属于字符型常量的是？

A. `'97'`  
B. `a`  
C. `"a"`  
D. `'b'`

**答案：D。**

解析：`'97'` 中有两个字符；`a` 没有单引号，不是字符常量；`"a"` 是字符串常量；`'b'` 是字符常量。

### 例题14：下面说法正确的是？

A. `char` 类型只能存储英文字母。  
B. `char` 类型的本质是整数类型，存储的是字符编码。  
C. `char` 和 `int` 没有任何关系。  
D. `'123'` 是合法的字符赋值。

**答案：B。**

解析：`char` 不只能存储英文字母，也可以存储数字字符、符号字符、转义字符等。`char` 本质上存储的是字符编码，因此可以和整数产生联系。`'123'` 不是单个字符，不符合基础阶段对字符常量的要求。

## 十七、浮点型

浮点型用来表示小数，主要有两种：

```c
float
double
```

其中 `float` 是单精度浮点型，通常占 4 字节；`double` 是双精度浮点型，通常占 8 字节。一般来说，`double` 的精度高于 `float`。

定义浮点型变量：

```c
float x = 3.14f;
double y = 3.14;
```

基础阶段也常见下面这种写法：

```c
double a = 1.;
double b = .1;
```

其中：

```c
1.
```

表示 `1.0`；

```c
.1
```

表示 `0.1`。

小数点两边如果有一边是 0，可以省略。但为了代码清晰，实际编程中更推荐写成 `1.0`、`0.1`。

## 十八、浮点数的指数形式

浮点数还可以用指数形式表示，也叫科学计数法。例如：

```c
2.55e1
```

表示 $2.55 \times 10^1 = 25.5$。

再如：

```c
1.23e4
```

表示 $1.23 \times 10^4 = 12300$。

指数形式需要记住一个重要规则：

**`e` 或 `E` 前后都必须有数字，并且 `e` 或 `E` 后面必须是整数。**

例如：

```c
2.3e2
```

是合法的。

```c
2.3e
```

不合法，因为 `e` 后面没有数字。

```c
2.3e2.3
```

不合法，因为 `e` 后面不是整数。

```c
e3
```

不合法，因为 `e` 前面没有数字。

### 例题15：下面关于 C 语言浮点数的说法正确的是？

A. `float` 类型的精度比 `double` 类型更高。  
B. 可以使用 `E` 表示法表示浮点数，例如 `1.23e4` 表示 12300。  
C. `float` 和 `int` 都能表示浮点数。  
D. `double` 类型不能表示负数。

**答案：B。**

解析：`double` 通常比 `float` 精度更高；`int` 是整数类型，不能表示小数；`double` 可以表示正数、负数和 0；`1.23e4` 表示 $1.23 \times 10^4 = 12300$。

### 例题16：将下列科学计数法转化为十进制数。

#### 1\. `3.5e2`

$3.5e2 = 3.5 \times 10^2 = 350$

答案：

```c
350
```

#### 2\. `2.75e-3`

$2.75e^{-3} = 2.75 \times 10^{-3} = 0.00275$

答案：

```c
0.00275
```

#### 3\. `1.0e0`

$1.0e0 = 1.0 \times 10^0 = 1.0$

```c
1.0
```

## 十九、本节小结

C 语言最基础、最容易出选择题和判断题的内容如下。

首先，C 语言程序由函数构成，函数是 C 语言程序的基本单位。程序从 `main` 函数开始执行，`main` 函数结束，程序通常也随之结束。基础程序模板中要特别注意 `#include <stdio.h>`、`int main()`、`printf`、`return 0;` 和分号等细节。

其次，标识符是变量名、函数名等名称，必须满足"只能由字母、数字、下划线组成；不能以数字开头；不能是关键字"这三条规则。判断标识符是否合法是考试常考题。

然后，C 语言中的整数常量常见写法有十进制、八进制和十六进制。普通数字默认是十进制；前面加 `0` 是八进制；前面加 `0x` 或 `0X` 是十六进制。

变量必须先声明后使用，可以声明时初始化，也可以后续赋值。多个变量可以用逗号同时声明，例如 `int a, b, c;`。不能重复声明同一个变量，也要区分"连续初始化"和"连续赋值"。

数据类型方面，基础阶段重点掌握 `char`、`short`、`int`、`long`、`float`、`double` 及其常见字节数。`unsigned` 表示无符号类型，不能表示负数。

字符型 `char` 是重点。字符常量用单引号，字符串用双引号。字符本质上存储的是 ASCII 编码，因此字符可以参与加减运算。常考 ASCII 值包括：`'0'` 到 `'9'` 是 48 到 57，`'A'` 到 `'Z'` 是 65 到 90，`'a'` 到 `'z'` 是 97 到 122。字符数字转整数数字的核心方法是减去 `'0'`。

最后，浮点型用于表示小数，`double` 通常比 `float` 精度更高。浮点数可以使用指数形式，例如 `1.23e4` 表示 $1.23 \times 10^4$。指数形式中，`e` 前后必须有数字，并且 `e` 后面必须是整数。
