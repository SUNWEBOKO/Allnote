## 一、输出函数 `printf`

在 C 语言中，`printf` 是最常用的输出函数，用于将程序中的数据按指定格式输出到屏幕。

注意：函数名是 `printf`，不是 `print`。使用 `printf` 之前，需要在程序开头包含标准输入输出头文件：

```c
#include <stdio.h>
```

一个最基本的 C 程序通常写成：

```c
#include <stdio.h>

int main() {
    printf("Hello World");
    return 0;
}
```

这段程序运行后，会在控制台输出：

```
Hello World
```

其中，`printf("Hello World");` 的意思是：把双引号中的字符串原样打印到屏幕上。

## 二、`printf` 的两种常见使用形式

`printf` 的使用大致可以分为两种情况：

第一种是**只有一个参数**，也就是只输出固定内容。

```c
printf("Hello World");
```

这时双引号里面写什么，屏幕上就输出什么。

第二种是**有多个参数**，也就是在字符串中使用格式控制符，让后面的变量或数据替换到指定位置。

例如：

```c
printf("这个整型数值是%d", 123);
```

输出结果是：

```
这个整型数值是123
```

这里的 `%d` 就是一个**占位符**，表示这个位置要输出一个整型数据。后面的 `123` 会替换掉前面的 `%d`。

这种写法的一般格式是：

```c
printf("格式字符串", 参数1, 参数2, 参数3, ...);
```

其中，双引号中的内容叫做**格式字符串**。格式字符串中可以同时包含两类内容：

一种是普通字符，例如 `"A="`、`"B="`、逗号、空格等，这些内容会原样输出；另一种是格式控制符，也叫占位符，例如 `%d`、`%f`、`%c` 等，它们会被后面的参数依次替换。

例如：

```c
printf("A=%d, B=%d", 12, 34);
```

输出结果是：

```
A=12, B=34
```

第一个 `%d` 被 `12` 替换，第二个 `%d` 被 `34` 替换，所以最终输出 `A=12, B=34`。

注意：格式控制符和后面的参数要**数量对应、类型匹配、顺序一致**。如果格式控制符和参数类型不匹配，程序可能输出错误结果，严重时可能出现运行异常。

## 三、`printf` 常用格式控制符

不同类型的数据需要使用不同的格式控制符。

| 数据类型或输出形式 | 格式控制符 | 说明 |
| --- | --- | --- |
| `int` | `%d` | 输出十进制整数 |
| `long` | `%ld` | 输出长整型 |
| `unsigned int` | `%u` | 输出无符号十进制整数 |
| `float` / `double` | `%f` | 输出小数 |
| `char` | `%c` | 输出单个字符 |
| 字符串 | `%s` | 输出字符串 |
| 十六进制小写 | `%x` | 输出小写十六进制 |
| 十六进制大写 | `%X` | 输出大写十六进制 |
| 八进制 | `%o` | 输出八进制 |
| 百分号本身 | `%%` | 输出一个 `%` |

注意：在 `printf` 中，`float` 类型传参时会自动提升为 `double`，因此输出 `float` 和 `double` 一般都使用 `%f`。但是在 `scanf` 中，`float` 使用 `%f`，`double` 必须使用 `%lf`，两者不要混淆。

例如：

```c
printf("%d\n", 123);
printf("%ld\n", 123456789L);
printf("%u\n", 100U);
printf("%f\n", 3.14);
printf("%c\n", 'A');
printf("%s\n", "hello");
printf("%x\n", 15);
printf("%X\n", 15);
printf("%o\n", 8);
printf("90%%\n");
```

输出结果大致为：

```
123
123456789
100
3.140000
A
hello
f
F
10
90%
```

这里要注意，`%f` 默认会输出小数点后六位，所以 `3.14` 输出时通常显示为 `3.140000`。如果想控制小数位数，可以使用 `%.2f` 这类写法。

## 四、`printf` 中的宽度与精度控制

除了基本格式控制符以外，`printf` 还可以控制输出宽度和小数位数。

### 1\. `%5d`：控制整数输出宽度

```c
printf("A=%5d", 10);
```

`%5d` 表示输出一个整数，并且输出总宽度至少为 5 个字符。如果实际数字长度不足 5 个字符，就在左边用空格补齐，默认右对齐。

因为 `10` 只占 2 个字符，而总宽度要求是 5，所以前面会补 3 个空格。

输出结果是：

```
A=   10
```

### 2\. `%.2f`：控制小数位数

```c
printf("B=%.2f", 3.1415);
```

`%.2f` 表示输出浮点数，并保留小数点后 2 位。

输出结果是：

```
B=3.14
```

再看一个完整例子：

```c
#include <stdio.h>

int main() {
    int a = 10;
    float b = 3.1415;
    printf("A=%5d, B=%.2f", a, b);
    return 0;
}
```

输出结果是：

```
A=   10, B=3.14
```

这里 `A=   10` 中 `10` 前面有 3 个空格，因为 `%5d` 要求整数总宽度为 5；`B=3.14` 是因为 `%.2f` 要求保留两位小数。

## 五、`printf` 例题讲解

### 例题 1：变量与格式控制符的对应

已知代码：

```c
int a = 5;
float b = 3.14;
char ch = 'A';
printf("a的值是%d, b的值是%f, 字符是%c", a, b, ch);
```

分析：

`a` 是 `int` 类型，所以使用 `%d` 输出；`b` 是 `float` 类型，所以使用 `%f` 输出；`ch` 是 `char` 类型，所以使用 `%c` 输出。

输出结果是：

```
a的值是5, b的值是3.140000, 字符是A
```

如果写成：

```c
printf("a的值是%d, b的值是%.2f, 字符是%c", a, b, ch);
```

输出结果就是：

```
a的值是5, b的值是3.14, 字符是A
```

### 例题 2：八进制、十进制、十六进制输出

已知代码：

```c
int x = 017;
printf("%d\n", x);
printf("%o\n", x);
printf("%x\n", x);
```

分析：

在 C 语言中，如果一个整数常量以 `0` 开头，它表示八进制数。因此 `017` 不是十进制的 17，而是八进制的 17。

八进制 `17` 转换成十进制为：

$$
1 \times 8 + 7 = 15
$$

所以 `x` 的实际数值是十进制的 `15`。

第一行：

```c
printf("%d\n", x);
```

`%d` 按十进制输出，所以输出：

```
15
```

第二行：

```c
printf("%o\n", x);
```

`%o` 按八进制输出，所以输出：

```
17
```

第三行：

```c
printf("%x\n", x);
```

`%x` 按十六进制输出。十进制 `15` 对应十六进制 `f`，所以输出：

```
f
```

如果使用 `%X`，则会输出大写：

```
F
```

### 例题 3：判断格式控制符是否匹配

判断下面语句是否正确：

```c
printf("%c", 65);
```

这是可以输出字符的。因为 `%c` 用于输出字符，而字符在计算机内部本质上也对应一个整数编码。ASCII 码中，整数 `65` 对应大写字母 `'A'`，所以输出结果是：

```
A
```

再看下面几种写法：

```c
printf("%d", 3.14);
printf("%f", 'A');
printf("%s", 1234);
```

这些写法都不合适。

`%d` 用来输出整数，不能正确匹配 `3.14` 这样的浮点数；`%f` 用来输出浮点数，不能正确匹配字符 `'A'`；`%s` 用来输出字符串，不能输出普通整数 `1234`。

考试时要记住：**格式控制符必须和后面的参数类型相匹配。**

## 六、输入函数 `scanf`

`scanf` 是 C 语言中常用的输入函数，用于从键盘读取数据并保存到变量中。

使用 `scanf` 之前，也需要包含头文件：

```c
#include <stdio.h>
```

`scanf` 的基本格式是：

```c
scanf("格式字符串", 地址列表);
```

例如：

```c
int age;
scanf("%d", &age);
```

这段代码的意思是：从键盘输入一个整数，并把这个整数保存到变量 `age` 中。

这里最重要的是 `&age`。`&` 是取地址符号，表示把变量 `age` 的地址交给 `scanf`，让 `scanf` 能够把输入的数据存入这个变量。

如果写成：

```c
scanf("%d", age);
```

这是错误的。因为 `scanf` 需要的是变量地址，而不是变量当前的值。缺少 `&` 可能导致程序运行异常。

注意：对于普通变量，例如 `int`、`float`、`char`，使用 `scanf` 时一般都要加 `&`。字符串数组的情况稍微特殊，例如 `char str[20]; scanf("%s", str);` 中 `str` 本身就表示数组首地址，一般不再加 `&`。字符串数组后面再单独学习即可。

## 七、`scanf` 的格式必须与输入形式匹配

`scanf` 不仅要求数据类型匹配，也要求格式字符串中的普通字符和用户输入的普通字符匹配。

例如：

```c
int a, b;
scanf("%d,%d", &a, &b);
```

这里格式字符串是 `"%d,%d"`，两个 `%d` 中间有一个逗号。因此输入时也必须输入逗号：

```
10,20
```

这样才能正确读入，最终：

```
a = 10;
b = 20;
```

如果用户输入：

```
10 20
```

这就不匹配了。因为程序要求中间是逗号，而用户输入的是空格，所以无法按照预期读入。

再看一个使用空格分隔的例子：

```c
float x;
int y;
scanf("%f %d", &x, &y);
```

如果输入：

```
4.5 2
```

就是正确的。因为 `%f` 匹配 `4.5`，`%d` 匹配 `2`，中间的空格也符合格式要求。

注意：`scanf` 格式字符串里的空白字符比较特殊，它通常可以匹配输入中的任意数量空白，包括空格、换行、Tab。因此实际考试中，如果输入数据是用空格分隔，常写成：

```c
scanf("%f%d", &x, &y);
```

或者：

```c
scanf("%f %d", &x, &y);
```

两种写法通常都可以读入 `4.5 2`。但是如果格式字符串中写了逗号，例如 `"%f,%d"`，那么输入中就必须有逗号。

## 八、`scanf` 常用格式控制符

`scanf` 中也有格式控制符，但要特别注意：`printf` 和 `scanf` 中部分类型的写法并不完全一样。

| 数据类型 | `scanf` 格式控制符 | 示例 |
| --- | --- | --- |
| `int` | `%d` | `scanf("%d", &a);` |
| `long` | `%ld` | `scanf("%ld", &a);` |
| `unsigned int` | `%u` | `scanf("%u", &a);` |
| `float` | `%f` | `scanf("%f", &x);` |
| `double` | `%lf` | `scanf("%lf", &x);` |
| `char` | `%c` | `scanf("%c", &ch);` |
| 字符串数组 | `%s` | `scanf("%s", str);` |
| 八进制整数 | `%o` | `scanf("%o", &a);` |
| 十六进制整数 | `%x` | `scanf("%x", &a);` |

注意：在 `scanf` 中，`float` 用 `%f`，`double` 用 `%lf`。这是考试中很容易混淆的点。

## 九、`scanf` 例题讲解

### 例题 1：选择正确的输入语句

已有变量：

```c
float a;
int b;
```

输入数据形式为：

```
4.5 2
```

正确的输入语句应该是：

```c
scanf("%f %d", &a, &b);
```

分析：

`4.5` 是浮点数，所以要用 `%f` 匹配，并保存到 `float` 变量 `a` 中；`2` 是整数，所以要用 `%d` 匹配，并保存到 `int` 变量 `b` 中。两个输入数据之间是空格，所以格式中可以写空格。

错误写法示例：

```c
scanf("%d,%f", &a, &b);
```

这有两个问题：第一，`%d` 不能匹配 `4.5`；第二，格式字符串中有逗号，而输入数据中间是空格。

```c
scanf("%f,%d", &a, &b);
```

这虽然类型顺序是对的，但是格式中有逗号，而输入中没有逗号，所以仍然不符合题目输入形式。

### 例题 2：判断输入语句是否正确

下面哪一个输入语句是正确的？

```c
scanf("%d", &a, &b);
scanf("%d,%d", &a, &b);
scanf("%d,%d", a, b);
scanf("%d,%d", &a);
```

如果要读入两个整数，并且输入格式为：

```
10,20
```

正确写法是：

```c
scanf("%d,%d", &a, &b);
```

分析：

第一句只有一个 `%d`，但是后面给了两个变量地址，数量不匹配。

第三句没有写 `&a` 和 `&b`，没有传入变量地址，是错误的。

第四句有两个 `%d`，但是后面只有一个变量地址，数量不匹配。

所以正确的是：

```c
scanf("%d,%d", &a, &b);
```

## 十、字符输入与 ASCII 码转换

在 C 语言中，字符本质上是按照 ASCII 码存储的。比如：

```
'A' 的 ASCII 码是 65
'a' 的 ASCII 码是 97
```

小写字母和对应的大写字母之间相差 32：

$$
'a' - 'A' = 32
$$

因此，如果输入一个小写字母，要得到它对应的大写字母，可以让它减去 32。

例如：

```c
#include <stdio.h>

int main() {
    char a, b;
    printf("请输入一个小写字母：");
    scanf("%c", &a);
    b = a - 32;
    printf("小写字母是%c, 对应的大写字母是%c", a, b);
    return 0;
}
```

如果输入：

```
h
```

输出结果是：

```
小写字母是h, 对应的大写字母是H
```

本题利用了字符的 ASCII 码规律。小写字母比对应大写字母的 ASCII 码大 32，所以小写转大写可以写成：

```c
b = a - 32;
```

更规范的写法也可以使用字符常量关系：

```c
b = a - ('a' - 'A');
```

这样写比直接写 `32` 更直观。

## 十一、`scanf` 指定输入宽度

`scanf` 中也可以指定读取宽度，例如：

```c
scanf("%2d%4d%d", &x, &y, &z);
```

这里的 `%2d` 表示最多读取 2 位数字，`%4d` 表示最多读取 4 位数字，最后的 `%d` 表示按普通整数继续读取。

### 例题 1：输入连续数字

```c
int x, y, z;
scanf("%2d%4d%d", &x, &y, &z);
```

如果输入：

```
1234567
```

读取过程如下：

`%2d` 读取前 2 位数字 `12`，所以：

```c
x = 12;
```

`%4d` 继续读取后面 4 位数字 `3456`，所以：

```c
y = 3456;
```

最后 `%d` 继续读取剩下的数字 `7`，所以：

```c
z = 7;
```

最终结果是：

```
x=12, y=3456, z=7
```

### 例题 2：输入中间有空格

同样的代码：

```c
int x, y, z;
scanf("%2d%4d%d", &x, &y, &z);
```

如果输入：

```
1 234567
```

读取过程为：

`%2d` 最多读取 2 位，但遇到空格后当前整数结束，所以它只读取 `1`：

```c
x = 1;
```

接下来 `%4d` 会跳过空格，然后读取后面的前 4 位数字 `2345`：

```c
y = 2345;
```

最后 `%d` 继续读取剩余数字 `67`：

```c
z = 67;
```

最终结果是：

```
x=1, y=2345, z=67
```

注意：`%3d` 不是限制用户最多只能输入三位整数，而是表示 `scanf` **最多读取三位数字**。用户仍然可以输入更多内容，多出来的内容会留在输入缓冲区，可能被后续的输入语句继续读取。

例如：

```c
int a;
scanf("%3d", &a);
printf("%d", a);
```

如果输入：

```
12345
```

`%3d` 只读取前三位 `123`，所以输出：

```
123
```

剩下的 `45` 并没有消失，而是留在输入缓冲区中。

## 十二、`%d` 与 `%c` 的区别

`%d` 和 `%c` 是 `scanf` 中非常容易混淆的两个格式控制符。

`%d` 用来读取整数。

`%c` 用来读取字符。

例如：

```c
int x;
char y;
scanf("%d", &x);
scanf("%c", &y);
```

如果对于第一个 `scanf` 输入：

```
1
```

那么 `x` 得到的是整数 `1`。

但如果对于 `%c` 输入：

```
1
```

那么 `y` 得到的不是整数 `1`，而是字符 `'1'`。

字符 `'1'` 的 ASCII 码是 `49`，所以：

```c
printf("%d", y);
```

输出的是：

```
49
```

而：

```c
printf("%c", y);
```

输出的是：

```
1
```

这里要区分：

```
整数 1：数值就是 1
字符 '1'：本质是一个字符编码，ASCII 码为 49
```

同理，字符 `'0'` 的 ASCII 码是 `48`，字符 `'A'` 的 ASCII 码是 `65`。

## 十三、`scanf("%c")` 不会跳过空格和回车

这是 `scanf` 中非常重要的考点。

对于 `%d`、`%f` 这类读取数字的格式控制符，`scanf` 会自动跳过输入前面的空格、换行和 Tab。

但是 `%c` 不会跳过空格、换行和 Tab，因为 `%c` 的作用就是读取一个字符，而空格和回车本身也是字符。

例如：

```c
int a;
char ch;
scanf("%d", &a);
scanf("%c", &ch);
printf("a=%d, ch=%c", a, ch);
```

如果用户输入：

```
65
```

然后按回车，那么第一个 `scanf("%d", &a);` 会读取整数 `65`，于是：

```c
a = 65;
```

但是输入完 `65` 后，用户按下的回车还留在输入缓冲区中。第二个 `scanf("%c", &ch);` 不会跳过这个回车，于是它直接读取了回车字符。

所以 `ch` 得到的不是 `'A'`，而是换行符 `'\n'`。

输出看起来可能像这样：

```
a=65, ch=
```

`ch=` 后面好像什么都没有，其实它输出的是一个回车。

如果想让 `%c` 跳过前面的空格和回车，可以在 `%c` 前面加一个空格：

```c
scanf(" %c", &ch);
```

这个空格的作用是：让 `scanf` 先跳过前面的空白字符，再读取真正需要的字符。

## 十四、`getchar` 的作用

`getchar()` 是一个用于读取单个字符的函数。它会从输入缓冲区中取走一个字符，包括空格、换行这类字符。

例如：

```c
int a;
char ch;
scanf("%d", &a);
getchar();
scanf("%c", &ch);
printf("a=%d, ch=%c", a, ch);
```

如果用户输入：

```
123A
```

过程是这样的：

第一步：

```c
scanf("%d", &a);
```

读取整数 `123`，所以：

```c
a = 123;
```

此时用户输入 `123` 后按下的回车还留在输入缓冲区中。

第二步：

```c
getchar();
```

`getchar()` 读取并丢弃这个回车。

第三步：

```c
scanf("%c", &ch);
```

这时输入缓冲区中下一个有效字符就是 `A`，所以：

```c
ch = 'A';
```

最终输出：

```
a=123, ch=A
```

这里的 `getchar()` 常用于"吃掉"前一次输入后留下的回车，避免它影响后面的字符输入。

## 十五、`printf` 与 `scanf` 对比总结

`printf` 是输出函数，用来把内容显示到屏幕上；`scanf` 是输入函数，用来从键盘获取数据并保存到变量中。

`printf` 的格式是：

```c
printf("格式字符串", 参数1, 参数2, ...);
```

`scanf` 的格式是：

```c
scanf("格式字符串", &变量1, &变量2, ...);
```

两者都需要格式控制符，但使用时重点不同。

`printf` 的重点是：格式控制符要和输出参数的类型匹配。

`scanf` 的重点是：格式控制符要和输入数据类型匹配，普通字符也要和输入格式匹配，并且变量名前通常要加 `&`。

尤其要记住以下几个易错点：

1. `printf` 和 `scanf` 都需要头文件：

```c
#include <stdio.h>
```

2. 输出整数用 `%d`，输出字符用 `%c`，输出字符串用 `%s`，输出小数用 `%f`。

3. `scanf` 中普通变量一般要加 `&`：

```c
scanf("%d", &a);
```

4. `scanf("%c", &ch);` 不会自动跳过回车和空格。

5. 如果要让 `%c` 跳过空白字符，可以写成：

```c
scanf(" %c", &ch);
```

6. `scanf("%3d", &a);` 表示最多读取三位整数，不是限制用户只能输入三位。

7. `printf` 中 `%.2f` 表示保留两位小数，`%5d` 表示整数输出总宽度至少为 5。

8. `printf` 输出 `double` 通常用 `%f`，但 `scanf` 输入 `double` 必须用 `%lf`。

## 十六、本节小结

C 语言中两个最基础、最常用的输入输出函数是 `printf` 和 `scanf`。

`printf` 负责输出，核心是理解格式字符串和格式控制符。普通字符会原样输出，占位符会被后面的参数依次替换。常见格式控制符包括 `%d`、`%f`、`%c`、`%s`、`%x`、`%o` 和 `%%`。在输出时，还可以通过 `%5d` 控制整数宽度，通过 `%.2f` 控制小数精度。

`scanf` 负责输入，核心是把键盘输入的数据保存到变量中。普通变量名前通常必须加 `&`，表示把变量地址传给 `scanf`。输入时不仅数据类型要匹配，格式字符串中的普通字符也要和用户输入保持一致。特别要注意 `%c` 不会跳过空格和回车，而 `%d`、`%f` 等读取数字时会跳过前面的空白字符。

复习时要重点掌握格式控制符的含义、参数与占位符的匹配关系、`scanf` 中 `&` 的使用、输入格式匹配，以及 `%c` 和 `%d` 的区别。
