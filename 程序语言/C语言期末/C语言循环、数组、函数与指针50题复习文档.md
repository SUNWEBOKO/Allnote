## 一、循环结构（for / while / do-while）

### 核心知识点

1. **for 循环**：`for (初始化; 条件; 更新)` — 执行顺序：初始化 → 条件判断 → 循环体 → 更新 → 条件判断...
2. **while 循环**：`while (条件)` — 先判断，后执行；可能执行 0 次
3. **do-while 循环**：`do { } while (条件);` — 先执行，后判断；**至少执行 1 次**
4. **break**：立即退出当前循环（仅最内层）
5. **continue**：跳过本次循环剩余语句，进入下一次迭代。在 for 中仍执行更新表达式
6. **嵌套循环**：外层执行 1 次，内层完整执行一轮；总次数 = 各层次数乘积
7. **无限循环**：`for (;;)` 或 `while (1)`，需配合 break 退出
8. **赋值陷阱**：`while (k = 0)` 中 `=` 是赋值，表达式值为 0（假），循环体不执行
9. **连续比较陷阱**：`a < b < c` 在 C 中等价于 `(a < b) < c`，不表示数学区间
10. **数字反转典型代码**：`rev = rev * 10 + n % 10; n /= 10;`

## 二、一维数组

### 核心知识点

1. **声明**：`类型 数组名[大小];`，如 `int a[10];`
2. **下标范围**：从 0 开始，有效范围 `0` ~ `size-1`
3. **部分初始化**：`int a[5] = {1, 2, 3};` — 未指定元素自动补 0
4. **自动确定大小**：`int a[] = {1, 2, 3, 4, 5};` — 大小由初始化列表元素个数决定
5. **数组名**：在表达式中代表首元素地址（`&a[0]`），是一个**常量指针**
6. **常见操作**：求最值、求和、反转、线性查找
7. **越界访问**：C 不检查下标边界，`a[size]` 访问越界但编译不报错，运行时可能崩溃

## 三、二维数组

### 核心知识点

1. **声明**：`类型 数组名[行][列];`，如 `int a[3][4];`
2. **元素个数**：行数 × 列数
3. **行优先存储**：先存第 0 行所有列，再存第 1 行所有列……`a[i][j]` 在 `a[i][j+1]` 之前
4. **初始化省略**：只有**第一维（行数）**可以省略，第二维（列数）必须指定
5. **遍历**：外层循环行，内层循环列

## 四、函数

### 核心知识点

1. **定义**：`返回类型 函数名(参数列表) { 函数体 }`
2. **声明（函数原型）**：若定义在调用之后，调用前需声明，如 `int func(int a, int b);`
3. **传值调用**：形参是实参的副本，修改形参不影响实参
4. **return**：退出函数并返回值；void 函数可写空 return 或无 return
5. **数组参数**：数组作为参数退化为指针，函数内可修改原数组元素
6. **递归**：函数调用自身，必须有递归基（base case）防止栈溢出
7. **复合调用**：`f(f(x, y), z)` 先计算内层参数，再计算外层
8. **返回类型**：默认返回 int（旧标准）；返回类型与表达式类型不匹配时自动截断

## 五、指针基础

### 核心知识点

1. **声明**：`类型 *指针名;`，如 `int *p;` — p 是一个指向 int 类型数据的指针变量
2. **取地址 `&`**：获取变量的内存地址，如 `int *p = &a;`
3. **解引用 `*`**：通过指针访问指向的值，`*p` 等价于 a
4. **指针与数组**：`a[i]` 完全等价于 `*(a + i)`，`a + i` 是第 i 个元素的地址
5. **指针算术**：`p++` 使指针移动到下一个元素（跳过 sizeof(类型) 字节）
6. **指针作函数参数**：通过传递地址，函数内可修改调用者的变量（模拟引用传递）
7. **NULL 指针**：`int *p = NULL;` 指向空地址，使用前应检查 `if (p != NULL)`
8. **野指针**：未初始化的指针，指向未知内存，解引用可能导致崩溃
9. **数组名 vs 指针**：数组名是常量指针（不可赋值），`sizeof(数组名)` 返回整个数组大小

## 六、高频易错点总结

| 编号 | 易错点 | 典型错误 | 正确做法 |

| 1 | **数组下标从 0 开始** | 遍历 `for(i=1; i<=n; i++)` 访问 `a[i]` | `for(i=0; i<n; i++)`，最大下标为 size-1 |
| 2 | **越界不报错** | `int a[5]; a[5] = 10;` 编译通过 | 编译不报错但运行时可能覆盖其他变量或崩溃 |
| 3 | **函数缺少原型** | 在 `main` 之后定义函数，调用处报错 | 调用前加函数声明 `int func(int, int);` |
| 4 | **传值不能修改实参** | 写 `swap(a, b)` 企图交换，形参交换但实参不变 | 用指针：`swap(&a, &b)`，形参写 `int *x, int *y` |
| 5 | **数组参数 sizeof 失效** | 函数内 `sizeof(arr)/sizeof(arr[0])` 算不出长度 | 数组参数退化为指针，需额外传长度参数 |
| 6 | **递归缺基** | 递归函数无终止条件 | 必须写 `if (终止条件) return 值;` 作为 base case |
| 7 | **break 只退最内层** | 嵌套循环中期望 break 退出所有循环 | 可用标志变量或 `goto` 退出多层循环 |
| 8 | **continue 在 for 中仍执行更新** | 误以为 continue 跳过整个后续包括更新 | for 中 continue 后仍执行 `i++`，与 while 不同 |
| 9 | **野指针解引用** | `int *p; *p = 10;` 未初始化 | 初始化为 `NULL` 或指向有效变量 |
| 10 | **while 中 `=` 误写为 `==`** | `while (k = 0)` 赋值而非比较 | 用 `k == 0`，或常量放左侧 `0 == k` |
| 11 | **连续比较误解** | 用 `a < b < c` 表示区间判断 | 应写 `a < b && b < c` |
| 12 | **do-while 漏分号** | `do { } while (条件)` 末尾漏 `;` | `do { } while (条件);` — 结尾必须有分号 |
