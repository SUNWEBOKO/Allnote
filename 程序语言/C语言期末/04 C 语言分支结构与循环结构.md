# C 语言分支结构与循环结构复习讲义

## 一、C 语言程序的三种基本结构

C 语言程序的执行结构通常分为三种：

1. **顺序结构**
    
2. **分支结构**
    
3. **循环结构**
    

前面学习的很多程序都是按代码书写顺序从上到下逐条执行，这种结构叫做**顺序结构**。而当程序需要根据条件选择执行不同代码时，就需要使用**分支结构**。当程序需要重复执行某一段代码时，就需要使用**循环结构**。

---

## 二、分支结构

分支结构解决的是“如果满足某个条件，就执行某段代码；否则执行另一段代码”的问题。在 C 语言中，常见的分支结构包括：

- `if` 语句
    
- `if...else` 语句
    
- `if...else if...else` 语句
    
- 条件表达式
    
- `switch` 语句
    

---

## 三、`if` 语句

### 3.1 单独的 `if` 语句

最简单的分支结构是单独的 `if` 语句。

```c
if (条件表达式)
{
    语句;
}
```

执行过程：先判断括号中的条件表达式，如果结果为真，就执行花括号中的代码；如果结果为假，就跳过这一段代码。

例如：

```c
#include <stdio.h>

int main()
{
    int score = 85;

    if (score >= 60)
    {
        printf("考试通过\n");
        printf("继续保持\n");
    }

    return 0;
}
```

在这段代码中，`score` 的值为 `85`，满足 `score >= 60`，所以程序会执行 `if` 语句中的两行 `printf`。

---

## 四、`if...else` 语句

如果需要表达“如果……否则……”的逻辑，就可以使用 `if...else` 语句。

```c
if (条件表达式)
{
    语句1;
}
else
{
    语句2;
}
```

运行机制：如果条件表达式为真，就执行 `if` 后面的代码；如果条件表达式为假，就执行 `else` 后面的代码。

例如：

```c
#include <stdio.h>

int main()
{
    int temperature = 25;

    if (temperature > 30)
    {
        printf("开启空调\n");
    }
    else
    {
        printf("关闭空调\n");
    }

    return 0;
}
```

因为 `temperature` 的值为 `25`，不满足 `temperature > 30`，所以程序会执行 `else` 中的语句，输出“关闭空调”。

---

## 五、`if...else if...else` 语句

当程序需要判断多个条件时，可以使用 `if...else if...else` 结构。

```c
if (条件1)
{
    语句1;
}
else if (条件2)
{
    语句2;
}
else if (条件3)
{
    语句3;
}
else
{
    语句4;
}
```

程序从上往下依次判断条件。一旦某个条件成立，就执行对应代码块，执行完之后整个分支结构结束，后面的条件不再判断。

例如：

```c
#include <stdio.h>

int main()
{
    int score = 85;

    if (score >= 90)
    {
        printf("优秀\n");
    }
    else if (score >= 80)
    {
        printf("良好\n");
    }
    else if (score >= 60)
    {
        printf("及格\n");
    }
    else
    {
        printf("不及格\n");
    }

    return 0;
}
```

这里 `score = 85`，它既满足 `score >= 80`，也满足 `score >= 60`，但程序不会同时输出“良好”和“及格”。因为程序从上往下判断，先遇到成立的 `score >= 80`，输出“良好”后，整个 `if...else if...else` 结构就结束了。

注意：`if...else if...else` 不是把所有满足条件的分支都执行，而是**只执行第一个满足条件的分支**。

---

## 六、`if` 语句中的花括号问题

在 C 语言中，如果 `if` 或 `else` 后面只控制一条语句，花括号可以省略。

例如：

```c
if (score >= 60)
    printf("及格\n");
else
    printf("不及格\n");
```

这是合法写法。

但是，如果 `if` 或 `else` 后面有多条语句，就必须使用花括号。

错误写法：

```c
if (score >= 60)
    printf("及格\n");
    printf("继续努力\n");
else
    printf("不及格\n");
```

这段代码的问题是：由于没有花括号，`if` 实际上只控制第一条 `printf("及格\n");`，第二条 `printf("继续努力\n");` 不属于 `if`。并且这里的 `else` 也会因为结构不匹配而导致语法错误。

正确写法：

```c
if (score >= 60)
{
    printf("及格\n");
    printf("继续努力\n");
}
else
{
    printf("不及格\n");
}
```

考试中经常考查花括号是否可以省略，要记住：**只有一条语句时可以省略花括号，多条语句时不能省略。**

---

## 七、`if...else` 中常见语法错误

### 7.1 `printf` 后忘记分号

错误写法：

```c
if (score >= 60)
{
    printf("及格\n")
}
```

`printf` 是一条语句，后面必须加分号。

正确写法：

```c
if (score >= 60)
{
    printf("及格\n");
}
```

### 7.2 在 `if` 或 `else` 后乱加分号

错误写法：

```c
if (score >= 60);
{
    printf("及格\n");
}
else;
{
    printf("不及格\n");
}
```

`if (条件)` 后面直接加分号，相当于让 `if` 控制了一条空语句，后面的代码块就不再属于 `if`。这会导致程序逻辑错误，甚至造成 `else` 无法匹配。

正确写法：

```c
if (score >= 60)
{
    printf("及格\n");
}
else
{
    printf("不及格\n");
}
```

### 7.3 花括号后一般不加分号

```c
if (score >= 60)
{
    printf("及格\n");
}
```

这里右花括号 `}` 后面不需要加分号。虽然某些情况下加一个空语句分号不会立刻报错，但考试中一般认为不规范，尤其在 `if...else` 配对中容易导致结构错误。

## 八、悬空 `else` 问题

在嵌套的 `if...else` 中，考试经常考查 `else` 到底和哪个 `if` 配对。C 语言规定：

**`else` 总是与它前面最近的、还没有配对的 `if` 配对。**

这和缩进无关，也和是否在同一行无关。缩进只是给人看的，真正决定配对关系的是 C 语言语法规则。

例如：

```c
if (a < b)
    if (c < d)
        x = 1;
    else
        x = 2;
```

这里的 `else` 与最近的 `if (c < d)` 配对，而不是与 `if (a < b)` 配对。

如果想让 `else` 和外层 `if` 配对，必须用花括号明确结构：

```c
if (a < b)
{
    if (c < d)
        x = 1;
}
else
{
    x = 2;
}
```

所以在考试中，如果看到多个 `if` 和 `else` 挤在一起，第一步不要急着代入数据，而是先根据“就近配对原则”确定每个 `else` 对应哪个 `if`。

## 九、例题：嵌套 `if...else` 判断

当 `a = 1`，`b = 3`，`c = 5`，`d = 4` 时，执行下面程序段后，`x` 的值是多少？

```c
if (a < b)
    if (c < d)
        x = 1;
    else
        if (a < c)
            if (b < d)
                x = 2;
            else
                x = 3;
        else
            x = 4;
else
    x = 5;
```

分析时先确定 `else` 的匹配关系：

```c
if (a < b)
{
    if (c < d)
    {
        x = 1;
    }
    else
    {
        if (a < c)
        {
            if (b < d)
            {
                x = 2;
            }
            else
            {
                x = 3;
            }
        }
        else
        {
            x = 4;
        }
    }
}
else
{
    x = 5;
}
```

然后代入数值：

`a = 1`，`b = 3`，所以 `a < b` 成立，进入外层 `if`。

接着判断 `c < d`，即 `5 < 4`，不成立，所以进入对应的 `else`。

然后判断 `a < c`，即 `1 < 5`，成立。

继续判断 `b < d`，即 `3 < 4`，成立，所以执行：

```c
x = 2;
```

因此最终结果为：

```c
x = 2;
```

## 十、变量交换技巧

在学习分支结构时，经常会遇到交换两个变量值的题目。交换两个变量不能直接写：

```c
a = b;
b = a;
```

这样会导致 `a` 原来的值丢失。正确方法是引入临时变量。

```c
t = a;
a = b;
b = t;
```

这三步的含义是：

1. 先把 `a` 的值保存到临时变量 `t` 中；
    
2. 再把 `b` 的值赋给 `a`；
    
3. 最后把原来保存的 `a` 的值赋给 `b`。
    

---

## 十一、例题：利用 `if` 语句排序

```c
#include <stdio.h>

int main()
{
    int a = 3, b = 7, c = 1, t;

    if (a > b)
    {
        t = a;
        a = b;
        b = t;
    }

    if (a > c)
    {
        t = a;
        a = c;
        c = t;
    }

    if (b > c)
    {
        t = b;
        b = c;
        c = t;
    }

    printf("%d %d %d\n", a, b, c);

    return 0;
}
```

分析过程如下：

初始时：

```c
a = 3, b = 7, c = 1
```

第一个 `if` 判断 `a > b`，即 `3 > 7`，不成立，所以不交换。

第二个 `if` 判断 `a > c`，即 `3 > 1`，成立，所以交换 `a` 和 `c`。交换后：

```c
a = 1, b = 7, c = 3
```

第三个 `if` 判断 `b > c`，即 `7 > 3`，成立，所以交换 `b` 和 `c`。交换后：

```c
a = 1, b = 3, c = 7
```

因此最终输出：

```c
1 3 7
```

这类题目的本质是：通过多次两两比较与交换，把三个数按从小到大的顺序排列。

## 十二、条件表达式

条件表达式是 `if...else` 的一种简洁写法，也叫三目运算符。

基本形式为：

```c
条件表达式 ? 表达式1 : 表达式2
```

执行过程：

- 如果条件表达式为真，整个表达式的值就是 `表达式1` 的值；
    
- 如果条件表达式为假，整个表达式的值就是 `表达式2` 的值。
    

例如：

```c
int a = 1, b = 2;
int max;

max = (a > b) ? a : b;
```

因为 `a > b` 即 `1 > 2` 为假，所以执行冒号后面的表达式 `b`，最终：

```c
max = 2;
```

条件表达式常用于从两个值中选择一个值，例如求较大值、较小值、判断奇偶后选择不同结果等。

---

## 十三、条件表达式例题

### 13.1 普通条件表达式

假设：

```c
int x = 1;
```

求下面表达式的值：

```c
x > 0 ? 2 * x + 1 : 2 * x - 1
```

因为 `x = 1`，所以 `x > 0` 成立，执行问号后、冒号前的表达式：

```c
2 * x + 1 = 2 * 1 + 1 = 3
```

因此表达式的值为：

```c
3
```

### 13.2 嵌套条件表达式

例如：

```c
1 ? (0 ? 3 : 2) : 4
```

先看最外层条件 `1`。在 C 语言中，非零为真，所以执行问号后面的表达式：

```c
0 ? 3 : 2
```

继续判断里面的条件 `0`。在 C 语言中，`0` 为假，所以执行冒号后面的表达式：

```c
2
```

因此整个表达式的值为：

```c
2
```

## 十四、`switch` 语句

当一个变量或表达式需要和多个固定值进行匹配时，可以使用 `switch` 语句。

基本形式为：

```c
switch (表达式)
{
    case 常量1:
        语句1;
        break;

    case 常量2:
        语句2;
        break;

    case 常量3:
        语句3;
        break;

    default:
        默认语句;
        break;
}
```

运行机制：先计算 `switch` 括号内表达式的值，然后依次和每个 `case` 后面的常量值比较。如果匹配成功，就从对应的 `case` 开始执行。

例如：

```c
#include <stdio.h>

int main()
{
    int choice;

    printf("请输入选项：");
    scanf("%d", &choice);

    switch (choice)
    {
        case 1:
            printf("开始游戏\n");
            break;

        case 2:
            printf("继续游戏\n");
            break;

        case 3:
            printf("退出游戏\n");
            break;

        default:
            printf("输入无效\n");
            break;
    }

    return 0;
}
```

如果输入 `1`，输出“开始游戏”；如果输入 `2`，输出“继续游戏”；如果输入 `3`，输出“退出游戏”；如果输入其他值，就执行 `default`，输出“输入无效”。

---

## 十五、`switch` 语句的重点规则

### 15.1 `switch` 表达式的类型

`switch` 括号中的表达式通常应该是整型、字符型或枚举类型。因为字符型本质上也可以按整数编码参与比较，所以 `char` 类型也常用于 `switch`。

例如：

```c
char ch = 'A';

switch (ch)
{
    case 'A':
        printf("优秀\n");
        break;
}
```

### 15.2 `case` 后面必须是常量表达式

`case` 后面不能写变量，也不能写范围判断。

错误写法：

```c
case score >= 80 && score < 90:
```

这是错误的。因为 `case` 后面不能写这种关系表达式。

正确思路是：先把数据转换成适合匹配的固定值，再用 `case` 匹配。

### 15.3 `break` 的作用

`break` 用于跳出当前 `switch` 结构。如果某个 `case` 后面没有 `break`，程序不会自动跳出 `switch`，而是会继续执行后面的 `case`，这种现象叫做“贯穿”或“穿透”。

例如：

```c
switch (x)
{
    case 1:
        printf("A\n");

    case 2:
        printf("B\n");
        break;
}
```

如果 `x = 1`，程序会先执行 `case 1`，输出 `A`，然后由于没有 `break`，继续执行 `case 2`，输出 `B`。

所以一般情况下，每个 `case` 结束时都应该写 `break`。只有在故意利用贯穿特性时，才可以省略。

### 15.4 `default` 的作用

`default` 表示默认分支。当所有 `case` 都无法匹配时，就执行 `default` 中的代码。`default` 可以省略；如果省略且没有任何 `case` 匹配，那么整个 `switch` 什么也不做。

## 十六、例题：嵌套 `switch` 与 `break`

```c
#include <stdio.h>

int main()
{
    int x = 1, y = 0;
    int a = 0, b = 0;

    switch (x)
    {
        case 1:
            switch (y)
            {
                case 0:
                    a++;
                    break;

                case 1:
                    b++;
                    break;
            }

        case 2:
            a++;
            b++;
            break;
    }

    printf("a=%d, b=%d\n", a, b);

    return 0;
}
```

分析过程如下：

`x = 1`，所以外层 `switch` 匹配到 `case 1`，进入 `case 1`。

在 `case 1` 中又有一个内层 `switch (y)`。因为 `y = 0`，所以匹配内层的 `case 0`，执行：

```c
a++;
```

此时：

```c
a = 1, b = 0
```

然后遇到内层 `switch` 的 `break`。注意：这个 `break` 只跳出内层 `switch`，不会跳出外层 `switch`。

继续执行外层 `switch`。由于外层 `case 1` 后面没有 `break`，所以程序会继续贯穿到外层 `case 2`，执行：

```c
a++;
b++;
```

此时：

```c
a = 2, b = 1
```

因此最终输出：

```c
a=2, b=1
```

这道题的关键是：**内层 `switch` 的 `break` 只能结束内层 `switch`，不能结束外层 `switch`。**

## 十七、例题：用 `switch` 判断成绩等级

题目：从键盘输入一个百分制成绩 `score`，按下面规则输出等级，要求使用 `switch` 语句。

- `score >= 90`：等级为 `A`
    
- `80 <= score < 90`：等级为 `B`
    
- `70 <= score < 80`：等级为 `C`
    
- `60 <= score < 70`：等级为 `D`
    
- `score < 60`：等级为 `E`
    

如果使用 `if`，可以直接写区间判断：

```c
if (score >= 80 && score < 90)
{
    printf("B\n");
}
```

但是 `switch` 不能这样写：

```c
case score >= 80 && score < 90:
```

因为 `case` 后面必须是常量表达式，不能是区间条件。

这道题的关键技巧是：把成绩除以 `10`。

- `90` 到 `100`，`score / 10` 的结果是 `9` 或 `10`
    
- `80` 到 `89`，`score / 10` 的结果是 `8`
    
- `70` 到 `79`，`score / 10` 的结果是 `7`
    
- `60` 到 `69`，`score / 10` 的结果是 `6`
    
- `60` 以下，对应其他值
    

代码如下：

```c
#include <stdio.h>

int main()
{
    int score;
    char grade;

    printf("请输入一个百分制成绩（0~100）：");
    scanf("%d", &score);

    if (score < 0 || score > 100)
    {
        printf("输入错误\n");
        return 0;
    }

    switch (score / 10)
    {
        case 10:
        case 9:
            grade = 'A';
            break;

        case 8:
            grade = 'B';
            break;

        case 7:
            grade = 'C';
            break;

        case 6:
            grade = 'D';
            break;

        default:
            grade = 'E';
            break;
    }

    printf("等级为：%c\n", grade);

    return 0;
}
```

这里 `case 10:` 后面没有 `break`，是故意利用 `switch` 的贯穿特性。因为 `100 / 10 = 10`，`90~99 / 10 = 9`，它们都应该被判为 `A`，所以可以写成：

```c
case 10:
case 9:
    grade = 'A';
    break;
```

## 循环结构

## 十八、循环结构的作用

循环结构用于重复执行某一段代码。C 语言中常见的循环结构有三种：

1. `while` 循环
    
2. `do...while` 循环
    
3. `for` 循环
    

循环结构常用于重复输入、累加求和、统计次数、打印图形、遍历数组等场景。

---

## 十九、`while` 循环

### 19.1 基本形式

```c
while (条件表达式)
{
    循环体语句;
}
```

执行过程：先判断条件表达式。如果条件为真，就执行循环体；执行完循环体后，再回到条件处继续判断。只要条件一直为真，循环就会一直执行；当条件为假时，循环结束。

例如：

```c
#include <stdio.h>

int main()
{
    int n = 5;

    while (n > 0)
    {
        printf("%d\n", n);
        n--;
    }

    return 0;
}
```

执行过程如下：

- 初始 `n = 5`，满足 `n > 0`，输出 `5`，然后 `n--`，变成 `4`
    
- `n = 4`，继续输出 `4`
    
- 依次输出 `3`、`2`、`1`
    
- 当 `n = 0` 时，不满足 `n > 0`，循环结束
    

最终输出：

```c
5
4
3
2
1
```

注意：`while` 循环是**先判断，后执行**。如果条件一开始就是假，那么循环体一次都不会执行。

## 二十、`while` 后省略花括号的问题

和 `if` 类似，如果 `while` 后面只有一条语句，可以省略花括号。

例如：

```c
while (n > 0)
    n--;
```

但是如果循环体有多条语句，就必须加花括号。

```c
while (n > 0)
{
    printf("%d\n", n);
    n--;
}
```

如果忘记花括号，可能导致只有第一条语句属于循环，后面的语句不属于循环，从而产生严重逻辑错误。

## 二十一、例题：`while (k = 0)` 的陷阱

题目：判断下面程序段中循环体执行情况。

```c
int k = 10;

while (k = 0)
    k--;
```

很多同学看到 `k = 10`，会误以为循环执行十次。但这里要特别注意：条件表达式中写的是一个等号：

```c
k = 0
```

这不是判断相等，而是赋值。它表示把 `0` 赋值给 `k`，并且整个赋值表达式的值就是被赋的值，也就是 `0`。

在 C 语言中：

- `0` 表示假；
    
- 非零表示真。
    

所以 `while (k = 0)` 的条件结果为假，循环体一次都不执行。

正确结论是：**循环体语句一次也不执行。**

如果想判断 `k` 是否等于 `0`，应该写：

```c
while (k == 0)
```

一个等号 `=` 是赋值，两个等号 `==` 才是判断相等。这是 C 语言考试中的高频陷阱。

## 二十二、例题：关系表达式连写的陷阱

题目：分析下面程序段运行结果。

```c
int a = 1, b = 2, c = 2, t;

while (a < b < c)
{
    t = a;
    a = b;
    b = t;
    c--;
}

printf("%d%d%d\n", a, b, c);
```

关键陷阱是：

```c
a < b < c
```

在数学中可以表示 `a < b` 且 `b < c`，但是在 C 语言中不能这样理解。C 语言会从左到右计算：

```c
(a < b) < c
```

第一次循环：

```c
a = 1, b = 2, c = 2
```

先算：

```c
1 < 2
```

结果为真，真在 C 语言中通常用 `1` 表示，所以表达式变成：

```c
1 < 2
```

结果仍为真，进入循环。

循环体交换 `a` 和 `b`，并执行 `c--`，所以：

```c
a = 2, b = 1, c = 1
```

第二次判断：

```c
a < b < c
```

即：

```c
2 < 1 < 1
```

先算：

```c
2 < 1
```

结果为假，即 `0`。表达式变成：

```c
0 < 1
```

结果为真，所以继续循环。

循环体再次交换 `a` 和 `b`，并执行 `c--`：

```c
a = 1, b = 2, c = 0
```

第三次判断：

```c
1 < 2 < 0
```

先算：

```c
1 < 2
```

结果为真，即 `1`。表达式变成：

```c
1 < 0
```

结果为假，循环结束。

最终输出：

```c
120
```

注意：在 C 语言中判断区间应写成：

```c
a < b && b < c
```

不能写成：

```c
a < b < c
```

## 二十三、`getchar` 与 `putchar`

`getchar()` 用于从输入中读取一个字符。

```c
char c;
c = getchar();
```

`putchar()` 用于输出一个字符。

```c
putchar(c);
```

这两个函数常用于字符处理题目中。

## 二十四、例题：读取字符直到遇到指定字符

```c
#include <stdio.h>

int main()
{
    char c;

    while ((c = getchar()) != '$')
    {
        if (c >= 'A' && c <= 'Z')
        {
            putchar(c);
        }
        else if (c >= 'a' && c <= 'z')
        {
            putchar(c - 32);
        }
    }

    return 0;
}
```

这段代码的关键在于 `while` 条件：

```c
(c = getchar()) != '$'
```

它先使用 `getchar()` 读取一个字符，把它赋值给变量 `c`，然后判断 `c` 是否不等于 `'$'`。

- 如果 `c != '$'` 成立，就进入循环；
    
- 如果读到 `'$'`，循环结束。
    

循环体中的逻辑是：

1. 如果 `c` 是大写字母 `'A'` 到 `'Z'`，直接输出；
    
2. 如果 `c` 是小写字母 `'a'` 到 `'z'`，则通过 `c - 32` 转成对应的大写字母再输出；
    
3. 如果是其他字符，不输出；
    
4. 遇到 `'$'` 时停止循环。
    

注意：`c - 32` 把小写字母转换成大写字母，这种写法依赖 ASCII 编码，在考试中常见。更规范的实际编程方式可以使用 `toupper()`，但期末基础题中一般会直接考 `c - 32`。

## 二十五、编程题：用 `while` 求 `1 + 2 + ... + 100`

题目：使用 `while` 循环编写程序，计算：

```c
1 + 2 + 3 + ... + 100
```

代码如下：

```c
#include <stdio.h>

int main()
{
    int i = 1;
    int sum = 0;

    while (i <= 100)
    {
        sum = sum + i;
        i++;
    }

    printf("%d\n", sum);

    return 0;
}
```

其中：

- `i` 表示当前加到哪个数；
    
- `sum` 用于保存累加和；
    
- 每次循环执行 `sum = sum + i;`
    
- 然后 `i++`，让 `i` 进入下一个数；
    
- 当 `i` 变为 `101` 时，不满足 `i <= 100`，循环结束。
    

最终输出：

```c
5050
```

## 二十六、`do...while` 循环

### 26.1 基本形式

```c
do
{
    循环体语句;
} while (条件表达式);
```

`do...while` 的特点是：**先执行一次循环体，再判断条件。**

因此，无论条件一开始是真还是假，`do...while` 的循环体至少都会执行一次。

注意：`do...while` 最后的 `while (条件表达式)` 后面必须有分号。

```c
} while (条件表达式);
```

这个分号不能省略。

---

## 二十七、`do...while` 与 `while` 的区别

`while` 循环：

```c
while (条件)
{
    循环体;
}
```

特点是先判断，再执行。如果条件一开始为假，循环体一次都不执行。

`do...while` 循环：

```c
do
{
    循环体;
} while (条件);
```

特点是先执行，再判断。无论条件如何，循环体至少执行一次。

所以：

- 不确定是否至少执行一次时，常用 `while`；
    
- 必须先执行一次，再根据结果判断是否继续时，常用 `do...while`。
    

例如要求用户输入一个正数，如果输入不合法就重新输入，就可以使用 `do...while`：

```c
#include <stdio.h>

int main()
{
    int x;

    do
    {
        printf("请输入一个正数：");
        scanf("%d", &x);
    } while (x <= 0);

    printf("你输入的正数是：%d\n", x);

    return 0;
}
```

这段代码会先让用户输入一次，然后判断 `x <= 0` 是否成立。如果输入的是非正数，就继续输入；如果输入的是正数，循环结束。

---

## 二十八、`do...while` 选择题常考点

### 28.1 循环体可以是复合语句

错误说法：`do...while` 循环体只能是一条语句，不能使用复合语句。

这是错误的。`do...while` 的循环体可以有多条语句，只要用花括号括起来即可。

```c
do
{
    scanf("%d", &x);
    sum += x;
} while (x != 0);
```

### 28.2 `while` 后面必须有分号

错误说法：`do...while` 结尾的 `while` 后面不能写分号。

这是错误的。`do...while` 末尾必须写分号。

```c
do
{
    语句;
} while (条件);
```

### 28.3 循环中通常要有改变条件的操作

如果循环体中没有任何操作能让条件最终变为假，就可能造成死循环。

例如：

```c
int x = 1;

do
{
    printf("%d\n", x);
} while (x > 0);
```

这里 `x` 一直为 `1`，条件永远成立，循环无法结束。

### 28.4 `do` 和 `while` 不能拆开省略

`do...while` 是一个完整结构，不能省略 `while`。

## 二十九、例题：`do...while` 中后置自减

```c
#include <stdio.h>

int main()
{
    int a = 1, b = 10;

    do
    {
        b = b - a;
        a++;
    } while (b-- < 0);

    printf("a=%d, b=%d\n", a, b);

    return 0;
}
```

分析过程如下：

初始：

```c
a = 1, b = 10
```

`do...while` 先执行一次循环体：

```c
b = b - a;
```

即：

```c
b = 10 - 1 = 9
```

然后执行：

```c
a++;
```

所以：

```c
a = 2
```

接着判断条件：

```c
b-- < 0
```

此时 `b = 9`，因为 `b--` 是后置自减，所以先用 `9` 参与判断：

```c
9 < 0
```

结果为假，循环结束。

但因为执行了 `b--`，判断之后 `b` 会自减一次，所以：

```c
b = 8
```

最终：

```c
a = 2, b = 8
```

这类题目的关键是理解后置自增、自减：

- `b--`：先使用 `b` 的当前值，再让 `b` 减 `1`；
    
- `--b`：先让 `b` 减 `1`，再使用新值。

## 三十、编程题：用 `do...while` 实现数字累加器

题目要求：

1. 用户输入一系列整数；
    
2. 当用户输入 `0` 时，表示输入结束；
    
3. 计算并输出所有输入数字的累加和。
    

代码如下：

```c
#include <stdio.h>

int main()
{
    int number;
    int sum = 0;

    printf("请输入一系列整数，输入0结束：\n");

    do
    {
        scanf("%d", &number);
        sum = sum + number;
    } while (number != 0);

    printf("累加和为：%d\n", sum);

    return 0;
}
```

这段代码中，`number` 用来保存每次输入的整数，`sum` 用来保存累加结果。

当输入的 `number` 不等于 `0` 时，循环继续；当输入 `0` 时，虽然 `0` 也会加到 `sum` 中，但加 `0` 不影响结果，然后条件 `number != 0` 为假，循环结束。

## 三十一、`for` 循环

### 31.1 基本形式

```c
for (初始化; 循环条件; 循环更新)
{
    循环体语句;
}
```

`for` 循环通常用于循环次数比较明确的情况。

执行顺序如下：

1. 执行初始化部分，只执行一次；
    
2. 判断循环条件；
    
3. 如果条件为真，执行循环体；
    
4. 执行循环更新；
    
5. 回到第 2 步继续判断；
    
6. 如果条件为假，循环结束。
    

例如：

```c
#include <stdio.h>

int main()
{
    int i;

    for (i = 1; i <= 5; i++)
    {
        printf("%d\n", i);
    }

    return 0;
}
```

执行过程：

- 初始 `i = 1`
    
- 判断 `i <= 5`，成立，输出 `1`
    
- 执行 `i++`，`i = 2`
    
- 继续判断，输出 `2`
    
- 依次输出 `3`、`4`、`5`
    
- 当 `i = 6` 时，不满足 `i <= 5`，循环结束
    

最终输出：

```c
1
2
3
4
5
```

---

## 三十二、`for` 循环中的分号

`for` 循环括号中有三部分：

```c
for (初始化; 循环条件; 循环更新)
```

这三部分之间必须用分号隔开，不能用逗号代替。

错误写法：

```c
for (i = 1, i <= 5, i++)
```

正确写法：

```c
for (i = 1; i <= 5; i++)
```

即使某一部分被省略，分号也不能省略。

---

## 三十三、`for` 循环的省略形式与死循环

`for` 循环中的初始化、循环条件、循环更新都可以省略，但两个分号不能省略。

例如：

```c
for (;;)
{
    printf("hello\n");
}
```

这里没有循环条件，默认条件一直为真，所以它会不断执行，形成死循环。

所谓死循环，就是循环条件一直为真，程序无法自动结束循环。死循环可能出现在 `while`、`do...while` 和 `for` 中。

例如：

```c
while (1)
{
    printf("hello\n");
}
```

或者：

```c
for (;;)
{
    printf("hello\n");
}
```

都是死循环。

## 三十四、`break` 和 `continue`

### 34.1 `break`

`break` 用于提前跳出整个循环。

例如：

```c
for (int i = 1; i <= 10; i++)
{
    if (i == 5)
    {
        break;
    }

    printf("%d\n", i);
}
```

当 `i == 5` 时，执行 `break`，整个循环结束，所以只会输出：

```c
1
2
3
4
```

在多重循环中，`break` 只能跳出离它最近的一层循环，不能一次跳出所有循环。

### 34.2 `continue`

`continue` 用于跳过本次循环中剩下的语句，直接进入下一次循环。

例如：

```c
for (int i = 1; i <= 5; i++)
{
    if (i == 3)
    {
        continue;
    }

    printf("%d\n", i);
}
```

当 `i == 3` 时，执行 `continue`，跳过后面的 `printf`，所以不会输出 `3`。

最终输出：

```c
1
2
4
5
```

注意：`continue` 不会结束整个循环，只是结束当前这一轮循环。

## 三十五、例题：`break` 与 `continue` 综合

代码如下：

```c
#include <stdio.h>

int main()
{
    int i;

    for (i = 1; i <= 10; i++)
    {
        if (i % 2 == 0)
        {
```

分析过程：

`for` 循环中，`i` 从 `1` 到 `10`。

第一个 `if`：

```c
if (i % 2 == 0)
{
    continue;
}
```

用于判断 `i` 是否为偶数。如果是偶数，就执行 `continue`，跳过本轮循环，不输出。

第二个 `if`：

```c
if (i == 9)

    break;
}
```

当 `i == 9` 时，执行 `break`，整个循环结束。

所以：

- `i = 1`，不是偶数，也不是 `9`，输出 `1`
    
- `i = 2`，是偶数，跳过
    
- `i = 3`，输出 `3`
    
- `i = 4`，跳过
    
- `i = 5`，输出 `5`
    
- `i = 6`，跳过
    
- `i = 7`，输出 `7`
    
- `i = 8`，跳过
    
- `i = 9`，执行 `break`，循环结束，不输出 `9`
    

最终输出：

```c
1357
```

## 三十六、`for` 循环选择题常考点

### 36.1 `for` 不只能用于次数确定的循环

错误说法：`for` 循环只能用于循环次数已经确定的情况。

这不完全正确。虽然 `for` 常用于循环次数明确的场景，但也可以写成死循环：

```c
for (;;)
{
    /* 死循环 */
}
```

所以不能说 `for` 只能用于次数确定的情况。

### 36.2 `for` 也是先判断后执行

错误说法：`for` 循环先执行循环体，再判断表达式。

这是错误的。`for` 循环和 `while` 一样，都是先判断循环条件，再执行循环体。只有 `do...while` 是先执行循环体，再判断条件。

### 36.3 `for (;)` 是错误写法

死循环的正确写法是：

```c
for (;;)
```

括号里必须有两个分号。

只有一个分号：

```c
for (;)
```

是错误写法。

### 36.4 多条循环语句必须用花括号

如果循环体包含多条语句，必须用花括号括起来。

正确写法：

```c
for (i = 0; i < 10; i++)
{
    scanf("%d", &a);
    sum += a;
}
```

```c
1, 2, 3, 4
```

## 三十八、循环嵌套

循环嵌套是指一个循环内部又包含另一个循环。外面的循环叫外层循环，里面的循环叫内层循环。

例如：

```c
for (i = 1; i <= 4; i++)
{
    for (j = 1; j < i; j++)
    {
        printf(" ");
    }

    printf("*");
    printf("\n");
}
```

这段代码中，外层循环控制行数，内层循环控制每一行前面的空格数。

### 38.1 执行过程分析

外层循环：

```c
for (i = 1; i <= 4; i++)
```

表示一共执行四次，对应输出四行。

内层循环：

```c
for (j = 1; j < i; j++)
```

用于输出空格。

第一轮外层循环：

```c
i = 1
```

内层循环条件：

```c
j < i
```

即：

```c
1 < 1
```

不成立，所以不输出空格。然后输出 `*` 和换行。

第一行：

```c
*
```

第二轮外层循环：

```c
i = 2
```

内层循环从 `j = 1` 开始，判断：

```c
1 < 2
```

成立，所以输出一个空格。然后 `j++`，`j = 2`，判断 `2 < 2` 不成立，内层循环结束。接着输出 `*` 和换行。

第二行：

```c
 *
```

第三轮外层循环：

```c
i = 3
```

内层循环从 `j = 1` 重新开始。注意：每次进入内层 `for`，都会重新执行初始化 `j = 1`。

这一次会输出两个空格，然后输出 `*`。

第三行：

```c
  *
```

第四轮外层循环：

```c
i = 4
```

内层循环输出三个空格，然后输出 `*`。

第四行：

```c
   *
```

最终输出结果为：

```c
*
 *
  *
   *
```

这类图形题的关键是：

1. 外层循环通常控制行数；
    
2. 内层循环通常控制每行输出多少个空格或字符；
    
3. 内层循环每次进入时都会重新初始化；
    
4. 分清哪些语句属于内层循环，哪些语句属于外层循环。

## 三十九、编程题：输入 10 个数求平均数

题目：编写代码，从键盘输入 10 个数，求它们的平均数。

代码如下：

```c
#include <stdio.h>

int main()
{
    int a;
    int i;
    int sum = 0;
    double average;

    for (i = 0; i < 10; i++)
    {
        scanf("%d", &a);
        sum = sum + a;
    }

    average = sum / 10.0;

    printf("平均数为：%lf\n", average);

    return 0;
}
```

这里需要注意：

```c
average = sum / 10.0;
```

不能写成：

```c
average = sum / 10;
```

因为 `sum` 和 `10` 都是整数时，执行的是整数除法，小数部分会被舍去。写成 `10.0` 后，表达式会按浮点数除法计算，结果才能保留小数。

例如：

```c
int sum = 95;
```

如果写：

```c
average = sum / 10;
```

结果是：

```c
9
```

如果写：

```c
average = sum / 10.0;
```

结果是：

```c
9.5
```

所以在求平均数时，除数要写成 `10.0`，或者把 `sum` 强制转换为浮点类型。

## 四十、本节高频易错点总结

分支结构中，首先要掌握三种基本写法：`if`、`if...else`、`if...else if...else`。`if...else if...else` 是从上往下依次判断，只执行第一个满足条件的分支。

`if`、`else`、`while` 后面如果只有一条语句，可以省略花括号；如果有多条语句，必须加花括号。考试中经常通过省略花括号制造陷阱。

嵌套 `if...else` 中，`else` 总是和它前面最近的、尚未配对的 `if` 配对。缩进不决定语法结构。

条件表达式的格式是：

```c
条件 ? 表达式1 : 表达式2
```

条件为真时取表达式1，条件为假时取表达式2。

`switch` 中，`case` 后面必须是常量表达式，不能写变量、范围判断或关系表达式。每个 `case` 后通常要写 `break`，否则会发生贯穿。`default` 表示默认分支，可以省略。

`while` 和 `for` 都是先判断条件，再执行循环体；`do...while` 是先执行循环体，再判断条件，所以循环体至少执行一次。

`do...while` 末尾必须有分号：

```c
} while (条件);
```

`for` 循环中三部分之间必须用分号分隔：

```c
for (初始化; 条件; 更新)
```

死循环可以写成：

```c
for (;;)
```

不能写成：

```c
for (;)
```

`break` 用于跳出整个循环或当前 `switch`；在多重循环中，`break` 只能跳出离它最近的一层循环。

`continue` 用于跳过本次循环，直接进入下一次循环，不会结束整个循环。

关系表达式不能像数学中那样连写。例如判断 `a < b < c`，不能直接写：

```c
a < b < c
```

应该写成：

```c
a < b && b < c
```

赋值号和判断相等要区分：

```c
k = 0     // 赋值
k == 0    // 判断是否相等
```

在循环条件中写成 `while (k = 0)`，会先把 `0` 赋值给 `k`，表达式结果为 `0`，循环不会执行。
