# Allnote

这是一个以 Obsidian 为主的个人学习笔记库，内容覆盖高等数学、线性代数、大学物理、电路分析、STM32、深度学习、程序语言、英语复习以及若干题库整理。

| 目录 / 文件 | 内容 |

## 使用方式

1. 用 Obsidian 打开本文件夹 `E:\Allnote`。
2. 通过左侧文件树按课程进入对应章节。
3. 图片资源通常放在相邻的 `images/` 或 `img/` 目录中，不要随意移动，否则笔记内图片链接可能失效。
4. 数学、物理、电路等公式默认使用 Markdown + LaTeX：

```markdown
行内公式：$E = mc^2$

块公式：
$$
F = ma
$$
```

## 笔记维护约定

- 章节笔记优先保持“可复习完成态”：概念、公式、推导、题型方法和易错处放在对应知识点下。
- 新增课程内容时，优先新建同名课程目录；新增章节时使用两位序号，例如 `01 函数.md`。
- 题库类文件可以放在根目录；系统性课程笔记建议放入对应学科目录。
- 配图、截图、手绘图尽量放到课程目录下的资源文件夹，避免散落在根目录。
- 修改公式后建议检查 `$...$` 和 `$$...$$` 是否成对，避免 Obsidian 渲染异常。

## Git 与同步

本目录已经是 Git 仓库，可用于记录笔记改动。`.gitattributes` 当前启用文本文件自动换行规范化。

提交前建议检查：

```powershell
git status --short
```

如果使用 Obsidian 插件或同步工具，`.obsidian/` 下的配置可能会频繁变化。提交前最好确认这些配置变更是否确实需要保留。

## 适合的整理方向

- 按课程建立总览页，汇总章节链接和复习路线。
- 给重点课程补充“考试题型索引”或“公式速查表”。
- 对图片较多的章节统一整理资源目录，减少断链风险。
- 定期清理临时剪藏内容，把有价值的片段归入正式笔记。
