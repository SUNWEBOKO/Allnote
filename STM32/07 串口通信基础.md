## 1. 串口通信的本质

串口核心是数据按时间顺序**一位一位地串行发送**，而不是并行同时送出。单片机中最常见的是 **TTL 电平串口**，只需要两根数据线就能完成双向通信。

### 1.1 TTL 电平标准

| 电平 | 逻辑值 |
|------|--------|
| 0V | 逻辑 0 |
| 3.3V（或 5V） | 逻辑 1 |

### 1.2 TX 与 RX 交叉连接

```text
STM32 TX ─────────────────── RX 串口工具/另一设备
STM32 RX ─────────────────── TX 串口工具/另一设备
```

**TX（Transmit）** 发出数据，**RX（Receive）** 接收数据。两设备通信时，一方的 TX 必须接另一方的 RX。

### 1.3 共地

串口是单端信号，电压差 = 信号线的电压减去参考地。如果两设备的地电位不同：

```text
A 设备 GND = 0V，B 设备 GND = 0.5V
A 发出 3.3V → B 实际收到 3.3 - 0.5 = 2.8V → 可能误判
```

串口通信时必须**共地**，否则电平参考不一致会丢数据。

## 2. USART 与 UART

| 全称 | 区别 |
|------|------|
| **UART** | 通用异步收发器（Universal Asynchronous Receiver/Transmitter） |
| **USART** | 通用同步/异步收发器（Universal Synchronous/Asynchronous Receiver/Transmitter） |

USART = UART + 同步模式。异步模式使用时两者无区别，STM32 通常使用 USART 做异步串口。

---

## 3. 异步通信关键参数

异步通信没有时钟线，双方必须提前约定**波特率、数据位、停止位、校验位**。

| 参数 | 常见值 | 说明 |
|------|--------|------|
| 波特率 | 9600 / 115200 / 921600 | 每秒传输的符号数 |
| 数据位 | 8 | 每帧数据的位数 |
| 停止位 | 1 | 帧结束的标志位 |
| 校验位 | None | 可选奇/偶校验 |

```text
一帧数据：起始位(0) → 8 位数据 → 停止位(1)
          LSB 优先
```

波特率偏差过大时通信会完全失败。内部时钟（HSI）的精度不够稳定时，建议使用外部晶振（HSE）以获得准确的波特率。

---

## 4. CubeMX 配置步骤

| 步骤 | 操作 |
|------|------|
| 1 | 选择 USART 外设（如 USART1） |
| 2 | 模式选 `Asynchronous` |
| 3 | 设波特率（如 115200） |
| 4 | 数据位 8、无校验、停止位 1 |
| 5 | 确认 TX/RX 引脚分配 |
| 6 | 保存生成代码 |

### 4.1 GPIO 自动配置

CubeMX 选中 USART 异步模式后，TX 引脚自动配为**复用推挽输出**，RX 自动配为**浮空输入**（或上拉输入），通常不需要手动调整。

## 5. HAL 基础 API

| 函数 | 用途 |
|------|------|
| `HAL_UART_Transmit(huart, data, len, timeout)` | 阻塞发送 |
| `HAL_UART_Receive(huart, buf, len, timeout)` | 阻塞接收 |

阻塞含义：函数会一直在那里等待，直到发送/接收完成或超时。

```c
char msg[] = "Hello STM32\r\n";
HAL_UART_Transmit(&huart1, (uint8_t *)msg, strlen(msg), 1000);
```

## 6. 常见排障顺序

```text
物理层 → 配置层 → 逻辑层

物理层：TX↔RX 是否交叉？GND 是否连接？电平是否匹配？
配置层：波特率、数据位、停止位是否双方一致？
逻辑层：代码是否调用了发送函数？是否在正确的位置？
```

---

## 7. 高频易错点

1. **TX-RX 直连（没交叉）**。最常见错误。一方的 TX 接另一方的 TX 时，双方都在发送没人接收。

2. **没共地**。两设备地电位不同时，数据出现随机错位。

3. **波特率不匹配**。收发两端的波特率必须一致，偏差超过约 2% 就会丢帧。

4. **使用 HSI 导致波特率偏差**。内部 RC 振荡器精度不够，串口通信建议用 HSE。

5. **USART 没使能中断但用了中断函数**。`Transmit_IT`/`Receive_IT` 需要中断支持，否则收不到数据。

6. **忽略超时参数**。阻塞函数的 timeout 设得过短，正常传输被提前中断。

## 8. 一页速记

### 连线口诀
```text
TX↔RX，RX↔TX，GND↔GND
```

### 配置三要素
```text
波特率一致、数据位一致、停止位一致
```

### 核心 API
| 函数 | 用途 |
|------|------|
| `HAL_UART_Transmit(huart, data, len, tout)` | 阻塞发送 |
| `HAL_UART_Receive(huart, buf, len, tout)` | 阻塞接收 |

### 排障优先级
```text
连线 → 共地 → 波特率 → 引脚配置 → 代码逻辑
```

### 最重要的一句话
> 串口不工作时，不要先调代码——先拿万用表量 TX 引脚电平，再示波器看波形，硬件确认了再查软件。
