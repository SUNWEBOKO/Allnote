## 1. 驱动对接

### 1.1 硬件连接

| 蓝牙模块 | STM32 / USB 转串口 |
|----------|-------------------|
| TXD | RXD |
| RXD | TXD |
| GND | GND |
| VCC | 3.3V 或 5V（查模块手册） |

要点：

- TXD ↔ RXD **必须交叉**；
- 必须共地，否则电平无参考点；
- 供电电压以模块手册为准，不确定时优先用 3.3V。

---

### 1.2 驱动 API

```c
#include "bluetooth_serial.h"
```

| 函数 | 作用 |
|------|------|
| `BluetoothSerial_Init(huart)` | 初始化，启动中断接收 |
| `BluetoothSerial_SendString(str)` | 发送字符串（阻塞发送，50ms 超时） |
| `BluetoothSerial_Printf(format, ...)` | 格式化发送（内部调用 SendString） |
| `BluetoothSerial_OnUartRxCplt(huart)` | 串口接收中断处理（HAL 回调的入口） |

全局标志：

```c
extern char Bluetooth_RxPacket[BT_RX_PACKET_SIZE];   // 当前完整数据包（不含 [ ]）
extern volatile uint8_t Bluetooth_RxFlag;             // 收到完整包后置 1，用户清零
```

协议帧定界：

```text
[ ... ]   →   收到 [ 开始接收，收到 ] 结束，中间内容存入 Bluetooth_RxPacket
```

---

### 1.3 集成步骤

```c
// Step 1 — 初始化（传入已配置好的 UART 句柄）
BluetoothSerial_Init(&huart1);

// Step 2 — HAL_UART_RxCpltCallback 会自动路由到 BluetoothSerial_OnUartRxCplt
// 用户不需要重写 HAL_UART_RxCpltCallback（驱动已提供）

// Step 3 — 主循环检查 Bluetooth_RxFlag
while (1)
{
    if (Bluetooth_RxFlag)
    {
        Bluetooth_RxFlag = 0;
        ParsePacket(Bluetooth_RxPacket);   // 用户解析函数
    }
}
```

发送示例：

```c
BluetoothSerial_SendString("hello");
BluetoothSerial_Printf("[display,0,0,voltage:%d]", adc_value);
```

## 2. 小程序通信协议

### 2.1 统一格式

所有数据包采用统一结构：

```text
[类型,参数1,参数2,...]
```

- 包定界符：`[` 为包头，`]` 为包尾
- 参数间以英文逗号 `,` 分隔
- 驱动接收后 `Bluetooth_RxPacket` 中**不包含方括号**，仅保留中间内容

### 2.2 按键 — `K`

```text
[K,按键名称,down]     // 按下
[K,按键名称,up]       // 松开
```

| 字段 | 说明 |
|------|------|
| K | 按键标识符 |
| 按键名称 | 用户在小程序中设置的按键名 |
| down / up | 按下 / 松开 |

示例：

```text
[K,LED,down]
[K,forward,up]
```

### 2.3 滑杆 — `slider`

```text
[slider,滑杆名称,值]
```

| 字段 | 说明 |
|------|------|
| slider | 滑杆标识符 |
| 滑杆名称 | 用户设置的滑杆名 |
| 值 | 浮点数或整数格式 |

示例：

```text
[slider,Kp,3.25]
[slider,target,80]
```

### 2.4 摇杆 — `joystick`

```text
[joystick,左横向,左纵向,右横向,右纵向]
```

| 字段 | 说明 |
|------|------|
| joystick | 摇杆标识符 |
| 左横向 / 左纵向 / 右横向 / 右纵向 | 值范围 -100 ~ 100 |

示例：

```text
[joystick,0,100,0,0]
[joystick,-50,80,20,-10]
```

### 2.5 显示屏 — `display`

```text
[display,X,Y,内容,字号]
```

| 字段 | 说明 |
|------|------|
| display | 显示屏标识符 |
| X, Y | 显示坐标（像素） |
| 内容 | 显示文本 |
| 字号 | 可选，默认 18 |

清屏：

```text
[display-clear]
```

### 2.6 绘图 — `plot`

```text
[plot,值1]               // 单条曲线
[plot,值1,值2,值3]       // 多条曲线
```

示例：

```text
[plot,0]
[plot,50,-20,100]
```

清空绘图区：

```text
[plot-clear]
```

## 3. 绘图

### 3.1 单曲线示例

```c
float x = 0.0f;
float y = 0.0f;

while (1)
{
    x += 0.1f;
    y = sinf(x);
    BluetoothSerial_Printf("[plot,%f]", y);
    HAL_Delay(50);
}
```

### 3.2 多曲线示例

```c
float y1 = sinf(x);
float y2 = cosf(x);
BluetoothSerial_Printf("[plot,%f,%f]", y1, y2);
```

发送太快可能造成数据拥堵，建议间隔 **50 ~ 100 ms**。

### 3.3 坐标轴设置（小程序端）

- Y 轴自动缩放：小程序默认开启，可取消后手动设置 Ymin / Ymax；
- X 轴点数：控制显示窗口宽度；
- 固定 Y 轴范围适合观察固定幅值信号（如正弦波设为 -2 ~ 2）。

## 4. 调参

### 4.1 滑杆配置建议

| 参数 | 建议最小值 | 建议最大值 | 建议步距 |
|------|-----------|-----------|---------|
| Kp | 0 | 10 | 0.01 |
| Ki | 0 | 5 | 0.001 |
| Kd | 0 | 1 | 0.001 |
| 目标速度 | -100 | 100 | 1 |

### 4.2 解析示例（滑杆）

```c
static float Kp = 0.0f;
static float Ki = 0.0f;
static float Kd = 0.0f;

void ParseSliderPacket(void)
{
    char *name = strtok(NULL, ",");
    char *value = strtok(NULL, ",");

    if (name == NULL || value == NULL) return;

    if (strcmp(name, "Kp") == 0)
        Kp = atof(value);
    else if (strcmp(name, "Ki") == 0)
        Ki = atof(value);
    else if (strcmp(name, "Kd") == 0)
        Kd = atof(value);
}
```

### 4.3 滑杆合并到统一解析框架

```c
void ParsePacket(char *packet)
{
    char *tag = strtok(packet, ",");
    if (tag == NULL) return;

    if (strcmp(tag, "K") == 0)
    {
        char *name = strtok(NULL, ",");
        char *action = strtok(NULL, ",");
        if (name == NULL || action == NULL) return;

        // 根据 name 和 action 执行控制逻辑
    }
    else if (strcmp(tag, "slider") == 0)
    {
        ParseSliderPacket();
    }
    else if (strcmp(tag, "joystick") == 0)
    {
        int8_t lh, lv, rh, rv;
        lh = (int8_t)atoi(strtok(NULL, ","));
        lv = (int8_t)atoi(strtok(NULL, ","));
        rh = (int8_t)atoi(strtok(NULL, ","));
        rv = (int8_t)atoi(strtok(NULL, ","));
        // 映射到电机控制
    }
}
```

注意：`strtok` 会修改原字符串，如需保留原始数据包请先 `strcpy` 副本。

## 5. 完整解析框架

```c
#include <string.h>
#include <stdlib.h>
#include <stdio.h>

static float Kp = 0.0f, Ki = 0.0f, Kd = 0.0f;
static int8_t LH = 0, LV = 0, RH = 0, RV = 0;

static void ParseKey(void)
{
    char *name = strtok(NULL, ",");
    char *action = strtok(NULL, ",");
    if (!name || !action) return;

    if (strcmp(name, "LED") == 0 && strcmp(action, "down") == 0)
        BluetoothSerial_Printf("[display,0,0,LED:ON]");
    else if (strcmp(name, "LED") == 0 && strcmp(action, "up") == 0)
        BluetoothSerial_Printf("[display,0,0,LED:OFF]");
}

static void ParseSlider(void)
{
    char *name = strtok(NULL, ",");
    char *value = strtok(NULL, ",");
    if (!name || !value) return;

    float v = atof(value);
    if (strcmp(name, "Kp") == 0)       Kp = v;
    else if (strcmp(name, "Ki") == 0)  Ki = v;
    else if (strcmp(name, "Kd") == 0)  Kd = v;
}

static void ParseJoystick(void)
{
    LH = (int8_t)atoi(strtok(NULL, ","));
    LV = (int8_t)atoi(strtok(NULL, ","));
    RH = (int8_t)atoi(strtok(NULL, ","));
    RV = (int8_t)atoi(strtok(NULL, ","));
}

void ParsePacket(char *packet)
{
    char *tag = strtok(packet, ",");
    if (!tag) return;

    if (strcmp(tag, "K") == 0)        ParseKey();
    else if (strcmp(tag, "slider") == 0)    ParseSlider();
    else if (strcmp(tag, "joystick") == 0)  ParseJoystick();
}
```

主循环：

```c
while (1)
{
    if (Bluetooth_RxFlag)
    {
        Bluetooth_RxFlag = 0;
        ParsePacket(Bluetooth_RxPacket);
    }
}
```

## 6. 一页速记

### 6.1 硬件连线

```text
蓝牙 TXD → STM32 RXD
蓝牙 RXD → STM32 TXD
GND → GND（共地）
```

### 6.2 协议格式

| 类型 | 格式 |
|------|------|
| 按键 | `[K,名称,down/up]` |
| 滑杆 | `[slider,名称,值]` |
| 摇杆 | `[joystick,LH,LV,RH,RV]` |
| 显示 | `[display,X,Y,内容]` |
| 绘图 | `[plot,值1,值2,...]` |
| 清屏 | `[display-clear]` / `[plot-clear]` |

### 6.3 核心 API

| 函数 | 作用 |
|------|------|
| `BluetoothSerial_Init(huart)` | 初始化，启动中断接收 |
| `BluetoothSerial_Printf(fmt, ...)` | 格式化发送 |
| `Bluetooth_RxFlag` | 收到完整包后置 1，用户清零 |

### 6.4 解析框架

```c
void ParsePacket(char *packet)
{
    char *tag = strtok(packet, ",");
    if (!tag) return;

    if (strcmp(tag, "K") == 0)        ParseKey();
    else if (strcmp(tag, "slider") == 0)    ParseSlider();
    else if (strcmp(tag, "joystick") == 0)  ParseJoystick();
}
```

### 6.5 绘图要点

- 发送间隔：**50 ~ 100ms**，过快会造成数据拥堵
- Y 轴：先自动缩放，需要时固定范围
- `strtok` 会修改原字符串，如需保留原始包请先 `strcpy`
