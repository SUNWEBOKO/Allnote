## 1. 舵机控制原理

舵机是一个简化的伺服系统：电机 + 减速机构 + 电位器反馈 + 控制板。

```text
输入 PWM 信号 → 控制板解析占空比
                     ↓
              与电位器反馈比较（实际角度）
                     ↓
              误差不为 0 → 驱动电机转动
                     ↓
              电位器随动 → 反馈值逼近目标 → 误差归零 → 停止
```

对用户而言，核心任务只有一件：**給出对应目标角度的 PWM 信号。** 舵机内部会自动完成"目标 vs 实际"的闭环调节。

### 1.1 为什么不同占空比定在不同角度

舵机内部的电位器与输出轴固定连接，电位器分压 = 当前实际角度。控制板比较两路电压：

```text
目标角度（由 PWM 占空比决定）→ 设定电压 A
实际角度（由电位器采样得到）→ 采样电压 B
比较器输出 A - B：
  A > B → 正转（角度偏小，需要增大）
  A < B → 反转（角度偏大，需要减小）
  A = B → 停止（已到达目标）
```

这就是一个完整的**闭环控制**：PWM 占空比改变设定电压，电机在反馈作用下自动追赶到新位置。所以给持续 PWM 信号，舵机就维持在对应角度；不给信号，舵机失去保持力，可被外力扳动。

## 2. SG90 角度与 PWM 映射

### 2.1 常见参数

| 参数 | 值 |
|------|-----|
| 控制周期 | 20ms（对应频率 50Hz） |
| 0° 脉宽 | 500μs |
| 180° 脉宽 | 2500μs |
| 占空比范围 | 2.5% ~ 12.5% |

```text
0°  对应 500μs  / 20000μs = 2.5%
90° 对应 1500μs / 20000μs = 7.5%
180°对应 2500μs / 20000μs = 12.5%
```

### 2.2 脉宽与角度的关系

```text
角度 0°   → 脉宽 500μs  → 占空比 2.5%
角度 90°  → 脉宽 1500μs → 占空比 7.5%
角度 180° → 脉宽 2500μs → 占空比 12.5%
```

## 3. CubeMX 配置

| 配置项 | 设置值 |
|--------|--------|
| 系统时钟 | 72MHz（HSE + PLL） |
| 编码器输入 | TIM1, Encoder Mode |
| 舵机 PWM | TIM4_CH3 (PB8) |
| PWM 频率目标 | 50Hz |

PWM 参数示例：

```text
PSC = 719 → 计数频率 = 72MHz / 720 = 100kHz
ARR = 1999 → 周期 = 2000 / 100kHz = 20ms = 50Hz
```

实际操作时以定时器真实输入时钟为准，用公式反算确认：

$$
f_{pwm} = \frac{f_{tim}}{(PSC + 1) \times (ARR + 1)}
$$

## 4. HAL 代码实现

### 4.1 启动编码器与 PWM

```c
HAL_TIM_Encoder_Start(&htim1, TIM_CHANNEL_ALL);
HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_3);
```

### 4.2 主循环映射

```c
int32_t count = (int32_t)__HAL_TIM_GET_COUNTER(&htim1);
if (count < 0) count = 0;
if (count > COUNT_MAX) count = COUNT_MAX;

// 线性映射：计数 0~COUNT_MAX → 占空比 2.5%~12.5%
float ratio = (float)count / COUNT_MAX;
float duty  = (ratio * 10.0f + 2.5f) / 100.0f;
uint32_t ccr = (uint32_t)(duty * (ARR + 1));

__HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_3, ccr);
```

例如 `ARR = 1999` 时，一个 PWM 周期有 `2000` 个计数；`90°` 对应 `7.5%` 占空比，所以 `CCR ≈ 2000 × 0.075 = 150`。

## 5. 编码器计数范围的设计

视频示例中 `COUNT_MAX = 20`：

- 旋钮转一圈编码器约 40 个计数
- 舵机只需 0~180°（约半圈）
- 取 20 作为映射上限，使旋钮半圈对应舵机满行程

本质是"输入计数范围 → 输出角度范围"的线性标定。

---

## 6. 高频易错点

1. **整型除法陷阱**。`count / COUNT_MAX` 在 C 中是整型除法，结果为 0。必须显式转为浮点：`(float)count / COUNT_MAX`。

2. **舵机上电跳一下**。初始化时 PWM 输出对应某个固定角度，可考虑先配成中位值 90° 以减少冲击。

3. **供电不足导致复位或抖动**。舵机瞬时电流较大，必须注意供电裕量和共地。

4. **极限脉宽超出舵机范围**。不同舵机的极限脉宽有差异，最好实测后收紧上下限。

5. **PWM 频率不是 50Hz**。未用公式反算确认，导致舵机异常抖动或不到位。

## 7. 一页速记

### 控制链路
```text
角度 ⇔ 脉宽 ⇔ 占空比
```

### 常见参数
```text
50Hz（周期 20ms）
500μs (2.5%) → 0°
2500μs (12.5%) → 180°
```

### 软件核心
```text
读编码器 → 线性映射 → 写 CCR
```

### 核心 API
| 函数 | 用途 |
|------|------|
| `__HAL_TIM_SET_COMPARE(tim, ch, val)` | 设置占空比 |

### 最重要的一句话
> 舵机控制不是"给电机供电"，而是"告诉舵机控制板目标角度"——角度信息通过 PWM 占空比传递。
