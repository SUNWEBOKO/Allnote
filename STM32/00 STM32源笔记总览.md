# STM32 源笔记总览：从外设入门到项目闭环

> 这份总览用于把 `01` 到 `32` 的分散笔记串成一条复习路线。先按阶段建立主线，再回到单篇文档查配置、代码、排障和自测题。

---

## 1. 学习主线

STM32 学习不要从“背外设名字”开始，而要按工程闭环推进：

```text
看懂硬件连接 -> 配置 CubeMX -> 理解 HAL 初始化 -> 写最小验证代码 -> 排查现象 -> 封装成可复用模块
```

每篇笔记都尽量围绕这条线组织。复习时优先问自己：这一节的输入是什么、外设做了什么、输出如何验证、失败时先查哪里。

## 3. 复习检查表

每学完一篇，按下面 6 个问题自检：

1. 这节依赖哪些硬件连接？有没有高低电平、地址、引脚复用、供电或共地要求？
2. CubeMX 至少要配置哪些外设、模式、中断、DMA 或时钟参数？
3. HAL 初始化后，还要手动调用哪些启动函数，例如 `HAL_TIM_PWM_Start()`、`HAL_CAN_Start()`？
4. 最小可验证现象是什么？LED 亮、串口打印、计数器变化、屏幕刷新还是电机转动？
5. 最常见失败现象是什么？应该按硬件、CubeMX、启动函数、业务代码的顺序怎么查？
6. 这节能不能封装成独立模块？模块对外只暴露哪些 API？

## 4. 常见跨章节易错点

| 易错点 | 涉及章节 | 快速判断 |
|---|---|---|
| 只看代码，不查原理图 | GPIO、OLED、MPU、CAN、电机 | 先确认引脚、供电、共地和电平逻辑 |
| 忘记启动外设 | PWM、输入捕获、编码器、CAN、UART DMA | 初始化函数不等于外设已经开始工作 |
| 中断里做太多事 | 按键、串口、PID、显示 | 中断只采样/置标志，耗时逻辑放主循环或任务 |
| 地址位数混用 | I2C、OLED、MPU | 分清 7 位地址和 HAL 使用的左移地址 |
| 周期不固定 | PID、测速、滤波 | 控制和测速优先用定时器固定节拍 |
| 单位不统一 | ADC、编码器、IMU、PID | raw、物理量、显示量、控制量分层处理 |
| 过早追求完整项目 | STM32Watch、平衡车、电机闭环 | 先做最小闭环，再叠加功能和观感 |

---

## 5. 一页速记

如果只能记住一句话：

> STM32 学习的核心不是把每个外设孤立背熟，而是反复训练“硬件连接 -> 外设配置 -> 数据流/时序 -> 最小验证 -> 工程封装 -> 故障排查”的闭环能力。
