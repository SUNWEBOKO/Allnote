# 第10章 图像、文本与信号数据

## 本章核心问题

数学建模中的数据不只来自表格。图像、文本、声音、振动、传感器序列等都可以被转化为可计算的数值表示，再进入统计分析、机器学习或深度学习模型。本章的主线是：

1. 图像如何表示为矩阵或张量，并通过滤波、边缘、角点、局部描述子提取特征。
2. 文本如何从字符串变成向量，并用于分类、话题分析和情感分析。
3. 信号如何在时域、频域、时频域中提取指标，并通过滤波与分解提取有效成分。
4. 多模态模型如何把图像、文本、音频等信息对齐到统一表示空间。

建模时可以把本章方法理解成“非结构化数据的特征工程”：先把原始对象转成数值表示，再根据任务选择分类、预测、聚类、识别、检测或生成模型。

## 10.1 数字图像处理与计算机视觉

视觉数据通常以矩阵或三维张量形式存储。灰度图可以看作一个 $M \times N$ 矩阵，矩阵元素表示像素亮度；彩色图通常是 $M \times N \times 3$ 的三维数组，第三维表示颜色通道。OpenCV 是 Python 中常用的图像处理库，适合完成图像读取、颜色空间转换、滤波、形态学操作、特征点检测和匹配等任务。

### 10.1.1 数字图像的表示与基础处理

#### 图像读取与颜色通道

OpenCV 默认按 BGR 顺序读取图像，而 Matplotlib 默认按 RGB 顺序显示图像。因此，用 OpenCV 读图后，如果直接用 `plt.imshow` 显示，颜色可能会偏差；通常需要先做 BGR 到 RGB 的转换。

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

input_image = cv2.imread("noidea.jpg")
rgb_image = cv2.cvtColor(input_image, cv2.COLOR_BGR2RGB)

print(input_image.shape)  # 例如：(414, 625, 3)
plt.imshow(rgb_image)
plt.axis("off")
plt.show()
```

#### RGB 与 HSV

RGB 用红、绿、蓝三个通道表示颜色，适合显示设备；HSV 用色调 Hue、饱和度 Saturation、明度 Value 描述颜色，更接近人的颜色感知，常用于颜色分割和颜色识别。

在 OpenCV 中，图像读取后是 BGR，所以转换到 HSV 应使用 `cv2.COLOR_BGR2HSV`。

```python
image = cv2.imread("path_to_your_image.jpg")
hsv_image = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

# 以蓝色区域提取为例。OpenCV 中 H 的常用范围是 0-179。
lower_blue = np.array([110, 50, 50])
upper_blue = np.array([130, 255, 255])

mask = cv2.inRange(hsv_image, lower_blue, upper_blue)
result = cv2.bitwise_and(image, image, mask=mask)

cv2.imshow("Original Image", image)
cv2.imshow("Mask", mask)
cv2.imshow("Result", result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

这段代码的核心逻辑是：先把图像从 BGR 转到 HSV，再用上下阈值生成掩码，最后用掩码保留目标颜色区域。

```python
dogface = input_image[60:250, 70:350]
plt.imshow(cv2.cvtColor(dogface, cv2.COLOR_BGR2RGB))
```

把裁剪出的区域粘贴回原图时，要保证目标区域的尺寸与待粘贴区域一致。

```python
fresh_image = cv2.imread("noidea.jpg")

```

翻转和转置是常见几何变换。

```python
vertical_flip = cv2.flip(input_image, 0)      # 垂直翻转

```

#### 平滑、腐蚀与锐化

高斯平滑用于削弱噪声和细节。它用邻域像素的加权平均替代当前像素，距离中心越远权重越小。

```python
d = 5
img_blur = cv2.GaussianBlur(input_image, (2 * d + 1, 2 * d + 1), 0)
plt.imshow(cv2.cvtColor(img_blur, cv2.COLOR_BGR2RGB))
plt.axis("off")
plt.show()
```

腐蚀是形态学操作，常用于去除小的前景噪点、断开细连接。它用结构元素在图像上滑动，只有当结构元素覆盖区域满足前景条件时，中心点才保留为前景。

```python
image = cv2.imread("path_to_your_image.jpg", cv2.IMREAD_GRAYSCALE)
kernel = np.ones((5, 5), np.uint8)
eroded_image = cv2.erode(image, kernel, iterations=1)

cv2.imshow("Original Image", image)
cv2.imshow("Eroded Image", eroded_image)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

锐化用于增强边缘和细节，常通过卷积核完成。

```python
image = cv2.imread("path_to_your_image.jpg")

kernel = np.array([
    [-1, -1, -1],
    [-1,  9, -1],
    [-1, -1, -1],
])

sharpened_image = cv2.filter2D(image, -1, kernel)

cv2.imshow("Original Image", image)
cv2.imshow("Sharpened Image", sharpened_image)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

建模使用提示：平滑会降低噪声，但也可能抹掉边缘；锐化会突出边缘，但也可能放大噪声。图像预处理要服务于下游任务，不是越强越好。

### 10.1.2 边缘、角点与局部特征

图像特征点用于描述局部显著结构，例如边缘、角点、纹理突变区域。它们常用于图像匹配、目标识别、定位、跟踪和三维重建。

#### Sobel：梯度与边缘

Sobel 算子通过两个方向的卷积核计算图像灰度梯度。水平和垂直梯度变化越强，越可能对应边缘。

```python
sobel_image = cv2.cvtColor(input_image, cv2.COLOR_BGR2GRAY)

sobel_x = cv2.Sobel(sobel_image, cv2.CV_64F, 1, 0, ksize=9)
sobel_y = cv2.Sobel(sobel_image, cv2.CV_64F, 0, 1, ksize=9)

plt.imshow(sobel_x, cmap="gray")
plt.axis("off")
plt.show()
```

#### Canny：多阶段边缘检测

Canny 边缘检测比单纯梯度算子更完整，主要步骤是：高斯平滑、梯度计算、非极大值抑制、双阈值检测、边缘连接。它可以得到较细、较连续的边缘。

```python
th1 = 30
th2 = 60
d = 3

edge_result = input_image.copy()
edge_result = cv2.GaussianBlur(edge_result, (2 * d + 1, 2 * d + 1), 0)
gray = cv2.cvtColor(edge_result, cv2.COLOR_BGR2GRAY)
edge = cv2.Canny(gray, th1, th2)

edge_result[edge != 0] = (0, 255, 0)
plt.imshow(cv2.cvtColor(edge_result, cv2.COLOR_BGR2RGB))
plt.axis("off")
plt.show()
```

![img](img/docs-CH10-src-wps5.jpg)

图10.4 Canny 边缘检测效果

阈值选择会直接影响边缘数量：阈值过低会引入噪声边缘，阈值过高会漏掉真实边缘。

#### Harris：角点检测

角点可以理解为局部窗口在多个方向上灰度变化都很明显的位置。Harris 方法通过局部梯度自相关矩阵计算角点响应，响应值越大，越可能是角点。

```python
harris_test = input_image.copy()
gray = cv2.cvtColor(harris_test, cv2.COLOR_BGR2GRAY)
gray = np.float32(gray)

block_size = 4
kernel_size = 3
k = 0.05

dst = cv2.cornerHarris(gray, block_size, kernel_size, k)
dst = cv2.dilate(dst, None)

harris_test[dst > 0.01 * dst.max()] = [0, 0, 255]
plt.imshow(cv2.cvtColor(harris_test, cv2.COLOR_BGR2RGB))
plt.axis("off")
plt.show()
```

![img](img/docs-CH10-src-wps6.jpg)

图10.5 Harris 角点检测

Harris 适合检测角点，但尺度变化较大时需要更复杂的尺度空间方法。

#### ORB：局部特征描述与匹配

ORB 结合 FAST 角点检测和 BRIEF 描述子，并加入方向估计，使其具有较好的速度和旋转鲁棒性。ORB 描述子是二进制向量，匹配时常配合汉明距离。

```python
orb_image = input_image.copy()
orb = cv2.ORB_create()

kp = orb.detect(orb_image, None)
kp, des = orb.compute(orb_image, kp)

output = cv2.drawKeypoints(orb_image, kp, None)
plt.imshow(cv2.cvtColor(output, cv2.COLOR_BGR2RGB))
plt.axis("off")
plt.show()
```

### 10.1.3 计算机视觉任务

计算机视觉的目标不是简单“显示图像”，而是从图像中提取可用于决策的信息。传统视觉依赖人工设计特征；深度学习方法则通过神经网络自动学习特征。

#### 卷积神经网络

卷积可以理解为一个小矩阵在图像上滑动，对局部区域做按位乘加，得到新的特征图。卷积神经网络将卷积核参数作为可学习权重，从而自动提取边缘、纹理、形状和语义特征。

常见 CNN 结构包括 LeNet-5、VGG、GoogLeNet、ResNet、GhostNet 等。许多目标检测和分割模型也会使用 CNN 或视觉 Transformer 作为 Backbone。

#### 图像分类

图像分类把整张图像分到预定义类别中。早期方法依赖颜色、纹理、形状等人工特征；ImageNet 等大规模数据集推动了 AlexNet、VGG、GoogLeNet、ResNet 等深度模型的发展，使模型能够自动学习图像特征。

目标检测需要同时回答两个问题：图中有什么，以及目标在哪里。输出通常包含类别和边界框。常用评价指标包括 Precision、Recall、F1 和 mAP。典型模型包括 YOLO、SSD、Faster R-CNN、DETR 等。

## 10.2 计算语言学与自然语言处理

文本不能直接进入大多数数值模型。自然语言处理的关键步骤是：先把文本清洗、切分、编码成向量，再完成分类、聚类、话题建模、情感分析、问答或生成等任务。

### 10.2.2 文本嵌入表示

文本向量化的目标是把离散的词、字、句子或文档映射到数值向量，使模型能够计算相似度、分类边界或语义关系。

#### One-Hot

One-Hot 编码为词表中的每个词建立一个维度，某个词出现则对应位置为 1，其余为 0。它简单直观，但维度高、稀疏，不能表达词与词之间的语义接近关系。

#### TF-IDF

TF-IDF 用词频和逆文档频率衡量一个词对文档的代表性。一个词在当前文档中出现越多、在其他文档中越少，它越可能是当前文档的关键词。

$$
\operatorname{TFIDF}(t,d)=\operatorname{TF}(t,d)\cdot \operatorname{IDF}(t)
$$

$$
\operatorname{IDF}(t)=\log\frac{N}{N(t)+1}
$$

其中，$N$ 是文档总数，$N(t)$ 是包含词 $t$ 的文档数，分母加 $1$ 用于避免除零。

#### Word2Vec

Word2Vec 用神经网络学习词向量，典型结构有 CBOW 和 Skip-Gram。CBOW 用上下文预测中心词，适合较小语料；Skip-Gram 用中心词预测上下文，在大语料上表现更好。

## 10.3 数字信号处理与智能感知

数字信号处理关注信号的表示、变换、滤波、分解和特征提取。建模中常见信号包括声音、振动、电流、电压、温度、压力和各类传感器时间序列。

### 10.3.1 傅里叶变换

傅里叶变换把信号从时域转换到频域。时域关注“信号如何随时间变化”，频域关注“信号由哪些频率成分组成”。

连续傅里叶变换可写为：

$$
X(f)=\int_{-\infty}^{+\infty}x(t)e^{-j2\pi ft}\,dt
$$

其中，$x(t)$ 是时域信号，$X(f)$ 是频率 $f$ 处的频谱分量，$j$ 是虚数单位。傅里叶变换结果通常是复数，幅值表示频率成分强度，相位表示该频率成分的时间位置关系。

NumPy 可以直接计算离散傅里叶变换。

```python
import numpy as np
import matplotlib.pyplot as plt

fs = 150.0          # 采样频率
ts = 1.0 / fs       # 采样间隔
t = np.arange(0, 1, ts)
ff = 5              # 信号频率

y = np.sin(2 * np.pi * ff * t)

n = len(y)
k = np.arange(n)
T = n / fs
frq = k / T
Y = np.fft.fft(y) / n

Y = Y[: n // 2]
frq = frq[: n // 2]

plt.subplot(2, 1, 1)
plt.plot(t, y)
plt.xlabel("Time")
plt.ylabel("Amplitude")

plt.subplot(2, 1, 2)
plt.plot(frq, np.abs(Y), "r")
plt.xlabel("Freq (Hz)")
plt.ylabel("|Y(freq)|")

plt.tight_layout()
plt.show()
```

图10.22 原始信号与频谱图

离散傅里叶变换的频谱通常具有对称性，因此单通道实信号常展示一半频谱。实际任务中还要注意采样频率、奈奎斯特频率、窗函数、频率分辨率和泄漏问题。

二维傅里叶变换可用于图像频域分析，例如图像增强、去噪和纹理分析。

### 10.3.2 信号统计指标

信号特征通常分为时域、频域和时频域三类。时域特征直接描述波形的幅值、波动和冲击；频域特征描述频率成分分布；时频域特征用于描述随时间变化的频率结构。

设离散信号为 $x_1,x_2,\dots,x_N$，均值为 $\bar{x}$。

#### 时域指标

- 最大值 $x_{\max}$：观测区间内最大幅值。
- 最小值 $x_{\min}$：观测区间内最小幅值。
- 峰值 $X_p$：常取 $\max |x_i|$，用于描述最大冲击幅度。
- 均值：

$$
\bar{x}=\frac{1}{N}\sum_{i=1}^{N}x_i
$$

- 整流平均值：

$$
X_{\mathrm{arv}}=\frac{1}{N}\sum_{i=1}^{N}|x_i|
$$

- 标准差：

$$
\sigma=\sqrt{\frac{1}{N}\sum_{i=1}^{N}(x_i-\bar{x})^2}
$$

- 均方根值：

$$
X_{\mathrm{rms}}=\sqrt{\frac{1}{N}\sum_{i=1}^{N}x_i^2}
$$

- 偏度：

$$
\gamma=\frac{1}{N}\sum_{i=1}^{N}\left(\frac{x_i-\bar{x}}{\sigma}\right)^3
$$

偏度描述分布不对称程度。正偏表示右尾较长，负偏表示左尾较长。

- 峭度：

$$
K=\frac{1}{N}\sum_{i=1}^{N}\left(\frac{x_i-\bar{x}}{\sigma}\right)^4
$$

峭度常用于反映冲击特征，机械故障诊断中比较常见。

- 峰值指标：

$$
C=\frac{X_p}{X_{\mathrm{rms}}}
$$

- 波形指标：

$$
S_f=\frac{X_{\mathrm{rms}}}{X_{\mathrm{arv}}}
$$

- 脉冲指标：

$$
I_f=\frac{X_p}{X_{\mathrm{arv}}}
$$

- 裕度指标：

$$
C_L=\frac{X_p}{\left(\frac{1}{N}\sum_{i=1}^{N}\sqrt{|x_i|}\right)^2}
$$

这些指标常用于振动信号和设备故障分析。峰值、峭度、脉冲指标对突发冲击更敏感；均方根值更适合描述总体能量水平。

#### 频域指标

对信号做傅里叶变换或功率谱估计后，可以从频域提取统计特征。设第 $i$ 个频率点为 $f_i$，对应幅值或功率权重为 $A_i$。

- 重心频率：

$$
FC=\frac{\sum_i f_i A_i}{\sum_i A_i}
$$

它描述频谱能量的中心位置，设备状态变化可能导致重心频率偏移。

- 均方频率：

$$
MSF=\frac{\sum_i f_i^2 A_i}{\sum_i A_i}
$$

- 频率方差：

$$
VF=\frac{\sum_i (f_i-FC)^2 A_i}{\sum_i A_i}
$$

频率方差越大，说明频谱能量越分散。

#### 时频域指标

非平稳信号的频率结构会随时间变化，此时仅看全局频谱可能不够。可以使用短时傅里叶变换、小波变换或 EMD 等方法提取时频特征。

- 频带能量：统计某个频率区间内的能量，用于判断特定频段是否异常。
- 相对功率谱熵：衡量频谱分布均匀程度。设 $p_i=P_i/\sum_i P_i$，则

$$
H=-\frac{\sum_{i=1}^{n}p_i\ln p_i}{\ln n}
$$

谱熵越高，能量分布越均匀；谱熵越低，能量越集中在少数频率上。

### 10.3.3 滤波与分解

滤波用于去除不需要的频率成分或提取目标频段。常见滤波器包括低通、高通、带通和带阻滤波器。

#### 低通滤波示例

下面构造一个由 $5\text{ Hz}$ 和 $120\text{ Hz}$ 两个正弦分量组成的信号，再用低通滤波器去除高频成分。

```python
import numpy as np
import matplotlib.pyplot as plt

fs = 1000
t = np.linspace(0, 1, fs, endpoint=False)
f1, f2 = 5, 120

x = np.sin(2 * np.pi * f1 * t) + 0.5 * np.sin(2 * np.pi * f2 * t)

plt.figure(figsize=(10, 4))
plt.plot(t[:100], x[:100], label="Original Signal")
plt.title("原始信号")
plt.xlabel("时间 [秒]")
plt.ylabel("振幅")
plt.legend()
plt.show()
```

Scipy 中常见滤波器包括：

- Butterworth：通带平坦，适合不希望通带波动太大的场景。
- Chebyshev：通带或阻带允许波纹，换取更快衰减。
- Elliptic：通带和阻带都有波纹，能用较低阶数实现陡峭过渡。
- Bessel：相位特性较好，适合更关注波形形状的信号。
- FIR：通常易于设计线性相位滤波器。

滤波器参数不能只凭经验随意设定，至少要明确采样频率、目标频段、噪声频段、允许相位延迟和边界效应。

#### EMD 经验模态分解

经验模态分解（Empirical Mode Decomposition, EMD）适合分析非线性、非平稳信号。它把复杂信号分解为若干本征模态函数（Intrinsic Mode Functions, IMF），每个 IMF 表示不同时间尺度上的振荡成分。

安装 PyEMD 相关库：

```bash
pip install EMD-signal
```

示例代码：

```python
import numpy as np
import matplotlib.pyplot as plt
from PyEMD import EMD

t = np.linspace(0, 1, 200)
s = (
    np.sin(11 * 2 * np.pi * t)
    + np.sin(22 * 2 * np.pi * t)
    + 0.2 * np.random.normal(size=t.size)
)

emd = EMD()
imfs = emd(s)

plt.figure(figsize=(12, 9))
plt.subplot(len(imfs) + 1, 1, 1)
plt.plot(t, s, "r")
plt.title("Input signal: s(t)")
plt.xlabel("Time [s]")

for n, imf in enumerate(imfs):
    plt.subplot(len(imfs) + 1, 1, n + 2)
    plt.plot(t, imf, "g")
    plt.title("IMF " + str(n + 1))
    plt.xlabel("Time [s]")

plt.tight_layout()
plt.show()
```

![img](img/docs-CH10-src-wps56.jpg)

图10.25 原始信号与 IMF 分解结果

EMD 的优势是自适应，不必预设固定基函数；风险是端点效应、模态混叠和噪声敏感。若用于建模，需要对分解出的 IMF 做筛选、重构或进一步特征提取。

## 10.4 多模态数据与人工智能

### 10.4.1 多模态概念

模态指信息的表现形式或感知通道，例如文本、图像、音频、视频、传感器数据等。多模态学习的目标是让模型同时处理多种模态，并建立它们之间的对应关系。

常见任务包括图像描述、视觉问答、图文检索、视觉定位、视频分类、语音识别、音频情感分析和多轮对话。核心难点是：不同模态的数据结构不同、维度不同、语义粒度不同，需要通过编码、投影和对齐把它们放到可比较或可交互的表示空间中。

### 10.4.2 多模态模型结构与发展

多模态大模型通常可以拆成五类组件：模态编码器、输入投影器、大模型基座、输出投影器和模态生成器。

1. 模态编码器（Modality Encoder）：把图像、视频、音频等原始数据编码成特征表示。例如图像编码器、视频编码器、音频编码器。
2. 输入投影器（Input Projector）：把模态编码器输出映射到 LLM 可接收的空间。常见形式包括线性层、MLP、Cross-Attention 和 Q-Former。
3. 大模型基座（LLM Backbone）：负责语言理解、推理和生成，例如 ChatGLM、LLaMA、Qwen、Vicuna 等。
4. 输出投影器（Output Projector）：把 LLM 内部表示转换成目标模态需要的表示。
5. 模态生成器（Modality Generator）：生成图像、音频、视频等输出，例如 Stable Diffusion、AudioLDM 等。

### 10.4.3 Transformer 基础

Transformer 是当前多模态模型的重要基础结构。它用注意力机制替代 RNN 的顺序递推，使序列中任意位置之间可以直接建立联系。

![img](img/docs-CH10-src-wps63.jpg)

图10.32 Transformer 架构

Transformer 的关键组件包括：

- 自注意力机制：每个 token 可以关注序列中其他 token，并根据相关性加权汇总信息。
- 多头注意力：多个注意力头从不同子空间学习依赖关系，再拼接输出。
- 位置编码：为序列注入顺序信息，因为 Transformer 本身不按时间递推。
- 编码器-解码器结构：编码器理解输入，解码器生成输出。
- 残差连接：缓解深层网络训练中的梯度问题。
- 层归一化：稳定训练过程，提高收敛效果。

### 10.4.4 文本、图像与模态对齐

#### 文本转 Embedding

文本处理通常先做 Tokenization，把句子切分成 token 或子词，再通过 Embedding 层映射到连续向量。

![img](img/docs-CH10-src-wps64.jpg)

图10.33 Tokenizer 分词总结

例如句子 `thank you very much` 经过分词后可能得到：

```text
["thank", "you", "very", "much"]
```

若每个 token 被映射到 $2048$ 维向量，则整句话可表示为 $4 \times 2048$ 的 embedding 矩阵。

#### 图像转 Embedding

ViT 把图像切成固定大小的 patch，每个 patch 类似一个视觉 token。以 $224 \times 224$ 的 RGB 图像为例，若 patch 大小为 $14 \times 14$，则图像被切成：

$$
\frac{224}{14}\times \frac{224}{14}=256
$$

个 patch。每个 patch 展平成 $14\times14\times3=588$ 维向量，再经过线性层映射到 $D$ 维空间。例如 $D=768$ 时，整张图像可表示为 $256\times768$ 的视觉 token 序列。

![img](img/docs-CH10-src-wps65.jpg)

图10.34 图像 Embedding 处理

#### 模态对齐

模态对齐是把不同模态的表示放到可以比较、检索或联合生成的空间中。图文任务中，模型需要知道图像中的“小狗”和文本中的“小狗”对应同一语义对象。

![img](img/docs-CH10-src-wps66.jpg)

图10.35 图文对齐示意

常见对齐流程：

1. 特征提取：分别从图像、文本、音频等模态中提取向量表示。
2. 特征变换：用投影层或跨模态注意力把不同模态映射到共同空间。
3. 对齐约束：通过相似度、对比学习或生成损失，让匹配样本更接近、不匹配样本更远。
4. 端到端训练：让编码器、投影器和语言模型在任务目标下共同优化。

### 10.4.5 多模态模型训练流程

多模态大模型训练常分为多模态预训练和多模态指令调优两个阶段。

#### 多模态预训练

多模态预训练的目标是让模型学会把不同模态映射到统一表示。训练数据通常包含图像-文本、视频-文本、音频-文本等配对样本。训练时常冻结或部分冻结大模型基座，重点训练输入投影器和输出投影器，使模态特征能被 LLM 理解。

核心损失通常与条件文本生成、图文匹配或对比学习有关。直观地说，这一阶段是在教模型“看懂图像、听懂音频，并把它们转成语言模型能处理的表示”。

#### 多模态指令调优

指令调优让模型学会按人类指令完成具体任务。常见方法包括：

- 监督式微调（SFT）：把多模态样本改写成指令-回答格式，直接训练模型输出目标答案。
- 基于人类反馈的强化学习（RLHF）：用人类偏好或评分进一步优化模型输出。

这一阶段常使用视觉问答、图像描述、定位问答、多轮对话等数据。训练完成后，模型不仅能建立模态对应关系，还能按指令完成解释、判断、问答和生成。

## 本章速记

- 图像：灰度图是矩阵，彩色图是三维张量；OpenCV 读图默认 BGR。
- 颜色空间：RGB 适合显示，HSV 适合颜色分割。
- 边缘与特征：Sobel/Canny 看边缘，Harris/ORB 看局部关键点和匹配。
- 视觉任务：分类回答“是什么”，检测回答“是什么且在哪里”，分割回答“每个像素是什么”。
- 文本：先清洗和分词，再向量化；TF-IDF 看关键词权重，Word2Vec/BERT 学语义表示。
- NLP 任务：分类、序列标注、话题建模、情感分析都依赖文本表示质量。
- 信号：时域看波形，频域看频率成分，时频域看频率如何随时间变化。
- 傅里叶变换：把 $x(t)$ 转成 $X(f)$，便于发现周期、噪声和目标频段。
- 滤波：先明确采样频率和目标频段，再选滤波器类型与参数。
- 多模态：关键是编码、投影、对齐和指令调优，把不同信息形式统一到可交互的表示空间。
