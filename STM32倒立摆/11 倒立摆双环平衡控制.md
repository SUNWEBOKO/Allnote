# 11 倒立摆双环平衡控制

## 学习目标

- 实现手动启停和倒下停机。
- 调整角度内环的方向与中心角度。
- 接入位置外环限制横杆漂移。
- 验证按键定位与扰动恢复。

## 一、先立住，再约束位置

工程 `15-倒立摆` 的内环控制摆杆角度，外环控制横杆位置。内环试图让摆杆处在直立附近；外环通过略微改变目标倾角，让横杆移动回指定位置。

这与上一章速度内环的串级结构形式相似，但物理含义不同：

| 控制环 | 目标与反馈 | 输出 | 周期 | 源码初值 |
| --- | --- | --- | --- | --- |
| 角度内环 `AnglePID` | ADC 原始码 | 电机 PWM | 5 ms | P=0.3，I=0.01，D=0.4 |
| 位置外环 `LocationPID` | 编码器累计计数 | 角度目标修正量 | 50 ms | P=0.4，I=0，D=4 |

两环输出都限制为 ±100，但前者是 PWM 百分点，后者是 ADC 码，意义完全不同。外环 ±100 约对应 ±8.14° 的目标倾角修正；这不是实际摆杆必定达到的角度，也不是摆杆活动范围。

## 二、先建立启停框架，不急着加 PID

初始化 OLED、LED、按键、RP、电机、编码器、串口、ADC1，最后初始化 TIM1。主循环处理 K1 和显示；中断每 1 ms 调 `Key_Tick()`，读取 `Angle`，读取一次编码器增量并累加 `Location`。

工程 15 用 `RunState=0` 表示停止，1 表示控制。K1 松开产生键码后，主循环执行 `RunState=!RunState`。中断在每拍检查角度，若不在允许区间便置零；停止分支必须执行 `Motor_SetPWM(0)`，只是不再计算 PID 并不能取消之前写入的 PWM。

`RunState`、`Angle`、`Location` 以及主循环会显示或修改的 PID 成员由主循环和中断共同访问。课程源码依赖当前编译环境运行；较严谨的实现中，直接共享的标量通常应声明为 `volatile`，相关 PID 字段则通过一致性快照或短临界区交换，不能只给某一个成员加限定就认为整组数据同步了。`volatile` 也不能让 `RunState=!RunState` 这类“读后再写”自动具备原子性；若启停可靠性要求高，应由主循环提交启停请求，再由中断统一改变运行状态。

课程初始讲解用中心 2048、范围 500，最终源码中心为 2010：

```c
#define CENTER_ANGLE 2010
#define CENTER_RANGE 500
/* 每 1 ms 获取 Angle 后 */
if (!(Angle > CENTER_ANGLE - CENTER_RANGE &&
      Angle < CENTER_ANGLE + CENTER_RANGE))
    RunState = 0;

if (RunState) {
    /* 按周期执行两环 */
} else {
    Motor_SetPWM(0);
}
```

最终有效区间是严格的 $1510<Angle<2510$，恰好在边界也停机。若你仍用 2048，则边界是 1548 与 2548，不能把不同阶段的数字混用。

先让 PID 输出保持零，手动扶住摆杆到中心附近，按 K1 观察 LED 点亮；慢慢移出左右边界，LED 应熄灭。再次扶回中心不会自动重启，需要再次按键。这一阶段验证的是启停逻辑，不能因为摆杆被手扶着没倒就认为控制已经成功。

## 三、角度内环的代码与方向

先暂时屏蔽外环对角度目标的更新，固定 `AnglePID.Target=CENTER_ANGLE`。每 5 ms 执行：

```c
AnglePID.Actual = Angle;
PID_Update(&AnglePID);
Motor_SetPWM(AnglePID.Out);
```

开始调参时让 I、D 为零，P 从很小值开始。扶住摆杆接近直立，启动后轻微放松，观察它向一侧倾倒时，横杆是否向能接住摆杆的方向移动。若反而加剧倾倒，立即停止，检查电机方向、传感器增减方向及误差定义，再统一修改一处符号并重测。

不要随意把带中心偏置的 ADC 原始数取负而仍保留正中心目标；例如实际 -2010、目标 2010 会产生 4020 的假误差。若通过输出反相修正，需同时确认之后外环的作用方向，不能多处同时反相后靠试运气。

## 四、内环调参和中心角度校准

1. 由小 P 开始，观察横杆接住倾倒的反应。课程从 0.1 逐渐增加，到约 0.2～0.3 时响应足够，0.4 附近抖动明显。
2. 保持 P 约 0.3，逐步增加 D。课程比较 0.1、0.2、0.3、0.4，约 0.4 时阻尼较合适。过大的 D 也会放大角度噪声或使动作过于迟滞。
3. 观察横杆是否无论如何轻推，最终总往同一方向跑。先校准中心角度，不急着加位置环掩盖问题。
4. 按课程传感器方向，中心设得偏大时容易往一侧持续移动，逐步减小中心；设得偏小时反向移动，逐步加大。字幕演示 2048→2030→2010，再以 1990 作反向验证，最终用 2010。
5. 在 PD 基本可控后，若小误差纠正仍不足，可极小量加入 I。课程用 0.01 改善本机表现，远小于前面速度实验的 0.2～0.3。

更可靠的中心估计是观察已经稳定平衡时的 ADC 读数范围，取代表性平均值，再验证两侧漂移是否对称。手扶的“看起来竖直”只能给初始估计，机械装配使每台设备中心不同。

中心误差为何造成跑偏？如果真正直立是 2000，而控制器追踪 2048，相当于要求摆杆保持一定倾斜。为了不让它倒，横杆只能不断移动去接住它。因此“内环能立住但横杆到处跑”与“内环控制方向错误”是不同问题。

课程采用 5 ms 是经过这套设备试验得到的选择：40、20 ms 太慢，进一步缩短到 5 ms 后效果改善。周期不是越短越好，还受传感器、执行器、噪声和计算时间限制。改变周期后必须重新检查离散参数，不能直接搬用 40 ms 定位实验的数值。

内环验收是摆杆能在一定扰动下维持直立一段时间、没有固定方向的明显漂移趋势、超出范围会停机。此时横杆位置尚未闭环，不要求它停在固定位置。

## 五、接入外环时，减号非常关键

课程框图先用“中心加修正量”说明串级思路，实物调试后确认按现有方向应取减号，最终源码为：

```c
LocationPID.Actual = Location;
PID_Update(&LocationPID);
AnglePID.Target = CENTER_ANGLE - LocationPID.Out;
```

如果误用加号，可能让横杆越偏越远。判断方法不是背左和右，而是轻微改变横杆位置，观察外环给出的目标倾角是否促使它返回。

以源码符号为例，目标位置 0，实际位置 +20，外环 P=0.4，暂不计 D/I，则误差 -20，输出 -8，内环目标为 $2010-(-8)=2018$。这是否对应把横杆带回去，取决于前面已经确认的传感器和电机方向。用小 P 和受控位移验证一次，才可继续增益整定。

源码每 1 ms 都读取编码器并累加位置，变量虽仍名为 `Speed`，实际是 count/1ms，与电机速度实验的 count/40ms 不同；本工程主要使用它累加位置，不应直接拿它与早期速度参数比较。

## 六、外环调参、中心偏差与稳态误差

先固定内环，外环 I/D 为零、P 从小值开始。确认负反馈后，增加 P 使位置恢复更快；若来回摆且幅度扩大，先加 D 提供阻尼。课程外环从 P≈0.2、D≈2 调到 P=0.4、D=4，最终 I=0。

外环 D 的数值比内环大，不代表阻尼一定更强：两个环的输入单位和周期不同。RP3 若仍映射 0～1，达不到课程外环 D 的范围，需要按源码调试注释改成 0～9。

中心偏差会使外环 PD 留下稳态位置误差。设实际直立角码为 $A_*$，静止时 D 为零、内环误差近似为零，外环输出约为 $K_p e_x$，则

$$
A_*=A_c-K_p e_x,
\qquad e_x=\frac{A_c-A_*}{K_p}.
$$

本例中心设为 2030、实际为 2010、外环 P=0.4，需 $e_x=50$ 才能产生 20 的修正量，若目标位置 0，实际位置便约为 -50 count。符号取决于本工程约定，这个简化例子用于解释为何“中心角度误差”会变成“位置静差”。

解决时优先校准中心。必要时给位置外环加很小 I，例如课程演示的 0.01，使零位置误差时仍能保留角度修正；但大位置变化会累积积分，需要考虑积分分离和限幅。最终工程 15 的 `PID_Update` 没有这些措施，外环 Ki 也保持零，不能以为课程讲过就已加入代码。

## 七、按键移动和完整验收

工程 15：K1 启停；K2 使 `LocationPID.Target += 408`，上限 4080；K3 减 408，下限 -4080。它们分别表示约正反一圈和目标范围 ±10 圈。目标限幅不限制外力造成的实际位置变化。

验证顺序：

1. 固定装置，扶起摆杆，按 K1 启动，轻松开手，观察角度及位置稳定。
2. 施加小扰动，观察摆杆恢复直立、横杆回到目标附近。
3. 按 K2/K3，确认目标字段每次变动 408，横杆移动时仍保持平衡；到 ±4080 后不继续增加目标。
4. 让摆杆受控地离开中心区间，确认状态退出且电机命令归零。
5. 重新扶起并启动，观察是否有历史积分引起的冲击；若有，按下一章的接管初始化思路处理。

OLED 在停止时仍应显示实时 `Angle` 与 `Location`，因此源码显示的是统一采样变量，而不是只有 PID 执行时才更新的 `Actual` 成员。`Out` 显示可能仍保留最后一次算法值，不代表停止分支仍把这个值送到电机。

| 现象 | 优先检查 |
| --- | --- |
| 扶起即向错误方向冲 | 内环极性、传感器方向、目标中心 |
| 能立住但总往同一侧跑 | 中心角度是否偏移 |
| 内环能工作，接外环后发散 | 最终串级关系是否使用正确减号 |
| 横杆剧烈抖动、电机动作传不上来 | 顶丝是否对准切面、连接是否松动 |
| 外环目标为零却有固定位置偏差 | 中心角度和外环是否只有 PD |
| 第一次正常，重启异常 | 积分、误差历史和目标是否残留 |

手册中的“电机转但横杆仅小幅动作”及“能起摆但直立大幅抖动”分别提示打滑、顶丝未可靠对准等可能性，应先检查机械传动，再调算法。

## 八、从首次通电到双环通过的验收门

不要在一次启动中连续试完全部参数。每通过一层才开放下一层：

| 层级 | 允许的功能 | 必须观察到的通过条件 | 失败时禁止做什么 |
| --- | --- | --- | --- |
| 0 | 电机断电，读取传感器 | 直立附近 ADC 连续，编码器方向已知 | 不得启动闭环 |
| 1 | 低幅开环 PWM | 横杆响应方向与编码器符号一致 | 不得用 PID 修正方向错误 |
| 2 | 仅启停和越界保护 | 中心内可启动，越界后 PWM 归零 | 不得认为手扶不倒等于闭环成功 |
| 3 | 仅角度 P | 两侧倾倒都产生“接住摆杆”的动作 | 方向不对时不得增加 P |
| 4 | 角度 PD/微量 I | 可稳定一段时间，无固定单向漂移 | 中心未校准时不得接位置环 |
| 5 | 位置外环小 P | 横杆偏离后产生返回趋势 | 外环符号未通过时不得加 D |
| 6 | 完整双环 | 扰动可恢复，K2/K3 移动时仍平衡，倒下可靠停机 | 不得直接进入自动起摆 |

课程参数 `AnglePID=(0.3,0.01,0.4)`、`LocationPID=(0.4,0,4)` 和中心 2010 只是原装设备的最终起点。记录自己的中心码、参数、供电、机械状态、稳定时长、位置误差和越界停机结果；没有这些条件，单独抄一组 P/I/D 无法复现实验。

调试中若需要抓取波形，优先发布同一控制拍的快照，由主循环发送。不要在 5 ms 角度分支内阻塞打印浮点数，也不要为显示再次读取编码器；前者改变时序，后者会清掉控制所需的增量。
