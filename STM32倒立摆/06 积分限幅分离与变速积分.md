# 06 积分限幅分离与变速积分

## 学习目标

- 复现积分饱和与恢复迟缓。
- 实现误差积分限幅。
- 实现积分分离和变速积分。
- 区分积分累积与积分输出的加权。

## 一、先区分三种问题

积分限幅解决“历史累积太大”；积分分离解决“大误差阶段不宜积累”；变速积分解决“积分强弱切换太生硬”。三者都改变积分状态，但并不是互相替代的同一种算法。

工程 06 是速度控制，07、08 是位置控制；都保留 40 ms 周期、±100 PWM 限幅和 RP 调参。实验时分别复制相应原工程，避免把上一个实验尚未清掉的积分状态带进来。

## 二、工程 06：看见积分饱和

### 为什么输出限幅挡不住积分增长

设目标为 100、执行器没有转动，每拍误差都是 100。积分和每拍增加 100，即使 `Out` 从第一拍起已经被限制为 100，积分仍能变成 100、200、300……。恢复执行器后，反馈可能已经超过目标，但必须靠反向误差逐步消掉旧积分，输出才能从限幅退下来。

这就是“控制器想做的”和“执行器实际能做的”不一致。它既可能来自目标过大，也可能来自输出禁用、堵转等原因。

工程 06 用 `MotorFlag` 模拟输出失效：K1 切换标志，LED 指示；控制器继续计算，但标志为 0 时调用 `Motor_SetPWM(0)`。这样能观察积分累积，不必长时间用手堵住电机。

### 操作与观测

1. 打开工程 06，串口四列是 `Target,Actual,Out,ErrorInt`。先用合适的 PI 参数建立正常速度跟踪，例如 P 约 0.3、I 约 0.2。
2. 在实验副本中暂时注释积分限幅两行，复位后设一个非零目标；按 K1 禁止驱动，观察实际速度降到零，积分持续增加。
3. 短时间后再按 K1 恢复驱动，观察超调与恢复延迟；结束后停机，不让错误积分持续扩大。
4. 恢复积分限幅，复位，以同样目标和禁用时长重复。积分曲线应停在 ±500，恢复后的过度驱动通常减轻。

课程限制的是误差积分和：

```c
ErrorInt += Error0;
if (ErrorInt > 500) ErrorInt = 500;
if (ErrorInt < -500) ErrorInt = -500;
Out = Kp * Error0 + Ki * ErrorInt + Kd * (Error0 - Error1);
if (Out > 100) Out = 100;
if (Out < -100) Out = -100;
Motor_SetPWM(MotorFlag ? Out : 0);
```

当 $K_i=0.2$ 时，积分输出被约束为 ±100；当 $K_i=0.5$ 时，同样的 ±500 允许积分输出达到 ±250。因此 ±500 不是与参数无关的“标准值”。若希望积分贡献限制在 $I_{\max}$，且 $K_i>0$，应按 $|S|\le I_{\max}/K_i$ 选择范围，或直接保存并限制积分输出。

课程工程 06 与基础位置式代码不同：积分每拍都累加，并没有在 `Ki==0` 时清零。关闭 I 再打开仍可能出现已有积分带来的跳变，应结合实际源码判断。

### 保存积分和与保存积分输出

`I = Ki * sum(e)` 与 `I += Ki * e` 在 Ki 恒定且初值对应时等价。在线修改 Ki 时，前者会把全部历史一起重新加权，后者只影响之后的增量。例如已有积分和 100，Ki 从 0.1 改成 0.2，前者积分输出立即从 10 变 20；后者已经保存的 10 不会自动变成 20。

固定限幅只能控制积累大小，不能保证所有饱和工况都恢复迅速。更进一步可在输出饱和且误差还推动它继续向饱和方向发展时暂停积分，或按实际执行输出做回算；本课工程未实现这些策略。不要把“有限幅”误读成完整解决了所有抗饱和问题。

## 三、工程 07：积分分离

位置目标大步进时，开始阶段 P 已经足够驱动，大误差积分反而容易给终点留下过大推力。积分分离规定只在靠近目标时使用积分。

课程代码采用“大误差清零、小误差累加”：

```c
if (fabs(Error0) < 50)
    ErrorInt += Error0;
else
    ErrorInt = 0;
```

阈值单位是位置计数，50 count 约为 $50\times360/408=44.12^\circ$。严格小于意味着恰好 50 时也清零。它不是“保留已有积分暂停增长”，两种处理在再次进入小误差区时状态不同。

操作时先在工程 04 观察加小 I 后的大步进超调，再运行工程 07，以相同 P/D、I 约 0.1～0.2 和目标变化比较。大误差时积分为零，接近目标后才开始累积，通常能减少远距离移动留下的积分包袱。为明确验证，可把 `ErrorInt` 加成第四列观察。

随后把阈值改小作对照，例如 20。如果系统因摩擦停在误差 25，积分始终不允许启动，就可能一直卡在阈值外。应先判断阈值是否覆盖实际残差，再调 I；一味增大 Ki 没用，因为积分分支根本没有执行。

本例取误差序列 80、40、10，初始积分 0：第一拍超出阈值，积分为 0；第二拍积分为 40；第三拍积分为 50。若 Ki=0.1，I 输出为 0、4、5。可见积分分离并非“到目标才积分”，而是在选定邻域内累积。

另一种写法是积分始终累加，但只在小误差时把 I 项接入输出。它会保留大误差阶段的历史，重新接入时可能跳变，不等价于本工程的大误差清零。选择前要明确希望状态如何演化。

## 四、工程 08：变速积分

积分分离在阈值处突然切换，变速积分则连续调整每拍积分的增长速度。课程使用

$$
C(e)=\frac{1}{1+0.2|e|},\qquad
S_k=S_{k-1}+C(e_k)e_k.
$$

当误差很小时，$C$ 接近 1，保留积分消除小偏差的能力；误差大时 $C$ 减小，避免快速积累。注意每拍增量是 $C(e)e$，不是单看 $C$。

| 误差 $e$ | $C$ | 本拍积分增量 $Ce$ |
| --- | --- | --- |
| 1 | 0.8333 | 0.8333 |
| 10 | 0.3333 | 3.3333 |
| 100 | 0.04762 | 4.7619 |

正误差越大，增量逐渐接近 5；它并不会因为误差很大就变成零。若不可达误差长期存在，积分仍能无限增长，因此变速积分不能代替积分限幅。

在工程 08 中找到：

```c
float C = 1 / (0.2 * fabs(Error0) + 1);
ErrorInt += C * Error0;
```

保持 P/D 与工程 07 的对照条件，先用 I 约 0.2，再试 0.1，观察接近目标时的超调和残差消除时间。课程也讨论过把分母系数取 1，此时大误差每拍最多贡献接近 1，积分更弱，消差可能太慢；从 1 改为 0.2 就是提高了大误差时的积分速度。

一种可选的分段线性权重是：

$$
C(e)=\begin{cases}
1,& |e|\le A,\\
\dfrac{B-|e|}{B-A},& A<|e|<B,\\
0,& |e|\ge B,
\end{cases}\qquad 0\le A<B.
$$

本例取 $A=10,B=50$，误差 30 时权重为 0.5，本拍积分增加 15。这里大误差权重为零只代表停止新增，不会自行清除已有积分；若希望清零，要另写状态规则。

## 五、权重乘在哪里，结果就在哪里改变

必须区分两种式子：

$$
I_k^{(1)}=K_i\sum_{j=0}^{k}C(e_j)e_j,
\qquad
I_k^{(2)}=K_i C(e_k)\sum_{j=0}^{k}e_j.
$$

第一种在每次误差进入历史时加权；第二种用当前权重重新缩放全部历史。权重随误差变化时，它们通常不同。

本例取 $K_i=1$，两拍误差 100、10，使用课程权重。第一种结果为 $100/21+10/3\approx8.0952$；第二种在第二拍得到 $(100+10)/3\approx36.6667$。两者相差很大，所以不能将“改变积分速度”与“缩放积分输出”视作效果一样。

本章验收时分别确认：工程 06 的历史被限制、工程 07 的积分在大误差时清零、工程 08 的增量随误差平滑变化。再看实际运动是否满足超调与消差时间要求，不能只凭公式名字认定改进一定成功。
