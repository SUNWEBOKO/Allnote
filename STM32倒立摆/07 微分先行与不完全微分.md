# 07 微分先行与不完全微分

## 学习目标

- 用微分先行消除目标变化对 D 项的直接激励。
- 用一阶递推滤波抑制微分噪声。
- 区分位置状态漂移与独立测量噪声。

## 一、微分的两个问题来自不同输入

离散误差微分为 $D_k=K_d(e_k-e_{k-1})$。把 $e=r-y$ 展开：

$$
D_k=K_d(r_k-r_{k-1})-K_d(y_k-y_{k-1}).
$$

第一部分会对目标突变产生冲击；第二部分提供运动阻尼，却也会放大测量抖动。工程 09 和 10 分别研究这两个问题，两种改进可以组合，不能互相代替。

## 二、工程 09：微分先行

微分先行只对测量值求差分：

$$
D_k=-K_d(y_k-y_{k-1}).
$$

目标不变时它与误差微分一致；目标改变时，去掉了目标差分项，因此目标跳变不会直接让 D 产生尖峰。P 仍会随目标变化，这是正常的控制响应。

源码在更新位置前保存旧位置：

```c
Actual1 = Actual;
Actual += Encoder_Get();
Error1 = Error0;
Error0 = Target - Actual;
/* 积分按原工程规则更新 */
DifOut = -Kd * (Actual - Actual1);
Out = Kp * Error0 + Ki * ErrorInt + DifOut;
/* 之后仍需限制 Out 到 ±100，再输出给电机 */
```

若把 `Actual1=Actual` 放在位置更新之后，差分会被清成零。串口四列为目标、实际、总输出、`DifOut`，应单独看 D 曲线，而不是只看总输出有没有动。

### 数值与实物对照

本例取 $K_d=0.4$，目标从 0 跳到 100，实际仍为 0。普通误差微分输出 40，微分先行输出 0；下一拍实际从 0 增至 10、目标保持 100，两者都得到 -4。这显示它保留了测量运动的阻尼，去掉了设定值的直接踢动。

实物按以下顺序操作：

1. 使用工程 09，固定 40 ms 周期，设 `Kp=Ki=0`，给适中的 D。
2. 转动目标旋钮，理想情况下不应仅因目标变化产生驱动；若出现尖峰，查是否仍在对误差求导。
3. 手动缓慢转动转盘，应能感到与运动相反的作用；静止后 D 趋近零。只用 D 不会把转盘拉回指定位置。
4. 加回适中的 P，重复位置阶跃，与工程 04 对照。目标改变仍有 P 响应，但 D 曲线不再含目标跳变本身的尖峰。

通过标准是 D 对真实运动有反应、对纯目标跳变无直接响应。这个方法不会自动消除编码器噪声。

## 三、工程 10：不完全微分

直接差分对高频变化很敏感。假设实际位置没动，测量却一拍偏高 10、下一拍偏低 10，差分就出现 -20；增大 D 会把这种抖动变成执行器抖动。

课程先算理想 D，再通过一阶递推平滑：

$$
D_k=(1-a)K_d(e_k-e_{k-1})+aD_{k-1},\qquad 0\le a<1.
$$

当前新数据占 $1-a$，历史输出占 $a$。$a=0$ 没有滤波；接近 1 时平滑更强，但响应更慢；$a=1$ 会使 D 永远保持初值，不能当成正常滤波设置。

源码核心是：

```c
float a = 0.9;
DifOut = (1 - a) * Kd * (Error0 - Error1) + a * DifOut;
```

本例初始 `DifOut=0`，理想 D 输入一拍为 20，之后为 0，取 $a=0.9$，滤波后依次为 2、1.8、1.62……。尖峰变小了，却被摊到后面多个周期。这解释了为什么曲线平滑并不代表没有代价。

若把一阶连续滤波用后向欧拉离散，可得到 $a=\tau/(\tau+T_s)$。在 $T_s=40$ ms、$a=0.9$ 时，对应的这种近似时间常数约为 0.36 s。改变控制周期却不改 $a$，实际平滑时间也会改变。

### 噪声演示中必须注意的状态问题

工程 10 的原代码是：

```c
Actual += Encoder_Get();
Actual += rand() % 41 - 20;
```

每拍随机数在 -20～20，但它被不断加进累计位置，所以测量误差是随机数的累积，而不是每拍独立的 ±20 测量噪声。即使电机不动，显示位置也可能逐步漂走；D 滤波不能把这个被污染的位置状态恢复为真实值。

若目的是演示独立测量噪声，可作如下教学改写，在该控制分支外保存真实累计位置：

```c
static int32_t PositionCount = 0;
PositionCount += Encoder_Get();
Actual = (float)PositionCount + (rand() % 41 - 20);
```

这里每拍 `Actual` 都从干净的编码器累计值重新构造，噪声不会写回 `PositionCount`。改写后才能把“真实位置”和“带噪反馈”分开比较。`rand()` 不播种会产生可复现序列，适合对照；这种注入是教学模拟，不能代表所有真实传感器噪声。

### 实验步骤

1. 复制工程 10，先关闭噪声注入，以小目标变化确认定位链路正常。
2. 启用噪声，先设 $a=0$，保持同一 P/I/D，观察 `Actual` 抖动、`DifOut` 尖峰及电机动作。
3. 改为 $a=0.9$，复位并重复目标变化，比较 D 峰值与响应迟缓程度。若采用上述独立噪声改写，两次对照都使用同一实现。
4. 关闭人工噪声，检查平滑是否仍然值得保留，避免为了漂亮曲线牺牲过多响应速度。

验收应同时满足：D 高频抖动减弱，目标响应没有慢到不满足需求。只看总输出变平滑，可能掩盖位置状态漂移或反馈延迟。

## 四、组合时的正确位置

要同时避免设定值冲击与减弱微分噪声，可先对实际值求负差分，再滤波：

$$
D_k=(1-a)\big[-K_d(y_k-y_{k-1})\big]+aD_{k-1}.
$$

这只过滤 D 支路，不会自动过滤 P 和 I 看到的测量噪声。若另外过滤整个反馈，控制延迟也会改变，必须重新观察闭环稳定性。启动时把历史实际值设为当前采样、D 状态清零，可避免把“从零到当前测量”的假变化当成真实运动。
