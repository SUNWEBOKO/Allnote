# 13 综合验收与调试记录

## 学习目标

- 用同一套记录格式复现工程 01～16。
- 把故障定位到供电、机械、采集、时序、控制或状态机中的具体一层。
- 用可计算的指标比较参数，而不是只凭“看起来更稳”。
- 完成倒立、移动、停机和重复起摆的整机验收。

## 一、最终要交付什么

学完课程后，最终结果不只是“倒立摆曾经立起来”，而是一套能复查的证据：

1. 硬件基线：供电、接线、顶丝、传感器方向和中心码。
2. 软件基线：工程版本、控制周期、常量、P/I/D 与改动说明。
3. 波形或数据：目标、反馈、输出和关键状态来自同一控制拍。
4. 验收结果：正反方向、扰动、越界停机、重启及自动起摆成功率。
5. 失败记录：症状、定位层、修改项和修改后的复测结果。

若换了一台电机、重新装过联轴器、改变供电或修改采样周期，应建立新的基线。原参数可以作为起点，不能继续当作已验证结果。

## 二、上电前检查卡

### 2.1 电气与机械

| 检查项 | 要求 | 未通过的风险 |
| --- | --- | --- |
| 电源 | 配套 12 V/1 A；可调电源限流不超过 1 A | 短路或接反时扩大损坏 |
| 供电入口 | DC 插座和端子只用一个 | 两路电源互相倒灌 |
| 调试器 | 已有外部供电时只接 SWDIO、SWCLK、GND | 3.3 V 电源并接冲突 |
| 串口 | TX/RX 交叉、GND 共地，逻辑电平匹配 | 无数据、乱码或引脚过压 |
| 驱动模块 | 方向、排针位置和配套型号正确 | 模块或电容损坏 |
| 顶丝 | 四颗均固定并对准轴切面 | 打滑、间隙、直立时大幅抖动 |
| 传感器 | G1/G2 与程序通道一致，盲区在下方 | 直立附近读数跳变 |
| 夹具 | 木块垫底，底板夹紧，活动区清空 | 失控旋转、底板破损或碰撞 |

### 2.2 软件与人员

- 屏幕能标识当前工程或当前状态，避免下载后误判仍在运行旧程序。
- 第一轮测试使用低 PWM、小目标和小增益；调参人员能立即关闭板上电源。
- 中断中没有 OLED 刷屏、阻塞串口、延时或未界定上限的循环。
- 送入 `Motor_SetPWM()` 前已经最终限幅，停机分支明确调用 `Motor_SetPWM(0)`。
- 倒立摆阶段不能用手握住横杆或摆杆对抗电机；只做轻扰动后立即离开活动区。

## 三、从底层到整机的验收顺序

任何上层异常都先回到最近一个通过的下层，不在未知硬件上直接调 PID。

```mermaid
flowchart LR
    A[供电与下载] --> B[按键/旋钮/OLED]
    B --> C[PWM方向]
    C --> D[编码器与角度ADC]
    D --> E[单环速度/位置]
    E --> F[算法改进]
    F --> G[速度-位置串级]
    G --> H[角度内环]
    H --> I[位置外环]
    I --> J[自动起摆]
    J --> K[重复性验收]
```

| 层级 | 对应工程 | 输入 | 关键状态/处理 | 输出与通过条件 |
| --- | --- | --- | --- | --- |
| 基础 I/O | 01 | 按键、RP、串口 | 1 ms Tick、ADC2、主循环显示 | 通道对应且数值范围正确 |
| 开环执行 | 01 | ±PWM | TIM2 20 kHz、方向脚 | 电机能停和双向转动 |
| 编码反馈 | 01 | 手转/开环转动 | TIM3 读数后清零 | 静止近 0，正反符号匹配 |
| 单环 | 02～05 | 速度或位置目标 | 40 ms PID、状态与限幅 | 可达目标稳定，不发散 |
| 改进算法 | 06～11 | 故障或阶跃场景 | 积分、微分、偏移、死区 | 目标副作用按预期减轻 |
| 电机串级 | 12～13 | 位置目标 | 位置外环→速度目标→PWM | 扰动后回位，速度受控 |
| 角度采集 | 14 | 摆杆角度 | ADC1 通道 8 | 直立附近连续、盲区在下方 |
| 手动倒立 | 15 | 扶起、K1、位置命令 | 5 ms 角度环、50 ms 位置环 | 能平衡、移动、越界停机 |
| 自动起摆 | 16 | 下垂、K1 | 三点极值、脉冲链、接管 | 多次起摆后可靠进入平衡 |

## 五、从波形计算指标

### 5.1 阶跃响应

目标从 $r_0$ 跳到 $r_1$，变化量为 $\Delta r=r_1-r_0$。若正阶跃的最大反馈为 $y_{\max}$，百分比超调量可写为

$$
M_p=\frac{y_{\max}-r_1}{|\Delta r|}\times100\%.
$$

负阶跃应按运动方向选择最小值，不能直接套正阶跃的最大值。稳态误差可用末尾一段样本的平均反馈 $\bar y$ 计算：

$$
e_{ss}=r_1-\bar y.
$$

先定义允许带，例如目标的 ±5% 或位置 ±5 count；反馈进入并持续留在允许带后的最早时刻才是调节时间。只第一次穿过目标，不能算已经稳定。

### 5.2 输出饱和与积分恢复

同时记录输出等于 ±100 的连续拍数。响应慢但长期满输出时，优先考虑目标不可达、负载过大或积分饱和，而不是继续增益。恢复驱动后，若反馈已经越过目标但输出仍长时间保持同一方向，查看 `ErrorInt` 是否在输出禁用期间继续累积。

### 5.3 倒立摆专用指标

| 指标 | 记录方法 |
| --- | --- |
| 平衡稳定时间 | 从进入状态 4 到退出或人工停止 |
| 角度波动 | 稳定阶段 ADC 最大值、最小值及中心偏差 |
| 位置误差 | 稳定阶段 `LocationPID.Target-Location` 的范围 |
| 扰动恢复 | 轻推后重新进入允许带的时间 |
| 起摆耗时 | K1 启动到首次进入状态 4 的时间 |
| 起摆成功率 | 相同初始条件下成功次数/总次数 |
| 停机延迟 | 越界或 K1 停止到实际 PWM 归零的时间 |

角度 ADC 波动可以换算为近似角度，但直立中心应使用本机校准值，换算只在传感器有效线性区内成立。

## 六、按信号链排查，而不是按参数猜测

完整链路是：

`目标/按键 -> 调度与状态机 -> 反馈采样 -> PID状态 -> 限幅/补偿 -> PWM与方向 -> 电机/机械 -> 编码器与角度传感器`

从输出端看到异常时，按相反方向逐层检查：

1. **供电与机械**：电源、电机插口、模块方向、四颗顶丝、轴承和线缆是否正常。
2. **执行器**：固定小 PWM 是否能产生确定方向的横杆运动。
3. **反馈**：同一运动下编码器和角度 ADC 的符号、连续性是否符合记录。
4. **周期**：1 ms 基准、40/5/50 ms 分频是否真的执行，反馈是否被重复读取。
5. **控制状态**：误差、积分、历史差分和 `Out` 是否按一拍一拍演化。
6. **串级关系**：外环输出单位、限幅和加减号是否正确送到内环目标。
7. **状态机**：当前状态、计时器、三点样本和接管初始化是否一致。

| 症状 | 第一检查层 | 判断依据 |
| --- | --- | --- |
| OLED 正常但电机不动 | 供电/执行器 | 12 V、开关、插口、驱动方向与小 PWM |
| 电机转而横杆只小动 | 机械 | 联轴器或顶丝打滑 |
| 一闭环就满速冲走 | 反馈方向 | 正输出是否让误差减小 |
| 转速值始终为零 | 编码反馈 | PA6/PA7、TIM3、插头与读取位置 |
| 位置不断回零 | 处理 | 是否把增量直接赋给位置而未累加 |
| 参数归零仍然转 | 控制状态 | 增量式 `Out` 是否保留 |
| 直立附近 ADC 突跳 | 机械/采集 | 盲区位置、接线、G1/G2 通道 |
| 内环能立，外环一开就发散 | 串级关系 | `CENTER_ANGLE - LocationPID.Out` 的方向 |
| 总向一侧移动 | 校准 | 中心角度是否偏离真实直立值 |
| 自动起摆越摆越小 | 状态机/相位 | 极值方向、陈旧样本和脉冲符号 |
| 第一次成功，第二次猛冲 | 状态生命周期 | 目标、积分、历史误差和输出是否重置 |

## 七、整机验收用例

### 7.1 手动扶起模式

1. 摆杆在中心区间外时按 K1，不应持续执行平衡输出。
2. 扶到中心后启动，逐渐松手，持续记录角度、位置和输出。
3. 分别向两个方向轻扰，观察是否恢复且输出不长期饱和。
4. K2、K3 各执行一次，横杆应约移动一圈且过程中保持平衡。
5. 让摆杆受控越界，确认进入停止状态并实际输出零。
6. 重新扶起再启动，确认旧积分和差分不会造成首拍冲击。

### 7.2 自动起摆模式

固定机械和参数后，完成至少 10 次冷启动：

| 次数 | 初始横杆位置 | 起摆耗时 | 是否进入状态 4 | 稳定时间 | 失败状态/现象 |
| --- | --- | --- | --- | --- | --- |
| 1～10 | 分次记录 |  |  |  |  |

每次还应覆盖起摆中 K1 停止、接管后 K1 停止、越界自动停止和再次启动。成功的最低定义应事先写清，例如“进入状态 4 后连续平衡 30 s，位置未越过夹具允许范围”；不能在看到状态 4 的瞬间就计为成功。

### 7.3 回归条件

修改以下任一项后，至少回归对应下层：

| 修改项 | 必须重测 |
| --- | --- |
| 电机线、编码器线、方向脚 | 开环方向、编码器符号、所有闭环方向 |
| 顶丝、联轴器、横杆结构 | 机械基线、中心角度、双环与自动起摆 |
| 控制周期 | 离散参数、滤波系数、所有动态指标 |
| `Motor_SetPWM()` 或 PWM 频率 | 起转门槛、输出偏移、内环参数 |
| 角度接口或传感器安装 | ADC 方向、盲区、中心角度、越界范围 |
| PID 重置或状态机 | 停机、接管、重复启动和失败恢复 |

## 八、课程实现与工程改进的边界

课程源码适合观察控制现象，但没有完整实现以下工程能力：

- 输出饱和方向相关的条件积分或反算抗饱和；
- 参数更新的原子发布和主循环/中断之间清晰的状态所有权；
- 传感器断线、ADC 卡死、编码器异常及电机堵转诊断；
- 独立硬件急停、看门狗、过流和运动范围保护；
- 严格等间隔的数据记录、时间戳和掉电参数保存；
- 自动起摆的能量估计、角速度接管条件和正式成功判据。

学习时先复现课程原逻辑，再一次只改一项并做回归。把改进代码和课程原代码分别保存，记录行为差异，才能判断改进是否有效。

## 九、完成条件与下一步

整套学习完成时，应能从一次失败现象追到具体链路，给出数据证据并复测，而不只是背出 PID 公式。最终检查：工程 01～16 的关键层级均有记录；手动双环和自动起摆分别通过；停机路径确实把 PWM 归零；10 次起摆成功率、稳定时间和位置容差已经量化。

在此基础上，下一步才适合选择一个明确方向继续：增加条件积分与无扰切换、重构命令/状态所有权、加入故障保护，或用更严格的能量控制替代经验脉冲起摆。每次扩展仍沿用本章的输入、处理、状态、输出和上下游验收链。
