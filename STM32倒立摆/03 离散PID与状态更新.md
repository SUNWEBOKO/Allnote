# 03 离散PID与状态更新

## 学习目标

- 推导位置式离散 PID。
- 推导增量式 PID 的差分公式。
- 正确更新误差历史与输出状态。
- 解释采样周期和限幅带来的差异。

## 一、单片机只能在离散时刻计算

连续控制器每时每刻都可响应；程序只能在第 $k$ 次采样时读取数据、计算、更新输出，然后将输出保持到下一次计算。设固定采样周期为 $T_s$，采样时间为 $t_k=kT_s$，当前误差记为 $e_k=r_k-y_k$。

用矩形面积近似积分、相邻样本之差近似微分：

$$
\int_0^{t_k}e(t)\,dt\approx T_s\sum_{j=0}^{k}e_j,
\qquad
\left.\frac{de}{dt}\right|_{t_k}\approx\frac{e_k-e_{k-1}}{T_s}.
$$

这里积分下标与启动时第一次采样的约定有关，实际代码由积分初值和第一次更新确定；重要的是所有周期都使用同一种约定。

代入并联 PID：

$$
u_k=K_Pe_k+(K_IT_s)\sum_{j=0}^{k}e_j+
\frac{K_D}{T_s}(e_k-e_{k-1}).
$$

课程把周期吸收到参数中，定义 $K_p=K_P$、$K_i=K_IT_s$、$K_d=K_D/T_s$，得到程序使用的形式：

$$
u_k=K_pe_k+K_iS_k+K_d(e_k-e_{k-1}),\qquad S_k=S_{k-1}+e_k.
$$

因此课程代码中的 `Ki`、`Kd` 与上一章连续参数不是直接相同的数字。若误差单位保持不变、周期从 40 ms 改为 20 ms，为维持近似相同的连续增益，应先令离散 `Ki` 减半、`Kd` 加倍，再实测整定。若速度单位还从 count/40ms 改成 count/20ms，误差尺度也变了，不能只做这一步缩放。

## 二、位置式：每次算出完整输出

“位置式”指输出的绝对值形式，不代表只能控制电机位置。速度控制同样可以用位置式 PID。

其核心计算顺序如下，适用于工程 02 的每 40 ms 控制分支：

```c
Actual = Encoder_Get();       // 速度实验：本周期计数
Error1 = Error0;              // 保存上一拍误差
Error0 = Target - Actual;     // 计算当前误差
if (Ki != 0) ErrorInt += Error0;
else ErrorInt = 0;            // 课程用于在线调参的处理

Out = Kp * Error0 + Ki * ErrorInt
    + Kd * (Error0 - Error1);
if (Out > 100) Out = 100;
if (Out < -100) Out = -100;
Motor_SetPWM(Out);
```

不能先算 `Error0` 再执行 `Error1=Error0`，否则历史误差被覆盖，D 项永远为零。也不能把 `ErrorInt` 定义成每次进入函数都会清零的自动局部变量；积分必须跨周期保存，通常使用全局变量、静态变量或结构体成员。

课程在 `Ki==0` 时清积分，是为了调试期间关闭 I 后不暗中积累大量误差。它没有限制 `Ki!=0` 时的积分，因此不是完整的抗积分饱和机制。输出限幅也只约束 `Out`，不会自动约束 `ErrorInt`。

### 一个完整的逐拍计算

本例取 $K_p=0.3$、$K_i=0.2$、$K_d=0.1$，初始积分和历史误差均为 0，连续误差为 10、6、2，输出未触及限幅。

| 拍次 | 当前误差 | 积分和 $S_k$ | P | I | D | 输出 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | 10 | 10 | 3 | 2 | 1 | 6 |
| 1 | 6 | 16 | 1.8 | 3.2 | -0.4 | 4.6 |
| 2 | 2 | 18 | 0.6 | 3.6 | -0.4 | 3.8 |

误差正在变小，所以 D 为负；误差尚未反向，所以积分仍在增加。这种“P 下降、I 仍上升”的组合，是理解位置控制超调的重要线索。

## 三、增量式：每次算输出该改多少

把上一拍位置式写出来：

$$
u_{k-1}=K_pe_{k-1}+K_iS_{k-1}+K_d(e_{k-1}-e_{k-2}).
$$

在参数不变的条件下，两式相减，利用 $S_k-S_{k-1}=e_k$：

$$
\Delta u_k=K_p(e_k-e_{k-1})+K_ie_k+
K_d(e_k-2e_{k-1}+e_{k-2}).
$$

再由 $u_k=u_{k-1}+\Delta u_k$ 得到新输出。课程的实现是：

```c
Error2 = Error1;
Error1 = Error0;
Error0 = Target - Actual;
Out += Kp * (Error0 - Error1) + Ki * Error0
     + Kd * (Error0 - 2 * Error1 + Error2);
if (Out > 100) Out = 100;
if (Out < -100) Out = -100;
Motor_SetPWM(Out);
```

误差必须从最旧的状态开始搬移，避免覆盖。增量式不需要显式误差积分和，但 `Out` 本身成为累积状态，初值不能随意给。

这里还要区分两种容易写错的程序：`Out = Kp * Error0` 是纯比例，`Out += Kp * Error0` 则每拍累加误差，实际具有积分作用，不能因为变量叫 `Kp` 就称它为比例控制。真正的增量式 P 要累加的是 `Kp * (Error0 - Error1)`。

课程电机接口接收的是当前 PWM 命令，所以要先累加得到 `Out`，不能把单拍的 $\Delta u_k$ 直接交给 `Motor_SetPWM()`。只有下游接口明确把输入解释为增量并负责累积命令时，才可直接传增量；物理对象本身存在积分环节，并不意味着 PWM 接口也会自动替控制器累加输出。

继续使用上一例：第一拍增量为 $3+2+1=6$；第二拍为 $-1.2+1.2-1.4=-1.4$；第三拍为 $-1.2+0.4+0=-0.8$。输出依次为 6、4.6、3.8，与位置式一致。这验证了推导，但也提醒我们：等价依赖于相同参数、相容初值和相同历史。

## 四、为什么真实程序里两种算法可能不同

最直接的原因是限幅。取纯 P、$K_p=1$，误差按 $0\rightarrow200\rightarrow0$ 变化，输出限制为 $[-100,100]$。

位置式在误差 200 时输出被裁剪到 100，回到误差 0 时重新计算完整输出，结果为 0。增量式先加 200，被裁剪到 100；误差回到 0 时增量为 -200，于是输出变为 -100。被裁掉的那部分历史已经丢失，差分等价关系不再成立。

| 条件变化 | 为什么会影响等价 |
| --- | --- |
| 输出裁剪 | 增量式下一拍从裁剪后的 `Out` 累加 |
| 在线改变增益 | 差分推导原本假定两拍使用同一组增益 |
| 手动改 `Out` | 给增量式引入了额外的输出偏置 |
| 历史误差未初始化 | 首拍出现不符合实际变化的差分 |
| 两式积分策略不同 | 清零、限幅、条件积分会改变状态演化 |

尤其要注意：增量式的三项参数全设为零，只会让输出增量为零，旧 `Out` 仍保留。因此“把参数归零”不能作为通用停机方法。停机必须显式输出零，再按启动策略重置或保持控制器状态。

## 五、把算法放进正确的时间框架

工程用 TIM1 每 1 ms 中断一次，在其中计数到 40 才执行电机 PID。主循环负责旋钮、OLED 和串口。这使屏幕刷新耗时不会直接决定控制周期。

```c
void TIM1_UP_IRQHandler(void)
{
    static uint16_t Count;
    if (TIM_GetITStatus(TIM1, TIM_IT_Update) == SET)
    {
        Key_Tick();
        if (++Count >= 40)
        {
            Count = 0;
            /* 获取反馈 -> 更新误差 -> PID -> 限幅 -> 电机 */
        }
        TIM_ClearITPendingBit(TIM1, TIM_IT_Update);
    }
}
```

上面是调度结构，完整 PID 计算放入注释所在位置。`Timer_Init()` 放在各模块初始化之后，避免第一次中断访问尚未准备好的外设。

读取反馈、计算和输出构成一条完整链路；只写 PID 公式，未保证反馈单位、历史状态、限幅和周期正确，程序仍然可能失败。跨主循环和中断共享变量时，应考虑 `volatile` 和一致性快照；`volatile` 只能约束编译器访问，不能让整组 PID 参数的更新自动成为原子事务。需要成组更新时，可在短临界区发布参数，或在固定控制边界应用新参数。

## 六、控制器不只需要 Update，还需要 Reset

PID 的误差历史、积分和输出都是状态。只写一个 `PID_Update()`，却不规定这些状态在启动、停机、目标跳变和模式切换时怎样处理，第一次运行可能正常，第二次就可能带着旧状态冲击执行器。

可为教学工程增加一个明确的重置入口：

```c
void PID_Reset(PID_t *p, float actual, float out)
{
    float error = p->Target - actual;
    p->Actual = actual;
    p->Error0 = error;
    p->Error1 = error;
    p->ErrorInt = 0;
    p->Out = out;
}
```

把两拍误差都设为当前误差，可避免重启首拍把“旧测量到新测量”的差当成真实微分。`out` 通常取 0；若系统需要无扰切换，应由上一个控制模式的实际输出和新控制器结构共同决定，不能盲目清零。

课程 `Motor_SetPWM()` 的形参是 `int8_t`。浮点 `Out` 必须先限制在 -100～100，再转换或传入；若先转换一个超范围值，不能指望之后的限幅补救。累计位置则不应长期保存在 `int16_t` 中；超过约 ±32767 count 后会溢出，长时间实验宜用 `int32_t`。

### 本章静态验收

- 位置式历史更新顺序为“保存旧误差→计算新误差→更新积分→求和→限幅”。
- 增量式历史按 `Error2←Error1←Error0` 更新，并明确 `Out` 是累积状态。
- 调度代码中反馈只读一次，控制周期由定时器而不是主循环耗时决定。
- 启停、切换工程或切换控制模式时，对目标、积分、误差历史和输出都有明确策略。
- 任何送入 `Motor_SetPWM()` 的路径都先完成最终限幅。
