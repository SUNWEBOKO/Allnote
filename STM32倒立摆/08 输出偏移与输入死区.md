# 08 输出偏移与输入死区

## 学习目标

- 测量正反方向的起转门槛。
- 实现带符号的输出偏移。
- 用位置容差设置输入死区。
- 解释死区内外的积分状态变化。

## 一、为什么有误差、有输出，却仍然不动

在工程 04 的位置 PD 控制中，目标与实际还差一些计数，但电机已经停下。若 $K_p=0.3$、误差为 12，静止时 D 约为零，输出只有 3.6。整数 PWM 接口将其截断后可能只有 3，小于克服静摩擦所需的门槛。

提高 P 能缩小这类残差，但会同时改变整个运动过程；加 I 可以慢慢积累到起转门槛，却可能增加超调。输出偏移则尝试补偿执行器小命令区域的非线性。

## 二、先测门槛，再补偿

使用工程 01 的开环电机测试副本，把按键增减步长从 10 改为 1。每次从停止开始缓慢增加正 PWM，记录开始连续转动时的命令；归零，待停止后测负方向。重复几次，避免把已经运动时的维持门槛当成静止起转门槛。

课程设备演示约为 ±6，这只是该电机、负载和电源下的参考值。正反方向也可能不同。记录时说明是空载还是安装了横杆，不能将空载门槛当成所有机械形态的常量。

## 三、工程 11：输出偏移的正确顺序

设 PID 原始结果为 $u$，正负偏移幅度分别为 $b_+$、$b_-$，补偿后为

$$
u_c=\begin{cases}
u+b_+,&u>0,\\
0,&u=0,\\
u-b_-,&u<0.
\end{cases}
$$

然后再把 $u_c$ 限制到 ±100。必须按输出符号加偏移，而不是不分正负都加 6；否则负向小输出可能被抵消甚至反向。

课程工程 11 使用对称偏移 6：

```c
Out = Kp * Error0 + Ki * ErrorInt + Kd * (Error0 - Error1);
if (Out > 0) Out += 6;
else if (Out < 0) Out -= 6;
/* 最后才执行 ±100 限幅 */
```

本例原输出 3.6，补偿后为 9.6，传给整数接口约为 9，可能越过起转门槛。原输出 -3.6 则变成 -9.6。原输出已经为 98 时，加偏移后达到 104，最后限幅为 100，因此限幅不能放在偏移之前就结束。

### 先单独观察偏移效果

工程 11 的最终程序同时含死区。为分清作用，在实验副本中先临时取消死区判断，让 PID 与偏移每拍都执行，使用与工程 04 相近的 PD 参数，I 保持零。改变位置目标，观察原本卡住的小误差是否缩小；再看目标附近是否开始来回微动。

微小误差改变符号时，补偿输出可能从接近 +6 跳到接近 -6，反复克服摩擦，造成抖动。这不是把偏移值加得越准就必然能消除的现象，而是带符号补偿在零附近存在不连续。

## 四、输入死区：接受一段位置误差

工程最终采用：

```c
if (fabs(Error0) < 5)
{
    Out = 0;
}
else
{
    /* 按 Ki 是否为零更新积分 */
    /* PID 求和 -> 按输出符号加偏移 */
}
/* 限幅 -> Motor_SetPWM(Out) */
```

这不是传感器测不到，而是控制器规定误差足够小时不再驱动。5 count 约为 $5\times360/408=4.41^\circ$，所以代价是接受这一量级的位置容差。严格条件为 $|e|<5$，等于 5 时仍执行控制。

恢复死区判断，复位后重复相同位置阶跃。应看到接近目标时输出归零，抖动减少；缓慢将位置推离容差区，控制重新介入。若容差不满足任务，不能以“停得很安静”作为验收通过。

### 死区并没有自动清积分

工程 11 在死区内不进入积分分支，所以 `ErrorInt` 保持旧值，误差历史仍在死区判断前更新。即使这时 Ki 被调为零，也不会在死区内执行清积分；只有离开死区进入相应分支后才清。这解释了重新离开死区时可能出现的额外驱动。

如果需要“进入死区就清积分”或“保留保持力”，必须设计不同的状态规则，而不能认为当前程序已实现。需要持续支撑负载或维持平衡时，直接把输出设零可能破坏任务；本课这一方案主要用于可接受位置容差的转盘实验，不能照搬到倒立摆角度内环。

## 五、如何判断该用哪一种措施

若位置静止后留下小误差、输出低于起转门槛，偏移有明确针对性；若加偏移后在零附近反复换向，而任务允许几计数误差，可以引入死区。若外力会持续改变位置，即使在死区内输出为零，系统也可能反复越界、重启驱动，产生边界振荡。

| 现象 | 检查项 | 调整依据 |
| --- | --- | --- |
| 正向改善，反向更差 | 是否按符号分别补偿 | 负输出应减偏移幅值 |
| 补偿后偶尔超过满量程 | 是否在偏移后最终限幅 | 保证送入接口的命令范围 |
| 死区内仍显示旧 PID 输出 | 是否真正把 `Out` 赋零 | 不只是跳过 PID 计算 |
| 离开死区猛冲 | 积分是否保留、偏移是否过大 | 明确重入状态与实际门槛 |
| 安静了但定位太粗 | 死区的计数换算角度 | 用任务容差决定阈值 |

本实验的完整结果应同时记录定位误差、是否微动以及正反起转表现，而不是只记录一个“最佳偏移值”。
