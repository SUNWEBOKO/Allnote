# 06 积分抗饱和：限幅、分离与变速积分

## 本章问题

执行器已经到上限时，积分为什么还会继续增长？怎样限制、暂停或平滑积分？

> 前置：先完成 [[05 四种单环控制实验]]，保持目标、负载和采样窗口不变。
>
> 本章对应标准库程序的 06～08：积分限幅、积分分离和变速积分。

## 1. 积分饱和

位置式 PID 中：

$$
I_k=I_{k-1}+e_k
$$

当电机已经输出 +100，而目标仍很远时，误差仍可能为正，`I` 会继续变大。误差随后反向时，控制器要花时间退出饱和，这就是积分 windup。

先建立正常 P/PI 速度控制，再故意让目标长期不可达，观察 `pid.integral`。

## 2. 积分限幅

本工程提供：

```c
config.integral_min = -500.0f;
config.integral_max = 500.0f;
```

课程中的 ±500 是误差积分和的上下限，不是与 `Ki` 无关的通用标准。`I_term = Ki * integral`，改变 `Ki` 会改变同样的积分和能产生多大的输出。

## 3. 条件积分

`pid_config_t.conditional_integration` 打开后，若当前误差仍把试算输出继续推向饱和，本次积分增长会被拒绝。它比单纯限幅更接近"输出已经到边界就不再累积"的行为。

HAL 实现事实：位置式在输出试算后检查饱和方向；增量式则在上一拍输出已顶到限位、且误差继续同向时，把本拍积分增量取 0——两种形式都有效，可以在速度和位置实验中分别验证。

验收时同时记录：

```text
target、actual、integral、P、I、D、raw_output、output、saturated
```

只看总输出无法判断是否发生 windup。

## 4. 积分分离

课程位置实验使用：

```c
if (fabs(error) < 50.0f)
    integral += error;
else
    integral = 0;
```

本工程用 `separation_error` 表达该策略：

```c
config.separation_error = 50.0f;
```

大误差时清零，小误差时恢复。阈值必须带单位；位置 count 和角度 ADC 码不能共用同一个阈值。

HAL 实现事实：判据用未经死区闸门的原始误差；`|e| >= separation_error` 时清零积分，恰好等于阈值也清零（与课程判据的边界行为一致）；`separation_error` 为 0 或负值时该功能关闭。增量式下的分离等价于冻结当拍积分增量，而不是清零历史输出。

边界要明确：若写 `fabs(error) < 50`，恰好 50 不积分；不要在不同实验中默默改成 `<=`。

## 5. 变速积分

课程公式：

$$
C(e)=\frac{1}{1+0.2|e|}
$$

$$
I_k=I_{k-1}+C(e_k)e_k
$$

本工程对应：

```c
config.variable_integral_beta = 0.2f;
```

大误差时积分仍会增加，只是速度变小；因此变速积分不能代替积分限幅。还要区分：

$$
I_k^{(1)}=K_i\sum C(e_j)e_j
$$

和

$$
I_k^{(2)}=K_iC(e_k)\sum e_j
$$

二者不是同一个算法。本工程位置式实现的是 $I^{(1)}$（$C(e)$ 乘在每拍累加项上）；增量式则把 $C(e)$ 乘在当拍积分增量上，二者在无饱和时数值一致。

## 6. 分步对照实验

本章所有实验都在 `User/Src/pid.c` 的同一套 `pid_t` 上完成，不修改 CubeMX。每组实验都从 `Ki=0` 的快照开始，再只打开一种积分策略。

### 6.1 普通积分：先制造 windup

1. 选择 `APP_DEMO_SPEED` 或 `APP_DEMO_POSITION`。
2. 设置一个很小的 `Kp`、一个非零 `Ki`，暂时关闭条件积分、分离和变速积分。
3. 给出明显超过机械能力的正目标，保持 1～2 秒。
4. 记录 `integral`、`raw_output`、`output` 和 `saturated`。
5. 把目标改成反向值，观察需要多久退出饱和。

**预期**：误差存在时积分仍持续增加；总输出已经是 ±100 时，积分可能继续偏离；反向目标会出现恢复迟缓。

**代码落点**：`User/Src/pid.c` 的 `pid_step()` 积分分支和位置式输出分支；配置在 `User/Src/app.c` 的 `init_controllers()`。

### 6.2 积分限幅

只打开：

```c
config.integral_min = -500.0f;
config.integral_max = 500.0f;
```

重复 6.1 的目标序列。

**预期**：`integral` 不会越过配置上下限，但退出饱和的速度仍可能比理想情况慢。限幅解决的是数值范围，不是所有 windup。

### 6.3 条件积分

保持积分限幅，同时确认：

```c
config.conditional_integration = true;
```

重复正向饱和和反向退出实验。

**预期**：当试算输出会继续把系统推向当前饱和方向时，本次积分增长被拒绝；反向误差时积分可以重新参与恢复。

**通过**：能够指出哪一拍拒绝了积分，而不是只说"输出没有超限"。

### 6.4 积分分离

只对位置实验设置：

```c
config.separation_error = 50.0f;
```

位置反馈单位是 count；不要把 50 直接复制到角度 ADC 码实验。

**操作**：

1. 目标先离当前位置较远，观察积分是否保持为 0；
2. 目标进入阈值后，观察积分开始累积；
3. 目标再次远离，确认积分清零；
4. 记录恰好等于阈值时是否积分（按实现，等于阈值会被清零，不积分）。

**预期**：大误差阶段不积累历史，小误差阶段恢复积分；边界条件与代码中的严格不等号保持一致。

### 6.5 变速积分

设置：

```c
config.variable_integral_beta = 0.2f;
```

重复同一目标序列，并保持 `integral_min/max` 不变。

**预期**：大误差时积分仍会增加，但增长速度降低；它不能替代限幅或条件积分。

### 回滚点

任何策略出现异常，先恢复：

```text
conditional_integration = true
integral_min/max = ±500
separation_error = -1
variable_integral_beta = -1
```

然后回到普通 P/PI 基线。不要同时改变目标范围、电源和机械负载。

## 新手操作卡

1. 复制第 05 章的速度或位置工程。
2. 实际入口是 `User/Src/app.c` 的 `init_controllers()`，它调用 `base_pid_config()`；只在这里改对应 PID 配置。本章示例中的 `config.` 对应 `init_controllers()` 里的 `speed` 或 `position` 局部配置变量。
3. 先关闭电机或断开摆杆，单独观察 `pid.integral`。
4. 主机测试通过后再接小负载，保持目标、周期和 `Kp/Kd` 不变。
5. 记录普通积分、限幅、分离、变速积分四种结果。

## 7. 验收

- [ ] 能指出积分和而不仅是输出；
- [ ] 积分和始终在配置范围内；
- [ ] 大误差阶段按预期清零或减速；
- [ ] 反向误差可以退出饱和；
- [ ] 变速积分仍受总积分限幅；
- [ ] 停止、重新启动时积分状态已复位。

## 排障

- 关闭电机后积分仍暴涨：检查 `Ki=0` 时是否清零，以及是否在停止时仍调用 PID；
- 反向时有长时间空转：检查条件积分和输出限幅；
- 位置抖动变成缓慢漂移：分离阈值可能太大；
- 角度环使用位置 count 阈值：立即改回角度 ADC 码单位。
