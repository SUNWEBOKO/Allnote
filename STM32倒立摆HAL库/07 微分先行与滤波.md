# 07 微分先行与不完全微分

## 本章问题

目标突然改变时，如何避免 D 项产生不必要的尖峰？测量噪声又怎样处理？

> 前置：先完成 [[05 四种单环控制实验]]，能稳定记录同一反馈序列。
>
> 本章对应标准库程序的 09～10：微分先行和不完全微分。

## 1. 误差微分的分解

普通离散 D：

$$
D_k=K_d(e_k-e_{k-1})
$$

展开：

$$
D_k=K_d(r_k-r_{k-1})-K_d(y_k-y_{k-1})
$$

目标变化会直接激励微分；测量变化提供运动阻尼，但也放大编码器噪声。

## 2. 微分先行

只对测量值求导：

$$
D_k=-K_d(y_k-y_{k-1})
$$

本工程配置：

```c
config.derivative_mode = PID_D_MEASUREMENT;
```

目标从 0 跳到 100、测量仍为 0 时，第一拍 D 不应出现目标阶跃造成的尖峰；真实测量变化时，D 提供相反方向的阻尼。

课程工程需要在应用层手动保存旧位置：

```c
old_position = position;
position += encoder_delta;
```

HAL 实现事实：本工程不需要这一步——`pid_t.previous_source` 在 `derivative_term()` 内部自动维护上一拍微分源，应用层不要在 `app.c` 里另存 `old_position`。

## 3. 一阶不完全微分

本工程用 `derivative_filter_alpha`：

$$
D_k=(1-\alpha)D_{raw,k}+\alpha D_{k-1}
$$

- `alpha=0`：不滤波；
- `alpha` 越接近 1：越平滑，响应越慢，有效范围是 `[0, 1)`——`pid_init()` 会拒绝 `alpha >= 1` 的配置，而初始化失败现在会点亮 `FAULT` 并拒绝启动（OLED 第 1 行 `FAULT`），不会静默失效；
- `alpha=0.9` 是课程参考，不是所有机构的固定值。

改变采样周期时，不能只保持 `alpha` 就认为滤波时间常数不变。若采用时间常数近似：

$$
\alpha=\frac{\tau}{\tau+T_s}
$$

必须同时记录 `T_s`。

## 4. 噪声实验

课程原工程曾把随机数直接累加到位置状态：

```c
Actual += rand() % 41 - 20;
```

这会形成随机游走，不是独立测量噪声。正确做法是分开：

```c
static int32_t true_position = 0;
true_position += encoder_delta;
float measured_position = (float)true_position + noise;
```

噪声只进入本拍反馈，不写回真实累计位置。

**代码落点**：这段改造在 `User/Src/app.c` 的 `run_40ms_control()` 的 `APP_DEMO_POSITION` 分支做——把传给 `pid_step()` 的测量值换成带噪声的副本：

```c
/* USER CODE：噪声注入示例（仅实验用，验收后删除） */
static int32_t true_position = 0;
static uint8_t noise_idx = 0;
/* noise_table 为固定表或 LFSR，可重复 */
float measured = (float)app_location + noise_table[noise_idx++];
result = pid_step(&position_pid, app_position_target, measured);
```

不要改写 `app_location` 本身，否则噪声会永久进入位置累计值。

## 5. 分步对照实验

本章只改变微分输入和滤波参数，不改变电机、目标范围和采样周期。

### 5.1 误差微分基线

1. 复制第 05 章的位置工程为 `07_Derivative`。
2. 选择 `APP_DEMO_POSITION`。
3. 设置：

```c
config.derivative_mode = PID_D_ERROR;
config.derivative_filter_alpha = 0.0f;
```

4. 固定 `Kp/Ki`、目标阶跃和机械条件。
5. 先做一次目标阶跃，再做一次实际运动，记录 `p_term`、`d_term`、`raw_output` 和最终 `output`。

**预期**：目标突然变化时，误差微分可能出现尖峰；真实反馈变化也会产生 D 项。

### 5.2 测量微分

只改：

```c
config.derivative_mode = PID_D_MEASUREMENT;
```

重复完全相同的目标阶跃和运动。

**预期**：目标突然变化而测量值尚未变化时，不再产生同样的目标阶跃微分尖峰；机械运动时仍能得到阻尼项。

**代码落点**：`User/Src/pid.c` 的 `derivative_term()`；`User/Inc/pid.h` 的 `pid_derivative_mode_t`。

### 5.3 一阶滤波

在不改变微分模式的前提下比较：

```c
config.derivative_filter_alpha = 0.0f;
config.derivative_filter_alpha = 0.9f;
```

**预期**：`alpha=0.9` 时 D 峰值降低、变化变慢；响应延迟增加多少必须结合 40 ms 控制周期记录，不能只说"更平滑"。

### 5.4 固定噪声实验

不要把噪声写回真实累计位置。使用独立的测量值：

```c
true_position += encoder_delta;
measured_position = true_position + noise;
```

噪声使用固定表或已播种的 LFSR，保证每次实验可重复。

**预期**：测量微分对噪声更敏感；滤波后峰值降低，但不会消除真实运动带来的 D 项。

### 回滚点

如果目标阶跃仍产生尖峰：

1. 确认 `derivative_mode` 已切换；
2. 确认 `alpha` 没有误写；
3. 确认目标/测量变量没有在主循环中被重复改写；
4. 恢复到 `PID_D_ERROR + alpha=0` 的基线。

## 新手操作卡

1. 复制第 05 章位置工程。
2. 只改 `init_controllers()` 里 `position.derivative_mode`，在 `PID_D_ERROR` 和 `PID_D_MEASUREMENT` 间切换。
3. 再只改 `position.derivative_filter_alpha`，依次使用 0 和 0.9。
4. 噪声实验使用固定表或 LFSR，不把噪声写回位置累计值。
5. 对比目标、反馈、P、I、D 和最终输出六列数据。

## 6. 验收

- [ ] 目标阶跃时测量微分没有直接尖峰；
- [ ] 真实运动时 D 有阻尼作用；
- [ ] 滤波后峰值降低且延迟可接受；
- [ ] 噪声没有写回真实位置；
- [ ] 记录了 `alpha`、采样周期和 `Kd` 的离散含义。

## 排障

| 现象 | 检查 |
|---|---|
| 目标跳变时输出尖峰 | 是否仍使用误差微分 |
| D 项噪声很大 | alpha、输入滤波、机械松动和编码器屏蔽 |
| 改了 alpha 后响应变慢 | 滤波时间常数和采样周期是否改变 |
| 位置慢慢漂移 | 是否把噪声累加进了位置状态 |
