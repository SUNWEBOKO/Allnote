# 08 输出偏移与输入死区

## 本章问题

电机有静摩擦和起转门槛时，怎样补偿小输出？目标附近怎样减少抖动而不把控制器锁死？

> 前置：先完成 [[05 四种单环控制实验]]，并完成正负方向起转门槛测量。
>
> 本章对应标准库程序的 11：输出偏移与输入死区。

## 1. 起转门槛测量

从停止状态分别测量正、负方向连续转动的最小 PWM：

1. 断开摆杆或使用转盘形态；
2. 每次只增加 1 个 PWM 点；
3. 记录正方向、负方向和维持转动门槛；
4. 重复多次，取范围而不是单个神奇数字。

课程演示约 ±6，但本机不能直接照搬。

## 2. 带符号输出偏移

PID 先得到原始输出 `u`，再执行：

```c
if (u > 0.0f) u += output_offset_positive;
if (u < 0.0f) u -= output_offset_negative;
u = clamp(u, -100.0f, 100.0f);
```

课程 11 工程的示例值是 ±6（`Out > 0` 加 6、`Out < 0` 减 6）；本工程的默认值是 0，做实验时要在 `init_controllers()` 的对应配置里自行设置 `output_offset_positive/negative`，不要以为示例值已经生效。

顺序必须是"计算 → 偏移 → 最终限幅 → 电机"。例如原始 98 加 6 后仍必须限制为 100。

偏移会增加零附近的不连续性；它不是精度提升，也不是角度传感器的偏置。

## 3. 输入死区

课程 11 工程的输入死区是"输出闸门"：

```c
if (fabs(Error0) < 5)   /* 误差绝对值小于门槛 */
    Out = 0;            /* 直接输出 0，不做调控 */
```

注意它**不改写误差本身**：闸门内输出为 0、积分冻结；闸门外按原始误差正常计算 PID。HAL 实现与课程语义一致：

- 判据是严格小于——`|e|` 恰好等于 `input_deadband` 时仍正常调控；
- 闸门内积分保持原值，不累积新积分；
- 微分历史照常更新，退出死区时不会带着微分踢；
- 闸门内输出直接为 0，而不是"误差减去死区宽度"的折算值。

死区可以减少目标附近来回换向，但代价是死区内控制器完全放手，离开死区的瞬间要靠 P 项重新接管。

## 4. 输出死区

`output_deadband` 作用在最终输出：

```c
if (fabs(raw_output) <= output_deadband)
    raw_output = 0;
```

输入死区回答"误差多大才算需要动作"，输出死区回答"计算输出多大才实际动作"。两者不要混为一谈。

## 5. 分步实验

本章只在 `APP_DEMO_POSITION` 转盘定位实验中做对照，不能把死区直接带入倒立摆平衡内环。

### 5.1 测量起转门槛

1. 复制第 05 章位置工程为 `08_OffsetDeadband`。
2. 拆下摆杆，空载并限流。
3. 从 `PWM=0` 开始，每次增加 1 点，分别记录正转、反转的最小连续转动值。
4. 每个方向重复 5 次，取范围和平均值。
5. 记录维持转动门槛，不把它和启动门槛混成一个数。

**预期**：正负方向可能不对称；课程约 ±6 只作为参考。

### 5.2 输出偏移

先只打开一个方向：

```c
config.output_offset_positive = 0.0f;
config.output_offset_negative = 6.0f;
```

反转机械方向后，只改变另一侧。偏移必须经过最终限幅：

```text
raw → 加偏移 → clamp(-100, 100) → 电机
```

**观察**：靠近目标时是否减少"误差存在但不动"的时间；越过目标时是否增加反向冲量。

**通过**：偏移方向正确、最终输出没有超过 ±100，且没有把电机门槛当成角度/位置补偿。

### 5.3 输入死区

保持偏移不变，依次设置 `init_controllers()` 中对应配置的 `input_deadband`：

```c
position.input_deadband = 0.0f;
position.input_deadband = 2.0f;
position.input_deadband = 5.0f;
position.input_deadband = 10.0f;
```

每次让目标从一侧缓慢穿过死区，记录 `error`、`integral`、`output` 和实际位置。

**预期**：死区可以减少目标附近来回换向；进入死区时输出直接为 0、积分冻结，离开死区时 P 项按原始误差重新接管。

### 5.4 输出死区

最后单独设置：

```c
config.output_deadband = 3.0f;
```

保持输入死区不变，比较输出为零的阈值。不要把输出死区误认为输入死区。

### 主机回归

`Tests/host/test_control.c` 中的 `test_pid_output_offsets()` 会验证：

- 正输出偏移使正方向输出增加；
- 负输出偏移使负方向输出更负；
- 偏移后的结果仍经过最终限幅。

该测试通过后，再把 `output_offset_positive/negative` 写入实机配置。

### 回滚点

任何一项出现振荡或突然冲车：

```text
output_offset_positive = 0
output_offset_negative = 0
input_deadband = 0
output_deadband = 0
```

恢复到无补偿基线后，再一次只打开一个参数。

## 6. 不适用于平衡内环

倒立摆角度内环需要持续支撑力，不能因为误差小就把输出清零。`APP_DEMO_BALANCE` 和 `APP_DEMO_SWINGUP` 的角度 PID 不启用输入/输出死区；死区只作为转盘定位实验的对照。

## 新手操作卡

1. 复制第 05 章位置工程，先测正负起转门槛。
2. 实际入口是 `User/Src/app.c` 的 `init_controllers()`，它调用 `base_pid_config()`。

   在这里设置 `output_offset_positive/negative`。最后才启用 `input_deadband`。
3. 记录"补偿前后"的实际位置和 PWM，确认偏移后仍会限幅。
4. 依次测试死区 0、2、5、10 count。
5. 不要在 `APP_DEMO_BALANCE` 或 `APP_DEMO_SWINGUP` 中启用死区。

## 7. 验收

- [ ] 正负起转门槛分别测量；
- [ ] 偏移发生在最终限幅之前；
- [ ] 死区边界和积分行为写清楚；
- [ ] 目标附近抖动减少且没有重新启动猛冲；
- [ ] 未把 ±6 当作所有电机的常数；
- [ ] 平衡模式没有被死区破坏。

## 排障

| 现象 | 检查 |
|---|---|
| 小误差完全不动作 | 死区是否过大、输出偏移是否为正 |
| 离开死区突然冲一下 | 积分和上次输出是否在死区中保持/清除 |
| 一加偏移就振荡 | 偏移方向错误、重复补偿或静摩擦测量错误 |
| 倒立摆刚启动就倒下 | 是否错误套用了位置死区 |
