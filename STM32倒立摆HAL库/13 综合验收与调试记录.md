# 13 综合验收与调试记录

## 本章问题

如何从供电、驱动、采样、时序、控制到机械，逐层证明系统，而不是只凭"能动"验收？

本章使用的 HAL 工程底座必须先按 [[00 从零复刻HAL工程]] 完整生成并通过编译。00 SPL 综合测试程序是用户已实测的硬件对照，不要把它和 HAL 工程的"已编译"状态混为一谈。

本章对应标准库教程第 13 章和程序 01～16 的综合回归。

## 1. 自底向上回归顺序

```text
供电与下载
→ OLED / LED / 按键
→ PWM 方向
→ 编码器与角度 ADC
→ 速度单环
→ 位置单环
→ 积分/微分改进
→ 速度—位置串级
→ 角度内环
→ 角度—位置双环
→ 自动起摆
→ 重复性和故障记录
```

### 1.1 分层验收门

| 阶段 | 必须回答的问题 | 通过证据 |
|---|---|---|
| 供电与下载 | 芯片是否识别、程序是否从 `main()` 运行 | 下载日志、复位后 OLED |
| GPIO/OLED/按键 | 显示和输入是否真的到达应用层 | OLED 画面、按键事件记录 |
| PWM/编码器 | 电机方向、编码器方向和计数窗口是否一致 | 波形、正负 count、限流值 |
| 角度采集 | 直立附近是否连续、盲区和中心在哪里 | 角度 CSV/记录表 |
| 速度单环 | 误差、反馈和 PWM 是否按 40 ms 更新 | 单环 CSV、停止/重启结果 |
| 位置单环 | 累计位置是否正确、回零是否稳定 | 位置曲线、摩擦和死区记录 |
| PID 改进 | 积分、微分、偏移是否只改变预期现象 | A/B 对照表 |
| 串级控制 | 外环是否输出速度参考、内环是否独立 | `held_inner_setpoint`、两环状态（需调试器观察，CSV/OLED 不含这些字段） |
| 手动平衡 | 两侧倾倒是否能接住、越界是否同拍停机 | 角度/位置/PWM 视频或 CSV |
| 自动起摆 | 脉冲、极值、接管、故障是否按状态机工作 | 至少 10 次结果记录 |

## 4. 量化指标

阶跃超调：

$$
M_p=\frac{y_{max}-r_1}{|r_1-r_0|}\times100\%
$$

负阶跃要按运动方向选择极值，不能机械套用正向最大值。

稳态误差：

$$
e_{ss}=r_1-\overline{y}
$$

调节时间必须先定义允许带，例如 ±5% 或位置 ±5 count，并记录"进入后持续留在带内"的时间。

倒立摆专用：

- 进入平衡后的稳定时间；
- 角度码范围和中心偏差；
- 位置误差范围；
- 扰动恢复时间；
- 起摆耗时；
- 10 次起摆成功率；
- 停止到 PWM 实际归零的延迟。

## 5. 排障与故障定位表

| 症状 | 层次 | 首要证据 |
|---|---|---|
| 电机不转 | 电源/驱动 | 12 V、方向脚、PWM CCR、STBY/接线 |
| 电机转但横杆不动 | 机械 | 顶丝、联轴器、轴切面 |
| 一闭环就满输出 | 反馈方向 | 正 PWM 对应编码器符号 |
| 编码器恒零 | 采集 | PA6/PA7、TIM3、CH2 Falling、线序 |
| 角度值跳变 | 传感器 | PB0、ADC1_IN8、盲区、线缆 |
| P 增大振荡 | 控制 | 周期、延迟、采样噪声、机械间隙 |
| 位置外环发散 | 串级 | `center - outer_out` 符号、限幅 |
| 越界仍有一拍输出 | 状态机 | 是否同拍 return/直接停止 |
| 自动起摆越摆越小 | 相位控制 | 极值、脉冲符号、样本时序 |
| 第二次启动猛冲 | 状态生命周期 | 目标、积分、输出、计数器、样本 |
