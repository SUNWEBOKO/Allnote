# 工科变换学习路线：从 0 到看懂系统分析

这个文件夹适合按顺序学习。它的主线不是“背一堆变换公式”，而是理解一个工程问题：

> 复杂系统里的微分、卷积和频率分析，为什么可以通过变换变得更容易？

如果你是零基础，不建议直接从傅里叶变换公式开始。更稳的顺序是：

1. 先理解“坐标变换”和“函数也可以看成向量”。
2. 再理解“系统输出为什么等于输入和冲击响应的卷积”。
3. 再看傅里叶变换与拉普拉斯变换怎样把微分方程变成代数问题。
4. 最后用传递函数、频率响应和卷积定理把时域与频域连起来。

---

## 0. 学前需要知道什么

完全从 0 开始时，只要先有下面几个直觉即可，不需要一开始就严格证明：

| 概念 | 最低要求 |
| --- | --- |
| 函数 | 知道 $y=f(x)$ 表示输入 $x$ 得到输出 $y$ |
| 导数 | 知道导数表示变化率 |
| 积分 | 知道积分可以理解为连续求和 |
| 复数 | 知道 $j^2=-1$，$e^{j\omega t}$ 和旋转、正弦/余弦有关 |
| 线性 | 知道“先拆开算，再加起来”仍然成立 |

如果复数、矩阵或微分方程不熟，阅读时先抓直觉：公式先看每个符号的角色，暂时不要卡在严格推导上。

## 1. 推荐阅读顺序

### 第一步：`01 傅里叶变换入门.md`

目标：建立“变换就是换坐标”的总直觉。

重点看：

- 向量坐标变换；
- 函数内积和投影；
- 复指数为什么适合做基函数；
- 傅里叶级数怎样过渡到傅里叶变换。

读完应能说出：

> 傅里叶变换是在求函数投影到各个复指数频率基函数上的坐标。

### 第二步：`02 卷积与线性系统.md`

目标：理解系统输出为什么和“历史输入的累积影响”有关。

重点看：

- LTI 系统；
- 单位冲击响应；
- 离散卷积和连续卷积公式；
- 卷积题先找非零重叠区。

读完应能说出：

> 输入 $x$ 说明每个时刻给了多少，冲击响应 $h$ 说明一次输入之后会留下什么影响，卷积把这些影响加起来。

### 第三步：`03 傅里叶变换与拉普拉斯变换.md`

目标：理解傅里叶和拉普拉斯的关系。

重点看：

- 傅里叶变换为什么处理不了增长信号；
- 拉普拉斯变换中的 $s=\sigma+j\omega$；
- 微分性质和初值项；
- 极点、收敛域和频率响应的关系。

读完应能说出：

> 拉普拉斯变换比傅里叶变换多了指数衰减维度，所以更适合解工程微分方程。

### 第四步：`04 传递函数与卷积定理.md`

目标：把系统、卷积、拉普拉斯变换连成一条线。

重点看：

- 传递函数 $H(s)=Y(s)/X(s)$；
- 频率响应 $H(j\omega)$；
- 冲击响应和传递函数的对应；
- 卷积定理。

读完应能说出：

> 时域里输出是 $x*h$，变换到 $s$ 域就是 $Y=XH$。

### 第五步：`05 人工智能核心原理总结.md`

目标：从“函数映射 $y=f(x)$”角度理解 AI。

这篇不是前四篇的严格后续，但它延续同一个思想：把复杂系统看成输入、函数、输出，再通过参数、误差和优化去调整这个函数。

## 2. 新手自测

如果下面问题能用自己的话回答，说明这组笔记已经读通了：

1. 为什么可以把函数看成“无穷维向量”？
2. 傅里叶变换中的 $F(j\omega)$ 到底是什么？
3. 卷积公式里的 $h(t-\tau)$ 表示什么历史影响？
4. 为什么 LTI 系统才适合直接用卷积描述？
5. 拉普拉斯变换为什么能处理阶跃、指数和微分方程？
6. 传递函数为什么要在零初始条件下定义？
7. 频率响应 $H(j\omega)$ 和传递函数 $H(s)$ 有什么关系？
8. 为什么时域卷积到了频域会变成乘法？

不用一遍读完就全部答对。第一次阅读先建立地图，第二次再回到公式和例题。
