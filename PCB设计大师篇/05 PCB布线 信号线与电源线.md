# 05 PCB布线 信号线与电源线

## 学习目标

- 按"先信号、后电源、最后铺地"的顺序管理全板飞线。
- 用最短走线、包地与禁铺区处理晶振这类高频小信号。
- 把几十根 GPIO 分成三簇扇出，做到等距、同向、可读。
- 建差分组并用蛇形走线把 USB 对内误差压进 10mil。
- 按载流与焊盘宽度确定线宽，完成功率铺铜与主干走线。

## 1. 布线顺序与飞线管理

PCB 布线总原则：**先布重要线（单片机信号）→ 再布次重要线（电源）→ 最后铺地**；信号线内部再按**先短后长**执行。

先管好飞线：网络面板隐藏所有电源网络（USB+5V、VCC+5V、VCC+3.3V 等）的飞线，GND 早已隐藏——屏幕上只剩信号线，走向一目了然。

隐藏电源飞线不是为了省事，而是为了看清约束。电源飞线数量多、跨越整板，留在屏幕上会把信号线的走向淹没；等信号布完再解封，电源只需要沿已经让出的通道走。反过来先布电源，信号线就只能在剩余缝隙里绕，长度和对称性都保不住。

本章通用快捷键：

| 快捷键 | 功能 |
| --- | --- |
| `W` | 布线 |
| `B` | 布线中打孔换到另一层 |
| `T` / `B` | 视角切顶层 / 底层 |
| `V` | 放置过孔（属性里改网络） |
| `Tab` | 布线中改线宽 |
| `Shift+S` | 单层显示切换 |

## 2. 晶振先布：最短 + 包地 + 禁铺区

晶振是单片机最短的信号线，频率又最高，**必须最先布、长度最短**：

1. 两颗晶振线直接贴引脚拉出，起振电容就近连接；
2. **包地**：高频信号对外围干扰大，绕晶振走线一圈打**接地过孔**（`V` 放置后属性改网络为 GND），可用晶振自带的接地焊盘充当包围圈的一部分；过孔先排齐（左对齐 + 垂直等距），再按 `Tab` 改 **10mil** 地线把一圈过孔串联起来；
3. **禁止铺铜区**：放置 → 禁止区域 → 多边形，框住包地区域，层选"多层"、类型选"禁止铺铜"——防止 [06 章](06%20铺地与丝印DRC.md) 整板铺铜时铜皮挤进晶振区改变寄生参数。

高速晶振同样处理：布线 → 包地过孔 → 10mil 地线环绕 → 禁铺区。

包地的原理与法拉第笼相同：一圈接地过孔在地平面上围出一个"围墙"，外部干扰在围墙上感应出的电流被导入地，围内区域因此干净；同时晶振自身的辐射也被限制在圈内。禁铺区则是反向保护——整板铺铜时，铜皮不会自己判断"这里怕寄生电容"，必须显式禁止，否则铜皮贴到晶振走线旁边，负载电容被改变，起振裕量就没了。

## 3. GPIO 三簇扇出

排针引出的几十根 GPIO 飞线是全板最多的走线。按布局时的顺序分三簇，每簇自成一束、横平竖直、拐角 45°、**束内间距一致**：

1. **右侧簇**（芯片右缘 → 右排针）：从最靠边的引脚开始，贴着滤波电容引出，为左侧扇出留空间；逐根引出后统一微调拐角与间距；
2. **底部簇**（芯片下缘 → 右排针下半部分）：贴电容走线节省空间，同样保持间距一致；
3. **左侧簇**（芯片左缘 → 左排针）：先引出短路径的 PA2/PA1/PA0，其余从 PC3 开始**打过孔走底层**（顶层已被元件占满），过孔对称布置、对齐排布，底层走线绕过晶振包地区。

扇出过程中的高频操作：

- 走线中按 `B` 打过孔换层，底层接完再 `B` 回顶层；
- 遇到过孔干涉/间距报错，把过孔对称挪位或整体微调；
- 布完一簇立即"理顺"：统一拐角角度（45° 下弯）、统一间距——美观的走线束意味着可控的阻抗与可读的板子。

"束内间距一致"不只是好看。两条平行走线之间会通过分布电容互相耦合，间距忽大忽小，耦合量就不可预测；等距之后，串扰程度可以被估算。习惯上让线间距不小于 3 倍线宽（3W 原则），对 8mil 的信号线就是 24mil 中心距，本板排针扇出按这个尺度留空，代价只是每簇多占一点宽度。

## 4. 短线优先：LED、按键、复位、BOOT

- LED（PB6/PB7/PD8）、按键（PE13/14/15）、复位：横平竖直就近连接；开**自动生成泪滴**（设置 → PCB → 通用 → 自动生成泪滴），焊盘与导线过渡处自动补泪滴，增强焊接可靠性；
- BOOT 排针连线：先挪开挡线的电阻，对齐等距后再接；
- 串口座与 I2C 上拉电阻：先布短路径，右侧座子从 SMA 下方绕行；别忘了**底层的两个座子**（SPI/I2C）的上拉电阻。

## 5. 长线走底层 + 灵活调整

顶层被 GPIO 走线占满，长信号线一律**打过孔走底层**：

- LED 三根线、BOOT0/BOOT1、复位 RST、按键三根：源端（单片机引脚）打过孔 → 底层 → 目标端过孔回顶层；
- **挡路就拆**：PD8 与 BOOT0 的底层线挡住 ADC/DAC 四根线的通道 → 删掉 PD8 线、过孔右移让出通道，先走 ADC/DAC，再回头补 PD8 与 BOOT0。**布线方案要随实际走线情况灵活调整**，删几根重布是常态；
- ADC/DAC 四根（PA0/PA1/PA4/PA5 → SMA）：PA0/PA1 从上方走，PA4/PA5 从柱子下方绕行贴 PA1 的线走；
- 串口/SPI/I2C 座信号线：部分可借侧面 GPIO 的过孔中转，底层走不通时删开 BOT1 等既有走线腾出通道，布完再补。

## 6. USB 差分对与等长

USB 的 DP/DN 是差分信号，必须**成对等长**：

1. **建差分组**：网络面板 → 差分队 → 添加两组——Type-C 侧（正网络 USBP、负网络 USBN）与单片机侧（正网络 PA12、负网络 PA11）。之后布线软件会实时提示**对内误差**；
2. 先布通左侧（串口 Type-C → CH340）：DP/DN 并行走线，长度差约 60mil；
3. **等长调节**：布线 → 等长调节，在短线一侧拉**蛇形走线**补长，直到对内误差 ≤ **10mil**（设计规则里的差分误差值）；
4. 右侧（USB Type-C → 单片机 PA11/PA12）：先接上拉电阻，长线打过孔引出，PA12 走 PA11 上方（与过孔相对位置一致），蛇形补长后同样满足 10mil；
5. CH340 到单片机的 PA9/PA10 串口线是普通信号，**不需要**等长处理。

蛇形补长的意义：差分对内两根线长度一致，信号才同时到达、共模抑制才有效——10mil 的误差就是为这个服务的。

把误差换算成时间更直观：信号在 FR-4 上的传播速度约 6mil/ps，10mil 对应 1.7ps 的时差。USB 全速模式一个位宽是 83ns，看起来 1.7ps 微不足道；但差分对的价值在于"两线看到完全相同的干扰"，长度差会让两线拾取的噪声出现相位差，相减时残留一部分。10mil 是入门阶段的保守要求，速率再高（USB2.0 高速 480Mbps）就需要 5mil 甚至更严，同时还要控制 90Ω 差分阻抗。

阻抗控制要靠叠层参数：线宽、线距、到参考地平面的距离共同决定特性阻抗。两层板介质厚，通常需要"差分对两侧加地铜"的共面波导结构才做得到 90Ω，这部分留到高速板再展开；本板先保证等长、包地与少过孔。

## 7. 信号线收尾

- SWD 两根线（PA13/PA14 → 排针）：底层绕行 + 过孔上顶层，贴近已有通道走；
- 自动下载电路内部短线就近连接（DTR/RTS 打过孔连通三极管区）；
- 全板信号飞线清零后保存。屏幕上可见的飞线只剩 AGND 与 GND 两类（电源飞线仍处于隐藏状态）——前者留给 [06 章](06%20铺地与丝印DRC.md)，后者等整板铺铜统一处理，电源网络则由下文各节解封布通。

清零前做一次目检：按 `Shift+S` 只看当前层，检查有没有贴着焊盘走过的线、两条不同网络间距过小的线、从元件丝印框里穿过去的线。这些在彩色视图里容易被焊盘和丝印挡住，单层显示时一目了然。

## 8. 电源线总策略

在网络面板解封全部电源网络（GND 仍隐藏），进入电源布线。电源走线分三类处理：

| 类型 | 手段 |
| --- | --- |
| 大电流路径（12V 输入、5V 功率级） | **整块铺铜**（填充区域-多边形），铜皮载流能力远超细线 |
| 中等电流（3.3V 主干、VCC+5V 主干） | 粗导线 15~30mil + 过孔换层 |
| 小电流分支（LED、上拉电阻、芯片引脚） | 10~15mil 导线就近取电 |

三类手段的分界看电流。1oz 铜厚、允许 10℃ 温升时，外层 10mil 约载 0.9A、20mil 约 1.5A、40mil 约 2.4A（按 IPC-2221 曲线估算），内层散热差，同宽度按七折估。照这个尺子：3.3V 主干带 MCU 与外设，峰值不过几百毫安，30mil 绰绰有余；12V 输入与 5V 功率级要过安培级电流，必须用铺铜而不是拉线。课程里常引用的"10mil 约 0.65A、40mil 约 2.3A"是更保守的工程值，按保守值取宽，余量留给温升与铜厚偏差。

## 9. DC-DC 功率级：照着电流流向铺铜

对照 [04 章](04%20PCB布局%20设计规则与模块化整体布局.md) 的两条大电流回路逐段铺：

1. **12V 输入段**：放置 → 填充区域 → 多边形，把 DC 座/端子 → 防反管 → 输入滤波电容 → VIN 引脚整片框住（网络自动识别为输入网络）；
2. **PH 功率段**：PH 引脚 → 续流二极管 → 电感 一片整铜（这是开关节点，铜皮要大但要紧凑）；
3. **5V 输出段**：电感输出 → 输出滤波电容 → 开关 → 保险丝 一片整铜；
4. **电感下方放禁止铺铜区**（矩形，多层，禁止铺铜）：防止后续铺地铜皮贴到电感底部影响感值；
5. **反馈线（FB/VSENSE）**：纯信号线，10mil；从输出端（**采样点选在输出电容处**，那里电压最稳定）打过孔走 **15mil** 底层线，**绕开电感区域**回到反馈电阻——正是 [04 章](04%20PCB布局%20设计规则与模块化整体布局.md)"抗干扰"原则的落地。

开关节点（PH）的铜皮面积有一对矛盾的要求：载流要大，所以要宽；辐射要小，所以要小。解法是"短而宽"——铜皮不做成一整片大方块，而是贴着电流路径做成粗短的带状，既降低电阻，又不给天线提供面积。这也是数据手册布局示例里功率器件"一字排开"的原因：把回路拉成一条线，面积自然最小。

## 10. 5V 与 3.3V 主干

- **5V→LDO**：开关输出 → AMS1117 VIN 整块铺铜；3.3V 输出同样铺铜到 `VCCA+3.3`/`DVCC+3.3` 分支；
- **3.3V 铁律：LDO 输出必须从输出电容之后引出**——从电感/芯片脚直接引出没有经过滤波，纹波直达单片机；
- 线宽按载流与焊盘宽度双约束：
  - 主干与排针电源引出：**30mil**；
  - 芯片引脚连接：**15mil**；
  - **单片机 VDD 焊盘**：LQFP 焊盘仅约 12mil 宽，电源走线**不超过焊盘宽度**，取 **10mil**；
- **五个 VDD 引脚互连**：两侧引脚打过孔走底层绕到电容处连接；中间引脚借用芯片封装内部的走线通道（关掉顶层丝印层观察）；最后一个引脚走顶层做十字连接——五个 VDD 全部连通后再统一汇到 LDO 输出电容之后；
- 挡路的信号线（BOOT0 等）照例**先删后补**；
- **用高亮查漏**：左键点网络 → 高亮 → 选择高亮网络，所有 3.3V 网络一目了然，逐个消灭飞线（纽扣电池选择电路 10mil、LED 回路 10mil、各上拉电阻就近 3.3V）。

"不超过焊盘宽度"这条约束来自焊接工艺：线比焊盘宽，焊锡会沿着露出来的铜线爬出阻焊开窗，形成一条锡须，既难看又可能和旁边的焊盘连锡。所以遇到 LQFP 那种 12mil 的小焊盘，宁可把整段电源线降到 10mil，也不能为了载流硬拉 30mil——这段电流本来就只有几十毫安，10mil 完全够。真要过大电流，办法是在焊盘附近铺小铜皮，而不是把线加宽。

## 11. USB+5V 与排针电源

- **两个 Type-C 的 VBUS**：顶层走不通，在各 VBUS 引脚旁放一小块填充区域打两个过孔 → 切底层用**整块铺铜**把四个过孔连成一片 → 再一路铺到开关座；同一网络可直接复制铺铜区域；
- **排针电源引出**：左右排针的 5V/3.3V 各用一块矩形铺铜整体连接，载流余量充足；
- 保险丝输出 → 底层多打几个过孔（**增加载流面积**）+ 小块铺铜汇流，再用 30mil 粗线接到排针。

## 12. 电源布线收尾核对

按高亮逐网络清零飞线：USB+5V → VCC+5V → DC+5V → VCC+3.3V → VCCA/DVCC → 单个支路。完成后左侧只剩 **AGND 与 GND** 两类飞线，电源布线结束，地网络的处理进入下一章。

核对时可以借用 DRC 的"未连接"项当清单：每消掉一根飞线，网络面板里对应网络就从"有飞线"变成"已连通"，比肉眼扫全板可靠。铺铜区域改过之后记得右键"重建全部"，否则显示的还是旧铜皮，容易误判某根线没连上。
